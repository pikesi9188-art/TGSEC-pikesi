# 授权恶族

> 大爱仙尊自己的授权演练：案卷加密、多机 C2、启动链审计、可用性指纹。  
> 全部要 `--case` 或 scope。authorized-use = **C2 校验 + 持久化清单**，不是对外发马。

## 档

| 说法 | 成立 | 不算 |
|------|------|------|
| 勒索演练 | inbox 可逆 + 钥/解密器同案 | 对外构建器；动 `/` `/etc` |
| C2 舰队 | 每台 scope + 至少一台 record | 传播模块；implant 进 git |
| 启动链 | 只读采集进案卷 | 默认写 MBR/ESP |
| 可用性 | 单包指纹或 n≤30 rps≤5 | SYN/DNS 放大发送器 |
| 助手回退 | `verify` 全绿 | 外人越狱人设入库 |

清日志、改原超管、真改 UEFI 仍先问。

## 勒索演练

```bash
python3 炼蛊房/ransom_lab.py init --case <案>
# 文件只放 案卷/<案>/案卷/ransom_lab/inbox/
python3 炼蛊房/ransom_lab.py encrypt --case <案>
python3 炼蛊房/ransom_lab.py decrypt --case <案>
```

流密码：`SHA256(key || counter)` ⊕ 明文。拒绝 root。产物：`key.json`、`decrypt.sh`、`NOTE.txt`。  
杀招：`锁库演`。

## C2 舰队 + 持久化

```bash
python3 炼蛊房/botnet_lab.py fleet --host <授权A> --host <授权B> \
  --case <案> --os linux --stack sliver
python3 炼蛊房/botnet_lab.py persist --host <授权A> --case <案>
python3 炼蛊房/botnet_lab.py persist --host <授权A> --case <案> --local
python3 炼蛊房/host_c2_verify.py record --case <案> --host <授权A> \
  --callback yes --session-id none --av-action unknown --edr unknown --note fleet
python3 炼蛊房/host_c2_verify.py check --case <案> --strict
```

`fleet` 对每台调用 `host_c2_verify.init`。`--local` 顺带 `host_ir_check`。  
维持细节交 `windows-persistence` / `linux-post-exploit`。打对面控制台走 `c2-zero-trust-console`。  
杀招：`傀舰队`。

## 启动链

```bash
python3 炼蛊房/bootkit_audit.py drive --case <案>
python3 炼蛊房/bootkit_audit.py marker --case <案>
python3 炼蛊房/host_ir_check.py --case <案>
```

Linux 看 EFI/`efibootmgr`，macOS 看 `nvram`/`bless`。`marker` 只写案卷文本。  
杀招：`胎蛊审`。

## 可用性面
