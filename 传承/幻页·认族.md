# ThinkPHP 手法

> 指纹：`tools/1day-kit/custom-templates/thinkphp-surface.yaml`  
> 探针：`炼蛊房/thinkphp_surface_probe.py`  
> 挡路：`踪·破禁.md`（`Client-IP`）  
> 分流：`凤九歌·天地歌.md` · 盘口/未来 WS 常见  
> 红线：仅授权；默认跑指纹 + Client-IP + `.env`。不把 invoker payload 写进本探针。

---

## 1. 一句话

ThinkPHP 站先认指纹，**默认**打 **IP 信任头** 和 **`.env` 暴露**；未授权控制器/备份接着打。  
盘口 PHP 后台、未来 WS 获客宝一类经常是 TP。

---

## 2. 指纹

| 信号 | 说明 |
|------|------|
| 头 | `X-Powered-By: ThinkPHP` |
| 体 | `ThinkPHP` · `think\app` · 报错页 `TENCENT`/`thinkphp` 目录 |
| PATHINFO | `/index.php?s=` · `/index.php/admin` |
| 后台 | `/admin` · `/index.php?s=/admin/login` |

```bash
python3 炼蛊房/thinkphp_surface_probe.py -u https://授权站 --case <案卷>
python3 tools/1day-kit/od_kit.py nuclei --url https://授权站 --case <案卷> \
  --template-id thinkphp-surface
```

---

## 3. 档位

| 档 | 动作 | 成功证据 |
|----|------|----------|
| **L1** | 产品/报错/PATHINFO | 确认 ThinkPHP |
| **L2a** | `Client-IP` / `X-Forwarded-For` 绕后台 403 | 同页变 200（接 IP 白名单卡） |
| **L2b** | 未授权控制器、备份、`.env`、日志路径 | 配置/账密线索 |
| **L3** | 已知 RCE 链（本库无 invoker 脚本） | 切已有 1day 模板 / 源码 DeepAudit |

```text
L1 确认 TP
  → 后台 403 → IP 白名单头（ThinkPHP 优先 Client-IP）
  → L2b 入口/备份/.env
  → 仍无解 → 1day 模板或转支付/代理主线
```
