### 1.1 匿名网络链路组合（新）
已有引擎只有 `config/proxy-nodes.txt`（493 条出口代理），缺**全链路匿名方法论**：

| 链路模式 | 适用场景 |
|---|---|
| `境外流量卡 → frp → SoftEther VPN → LunaProxy(动态住宅代理)` | 最高匿名，APT 级 |

## 十二、MFA 终极绕过 — Device Code Phishing（§17）— 全新

### 12.1 攻击原理
```
攻击者调用 Microsoft API → 获得 device_code + user_code
→ 诱导受害者访问 microsoft.com/devicelogin 输入 code
→ 受害者在真实 Microsoft 页面完成认证(含 MFA/FIDO)
→ 攻击者轮询 token 端点 → 获得 Access + Refresh Token
```

**为什么能绕过 FIDO**：用户在**真实域名**操作 → FIDO 安全密钥验证通过 → 问题不在认证本身，在于"授权了什么"

⚠ 重置密码不撤销 Refresh Token！
