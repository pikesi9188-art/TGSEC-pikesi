# 大爱仙尊 CORS 作业手法

> 杀招：`借刀杀人·借窗`  
> 工具：`python3 炼蛊房/cors_csrf_probe.py cors`  
> 广谱：`core_web_surface_probe.py`（没有 `--cors` 开关）  
> 专卡：`/wp-json` Origin 反射走 `wp-rest-cors-ato`

目标须在 scope。`ACAO: *` 且无 Credentials 只算 L1，不要写成高危。

---

## 1. 立刻跑

```bash
python3 炼蛊房/cors_csrf_probe.py --self-test
python3 炼蛊房/cors_csrf_probe.py cors --url https://授权/api/user/info --case <案>
```

产物：`案卷/cors_csrf/cors.json`。

---

## 2. 四刀

1. **钉接口** — `/api/user` `/api/me` `/api/account`，不要只扫首页  
2. **Origin 矩阵** — 恶域、`null`、`evil.目标`、`目标.evil`  
3. **认档** — 反射 + `Credentials: true` 才是 L2；`* + true` 浏览器挡 Cookie，但自定义 `Authorization` 仍可读  
4. **要数据** — L2 后用恶页带票读 `/me`，填对象矩阵。有 XSS 再链会话

预检：`Access-Control-Allow-Headers` 放行 `Authorization` 记一笔，下一步打带票跨域。

---

## 3. 档位

| 档 | 成立 |
|----|------|
| L1 | `ACAO: *` 或反射但不带 Credentials |
| L2 | 反射/`null` + `ACAC: true`，或 `* + true` 且业务用自定义头 |
| L3 | 跨域读到他人/自己敏感字段（有身份回矩阵） |
