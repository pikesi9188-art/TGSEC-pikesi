## 1. 一句话

站点把 **AES / sign / salt / JWT secret** 写进 JS，或生产环境留着 **`.map`**，就能在站外算请求。  
本卡默认命令必须跑完；有密钥就立刻接已打穿的协议/假支付，不要停在「解 webpack」。

## 2. 默认命令（L1）

```bash
python3 炼蛊房/js_secret_hunter.py hunt \
  --base https://授权站 --case <案卷>
# 作战路由（auto_campaign）等价：
# python3 炼蛊房/js_secret_hunter.py hunt -u https://授权站 --out 案卷/recon/js_secrets.json
```

落盘：`案卷/<案卷>/案卷/js_secrets/js_secrets.json`  
L1 成功：JSON 里有 `score>=60` 的 aes/salt/jwt/pay_key，或 `sourcemaps` 非空。

已有 bundle：

```bash
python3 炼蛊房/js_secret_hunter.py file --path app.js --case <案卷>
```

## 3.5 webpack 第三参（本库钉死）

`webpackChunk.push` 返回值不是 require。第三个参数回调才是：

```js
window.__req = null;
window["webpackChunk"].push([["se-temp"], {}, function (r) { window.__req = r; }]);
```

用来复用页面自己的加密模块，以及扫 `req.m` 找 API 真参数。js-websocket / 国密细节见 `逆骨.md` §3 和 Skill `单页·约`。
