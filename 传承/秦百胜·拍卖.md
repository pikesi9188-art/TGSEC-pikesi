## 3. 从 cvebase 补的「数字商品 / 发卡栈」1day（本库原先缺）

> 说明：cvebase **没有**「异次元/独角」产品条目；发卡网 CVE 面主要是 **WP 数字下载插件** + 通用 WP/Laravel。  
> 匿名 API 易 429；单洞页：`https://cvebase.io/cve/<CVE>`

| CVE | 组件 | 未授权？ | 本库落点 | 作业优先级 |
|-----|------|----------|----------|------------|
| **CVE-2026-12800** | WP Premium Packages（WPDM 卖卡） | **是** SQLi | `坞·吞库.md` | ★★★ 有插件就打 |
| **CVE-2026-39503** | Easy Digital Downloads | **是** 越权 | `坞·横夺.md` | ★★ |
| **CVE-2026-59524** | Easy Digital Downloads | **是** 鉴权坏 | 同上 | ★★ |
| CVE-2026-15906 | Premium Packages | Admin+ SQLi | 同 WPDM 卡 L3 备注 | 降权 |
| CVE-2026-12476 | EDD 上传 | 需 Shop Manager | 同上 L3 备注 | 降权 |

## 4. 推荐推进顺序

```text
授权 → 指纹：ACG / 独角 Next / 独角 PHP / WP数字货 / 纯易支付对接
  → /dj.svg + use_balance → 独角 Next F18（勿并 acg-faka）
  → composer.json / Laravel → 先 sensitive-dir-dump（日志抽 merchant_pem/epay key）
  → 游客查单/状态 IDOR（已付才出卡；状态口可辅助，禁批量枚举）
  → callback 活 → pay_matrix（阴性勿死磕）
  → 严签且日志无钥 → 支付栈旁站弱口取钥（先于上游）
  → admin 无验证码/限流 → auth-brute（短字典；改原超管密先问）
  → 3306 MySQL 5.7 / SSH 22 公网 → middleware_unauth（空口只读；写/OUTFILE 先问）
  → shared_id/严签且支付栈打不开 → 上游库存
  → 彩虹/USDT/CF-IP 旁路资金
  → WP：nuclei（WPDM/EDD/Core REST）→ 对应手法卡
  → Laravel 上传 / 源码 DeepAudit → KEY 回灌假支付
  → STATUS
```
