# 东方长凡·推演

> 长时多假设、要机器可校验证据链时用。  
> 单点单假设默认仍走专卡 + `STATUS.md` + `evidence_gate`，不必建账本。

## 1. 30 秒

```text
目标已在 scope
  → case-triage 定级 + 对象矩阵
  → 单假设：专卡打到 L2，STATUS 写 observation → reproduction → impact
  → 多资产 / 多假设并行：证据/ledger.jsonl 记账
  → confirmed 必须三角色齐（观察+复现+影响）
  → 交差：case_ledger verify --report + case_review + evidence_gate
```

授权闸是 `授权范围`，不是会话口头锁定。不在 scope 先 `scope_expand.py --grant`。  
禁止「超出范围先做」；支付中转域才静默扩权。

## 2. 状态机（作业节奏，不是流水线）

```text
IDLE → RECON ⇄ ENUMERATE ⇄ VALIDATE → EXPLOIT → POST-EXPLOIT → REPORT
```

| 状态 | 本库动作 | 退出 |
|------|----------|------|
| IDLE | scope + triage | 有授权 → RECON |
| RECON | `origin_recon` / `kit_run` / 家族探针 | 有信号 → ENUMERATE |
| ENUMERATE | 写下假设 + 证伪条件 | 选一条 → VALIDATE |
| VALIDATE | 当假阳性打；证据入账 | 证实 → EXPLOIT；证伪 → killed 并写重访条件 |
| EXPLOIT | 专卡 L2，最小复现即 reproduction | 成功 → POST-EXPLOIT |
| POST-EXPLOIT | 补 impact；新面回 RECON；有身份先矩阵 | 完成 → REPORT |
| REPORT | `verify --report` + `case_review` | 结案 |

证伪不是失败。Active 假设连续 3 轮无进展 → `deferred`。  
无独立证据只能 `inconclusive`，不能 `confirmed`。  
禁止虚构命令输出。

跨域先记（再进长文）：过滤逻辑常复用；WAF 多查值不查参数名；二次注入普遍；BOLA 要 A/B 换票重放；旧 API 版本漏补；业务逻辑（券/价/库存）扫描器常漏；竞态优先一次性操作；JWT 先看 `alg`/`kid`/JWKS 再打。

## 4. 账本命令

```bash
# 案卷名 → 案卷/<案卷>/证据/
python3 炼蛊房/case_ledger.py init <案卷>
# --id / --hypothesis 可省：自动 H1/E1/V1，证据挂最近未结案假设
python3 炼蛊房/case_ledger.py hypothesis <案卷> \
  --claim "网关 Actuator 未授权可读 routes" \
  --scope "https://授权站" --disprove-if "health 以外全 401"

python3 炼蛊房/case_ledger.py evidence <案卷> \
  --role observation --effect supports \
  --artifact STATUS.md --summary "health 200 且含 components"

python3 炼蛊房/case_ledger.py evidence <案卷> \
  --role reproduction --effect supports \
  --file /tmp/probe.json --summary "探针 JSON"

python3 炼蛊房/case_ledger.py next <案卷>
python3 炼蛊房/case_ledger.py verdict <案卷> \
  --status provisional --reason "观察+复现齐，影响待补"

python3 炼蛊房/case_ledger.py verify --report <案卷>
python3 炼蛊房/case_ledger.py render <案卷>
python3 炼蛊房/case_ledger.py context <案卷>
```

工件放 `证据/artifacts/`，或直接引用案卷根的 `STATUS.md` / `案卷/*.json`。账本只记相对路径 + SHA-256。  
`evidence-validation.md` 由 `render` 生成，禁止手改。

## 5. 和已有闸的关系

| 闸 | 管什么 |
|----|--------|
| `object_matrix.py` | 有身份先填格子 |
| `evidence_gate.py` | STATUS 字面量对得上 |
| `case_review.py` | 交差目录 / 矩阵 / 结案词 |
| `case_ledger.py` | 多假设闭环（观察/复现/影响） |

长时案：先 ledger `verify --report`，再 `case_review` + `evidence_gate --from-status`。
