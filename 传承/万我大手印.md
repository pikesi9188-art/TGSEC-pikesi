# 大爱仙尊越权 IDOR 作业手法

> 杀招：`万我大手印`  
> 工具：`python3 炼蛊房/idor_swap_probe.py`  
> Shop GT/IN：`fastadmin-shop-tenant-bola`（EQ 改 shop_id 阴性不算隔离）  
> 投顾 ashx：`dotnet-ashx-fintech-idor`

有身份先填对象矩阵。专卡阴性必须回表。

---

## 1. 立刻跑

```bash
python3 炼蛊房/idor_swap_probe.py \
  --url 'https://授权/api/order?id=1' --ids 1,2 \
  --header 'Authorization: Bearer <自己的票>' --case <案>
```

产物：`案卷/idor/idor_swap.json`。  
`differ=true` 只说明响应不同，还要读 body 确认是**他人对象**。

---

## 2. 四刀

1. **两个身份或两个 ID** — 一个人换号是水平；低权打管理 API 是垂直 / BFLA  
2. **换引用** — 自增 / 订单号 / 路径段 / JSON `userId` / 文件名  
3. **交叉** — 票 A 读 ID=B；票 B 读 ID=A。只测自己的 ID 不算  
4. **过过滤器** — FastAdmin Shop 必须打 GT/IN，EQ 阴性不许结案

UUID v1 可预测：时间戳+节点。雪花 ID 拆时间位。Hashids 先找盐再谈枚举。

---

## 3. 档位

| 档 | 成立 |
|----|------|
| L1 | 换 ID 状态或长度变 |
| L2 | body 出现他人字段（手机/余额/订单） |
| L3 | 写操作改到他人对象（先 marker） |

加款 / 真提现仍先问。
