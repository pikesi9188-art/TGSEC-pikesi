# 逆骨·认族

> 本库自有逆向路由层。单真源 + 回归 + ACT 前授权闸。  
> 作业层：`逆骨.md`  
> 分诊：`python3 炼蛊房/re_sample_triage.py --path <样本>`  
> 真源：`炼蛊房/reverse_routing.json`  
> 查询：`python3 炼蛊房/reverse_skill_route.py --hint "<任务>"`  
> 案卷复核：`python3 炼蛊房/case_review.py --case 案卷/<案卷>`

本卡**不替代**假支付 / 盘口 / Actuator / 发卡专链。  
授权闸门：仅 `授权范围`。C2 / 免杀 / 特征清理走 `edr-bypass-re` + `host-c2-verify`，不要停在百科。implant 不进 git。

## 1. 30 秒

```text
用户丢 APK / ELF / Mach-O / crx / PCAP / 厚客户端 / Ghidra / Go 剥离
  → re_sample_triage.py --path <文件>     # 认族，不联网
  → reverse_skill_route.py --hint

  → 打开 PRIMARY 杀招/<name>
  → 有本库探针就跑；没有就按卡上清单做静态分诊
  → 利用阶段再切 pwn-chain / binary-pwn / 业务专卡
```

网站案默认：能走 JS/APK 情报就不要先开通用逆向。  
改路由**只改** `炼蛊房/reverse_routing.json`，然后跑 `--self-test`。

## 3. 强制纪律

1. **开打前**目标在 scope。`--target` 未授权则 exit 2，禁止 ACT。本地样本 / 自有包 / 靶场写进案卷 `案卷/`。
2. **先静态后动态**。未知样本默认离线副本，不在作业机直接跑。
3. **先认族再开刀**：Go 剥离不要当普通 C；扩展不要当网页 JS；厚客户端不要当纯 Web。
4. **利用另切**：原理清楚后再 `pwn-chain` / 业务专卡。本卡只负责「看懂」。
5. **EDR / AMSI / 免杀**：`edr-bypass-re` + `sig_cleanup_scan.py`，授权机落地 `host-c2-verify`。WAF 走 `evasion-kit`。不要只开 CSS 08 结案。
6. **无线 / SDR / 工控**：无明确授权硬件/频谱范围则停在知识卡，不当网站案主刀。
7. **改路由只改 JSON**。禁止在 `reverse_skill_route.py` 里再堆硬编码 RULES。
