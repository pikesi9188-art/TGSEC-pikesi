> Skill：`杀招/常山阴·狼栈`  
> 探针：`炼蛊房/wolfstack_probe.py`  
> 指纹：`tools/1day-kit/custom-templates/wolfstack-cve-2026-73519.yaml`  
> 顾问：[GHSA-r3mw-2wmq-j6jg](https://github.com/wolfsoftwaresystemsltd/WolfStack/security/advisories/GHSA-r3mw-2wmq-j6jg)  
> 红线：仅 scope；默认列出容器；`--exec` 仅无害 `id`

## 0. 画像

| 项 | 内容 |
|----|------|
| 影响 | WolfStack **≤ 25.9.1**（修 **25.9.2**；exec 加固见 25.9.3） |
| 根因 | 内置 `CLUSTER_SECRET` 写入源码，请求头 `X-WolfStack-Secret` 可冒充集群节点 |
| 后果 | 枚举 Docker/LXC → `POST /api/containers/{runtime}/{id}/exec` 容器内命令执行 |
| 条件 | 未轮换自定义密钥（无有效 `/etc/wolfstack/custom-cluster-secret`） |

## 2. 成功口径

| 级别 | 口径 |
|------|------|
| L1 | **有密钥能列、无密钥被拒**（探针 `auth_ok` 且非纯 `baseline_open`） |
| L1b | 无密钥也能列 → 裸奔面板（另记，不单报 73519） |
| L2 | exec 回显 `uid=` / 等价命令结果 |
| 后续 | 容器挂载宿主机 → 读 `.env`/session → 切 `fernet-session-decrypt` / `tg-cloud-panel` |

## 3. 不要做

- 未授权扫网段  
- 默认破坏性命令 / 持久后门  
- 已轮换密钥仍报「必可打」
