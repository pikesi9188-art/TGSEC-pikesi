# Next.js 猎面手法

> 杀招：`次骨`  
> 探针：`炼蛊房/nextjs_surface_probe.py`  
> 大爱仙尊专卡。Kyber / `tgadmin.` / NEXTAUTH **先**走 `tg-bot-nextauth-takeover`。  
> 禁止只报 `x-nextjs` 结案。

---

## 1. 一句话

授权站是 Next.js 13/14/15 时，打：指纹 → 无会话 Server Action → 中间件旁路头 → `/_next/image` 白名单行为 → `/_next/data` IDOR → `__NEXT_DATA__` 泄密。  
默认不打 IMDS、不打 Rapid 缓存投毒、不把 400 当 SSRF。

```bash
python3 炼蛊房/nextjs_surface_probe.py --base https://授权站 --case <案卷>
```

落盘：`案卷/nextjs/surface.json`

---

## 2. 分流

| 信号 | 走 |
|------|----|
| `tgadmin.` / Kyber / `admin_session` / `/api/auth/callback/credentials` | **先** `tg-bot-nextauth-takeover` |
| `x-nextjs-*` / `__NEXT_DATA__` / `/_next/` / `Next-Action` | 本卡 |
| 只有 React SPA、无 `/_next/` | 回 `core_web_surface_probe` / JS 逆向 |

---

## 3. 档位

| 面 | L1 | L2（探针可做） | 不要默认做 |
|----|----|----------------|------------|
| 指纹 | 头/buildId/`__NEXT_DATA__` | — | — |
| sourcemap | `.js.map` 200 且含 `sources` | 抽 `NEXT_PUBLIC_` | 全量拖源码 |
| 开发态 | `/__nextjs_original-stack-frame` 正文含 overlay 针 | 记为 `next dev` 误上生产 | 仅非 404 不够（WAF 403 会误报）；禁止 launch-editor 读 `/etc/passwd` |
| Server Action | HTML/JS 抽出 action id | **无 Cookie** POST `Next-Action`，对照 401 vs 业务 JSON | 改余额/删用户 |
| 中间件 | `/admin` `/dashboard` 基线码 | `x-middleware-subrequest` 使 401/302→200（CVE-2025-29927） | 扫全站 |
| `/_next/image` | 非法 `url=` 得 **400**（白名单正常） | 仅当 OOB/体差异证明拉了内网 | **禁止**默认打 `169.254.169.254` |
| `/_next/data/{buildId}/` | 路径 200 JSON | 换 id 出现他人字段 | 拖全站 ISR |
| ISR 投毒 | — | 手测：独特 marker + 无 query 再取仍在 + cache 头 | 对全站用户投毒 |

CVE-2024-34351 是 **Server Actions 信 Host 的相对跳转 SSRF**，不是 `/_next/image`。修线：14.1.1+。  
CVE-2025-29927 修线：12.3.5 / 13.5.9 / 14.2.25 / 15.2.3。

---

## 4. 成功口径

| 级别 | 口径 |
|------|------|
| L1 | 确认 Next.js（头或 `__NEXT_DATA__` 或 `/_next/static`） |
| L2 | 无会话 action 回业务数据 **或** 中间件头把受保护路径打成 200 **或** `__NEXT_DATA__` 含非 `NEXT_PUBLIC_` 密钥 |
| 假阳性 | `/_next/image` 400 = 白名单拒绝，不是绕过；开发态 404 = 正常生产 |

---

## 5. 不要做

- 用百科 payload 替代探针 JSON
- 把 NEXTAUTH 管理面当本卡结案
- 默认打云元数据 / 对无关 Collaborator 打 SSRF
- 阴性后不回对象矩阵（有身份时）
