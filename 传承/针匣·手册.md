# Nuclei 引擎学习手册

> 官方：[github.com/projectdiscovery/nuclei](https://github.com/projectdiscovery/nuclei)（v3.x；本机版本以 `od_kit.py version` 为准）  
> 文档：[docs.projectdiscovery.io/tools/nuclei](https://docs.projectdiscovery.io/tools/nuclei)  
> 本库入口：`python3 tools/1day-kit/od_kit.py` · Skill：`杀招/一日针匣`  
> 作业清单（短）：`一日针匣.md`  
> 入库新 CVE：Skill `房睇长·日更`（写 JSON + 专卡 + 本库 YAML）

---

## 1. 一句话

**Nuclei 是 YAML 模板驱动的漏洞扫描器。**  
在大爱仙尊里它只负责 **L1：已知 CVE / 误配指纹**。命中后必须切 `nday_route` 或业务专卡，用业务口径验证；禁止「扫完 CVE 标签就结案」。

官方自己的定位：用社区贡献的 YAML DSL 模拟真实请求，降低误报，覆盖 HTTP / DNS / TCP / SSL / JS / Code 等协议。本库默认只用 **HTTP 指纹**，不默认开 `code` / `headless` / `dast` / `uncover`。

## 2. 三层，不要混

| 层 | 路径 | 谁维护 | 进 git？ |
|----|------|--------|----------|
| 引擎 | `tools/arsenal/bin/nuclei`（macOS Mach-O） | ProjectDiscovery 发版 | 二进制可有；源码 **不** clone 进 `tools/vendor` |
| 社区模板 | `tools/1day-kit/nuclei-templates/` | `od_kit.py update-templates` | **gitignore**，约 1.3 万条 |
| 本库指纹 | `tools/1day-kit/custom-templates/` | 本仓库，约 68 条 | **要进 git**，只探测、不炸 |

对应官方仓库：

- 引擎：`github.com/projectdiscovery/nuclei`（Go，`cmd/nuclei`）
- 模板：`github.com/projectdiscovery/nuclei-templates`
- 安装：`go install -v github.com/projectdiscovery/nuclei/v3/cmd/nuclei@latest`  
  本库优先：`bash scripts/install-arsenal-macos.sh`（拉 Darwin 资产到 arsenal）

`NUCLEI_TEMPLATES` 可覆盖社区模板目录。

## 3. 在作业流里排第几

```
授权闸门（scope）
    ↓
case-triage + 对象矩阵
    ↓
有业务指纹？──是──→ 专卡（Actuator / 假支付 / GVA / 芋道…）
    ↓ 否 / 要过已知洞
nday_route.py        先钉组件，命中专卡优先于广谱
    ↓
od_kit.py nuclei     L1 指纹（先 --custom-only，再 --tags cve,rce）
    ↓ 命中
对应 Playbook 验业务口径（读文件 / 未授权数据 / RCE）
    ↓
证据 案卷/<案卷>/案卷/1day/
```

并行情报：`od_kit.py cvebase trending|lookup` → 网站向 P0 走 `cve-daily-intel` 落盘，**不是**只口头报 CVE 号。

## 4. YAML DSL（用本库模板当教材）

官方模板长这样（社区 `CVE-2021-44228` 也是同一套结构）。本库教材：

`tools/1day-kit/custom-templates/spring-actuator-unauth.yaml`

```yaml
id: spring-actuator-unauth          # 全局唯一；扫的时候 --template-id 就用它

info:
  name: Spring Boot Actuator 未鉴权端点
  author: daaixianzun
  severity: high                    # info|low|medium|high|critical
  description: 检测 /actuator 系列端点未鉴权暴露
  tags: spring,actuator,unauth,misconfig   # --tags 过滤用

http:                               # 协议块：http / dns / tcp / ssl / javascript / file …
  - method: GET
    path:
      - "{{BaseURL}}/actuator"
      - "{{BaseURL}}/actuator/heapdump"

    matchers-condition: or
    matchers:
      - type: word                  # word | status | regex | dsl | size
        part: body                  # body | header | interactsh_protocol …
        words:
          - '"_links"'
          - '"activeProfiles"'

    extractors:                     # 抽证据，写进 jsonl
      - type: regex
        part: body
        name: endpoints
        regex:
          - '"href"\s*:\s*"([^"]+actuator[^"]+)"'
```

对照命令：

```bash
python3 tools/1day-kit/od_kit.py explain --id spring-actuator-unauth
python3 tools/1day-kit/od_kit.py explain --id CVE-2021-44228
```

### 4.1 内置变量（扫的时候 Nuclei 填）

| 变量 | 含义 |
|------|------|
| `{{BaseURL}}` | 含协议+主机+端口，无 path |
| `{{Hostname}}` | 主机（可带端口） |
| `{{interactsh-url}}` | OAST 回调域（盲洞 / Log4j） |
| `{{rand_int}}` / `{{randstr}}` | 防缓存、防碰撞 |

### 4.2 协议：本库用哪些

| 协议 | 官方用途 | 本库默认 |
|------|----------|----------|
| `http` | Web CVE / 误配 | **主用** |
| `dns` / `ssl` / `tcp` | 证书、中间件、端口 | 社区模板可带；广谱时用 `--tags` 收 |
| `javascript` | 复杂探测 | 少用 |
| `headless` | 浏览器 | 要显式 `-headless`，默认关 |
| `code` | 本机执行 | **默认关**（`-code` 才加载） |
| `dast` / fuzz | 参数fuzz | **默认关**（`-dast`） |
| `uncover` | Shodan/FOFA 拉目标 | **禁止**（会扩到未授权目标） |

### 4.3 官方 flags ↔ 本库命令

| 你想做的事 | 官方 | 本库 |
|------------|------|------|
| 单站扫 | `nuclei -u URL` | `od_kit.py nuclei --url … --case …`（scope 闸；**默认只跑本库 68 条**） |
| 只跑某标签 | `-tags cve,rce` | `--tags cve,rce`（此时才挂社区库） |
| 排除 dos/fuzz | `-etags dos` | `--exclude-tags dos,fuzz` |
| 只跑一条 | `-id …` / `-t file.yaml` | `--template-id …` 或 **`-t 路径`**（nday_route / 手法卡） |
| 只跑本库指纹 | `-t custom-templates/` | `--custom-only` 或裸跑（默认） |
| 严重度 | `-severity critical,high` | `--severity critical,high` |
| 更新模板 | `-update-templates -ud DIR` | `od_kit.py update-templates` |
| 校验 YAML | `-validate -t DIR` | `od_kit.py validate` |
| 列标签 | `-tgl` | `od_kit.py tags`（本库） |
| 自动按指纹选模板 | `-as`（wappalyzer→tags） | 本库不包；有组件指纹先 `nday_route` |
| 结果 | `-jsonl -o file` | 固定写到案卷 `案卷/1day/nuclei.jsonl` |

完整 flag 表以 `nuclei -h` 为准（TARGET / TEMPLATES / FILTERING / RATE-LIMIT / INTERACTSH / FUZZING / UPDATE）。

## 6. 自己写一条本库模板

对照 `cve-daily-intel`：网站向 P0/P1 才落 YAML。规矩：

1. 文件名：`<组件>-<面>.yaml` 或 `<组件>-cve-YYYY-NNNNN.yaml`
2. `id` 与文件名一致（小写、连字符）
3. `author: daaixianzun`
4. **只 GET/无害 POST**（登录弱口探测可以，禁止写 webshell / 删数据 / OUTFILE）
5. matcher 要能区分「组件存在」和「真未授权」；后者才标 high/critical
6. 落盘后：`od_kit.py validate` → `nday_route.py` ROUTES（若有专卡）→ `build_clear_entry.sh`

教材两条：

- 面探测：`spring-actuator-unauth.yaml`（多 path + or matcher）
- 弱口探测：`nacos-unauth.yaml`（GET 未授权 + POST `nacos/nacos` 抽 token）  
  Nacos **3.x** 命中后先走 Skill `纳言无门`（`--check-only`），不要跳过直接 Jasypt。

官方写模板长文：社区库里的 `TEMPLATE-CREATION-GUIDE.md`（已缓存在 `nuclei-templates/`）。

## 7. 成功口径

| 级别 | 算什么 | 不算结案 |
|------|--------|----------|
| L1 | `nuclei.jsonl` 有命中，且 matcher 对得上 | 只有 info 指纹、或广谱扫完无交接 |
| L2 | 专卡读到未授权数据 / 配置 / 用户列表 | 只复述 CVE 号 |
| L3 | 业务链打穿（堆转云、假付入账、超管票） | 仍停在 nuclei 输出 |

Actuator 命中 → `actuator_probe` + heapdump 分桶，禁止只扫 health。

## 8. 不要做

- 未进 scope 扫网段 / 对官方 example.com 当作业
- `-uncover` 把 FOFA/Shodan 结果当授权目标
- 把完整 `nuclei-templates` 或 nuclei 源码硬 clone 进 `tools/vendor`
- 在 custom YAML 里塞破坏性 exploit / `code` 协议
- 命中业务指纹后仍只跑 nuclei 结案
- 把报告里的第三方 UAT（`*.ktpaypro.com` 等）自动扩进 targets
- 当服务长期挂 `nuclei` HTTP API（官方也警告：当 service 有风险）
