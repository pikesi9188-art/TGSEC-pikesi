# 大爱仙尊网络验证与卡密作业手法

> 专卡：`杀招/卡密·破禁` · 探针：`炼蛊房/net_license_probe.py`  
> 分界：游戏外挂走 `client-crack-cheat`；发卡站走 `faka` / `acg-faka`；H5 VIP 旗标走 `client-state-skip`。  
> 立场：授权样本 / 自有软件找回。不散播注册机。

## 立刻跑

```bash
python3 炼蛊房/net_license_probe.py drive --path <样本> --case <案>
python3 炼蛊房/net_license_probe.py format --sample '<真卡密1>' --sample '<真卡密2>'
python3 炼蛊房/net_license_probe.py xor --plain known.bin --cipher enc.bin
python3 炼蛊房/net_license_probe.py patch-plan --path <PE>
```

## 族

| 族 | 指纹 | 打法 |
|----|------|------|
| 天盾 | `0xc000041d`、异或应答、反调试自毁 | drive 认面 → 反调试卡拆自毁 → 协议 4 态 |
| fndata | RSA 公钥嵌二进制、在线验卡 | 抽 PEM → 授权样本换钥或假服务器 |
| Nuitka / PyInstaller | `NUITKA_ONEFILE` / `PYZ-00.pyz` | 先解包再找 auth URL |
| 通用卡密 | checkLicense / 同构序列号 | format 恢复，禁止随机 CD-Key 当成功 |
| 在线验证 | activate/license URL | hosts/mitm 假 `{"status":"valid"}` |
| 短 JE | PE `74 XX` | patch-plan；`--apply` 必须 .bak + --case |

## 档

| 档 | 成立 |
|----|------|
| L1 | 壳或校验符号 |
| L2 | URL+RSA/符号，或卡密同构，或 XOR 钥流 |
| L3 | 授权补丁或假响应被吃 |

假服务器只绑授权样本的校验域。改生产超管密先问。
