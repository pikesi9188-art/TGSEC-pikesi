# 红衣·壳

> 大爱仙尊作业卡。分流：`python3 炼蛊房/hypothesis_route.py --signal "<词>"`  
> 杀招：`认族` · `linux-privilege-escalation` · `windows-privilege-escalation` · `ad-windows-router` · `llm-security`

点名 PwnKit / GodPotato / Log4Shell / ADCS / 拒答注入包时走本卡。不是 webshell 集。

| 层 | 是什么 | 本库怎么处理 |
|----|--------|--------------|
| 助手注入外壳 | 改本机 Claude/Codex 的拒答对齐注入 | **不部署第三方注入器**。立刻 `开源版不带助手注入` |
| 手法目录 | 提权 / 域 / Log4j / ADCS 等点名词 | 接到已有专卡 / checker / Playbook |

第三方注入器会扫本机 agents/rules/skills/memory。禁止在大爱仙尊工作区跑它。

## 工作节奏（不绕过授权闸）

1. **会改 artifact 先副本**（`.work` / 案卷目录），原件不动。  
2. **非平凡任务先 3–5 行阶段再打**，阶段间自动接，不空转。  
3. **授权闸仍走 `in_scope` / `scope_expand --grant`**，不把「lab 语义」当成可以打任意第三方。
