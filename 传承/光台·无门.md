# Ray 仪表盘未授权作业手法（CVE-2025-62593）

> Skill：`杀招/光台无门`  
> 指纹：`tools/1day-kit/custom-templates/ray-dashboard-unauth-cve-2025-62593.yaml`  
> 情报：`od_kit.py cvebase lookup --cve CVE-2025-62593`  
> 日报：`CVE日报-2026-08-17.md`  
> 红线：仅 `授权范围`。默认 **不提交 job**（那就是 RCE）。

---

## 1. 一句话

Ray 仪表盘（默认 **:8265**）关键 API **无鉴权**。`< 2.52.0` 只用「UA 以 Mozilla 开头」挡浏览器；`fetch` 可改 UA，再叠 DNS rebinding，就能从恶意页打开发者本机/内网 Ray。  
公网误暴露时，连 rebinding 都不需要：非浏览器 UA 直接 `GET /api/jobs`。

修：**2.52.0+**。对照老洞 ShadowRay（CVE-2023-48022）是同一面：jobs API 无认证。

## 3. 档位

| 档 | 动作 | 成功证据 |
|----|------|----------|
| **L1** | 首页 / `/api/version` | 确认 Ray 与版本 |
| **L2** | 非 Mozilla UA `GET /api/jobs` | 未授权列出作业（只读） |
| **L3** | `POST /api/jobs` 提交作业 | **先问**；授权内才用无害入口（如 `echo`） |

```text
L1 确认产品
  → L2 证明 jobs 未鉴权（本卡默认停在这里）
  → L3 提交作业 = RCE，先问
  → 得进程后走 linux-post-exploit / 内网隧道
```

L2 差分（记 STATUS，不要只写 CVE 号）：

| Mozilla UA | 自定义 UA | 含义 |
|------------|-----------|------|
| 拦 / 空 | 200 出 jobs | 62593 类 UA 防护可绕 |
| 都 200 | 都 200 | 经典无鉴权仪表盘（ShadowRay 面） |
| 都 401/403 | — | 已加认证，本卡阴性 |

## 4. 不要做

- 未授权公网扫 8265  
- 默认提交 job / 反弹壳 / 挖矿脚本  
- 只报 CVE 编号不验证 `/api/version`  
- 把开发者本机 Ray 和已授权业务站混为一谈（本机不在 scope 就停）
