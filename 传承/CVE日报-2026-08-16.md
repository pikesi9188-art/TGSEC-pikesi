**原理**：`/api/session/reset_password` 接口对 `token` 参数直接拼 SQL，无需认证，可盲注泄露 session token 进而接管管理员。

**复测命令**：
```bash

  --url https://<目标> \
  --case <案卷名> \

# nday 路由
python3 炼蛊房/nday_route.py -u https://<目标> --case <案卷>
```

**Playbook**：`传承/库府·吞库.md`

### CVE-2026-20349 — Cisco ASA/FTD SSL VPN DoS (HIGH 8.6) ⚠️ 待模板

**原理**：Cisco ASA/FTD 启用 Remote Access SSL VPN 时，HTTP 请求错误处理逻辑缺陷（CWE-244），未认证攻击者发送精心构造的 HTTP 请求导致设备重启。CISA KEV 08-11，在野利用确认。

**影响**：造成 VPN 服务 DoS；不直接产生代码执行。网站案降权，基础设施/运维面 P1。

**检测命令（指纹，不触发 DoS）**：
```bash
# 指纹探测
python3 tools/1day-kit/od_kit.py nuclei \
  --url https://<目标> \
  --case <案卷名> \
  -t tools/1day-kit/custom-templates/cisco-asa-sslvpn-dos-cve-2026-20349.yaml

# 手动指纹（仅 HEAD 探测版本头）
curl -sI https://<目标>/+CSCOE+/logon.html | grep -i "set-cookie\|server\|X-"
```

**缓解**：Cisco 已发布补丁；临时限制 SSL VPN 公网暴露面。

### CVE-2026-20316 — Cisco FMC 硬编码静态凭据 (MED 5.3) ⚠️ 待模板

**原理**：Cisco Secure Firewall Management Center Web 界面存在预置低权账号（CWE-259），未认证攻击者可直接用该账号登录读取敏感配置、设备列表、网络拓扑等信息。CISA KEV 07-29，在野利用确认。

**检测命令**：
```bash
# 指纹探测（尝试登录返回状态）
python3 tools/1day-kit/od_kit.py nuclei \
  --url https://<目标> \
  --case <案卷名> \
  -t tools/1day-kit/custom-templates/cisco-fmc-static-creds-cve-2026-20316.yaml

# 手动探测登录页
curl -sk https://<目标>/ui/login | grep -i "firepower\|fmc\|management center"
```

**注意**：FMC 管辖防火墙策略，若目标为安全运营中枢可升为 P0。
