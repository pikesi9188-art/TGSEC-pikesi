# Windows 提权手法

> 分流：`反客·总诀.md`  
> 检测：`python3 炼蛊房/windows_lpe_checker.py`（请在授权 Windows 目标上跑）  
> 长文：`智道藏书/九转/stages/07-本地提权（低权限升级高权限）.md`  
> 情报：cvebase `CVE-2026-68820`（AFD 本地面，KEV）  
> 红线：仅授权；内核 exploit / 写服务持久化 **先问**  
> **盘口/发卡 Linux 站默认不进本卡主线**，除非目标就是 Windows 主机且已在 scope。

---

## 1. 一句话

已有 **低权 Windows 进程/会话** → 先查 **配置误配**（服务权限、计划任务、AlwaysInstallElevated、未引用路径）→ 再看 **令牌/Potato 上下文** → 内核 CVE 最后且先问。

本库检测器：`炼蛊房/windows_lpe_checker.py`（macOS/Linux 上跑会跳过并提示拷到目标）。收集 whoami/priv、AlwaysInstallElevated、未引用服务路径、SeImpersonate。内核 exploit 不内置。

---

## 2. 开场检查（授权机上）

```text
whoami /all
whoami /priv
net localgroup administrators
systeminfo | findstr /B /C:"OS Name" /C:"OS Version"
```

```bash
# 在授权 Windows 目标上
python3 windows_lpe_checker.py --json --out 接管/lpe/windows_lpe.json
# 作业机预检（会 skipped）
python3 炼蛊房/windows_lpe_checker.py --help
```

| 面 | 看什么 | 成功口径 |
|----|--------|----------|
| 配置 | 可写服务 binPath、计划任务、AlwaysInstallElevated、未引用 DLL 路径 | 能换成高权进程 |
| 令牌 | SeImpersonate / SeAssignPrimaryToken（服务/IIS 上下文） | Potato 族方向（先问再打） |
| 凭据 | 当前用户可读的配置、计划任务明文、浏览器/WiFi（视授权） | 高权账密 |
| 内核 | 版本落未修区间（如 AFD CVE-2026-68820） | L3 先问 |

---

## 3. 档位

| 档 | 动作 | 成功证据 |
|----|------|----------|
| **L1** | whoami/priv + 系统版本 | 低权身份与补丁线索落盘 |
| **L2** | 配置误配（服务/任务/安装权限） | 新进程为 Administrators / SYSTEM |
| **L3** | 令牌模拟 / 内核（**先问**） | SYSTEM |

不要把 cvebase 上的 Windows KEV 自动当成 Web 案主刀。
