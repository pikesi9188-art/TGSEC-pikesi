# WordPress Easy Digital Downloads 未授权越权手法

> 情报：  
> - [CVE-2026-39503](https://cvebase.io/cve/CVE-2026-39503) 未授权 Broken Access Control（≤3.6.5）  
> - [CVE-2026-59524](https://cvebase.io/cve/CVE-2026-59524) 未授权 Broken Authentication（≤3.6.7）  
> 指纹：`tools/1day-kit/custom-templates/easy-digital-downloads-unauth-surface.yaml`  
> 分流：`秦百胜·拍卖.md`  
> 红线：仅授权；改订单/删下载先问

---

## 1. 一句话

**Easy Digital Downloads（EDD）** 是常见 WP「卖数字货/授权码」插件，海外发卡/授权站常用。  
≤3.6.5：**未授权访问控制缺失**；≤3.6.7：**未授权鉴权破坏** → 可能动特权功能（下单/下载/订单面，视补丁细节）。

降权同族：CVE-2026-12476（Shop Manager+ 任意上传）——有高权会话再测。

---

## 2. 指纹

| 信号 | 路径 |
|------|------|
| 插件 | `/wp-content/plugins/easy-digital-downloads/` |
| API/结账 | `/edd-api/` · `?edd_action=` · `/checkout` |
| 体/脚 | `edd_` 前缀脚本、下载按钮 |

```bash
python3 tools/1day-kit/od_kit.py nuclei --url https://授权站 --case <案卷> \
  --template-id easy-digital-downloads-unauth-surface
```

---

## 3. 档位

| 档 | 动作 | 成功证据 |
|----|------|----------|
| **L1** | 插件/EDD API 指纹 | 确认 EDD |
| **L2** | 无 Cookie 调本应鉴权的管理/订单类动作 | 200 + 业务变更或敏感 JSON（非登录页） |
| **L3** | 订单篡改 / 文件面（**先问**） | 未付款得下载或订单态被改 |

国内异次元/独角主线仍走假支付；**WP+EDD** 橱窗才升本卡。

---
