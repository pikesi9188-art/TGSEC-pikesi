# TrueConf 未授权脚本手法（CVE-2026-72529 / 72530）

> 情报：`od_kit.py cvebase lookup --cve CVE-2026-72529 --docs`  
> 指纹：`tools/1day-kit/custom-templates/trueconf-unauth-cve-2026-72529.yaml`  
> 总览：`CVE日报-2026-08-22.md`  
> 红线：仅授权目标；只指纹 Web/4307；不调未文档函数、不发逃逸脚本

---

## 0. 画像

TrueConf Server 的 **`4307/TCP`** 缺鉴权：未授权可调未文档函数跑脚本（72529，CVSS 9.8），再特制脚本逃出隔离打宿主（72530，9.0）。  
KEV 2026-08-20 · 在野 · 无公开 PoC。

影响：`5.3.x–5.3.9`、`5.4.x–5.4.9`、`5.5.x–5.5.5` 及更早。

---

## 1. 指纹（L1）

```bash
python3 炼蛊房/nday_family_probe.py --family trueconf --base https://授权站 --case <案卷>
```

nuclei 模板只作对照，不结案。

常见：标题 TrueConf、体 `TrueConf Server`、端口 **4307**。  
nuclei 的 BaseURL 要指到实际 Web 口；若控制台就在 4307，写成 `https://授权站:4307`。本卡不扫裸 TCP 未文档口。
