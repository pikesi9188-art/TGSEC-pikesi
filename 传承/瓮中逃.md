## 1. 一句话

shell 在 **Docker/K8s/LXC 容器内** 时，目标不是容器 root，而是 **宿主机 root**（或等价挂载宿主机根盘）。  
先走 **配置误配**（sock/组/特权/cap），再考虑内核 CVE。

---

## 2. 先确认「在不在容器」

```bash
id; hostname; uname -a
ls -la /.dockerenv /run/.containerenv 2>/dev/null
cat /proc/1/cgroup 2>/dev/null | head
cat /proc/1/environ 2>/dev/null | tr '\0' '\n' | head
ls -l /var/run/docker.sock /run/containerd/containerd.sock 2>/dev/null
groups; capsh --print 2>/dev/null | head
ls /var/run/secrets/kubernetes.io/serviceaccount/ 2>/dev/null
```

| 信号 | 含义 |
|------|------|
| `/.dockerenv` / cgroup 含 `docker`/`kubepods` | 在容器里 |
| 可写 `/var/run/docker.sock` 或在 `docker` 组 | **L2 高优先** 挂载宿主机 |
| `lxd`/`lxc` 组 | 建特权容器挂盘 |
| `cap_sys_admin` / Privileged | 可挂载、接近宿主机 |
| K8s SA token | 调 API 建特权 Pod（视 RBAC） |
| 内核落 SCTPhantom / OverlayFS / nf_tables | **L3 先问** |

```bash
python3 linux_lpe_checker.py --json --out /tmp/lpe.json
```

---

## 3. 档位

| 档 | 动作 | 成功证据 |
|----|------|----------|
| **L1** | 容器指纹 + sock/组/cap/SA | 落 `接管/lpe/container.json` |
| **L2** | docker.sock / docker 组 / lxd / 特权挂载 | 读到宿主机 `/etc/shadow` 或宿主机 `id` |
| **L3** | 内核逃逸（SCTPhantom / OverlayFS / nf_tables）（**先问**） | 宿主机 root |

```text
L1 确认容器
  → docker.sock 可写 / docker 组 → 挂载 / 到 /mnt → 宿主机根
  → lxd/lxc 组 → 特权容器挂盘
  → Privileged / cap_sys_admin → 挂载宿主机盘
  → K8s SA 有建 Pod 权 → `群瓮·特权.md`（L3 授权内直接做）
  → 全阴 → 收割容器内 .env/密钥；内核面先问再打
```

L2 配置面（docker 组挂载）是作业默认路径；**不要**一上来打内核。
