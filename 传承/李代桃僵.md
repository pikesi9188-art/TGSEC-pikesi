# 大爱仙尊 JWT 作业手法

> 杀招：`李代桃僵`  
> 摸面：`python3 炼蛊房/jwt_gql_probe.py`  
> 锻造：`python3 炼蛊房/jwt_forge_probe.py`  
> 附录：`传承/李代桃僵·星念.md`  
> 专卡：GVA / 若依 / TG `your_secret_key` 仍先认族

目标须在 scope。不默认改原超管密。接口本来就公开，**不要报 none**。

---

## 1. 立刻跑

```bash
python3 炼蛊房/jwt_gql_probe.py -u https://授权站 --token '<JWT>' --case <案>
python3 炼蛊房/jwt_forge_probe.py --self-test
python3 炼蛊房/jwt_forge_probe.py none --token '<JWT>' --url https://授权/api/user/info --case <案>
python3 炼蛊房/jwt_forge_probe.py claim --token '<JWT>' --url https://授权/api/me --set role=admin --case <案>
```

产物：`案卷/jwt_gql/surface.json`、`案卷/jwt_forge/none.json`。

---

## 2. 四刀

1. **摸票** — `jwt_gql_probe` 认 alg / kid / 弱 HS256 / 掩码 session  
2. **none** — `alg=none|None|NONE` + 空签重放 `/me`；对照未授权与垃圾票  
3. **改 claim** — `role` / `authorityId` / `admin` 用 none 重放；GVA 切静默提权卡  
4. **kid / jku** — kid 像路径就当 LFI 读钥；jku 指向你控的 JWK。RS256→HS256 要先拿到公钥

弱 HS256 撞 `dict/jwt_hs256_public.txt`，不要无字典爆破。

---

## 3. 档位

| 档 | 成立 |
|----|------|

| L2 | 弱签，或 none/空签被吃且 **不同于未授权** |
| L3 | 改 claim 后管理接口仍 200（只读证明即可） |
