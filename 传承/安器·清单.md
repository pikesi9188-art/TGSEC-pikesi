# Android 客户端渗透检查清单

> 大爱仙尊 Android 客户端渗透检查清单。  
> 情报抽取仍走 **`安器·探路.md`** · `apk_recon.py`（密钥/后台/测试域优先）  
> 动态绕过走 **`安器·钩.md`** · Skill `铁血冷·拆骨` / `mobile-reverse`  
> 授权：目标须在 `授权范围`。只测授权包；不装击键木马、不写界面劫持 APK。

**不是** Spring heapdump。拿到 APK 先抽业务密钥，再按本清单打客户端面。

---

## 0. 何时启用

| 指纹 / 用户说法 | 走 |
|-----------------|----|
| 只要密钥、后台路径、测试域、签名算法 | `apk-recon`（本卡可后置） |
| 「APP 渗透 / 客户端安全 / 组件导出 / WebView / allowBackup / 手势密码」 | **本卡全表** |
| 加固 / 证书固定 / root 检测挡抓包 | Frida 卡后再回本表未测项 |
| IPA / iOS | 本卡不覆盖；有包当静态情报 |

```bash
python3 炼蛊房/apk_recon.py extract --apk /tmp/app.apk --case <案卷>
# Manifest / 组件摘要也可：apktool d + 读 AndroidManifest.xml
```

证据：`案卷/<案卷>/案卷/apk/`（`client_checklist.md` 勾本表）。

## 1. 强制顺序

```
拿包 → apk_recon 情报
  → Manifest：签名 / debuggable / allowBackup / 权限 / 导出组件
  → 导出组件：am / drozer 验证（未登录能打开？Provider 能读？）
  → 本地存储：/data/data/<pkg> 权限与明文
  → WebView / JSBridge / SSL proceed
  → 通信：代理 / pinning / 硬编码密钥（回灌假支付）
  → 会话与手势 / 更新包 / 本地端口
```

禁止：没看 Manifest 就改 smali；没抽密钥就先做键盘/截屏项；仓库内实现击键记录或 Activity 劫持工具。

## 2. 包与 Manifest

| 项 | 怎么判 | 风险口径 |
|----|--------|----------|
| 签名身份 | `jarsigner -verify -verbose -certs app.apk` 或 `apksigner verify` | Debug / 第三方签 ≠ 客户生产证 → 记风险 |
| 可反编译 | jadx；失败再 apktool smali；有壳走内存 dump / Frida | 无混淆无壳 = 低防护，不单独当洞 |
| 完整性自校验 | 改 `assets/` 或 `res/raw` → apktool b → 签名安装 | 改完仍正常跑 = 无自校验（高） |
| `android:debuggable="true"` | Manifest | 可 jdb / `run-as` |
| `android:allowBackup` 未显式 `false` | 默认 true | `adb backup` / `adb restore` 可拖私有数据 |
| 权限膨胀 | Manifest vs 业务 | 超出业务所需记隐患 |
| 加固 / 多 DEX | 360/腾讯/梆梆；classes2.dex | 静态失败再动态 dump，勿判「不可分析」 |

导出规则（写清清单，交给业务确认是否必须导出）：

1. `exported="true"` → 可导出  
2. `exported="false"` → 不可  
3. 未写 `exported`：非 Provider 且有 `<intent-filter>` → 默认可导出；Provider 在 **API &lt; 17** 默认可导出，≥17 默认不可  
4. 动态 `registerReceiver` 不在 Manifest，要搜代码  
5. `protectionLevel=signature` / `signatureOrSystem` 降低跨包风险，仍要看逻辑

## 3. 四大组件（先列后打）

工具映射：旧文 Mercury → **drozer**；本库默认可 `adb shell am` / `content` 验证。

```bash
# 包名来自 apk_recon / Manifest
adb shell am start -n <pkg>/.SomeActivity          # 未登录能否出界面
adb shell am startservice -n <pkg>/.SomeService
adb shell am broadcast -a <action> -n <pkg>/.Rx
adb shell content query --uri content://<authority>/...
```

| 组件 | 看什么 | 成功口径 |
|------|--------|----------|
| Activity | 导出 + 未登录能进资金/个人页 | 越权界面或敏感数据 |
| Service | `onCreate` / `onStartCommand` / `onHandleIntent` 是否信 Intent | 未授权能驱后台逻辑 |
| Receiver | 静态 + `registerReceiver`；空 extra 是否崩 | 崩溃 = 本地 DoS；`sendBroadcast` 无权限 = 可伪造 |
| Provider | `openFile` / `query`；drozer `scanner.provider.injection` / `traversal` | SQLi 或任意读文件 |

Intent 本地 DoS（导出组件代码里搜 `get*Extra` / `getAction` / `getSerializableExtra`）：

- `getAction().equals(...)` 无空保护 → NPE  
- `getSerializableExtra` 无类 → `ClassNotFoundException`  
- `getIntegerArrayListExtra` 当固定长度用 → 越界  

验证用 `am start` 带畸形 extra，看到崩溃即可记；不要为了 DoS 写专用攻击 APK。

## 4. WebView

加深（Deeplink / 文件域 / NanoHTTPD / 导出 Provider）走 **`内窗·深链.md`** · `webview_bridge_probe.py harness`（授权验证页；`--collect` 回实验室）。

```bash
python3 炼蛊房/webview_bridge_probe.py scan --dir <jadx目录> --case <案卷>
```

| 检查 | 搜 / 测 | 何时高危 |
|------|---------|----------|
| JSBridge | `addJavascriptInterface` + `setJavaScriptEnabled(true)` | `targetSdkVersion < 17` 且未限制接口（CVE-2012-6636 族） |
| Deeplink 喂 URL | `getStringExtra("url")` → `loadUrl`；自定义 `scheme` | 未登录能打开任意页 |
| 文件域 | `setAllowUniversalAccessFromFileURLs(true)` | 本地 file:// 可读应用文件 |
| 本地 HTTP | `NanoHTTPD` / `new File(root, uri)` | 路径穿越读包内文件 |
| 证书 | `onReceivedSslError` → `handler.proceed()` | 忽略证书 = MITM 放行 |
| 密码保存 | `setSavePassword` 未显式 `false` | `databases/webview.db` 明文账密 |
| 旧版探测页 | 仅授权靶场；低 targetSdk 才值得复测 | 页面列出可反射接口即成立 |

`targetSdkVersion >= 19` 且无 Bridge 暴露敏感 API → 本项可降权。

## 5. 本地数据与进程

退出 App 后再测私有目录（退出时常清缓存）。

```bash
adb shell run-as <pkg> ls -l                    # 需 debuggable
# 或 root：
adb shell ls -l /data/data/<pkg>/
adb pull /data/data/<pkg>/shared_prefs/
```

| 项 | 判据 |
|----|------|
| 文件权限 | 普通文件末三位应空（`rw-rw----`）；出现 world read/write 或 `MODE_WORLD_*` |
| SharedPreferences | xml 里 token / 密码 / 手势 |
| SQLite | `*.db`；WebView 的 `webview.db` cookie / 表单 |
| 包内硬编码 | `apk_recon.py strings`；`.so` 丢 IDA / `pwn_triage` |
| SD 卡同名目录 | 缓存、日志、明文 |
| 加密质量 | Base64 当加密、硬编码 AES/DES 密钥、ECB、RSA 512 / NoPadding、全零 IV |
| logcat | 使用过程 `adb logcat -d` 是否打密码、验证码、token |
| 内存明文 | 授权设备上 Frida Hook `Cipher` / 登录字段；不默认上 MemSpector 改分 |
| `DexClassLoader` | DEX 是否落在可被其他 App 写的目录且无完整性校验 |
| 本地 listen | `adb shell netstat -tuanp` 或 `ss`；搜 `ServerSocket` / 未鉴权 `Runtime.exec` |
| 百度虫洞 | 源码/端口 **40310 / 6259 / 7777** + `/getcuid` `/getapplist` 有回显 |

手势密码（3×3，全排列约 9! = 362880）：

- 最少点数、改/关是否验旧手势  
- `/data/data/<pkg>/` 搜 `gesture` / `lock`；仅 MD5/SHA1 无盐可查表  
- 无锁定策略 = 可穷举  
- 抗攻击：页面能否被滑掉绕过（记现象即可，不装 SwipeBack 去打生产）

## 6. 通信与更新

代理分层（与 Frida 卡一致）：

1. 系统 HTTP 代理够用 → Burp / 本机抓包  
2. 不走系统代理 → Root 透明代理或改包  
3. 非 HTTP 私有协议 → Wireshark + 逆向摘协议；复杂则 Hook 加解密  

| 项 | 测法 | 口径 |
|----|------|------|
| 强制 HTTPS | 改 URL 为 http 是否仍走 | 明文 HTTP 且无应用层加密 = 高 |
| 证书校验 | 用户 CA / 换域名证书 | `HostnameVerifier` 恒 true、`proceed()` = 高 |
| 证书绑定 | 装用户证仍失败 | 有 pinning → Frida 绕过后再抓；绕过本身不算客户风险 |
| 字段加密 / 签名 | 代理改包是否被拒 | 无完整性 = 可重放改金额 |
| 会话 | 登出后旧 token 是否仍可用；空闲超时 | 服务端未销毁 = 高 |
| 更新 | 改检测更新返回的 apk URL | 无签名校验就装 = 高 |
| 短信接口 | 重放发短信包 | 可轰炸 = 中（生产限次） |

弱算法速查（jadx）：`DES/`、`AES/ECB`、`RSA/NONE/NoPadding`、`initialize(512)`、硬编码 `IvParameterSpec`。

命中硬编码支付/签名密钥 → **立刻回灌** `秦百胜·假契` / `apk_recon` sign-algo，不要停在客户端清单。

## 7. 会话与业务策略（人工为主）

弱口、锁定次数、多端登录、切后台是否清空密码框、`FLAG_SECURE` 防截屏、验证码是否服务端生成、改密是否验旧密、登录提示是否可枚举用户名。  
键盘项：只用系统输入法 = 可被第三方 IME 记录；随机键位但仍有按键动画 = 可被连截屏。**本库不提供击键/劫持 APK。**

## 9. 成功口径 / 禁止

- 情报：`apk_intel.json` 出现密钥、后台、测试域，并回灌对应专链。  
- 客户端：任一项高危可复现（未登录导出 Activity、Provider 读私有库、allowBackup 拖出 token、JSBridge RCE 条件成立、明文 HTTP 账密）。  
- 只反编译出混淆代码 **不算** 洞。  
- **禁止** 实现/下发击键记录、Activity 覆盖登录页、未授权重打包上架。  
- 生产短信轰炸、改更新 URL 装恶意包 → 先问。
