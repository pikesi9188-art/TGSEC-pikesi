# 芋道 TMA / Web 加密网关手法

> 金标准指纹来自扩展包 `yudao-tma-pentest` + `yudao-web-appapi-pentest`。  
> 世博/创世钱包类 Mini App、以及 `/app-api/encrypt` Web 站用这张卡。  
> Qzino `/api.html` **不要**走本卡，切 `telegram-tma-gambling`。  
> 管理端 `/admin-api` + `mock-enable` / `file-config` / 代付 `df-user` **不要**走本卡，切 `芋府·假面开天.md`。

## 1. 先认变体

| 变体 | 信号 | 协议 |
|------|------|------|
| TMA | `/runtime/app-config.js` 有 `PLATFORM_ID` + `API_LIST` | 每请求 AES-256-ECB + RSA 包 key + `X-Ca-Token=MD5` |
| Web | `/app-api/encrypt/*` 返回 base64；或能读 `sk_encrypt.json` | 静态 AES 密钥；常 CTR/CBC + gzip |

```bash
python3 炼蛊房/yudao_appapi_probe.py -u https://授权前端 --case <案卷>
```

## 2. TMA（`tenant-id` + initData）

1. 拉 ` /runtime/app-config.js` → `PLATFORM_ID`（租户）+ `API_LIST`。  
2. 从 `chunk/utils-*.js` 抽 MD5 salt（如 `Rt`）和 RSA 公钥（`Lt`）。  
3. 未授权先打：`/app-api/system/tenant/getTenantConfiguration`、热门游戏页（加密但无 token）。  
4. `telegramBot/autoLogin` **不加密**，body `tg_token=<initData>`；窗口短（约 1–5 分钟），拿到 initData **当轮立刻登**。  
5. 租户池共用 API：`1004003003 Token无效` 先换 tenant / 换 TMA 域，别判「加密错了」。  
6. 充提：`pay/bank/getRechargeChannel` → `deposit-order/create`；`set-pay-password` 在未设置时可直接设 6 位。  
7. 凭证上传常只验图片格式 → 人工审，**不等于自动入账**。假支付另打网关 notify。

全文步骤：`智道藏书/旁支传承/skills/yudao-tma-pentest/SKILL.md`

## 3. Web（`sk_encrypt.json`）

未登录先读（root 与 `/dflt` 常 200，`/app-api` 前缀可能 403）：

```text
/sys-upload/data/json/sk_encrypt.json
/dflt/sys-upload/data/json/sk_encrypt.json
```

base64 → JSON → `encrypt_key.configValue`。有密钥就能解全站加密响应。  
明文 `/app-api/*` 常同时可用，探测走明文，报告写清双通道。

算法以当前 bundle 为准：有的是 AES-CBC(key=iv)+gzip，有的是 AES-CTR。先 `sk_encrypt` 再写解密，不要先猜算法。

全文：`智道藏书/旁支传承/skills/yudao-web-appapi-pentest/SKILL.md`  
网关族补充：`encrypted-api-gateway-reversal`

## 4. 不要做

- 在 app 域死磕 `/admin-api`（常 404/SPA 回退）  
- initData 过期后还用旧 token 连打登录  
- 把「凭证已上传 / status=5」写成余额到账  
- 把 Qzino `method` 信封套到芋道 REST 上
