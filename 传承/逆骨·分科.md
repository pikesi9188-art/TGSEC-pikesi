# 逆骨·分科

> 大爱仙尊作业卡。不把大型逆向框架源码、越狱注入、IDA fat binary 拷进本库。  
> 专题路由和门禁并进已有卡。  
> 作业层（认族 / dump / 复现 / 过闸）：`逆骨.md`  
> 分诊：`python3 炼蛊房/re_sample_triage.py --path <样本>`

新开对话搜这些词时，走下面的本库入口。

---

## 1. 专题 → 本库

| 专题 | 本库 | 动作 |
|------|------|------|
| `credential-hunter` / 猎杀者 v5 | `sensitive-dir-dump` | 已融合；`space-hunt --domain` |
| `wxmini-security-audit` | **`wxmini-static-audit`** · `run` | scan+analyze+report；`--focus` 当定制 Agent；无子对话 |
| `webview-deeplink-pentest` | **`webview-deeplink-bridge`**（新） | 强标签才 L2；`scan --case` 出验证页；四条载荷齐；`--collect` 才回传实验室 |
| `web-reverse` 34 专题 | `js-reverse` + 本卡 §2 | 专题表，不搬 task-boot.mjs |
| `android-reverse` 24 专题 | `apk-reverse` / `apk-recon` + 本卡 §3 | 壳/JNI 门禁 |
| `xiaojianbang-auto-reverse` | `apk-reverse` Native 节 + Frida 卡 | dump-first，不内置 KPM |
| `win-reverse` | `ida-reverse` / `dotnet-reverse` / `thick-client` / `vm-and-bytecode-reverse` | 按形态切 |
| JADX MCP / IDA MCP | `apk-reverse`（jadx CLI）· `ida-reverse`（已有 MCP） | 不 vendor 68MB |
| 独立逆向 CLI | **不替代 Cursor** | 本库继续 Cursor + Skill |

外部卡里的「永不拒绝 / 越狱载荷」**一律丢弃**。

## 2. Web 专题 → 本库（`js-reverse`）

先 `python3 炼蛊房/reverse_skill_route.py --hint "<任务>"`。盘口国密 / `sk_encrypt` 仍专卡优先。

| 专题 | 何时读细 | 本库下一刀 |
|------|----------|------------|
| signature / protocol / userland-crypto / subtlecrypto | 签名、AES、WebCrypto | `js-reverse` → 密钥回灌假支付 |
| jsvmp / wasm / worker / dynamic-code | 自定义 VM、WASM、Worker | `js-reverse`；opcode VM 再 `dsl-vm-reverse` |
| source-map / ast-deobfuscation / string-array | `.map`、obfuscator.io | `js_secret_hunter.py hunt` |
| anti-debug / anti-tamper / fingerprint | 反调试、风控指纹 | 浏览器 MCP / scrapling；不要盲 `evaluate` 代替 hook |
| grpc-web / graphql-rpc / webrtc-datachannel | 非 REST | `spa-protocol-reverse` 或 `protocol-reverse` |
| webauthn-passkey / captcha-slider | 挑战链 | 滑块走 `geetest-captcha-bypass`；WebAuthn 只还原不造断言 |
| media-drm / video-frame | 媒体解密 | 降权，除非授权内容面 |

验收：请求被服务端接受，或本地 `pure-*` 脚本对同一输入复现签名。浏览器偶发成功不算交付。

## 3. Android 专题 → 本库

| 专题 | 本库 | 门禁 |
|------|------|----------------------|
| static-triage / java-api / call-flow | `apk-recon` 再 `apk-reverse` | 先情报后深挖 |
| webview-hybrid | **`webview-deeplink-bridge`** | 先静态探针 |
| protection-bypass / dex-loader | `apk-reverse` + Frida 卡 | **壳 ≥ 动态 DEX：禁止先 Frida 脱壳**；BlackDex/FART/eBPF 等本机有再用 |
| jni-bridge / native-so / native-network | `ida-reverse` / `ghidra-reverse` | 先桥后深 native |
| deobfuscation / vmp-analysis | `code-obfuscation-deobfuscation` / `vm-and-bytecode-reverse` | OLLVM 先静态再 hook |
| unidbg-simulation | 本机有 unidbg 再用 | 不内置 |
| kernel-assisted-re / xiaojianbang HWBP | 记录为升级手段 | **不内置** syscall-filter / KPM / 默认 superkey |

闪退 / constructor 早死：先看 `.init` / `.init_array` / `JNI_OnLoad`，再看匿名 RX；加密 so 必须 dump 后再下结论。
