## 3. 档位

| 档 | 动作 | 成功证据 |

### 3.1 JWT 四刀（有票再打）

探针会标 `alg` / `kid`。弱 HS256 撞上公开字典就是 L2。另外三刀手工补：

1. **none** — header 改 `{"alg":"none"}`，签名段留空，重放 `/me`  
2. **kid 路径** — `kid` 含 `../`、`/`、`file:` 就当 LFI 读钥  
3. **jku / x5u** — URL 指向你控的 JWK，看服务端是否拉公钥  
4. **RS256→HS256** — 拿到 PEM 公钥后改 alg=HS256 用公钥当 secret

`none` 轰炸全站不算作业。有一票一接口对照才算：

```bash
python3 炼蛊房/jwt_forge_probe.py none --token '<JWT>' --url https://授权/api/user/info --case <案>
```

细卡：`jwt-bypass-pentest` · `李代桃僵.md`。

```text
弱签 + GVA 味 → 静默提权卡（getSystemConfig / authorityId）
弱签 + 若依 → 若依四海 / captcha Redis
introspection 里 pay/notify/order → 假支付矩阵
introspection 里 user/admin 且无专栈 → authz-probe
PocketBase token → Skill pocketbase
阴性 → 当普通 /api 走 authz-probe，勿 none 算法轰炸
```
