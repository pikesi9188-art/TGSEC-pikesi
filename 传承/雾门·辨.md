# 企业 SSL VPN 门户指纹手法

> 杀招：`雾门`  
> 探针：`炼蛊房/sslvpn_surface_probe.py`  
> 大爱仙尊专卡。FortiOS 专洞仍走 `雾门·旁路.md`。  
> **网站案默认降权**：目标本身是 VPN 管理面且已在 scope 才打。只做产品指纹，不默认发 1day gadget。

---

## 1. 一句话

认 Cisco ASA / FortiGate / Citrix ADC / PAN GlobalProtect / Ivanti / F5 门户，交给 `nday_route` / 对应 Playbook。禁止把 VPN 当普通 Web 站 squatting。

```bash
python3 炼蛊房/sslvpn_surface_probe.py --base https://授权站 --case <案卷>
```

落盘：`案卷/sslvpn/surface.json`

---

## 2. 路径 → 产品

| 路径 / Cookie | 产品 | 下一跳 |
|---------------|------|--------|
| `/+CSCOE+/logon.html` · `webvpn=` | Cisco ASA / AnyConnect | CVE 日报 Cisco；**禁止 DoS** |
| `/remote/login` · `SVPNCOOKIE=` | FortiGate SSL-VPN | FortiOS 符号链接卡 |
| `/vpn/index.html` · `NSC_AAA=` | Citrix NetScaler | `nday_route` / 1day-kit |
| `/global-protect/login.esp` | Palo Alto GlobalProtect | 只指纹 |
| `/dana-na/auth/url_default/welcome.cgi` · `DSAuthSession=` | Pulse / Ivanti | 只指纹；历史链走 CVE 日报 |
| `BIGipServer` | F5 | 只指纹 |

网站主站误打到这些路径：记产品，**不进 ACTIVE A**，除非用户明确授权该 VPN 面。

---

## 3. 成功口径

| 级别 | 口径 |
|------|------|
| L1 | 上表任一路径 **200/302/401** 且 Cookie/正文含产品特征（`anyconnect`/`svpncookie`/`globalprotect` 等）。**禁止**把 404 回显 URI（`logon.html`/`dana-na`/`portal`）当指纹 |
| L2 | 版本可钉 + 对应专卡/CVE 模板已跑（FortiOS 等） |
| L3 | 具体 RCE/文件读（各专卡先问条款） |

---

## 4. 不要做

- 对 Cisco SSL VPN 发 DoS 类 CVE
- 把第三方 VPN 基础设施扩进 scope
- 用外部全文利用链替代本库 FortiOS 专卡
