## 3. 自动化命令

```bash
python3 tools/deepaudit/bin/da_pipeline.py status
python3 tools/deepaudit/bin/da_pipeline.py knowledge --case <站_日期>
python3 tools/deepaudit/bin/da_pipeline.py sast --source <本地源码> --case <站_日期>
python3 tools/deepaudit/bin/da_pipeline.py pay-hint --case <站_日期>

# 全栈 Agent（需 Docker）
bash tools/deepaudit/bin/da_start.sh
# UI: http://localhost:3000
```

产物：`案卷/<案卷>/案卷/deepaudit/`

`sast` / `pay-hint` 若在 gitleaks/trufflehog/日志中命中支付相关密钥，会写：

- `PAYMENT_PLAYBOOK_HINT.md`
- `payment_hint.json`
- `STATUS_SNIPPET.md` 内「假支付」警告段

---

## 4. 授权衔接

1. 远程目标必须在 `授权范围`。  
2. DeepAudit **不替代** Spring Gateway / 假支付 / PocketBase 等专用杀伤链。  
3. 适用：拿到源码、反编译包、Git 泄露后的白盒深挖。  
4. 沙箱 PoC 只打审计项目本身，禁止自动扩未授权旁站。  
5. **密钥命中后**必须转入 `payment-callback-forgery`（合法签矩阵）；中转域另授权。
