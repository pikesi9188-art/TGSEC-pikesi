# 月芒

> 默认探针：`炼蛊房/dirbrute_probe.py`（scope 门控、短字典、案卷落盘）  
> 加力：`tools/pentest/dirsearch/dirsearch.py`  
> 字典：`dict/gambling_backup_paths.txt`（路径）；`dict/cms_panels.txt` 是**弱口令**不是路径  
> 面板指纹：`panel_surface_probe.py`；非标口：`port_admin_scan.py`  
> 红线：仅授权；全量狂扫 / 把 WAF 打封先收敛；不自动下载大备份

---

## 1. 一句话

用**短字典**打 `.git` / `.env` / 备份包 / 面板 / Swagger / GraphQL，接到已验证专卡。  
不要靠百万级 dirb 当主攻。

---

## 2. 默认命令（L1）

```bash
python3 炼蛊房/dirbrute_probe.py -u https://授权站 --case <案卷>
```

落盘：`案卷/<案卷>/案卷/dirbrute/surface.json`  
L1 成功：`hits` 里有与 404 基线**不同**的 200/206/401/403。

加力（仍用短字典）：

```bash
python3 tools/pentest/dirsearch/dirsearch.py \
  -u https://授权站 \
  -w dict/gambling_backup_paths.txt \
  --timeout=8 -t 10 \
  --format=json -o 案卷/dirsearch.json
```

---

## 3. 档位

| 档 | 动作 | 成功证据 |
|----|------|----------|
| **L1** | 短字典 + 404 差分 | `surface.json` hits |
| **L2** | 打开备份/面板/`.git`/`.env`（小文件） | 可读配置或登录页；密钥打码 |
| **L3** | 进面板或源码 | 接宝塔/假支付/DeepAudit |

```text
.git / 源码 zip → DeepAudit → 密钥回灌假支付
.env / 密钥文件 → 打码后接支付或面板
phpMyAdmin / 宝塔 → 宝塔台.md
/wp-includes/ 目录列表或 11 位随机 `.php` → `坞壳落子猎.md`（禁止对情报域名扩权）
/actuator → Actuator 全链（禁只扫 health）
/graphql / swagger → jwt_gql_probe / authz-probe
403 大面积 → IP白名单绕过 / WAF，勿加线程
```
