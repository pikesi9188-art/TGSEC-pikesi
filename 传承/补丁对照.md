---

## 1. 一句话

先 **钉组件并接到已打穿的专卡**，再考虑 nuclei 广谱。  
补丁差分（ghidriff 等）只对已拿到的两个版本做，不作为网站案默认依赖。

---

## 2. 默认命令（L1）

```bash
python3 炼蛊房/nday_route.py -u https://授权站 --case <案卷>
# 路由 JSON 里的 hits[].cmd 必须逐条跑，不要跳过直接 nuclei 结案
python3 tools/1day-kit/od_kit.py nuclei --url https://授权站 --case <案卷>
```

落盘：`案卷/<案卷>/案卷/nday/route.json`  
L1 成功：`hits` 非空并已执行对应 cmd，或 `hits` 空且已跑 custom-templates 并写明无条目。

```bash
python3 tools/1day-kit/od_kit.py cvebase lookup --cve CVE-… --docs
# 有源码：
python3 tools/autocve/ac_pipeline.py --help
```

## 3. 档位

| 档 | 动作 | 成功证据 |
|----|------|----------|
| **L1** | `nday_route` 钉栈 + 专卡命令 | route.json；版本/产品名 |
| **L2** | 专卡或 nuclei 非破坏复测 | 与该 Playbook 成功口径一致 |
| **L3** | 补丁差分绕过 / 新洞 | AutoCVE Finding 或专卡命令 |

作业机若已装 **ghidriff / Diaphora / bindiff**：只对**已授权、已拿到**的两个版本做函数差分，输出落 `案卷/patchdiff/`。
