# AutoCVE 自动化 CVE 挖掘（Playbook）

上游：https://github.com/larlarua/AutoCVE（AGPL-3.0，钉扎 **v1.0.5**）  
封装：`tools/autocve/` · Skill：`杀招/自掘新伤/SKILL.md`  
关联：`tools/deepaudit`（工程前身参考；本引擎已对接）

## 1. 这是什么

Multi-Agent 白盒平台，面向 **挖可申报 CVE**：

```text
Orchestrator
  → Recon → Scan → Triage
  → Finding（核心）→ Verification → Merge / CVE 报告
```

| 模式 | 链路 | 场景 |
|------|------|------|
| 增强扫描 | Scan→Triage | 快滤工具误报 |
| 智能审计 | Finding | 深挖高价值洞 / 0day |
| 综合审计 | 两者融合 | 全量审计 |

官方一周测跑宣称约 **30 CVE / 14 项目**（见上游 README 成果表）。  
**不是**线上黑盒扫站器；远程目标仍走 `scope` + 业务杀伤链。

## 2. 大爱仙尊接入

| 能力 | 命令 |
|------|------|
| 知识摘要（无 Docker） | `python3 tools/autocve/bin/ac_pipeline.py knowledge --case <案卷>` |
| 装上游 | `bash tools/autocve/bin/install_upstream.sh` |
| 启全栈 | `bash tools/autocve/bin/ac_start.sh` 或 `--prod` |
| 健康检查 | `python3 tools/autocve/bin/ac_pipeline.py status` |
| 同步漏洞 | `ac_pipeline.py sync --case … --user … --password …` |

UI `http://localhost:3000` · API `http://localhost:8000` · Swagger `/docs`  
产物：`案卷/<案卷>/案卷/autocve/`

## 3. 推荐作业流

1. 授权源码就位（Git clone / 备份还原到本地，**勿**对未授权站乱扫）  
2. （可选）`da_pipeline.py sast --source … --case …` 粗扫 + pay-hint  
3. `ac_start.sh` → 配 LLM（可 Ollama）→ 导入项目 → 选 **智能审计/综合审计**  
4. 跟踪 Agent Tree / Verification  
5. `ac_pipeline.py sync` 落案卷；CVE 报告按上游模板导出  
6. 若洞在**已授权线上实例**可验证 → 再开对应黑盒 Playbook（Spring / 假支付等）

## 4. 与专用杀伤链优先级

```text
case-triage
  → 业务专用（假支付 / ACG共享货 / PocketBase / Spring / LiteLLM / free-claim…）
  → DeepAudit SAST / AutoCVE Finding（有源码时）
  → 广谱 nuclei
```
