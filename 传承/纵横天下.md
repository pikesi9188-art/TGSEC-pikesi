# 纵横天下移动

> 通过已建立的 SOCKS5 隧道，对内网快速测绘、识别高价值节点。  
> 工具：`tools/tunnel-kit/internal_scan.py`  
> 前置：`传承/太白云生·飞鹤游天.md`（tunnel-kit 建通 SOCKS5）

---

## 快速工作流

```
拿到 shell / SOCKS5 隧道
 └─ doctor 检查工具
     └─ ping 存活扫描
         └─ portscan 端口扫描
             └─ webfp Web 服务指纹
                 └─ 发现高价值节点 → 专用 Skill（actuator/nacos/gva 等）
                 └─ lateral SMB 横向（netexec）
```

---

## 1. 环境检查

```bash
python3 tools/tunnel-kit/internal_scan.py doctor
```

工具状态：

| 工具 | 安装方法 |
|------|---------|
| nmap | `brew install nmap` |
| naabu | `go install github.com/projectdiscovery/naabu/v2/cmd/naabu@latest` |
| httpx | arsenal bin 或 PD go install |
| netexec | `pip install netexec` |
| proxychains4 | `brew install proxychains-ng` |

---

## 2. 存活扫描

```bash
python3 tools/tunnel-kit/internal_scan.py ping \
  --cidr 10.0.0.0/24 \
  --socks 127.0.0.1:1080 \
  --case 站点_日期
```

输出：`案卷/.../internal/alive_hosts.json`

---

## 3. 端口扫描

```bash
python3 tools/tunnel-kit/internal_scan.py portscan \
  --cidr 10.0.0.0/24 \
  --ports "22,80,443,3306,6379,8080,9200,27017" \
  --socks 127.0.0.1:1080 \
  --case 站点_日期
```

默认扫描端口（涵盖数据库/中间件/Web）：  
`21,22,23,25,80,443,445,1433,1521,3306,3389,5432,5900,6379,8080,8443,8888,9200,27017`

---

## 4. Web 指纹识别

```bash
# 用端口扫描产出的地址列表
python3 tools/tunnel-kit/internal_scan.py webfp \
  --targets 案卷/.../internal/ports.json \
  --socks 127.0.0.1:1080 \
  --case 站点_日期
```

输出：`案卷/.../internal/webfp.json`（含 title / tech-detect / status）

---

## 5. SMB 横向

```bash
# 枚举 SMB 共享（匿名）
python3 tools/tunnel-kit/internal_scan.py lateral \
  --target 10.0.0.5 \
  --socks 127.0.0.1:1080 \
  --case 站点_日期

# 指定凭据
python3 tools/tunnel-kit/internal_scan.py lateral \
  --target 10.0.0.5 \
  --user administrator --password 'P@ssw0rd' \
  --socks 127.0.0.1:1080 \
  --case 站点_日期
```

## 6. 高价值节点分流

| 发现 | 下一步 |
|------|--------|
| `/actuator` | `spring-actuator-cloud-takeover` Skill |
| Nacos 8848 | `nacos-unauth.yaml` + Gateway Playbook |
| Redis 6379 未鉴权 | `redis-cli -h ... KEYS '*token*'` |
| MySQL 3306 弱口令 | `nmap --script mysql-brute` / `netexec` |
| 9200 ElasticSearch | `curl http://10.x.x.x:9200/_cat/indices` |
| 27017 MongoDB 无鉴权 | `mongo --host ... --eval "db.adminCommand({listDatabases:1})"` |
| GVA 后台 | `ginvue-admin-stealth-takeover` Skill |

---

## 注意

- 生产环境隧道和扫描操作须有明确授权；大 CIDR 用 `--ports` 缩小范围。
- proxychains DNS 泄漏：`proxy_dns` 选项已在临时 conf 中默认开启。
- naabu 比 nmap 快 5–10x，优先选用；nmap 用于详细版本指纹（`-sV`）。
