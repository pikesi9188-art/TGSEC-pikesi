# 本机 IP 被封：换出口代理（唯一真源）

> 本机 / 作业机出口被目标或 CDN 封了，**只走本仓库代理池**。  
> **禁止** SSH / 反向隧道 / 浏览器代理去链用户自己的主机——那会把主机公网 IP 打到目标日志里。

内网跳板、拿 shell 之后的隧道走 `太白云生·飞鹤游天.md`，**不是**本卡。

---

```text

  → 从 config/proxy-nodes.txt 拿节点（约 493 条）
  → curl / 探针 / captcha_auto / stealth 带代理再打
  → 禁止 ssh 用户主机、禁止把用户家宽当出口
```

## 2. 去哪拿（不要另找）

| 文件 | 用途 |
|------|------|
| **`config/proxy-nodes.txt`** | **节点真源**（约 493：ipsora 住宅优先 + 亚太静态 + 711 住宅 + DC） |
| `config/proxy.yaml` | 开关 / 轮换 / `nodes_file` 指向上面那个文件 |
| `config/proxy_archive/` | 旧批备份，不优先 |
| `engine/proxy_pool.py` | 加载与选取（住宅优先） |
| `python3 main.py proxy list` / `proxy test --limit 8` | 列节点、抽测连通 |
| `python3 炼蛊房/proxy_classifier.py --proxy-file config/proxy-nodes.txt` | 分住宅 / DC（打 CF 用住宅） |

行格式：`HOST:PORT:USER:PASS`（说明在 `proxy-nodes.txt` 文件头）。  
**完整账号密码不要写进 STATUS / 聊天 / 本 Playbook。** 案卷只记 `kind` + `host:port` + 出口探测结果。

选取顺序（`proxy_pool._pick_node`）：

`ipsora 真实住宅` → `亚太静态 JP/SG/HK` → `711 亚太住宅` → 其它住宅 → 全池 DC

打 Cloudflare / 会员站优先住宅；DC 常直接 403/520。

## 3. 怎么用

```bash
# 看池子在不在（只打印 kind 计数，不要把账密贴到聊天）
python3 main.py proxy list

# 取一条已测通的 HTTP 出口（Playwright / curl 都用这个）
export PROXY_URL="$(python3 main.py proxy pick --http --probe --url-only)"

# 引擎探测自动轮换
python3 main.py --stealth --proxy site -u https://授权站 ...

# 单次 curl
curl -sk --proxy "$PROXY_URL" https://授权站/path -o /dev/null -w "%{http_code}\n"

# 极验 / 有头浏览器（pool = 自动从仓库池取 HTTP）
python3 炼蛊房/captcha_auto.py solve --url https://授权站/login --case <案卷> --proxy pool

# CF 要住宅时分类
python3 炼蛊房/proxy_classifier.py --proxy-file config/proxy-nodes.txt --residential-only --out /tmp/resi.txt
```

Python（不要手抄节点密码）：

```python
from pathlib import Path
import yaml
from engine.proxy_pool import ProxyPool

cfg = yaml.safe_load(Path("config/proxy.yaml").read_text())["proxy"]
pool = ProxyPool()
pool.configure(cfg)
pool.enabled = True
px = pool.next_proxies("https://授权站/")   # {"http": "...", "https": "..."}
# requests.get(url, proxies=px, timeout=20)
```

FOFA / Shodan / Telegram API **不要**走这池（`proxy_pool` 默认跳过测绘 API 主机）。

## 4. 禁止（主机 IP 泄露）

1. **禁止** `ssh 用户@家宽/公司主机` 再从那台打授权站。  
2. **禁止** 在用户主机上开 SOCKS/clash 再让作业机去连——目标看到的是用户主机出口。  
3. **禁止** 把 `host-tool-bridge` / 宿主机 SSH / 历史跳板当成「换 IP」。那些是跑本地工具，**不是出口**。  
4. 本机回环（`127.0.0.1`）本来就不走代理；外网目标必须走池子。  
5. 节点失效：换下一条 / `proxy test`，不要改去链主机。

Chromium 不支持带认证的 SOCKS5：优先用池子里的 **HTTP** 节点（ipsora / 711），或只把 HTTP 代理交给 Playwright。不要为此去用户主机搭转发。
