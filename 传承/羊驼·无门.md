# Ollama 未授权 API 手法

> Skill：`杀招/羊驼无门`  
> 工具：`炼蛊房/ollama_unauth_probe.py` · nuclei `ollama-unauth-api.yaml`  
> 情报：HITCON ZD-2026-00572（校园 Ollama 未授权）  
> 红线：仅 `授权范围`。默认 **只 GET**。

---

## 1. 一句话

Ollama 默认把 HTTP API 绑在 `0.0.0.0:11434`。未授权 `GET /api/tags` 即可列模型。HITCON 2026 已有高校案例。本卡先确认暴露面，不拉模型、不对话、不写文件。

---

## 2. 指纹

| 信号 | 路径 |
|------|------|
| 版本 | `GET /api/version` → JSON `version` |
| 模型列表 | `GET /api/tags` → `models` |
| 运行中 | `GET /api/ps` |
| 常见口 | `:11434` · 反代到 `/` 或 `/ollama/` |

```bash
python3 炼蛊房/nday_route.py -u https://授权站 --case <案卷>
python3 炼蛊房/ollama_unauth_probe.py --base https://授权站 --case <案卷>
python3 炼蛊房/ollama_unauth_probe.py --base https://授权站 --case <案卷> --deep
python3 tools/1day-kit/od_kit.py nuclei --url https://授权站 --case <案卷> \
  -t tools/1day-kit/custom-templates/ollama-unauth-api.yaml
```

---

## 3. 档位

| 档 | 动作 | 成功证据 |
|----|------|----------|
| **L1** | version JSON 或标题 Ollama | 空 200 / 泛 404 |
| **L2** | 未授权 tags 列模型，或 `generate` 对假模型回 400/404（无 401） | 只开了 11434 |
| **L3** | generate / pull / 路径穿越写文件 | 先问。相关编号只作知情：CVE-2024-37032（pull digest）、CVE-2026-7020（digestToPath）、CVE-2026-42249（Windows 更新写文件） |

公开危险面（不默认跑）：`POST /api/generate`、`/api/pull`、`/api/push`、`/api/delete`、rogue OCI registry。
