## 1. 一句话

2026-08-15 Tenable 新洞里，WP 插件出现一批 **未认证就能种管理员会话、改支付状态、或写/删文件** 的面。授权内默认打到 L2（能进后台或账本变了），不要停在 readme。假支付主卡打 notify 阴性后，预约日历这两条可以 **不经过支付网关改账本**。

## 3. 档位（授权内直接跑）

| 档 | CVE | 动作 | 成功证据 |
|----|-----|------|----------|
| **L1** | 任一条 | 插件 readme | 版本 ≤ 受影响 |
| **L2 ATO** | 15341 / 15303 | REST 枚用户 + 猜 `admin@host`，种 cookie 后打 `/wp-admin/` | 已登录后台（含管理员邮箱） |
| **L2 假付** | 8840 / 12128 | `--reservation` 标已付或 `--price` 改价 | 订单态/结账价差分 |
| **L3 文件** | 14484 / 15965 | `--delete <路径>` / `--upload <文件>` | 删除或上传成功 |

### 15341（弱 AES）

未注册 `ussync-key` 槽 → 密钥 `md5('')`，IV `md5('another-secret')[:16]`，AES-256-CBC。  
`ussync-ref` 加密目标邮箱。参数：`ussync-key` `ussync-token` `ussync-ref`。

### 15303

`admin-ajax.php?action=six_storage_create_wp_user`。body 带目标邮箱（脚本会轮询常见字段名）。

### 8840 / 12128

不走 Epay notify。直接写 payments 表或 `price_total`。成功口径：**账本/结账价变了**，不是 HTTP 200。
