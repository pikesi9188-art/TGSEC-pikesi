# TG 号码管理系统接管手法

> 探针：`炼蛊房/tg_number_admin_probe.py`  
> 杀招：`太白云生·号册主府`  
> 对照：本库 `tg-account-library` 管的是**自己的** session 号库；本卡打的是**号商后台**（FOFA 标题「TG号码管理」）。  
> 红线：仅授权实例。默认弱口 + settings/export **只读头**。禁止改原超管密、禁止百万级拖号、禁止植入后门账号（先问）。

---

## 1. 指纹

| 信号 | 值 |
|------|----|
| 标题 | `TG号码` / `TG号码管理` + 登录 |
| FOFA（必须带授权域/IP） | `title="TG号码管理" && host="<授权>"` |
| 登录页注释 | 「首次部署后请立即修改默认密码」 |
| 默认口 | `admin` / `admin123`（同套源码多实例，未必全中） |
| 路由 | `/settings/` · `/settings/user/*` · `/settings/carrier/*` · `/batches/` · `/export/download/{id}` |

同源码多开：一口令中 2/3 也常见，未中的实例换口或打未授权导出，不要改已接管实例的原密去撞另一台。

---

## 2. 立刻跑

```bash
python3 炼蛊房/tg_number_admin_probe.py doctor
python3 炼蛊房/tg_number_admin_probe.py --base https://授权实例 --case <案>
```

---

## 3. 档位

| 档 | 动作 | 成功证据 |
|----|------|----------|
| **L1** | 标题 / 登录页默认口提示 | 确认号管系统 |
| **L2a** | `admin/admin123` 登录 | 进后台 Cookie / 跳转 `/batches` |
| **L2b** | `/settings/` 泄露表结构（`phone_numbers` / `export_items` / SQLite tabDB） | 他人 × 读 配置 |
| **L2c** | `/export/download/{id}` 无鉴权或登录后可下 | **只取状态码 + Content-Type + 前 80 字节**；证明拖号面即可 |
| **L2d** | 扒 JS 收齐 `/settings/user/add` 等 | 路由清单进案卷 |
| **先问** | `user/add` 植号、`change_password` 改原用户、整表/44GB 主库下载 | 改超管密 / 清数据级 |

对象矩阵：登录成功先填「自己 × 读/配置」；`export/download` 无鉴权填「他人 × 读」。

---

## 4. 不要和邻卡混

| 邻卡 | 区别 |
|------|------|
| `tg-account-library` | 本机 `_tg_accounts/` session 入库 |
| `tg-cloud-panel` | 云控 / Fernet / WASM |
| `tg-bot-nextauth-takeover` | NextAuth 技能沙箱 |
| `autonomous-social-engagement` | 技术面穷尽后的社工 |

- [ ] 未改原超管密、未默认全量 export
