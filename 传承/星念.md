# 大爱仙尊 GraphQL 作业手法

> 杀招：`星念`  
> 摸面：`python3 炼蛊房/jwt_gql_probe.py`  
> 越权：`python3 炼蛊房/gql_authz_probe.py`  
> 专卡：GitLab `/api/graphql` 走 `gitlab-graphql-unauth`

目标须在 scope。禁止把全 schema dump 进报告。mutation 加款/删用户仍先问。

---

## 1. 立刻跑

```bash
python3 炼蛊房/jwt_gql_probe.py -u https://授权站 --case <案>
python3 炼蛊房/gql_authz_probe.py introspect --url https://授权/graphql --case <案>
python3 炼蛊房/gql_authz_probe.py query --url https://授权/graphql \
  --query '{ user(id:1){id email} }' --case <案>
python3 炼蛊房/gql_authz_probe.py swap --url https://授权/graphql \
  --query '{ user(id:1){id email} }' --ids 1,2 \
  --header 'Authorization: Bearer <票>' --case <案>
python3 炼蛊房/gql_authz_probe.py batch --url https://授权/graphql \
  --query '{ __typename }' --case <案>
```

产物：`案卷/gql_authz/`。

---

## 2. 四刀

1. **找口** — `/graphql` `/api/graphql` `/gql`；`jwt_gql` 先摸  
2. **introspection** — `__schema`、`__type(name:"Query")`、换行、GET `?query=`  
3. **未授权 / 换号** — 无票能出 `data` 才是未授权读；`swap` 两个 id 都有 data 且 body 不同才是 IDOR  
4. **放大** — JSON 数组 batch、别名 `a0: field`。限流按「一次请求」算就被绕

禁 introspection 不要结案，换 `__type` / 前端里的 query 名再打。

---

## 3. 档位

| 档 | 成立 |
|----|------|
| L1 | 端点认 GraphQL（报错/语法） |
| L2 | 无票读到 data，或换 id 读到不同对象，或 batch/别名放大 |
| L3 | mutation 改权/改他人对象（破坏性先问） |
