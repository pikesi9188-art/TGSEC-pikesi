# Android APK 动态分析 · Frida Hook 手法

> 更新：2026-08-13  
> 前置：`apk-recon` Skill 静态分析已完成，找到目标类名/方法名  
> 客户端安全全表：`安器·清单.md`（本卡只负责 Hook / pinning / 脱壳）  
> 工具：Frida · objection · `炼蛊房/apk_recon.py`  
> 适用：博彩站 APP 内 JS 拿不到的加密接口、证书固定绕过、明文抓包  
> 红线：只 Hook 授权目标 APP，不Hook系统组件或他人 APP。  
> 壳 / 动态 DEX：**不要先上 Frida 脱壳**（360/爱加密/梆梆企业版对 Frida 是纵深检测）。本机有 BlackDex/FART/eBPFDexDumper 再用。加密 so 先 dump。闪退先看 `.init`/`JNI_OnLoad`。分流见 `逆骨·分科.md` §3。

## 0. 环境准备

### 0.1 主机端

```bash
# 安装 Frida 和工具
pip install frida-tools objection

# 验证
frida --version   # ≥16.x
objection --version
```

### 0.2 设备端（选一）

**方案 A：Root 真机 / 模拟器（推荐，稳定）**
```bash
# Android 模拟器（Genymotion / AVD x86_64 带 Root）
# 推到设备
adb push frida-server-16.x.x-android-x86_64 /data/local/tmp/frida-server
adb shell chmod 755 /data/local/tmp/frida-server
adb shell /data/local/tmp/frida-server &

# 真机（需要 Root，Magisk + frida-server ARM64）
adb push frida-server-16.x.x-android-arm64 /data/local/tmp/frida-server
adb shell su -c "chmod 755 /data/local/tmp/frida-server && /data/local/tmp/frida-server &"
```

**方案 B：非 Root 设备（objection patch APK）**
```bash
# objection patch（重打包注入 frida-gadget）
objection patchapk --source 目标.apk

# 安装 patched APK
adb install -r 目标.objection.apk
adb shell am start -n com.target.package/.MainActivity
# 启动后 frida-gadget 自动监听
frida -H 127.0.0.1:27042 -n Gadget
```

## 1. 证书固定（SSL Pinning）绕过

博彩站 APP 最常见：自定义证书校验，Burp 无法抓包。

### 1.1 objection 一键绕过（首选）

```bash
# 启动目标 APP
adb shell am start -n com.target.package/.MainActivity

# objection 连接
objection -g com.target.package explore

# 绕过 SSL Pinning（试这几个命令）
android sslpinning disable
android trust_manager disable

# Frida 脚本方式
objection -g com.target.package explore --startup-command "android sslpinning disable"
```

### 1.2 Frida 脚本（更精准）

```javascript
// ssl_bypass.js — 通用 SSL Pinning 绕过
Java.perform(function() {
    // 1. OkHttp3 CertificatePinner 绕过
    try {
        var CertificatePinner = Java.use("okhttp3.CertificatePinner");
        CertificatePinner.check.overload("java.lang.String", "java.util.List").implementation = function(hostname, certs) {
            console.log("[SSL Bypass] OkHttp3 CertificatePinner.check called for: " + hostname);
        };
        CertificatePinner.check.overload("java.lang.String", "[Ljava.security.cert.Certificate;").implementation = function(hostname, certs) {
            console.log("[SSL Bypass] OkHttp3 CertificatePinner.check2 called for: " + hostname);
        };
    } catch(e) {}

    // 2. TrustManager 绕过
    try {
        var TrustManagerImpl = Java.use("com.android.org.conscrypt.TrustManagerImpl");
        TrustManagerImpl.verifyChain.implementation = function(untrustedChain, trustAnchorChain, host, clientAuth, ocspData, tlsSctData) {
            console.log("[SSL Bypass] TrustManagerImpl.verifyChain for: " + host);
            return untrustedChain;
        };
    } catch(e) {}

    // 3. Webview SSL error bypass
    try {
        var SslErrorHandler = Java.use("android.webkit.SslErrorHandler");
        SslErrorHandler.cancel.implementation = function() {};
        SslErrorHandler.proceed.implementation = function() {
            console.log("[SSL Bypass] WebView SSL proceed");
            this.proceed();
        };
    } catch(e) {}

    // 4. HttpsURLConnection 绕过
    try {
        var HttpsURLConnection = Java.use("javax.net.ssl.HttpsURLConnection");
        HttpsURLConnection.setDefaultHostnameVerifier.implementation = function(verifier) {
            console.log("[SSL Bypass] setDefaultHostnameVerifier");
        };
    } catch(e) {}

    console.log("[SSL Bypass] 所有 SSL Pinning 已绕过");
});
```

```bash
# 执行绕过
frida -U -f com.target.package -l ssl_bypass.js --no-pause
# 或注入到已运行的进程
frida -U -n "目标APP名" -l ssl_bypass.js
```

绕过后，Burp Suite 设为系统代理即可正常抓包：
```bash
adb shell settings put global http_proxy <你的IP>:8080
```

## 2. Hook 加密函数（抓明文）

博彩站加密常用 AES-CBC，找加密类名后 hook 入参/出参。

### 2.1 先找加密类（静态分析）

```bash
# 用 apk-recon 静态扫
python3 炼蛊房/apk_recon.py --apk 目标.apk --out /tmp/apk_out/ --case <案卷>

# 或 jadx 反编译后 grep
jadx -d /tmp/apk_decompile 目标.apk
grep -r "AES\|Cipher\|encrypt\|decrypt\|sign\|md5\|sha256" /tmp/apk_decompile/sources/ -l
```

### 2.2 Hook AES 加解密

```javascript
// hook_crypto.js
Java.perform(function() {
    var Cipher = Java.use("javax.crypto.Cipher");

    Cipher.doFinal.overload("[B").implementation = function(input) {
        var result = this.doFinal(input);
        var algorithm = this.getAlgorithm();
        console.log("\n[Cipher.doFinal]");
        console.log("算法: " + algorithm);
        console.log("输入(hex): " + bytesToHex(input));
        console.log("输出(hex): " + bytesToHex(result));
        try {
            console.log("输入(utf8): " + Java.use("java.lang.String").$new(input, "UTF-8"));
            console.log("输出(utf8): " + Java.use("java.lang.String").$new(result, "UTF-8"));
        } catch(e) {}
        return result;
    };

    function bytesToHex(bytes) {
        var hex = [];
        for(var i = 0; i < bytes.length; i++) {
            hex.push(('0' + (bytes[i] & 0xFF).toString(16)).slice(-2));
        }
        return hex.join('');
    }

    console.log("[Hook] Cipher.doFinal 已 Hook");
});
```

### 2.3 Hook 自定义加密类（针对具体 APP）

```javascript
// hook_custom.js — 替换为实际类名
Java.perform(function() {
    // 示例：Hook com.target.util.CryptoUtil.encrypt(String) → String
    var CryptoUtil = Java.use("com.target.util.CryptoUtil");

    CryptoUtil.encrypt.overload("java.lang.String").implementation = function(plaintext) {
        console.log("\n[CryptoUtil.encrypt]");
        console.log("明文: " + plaintext);
        var result = this.encrypt(plaintext);
        console.log("密文: " + result);
        return result;
    };

    CryptoUtil.decrypt.overload("java.lang.String").implementation = function(ciphertext) {
        console.log("\n[CryptoUtil.decrypt]");
        console.log("密文: " + ciphertext);
        var result = this.decrypt(ciphertext);
        console.log("明文: " + result);
        return result;
    };

    console.log("[Hook] CryptoUtil 已 Hook，等待调用...");
});
```

## 3. Hook 网络请求（直接抓接口）

```javascript
// hook_okhttp.js — 拦截 OkHttp3 请求/响应
Java.perform(function() {
    var OkHttpClient = Java.use("okhttp3.OkHttpClient");
    var Request = Java.use("okhttp3.Request");
    var Buffer = Java.use("okio.Buffer");

    // Hook RealCall.execute（同步请求）
    var RealCall = Java.use("okhttp3.internal.connection.RealCall");
    RealCall.execute.implementation = function() {
        var request = this.request();
        console.log("\n[OkHttp] → " + request.method() + " " + request.url());
        console.log("[OkHttp] Headers: " + request.headers());

        // 打印 body
        var body = request.body();
        if(body !== null) {
            var buf = Buffer.$new();
            body.writeTo(buf);
            console.log("[OkHttp] Body: " + buf.readUtf8());
        }

        var response = this.execute();
        console.log("[OkHttp] ← " + response.code());
        return response;
    };

    console.log("[Hook] OkHttp3 请求拦截就绪");
});
```

## 4. 枚举 APP 内所有类方法

```bash
# objection 枚举
objection -g com.target.package explore
# 列举类
android hooking list classes | grep -i "crypto\|encrypt\|sign\|api\|net\|http"
# 列举方法
android hooking list class_methods com.target.util.CryptoUtil
# 一键 hook 某个类的所有方法（观察调用链）
android hooking watch class com.target.util.CryptoUtil --dump-args --dump-backtrace --dump-return
```

## 5. 拿到接口后直接 curl

Hook 到明文请求后，提取 headers / body，用 curl 重放：

```bash
# 示例：Hook 到 /hall/api/member/info 的真实请求格式
TOKEN="从 Hook 到的 token"
curl -sk "https://cloudht.yzgj88.vip/hall/api/member/info" \
  -H "Authorization: Bearer $TOKEN" \
  -H "x-data-mode: json_cipher" \
  --proxy "socks5h://USER:PASS@HOST:PORT"
```

## 6. 常见失败处理

| 问题 | 原因 | 解决 |
|------|------|------|
| frida-server 连不上 | 端口未开 / 版本不匹配 | `adb forward tcp:27042 tcp:27042` |
| SSL Pinning 还在 | APP 自实现 TrustManager | 用 IDA 找校验函数再精准 hook |
| 混淆类名 | R8/Proguard 混淆 | jadx 看 mapping，找特征字符串 |
| Root 检测 | APP 检测 su | objection root bypass / Magisk Hide |
| 模拟器检测 | 检测 `goldfish` / `generic` | 改 build.prop / 用真机 |
