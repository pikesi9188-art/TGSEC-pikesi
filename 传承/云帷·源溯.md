# CDN / 源站溯源

> 在授权范围内找出 CDN/WAF 背后的真实源站 IP。  
> 精炼 26 法：`tools/vendor/01-recon/cdn-origin-tracing/SKILL.v4.md`  
> 加厚 50 法：同目录 `SKILL.md`（v5）  
> 作业入口：`炼蛊房/origin_recon.py` · `space_search.py cert-origin`

## 心智

单方法不够稳。推荐顺序：

```text
crt.sh / 证书指纹 → 子域名枚举 → 历史 DNS / 被动 DNS
  → 空间引擎（FOFA/Shodan/Censys/ZoomEye/Quake）
  → Host 头直连验证 → 非 CDN 段才进攻击面
```

## 命令

```bash
# 综合（FOFA + cdn_tracer）
python3 炼蛊房/origin_recon.py --domain 授权根域 --case <案卷>

# 证书反查（需 config.yaml 引擎 Key）
python3 tools/space-search/bin/space_search.py cert-origin \
  --domain 授权根域 --case <案卷>

# 直调 tracer
python3 tools/vendor/01-recon/cdn-origin-tracing/cdn_tracer.py 授权根域 -o /tmp/cdn.json
```

证据：`案卷/<案卷>/案卷/origin.json`

## 硬规则

- 授权外域名/IP 不验证、不开打。  
- CDN 段 IP 过滤后再报「疑似源站」。  
- 验证必须带正确 `Host:`；HTTPS 优先。
