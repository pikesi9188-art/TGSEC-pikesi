## 1. 一句话

公开部署的 **Langflow**（Python 低代码 LLM 工作流）有多条并行未授权面，**不要只打 auto_login**：

| CVE / 面 | 入口 | 要点 |
|----------|------|------|
| **CVE-2025-3248** | 无票 `POST /api/v1/validate/code` | 验证端点把用户代码当装饰器执行；样本 1.0.19.post2 |
| **CVE-2026-9198** | `GET /api/v1/auto_login` → 持超管 JWT 打 `validate/code` | OSS 1.0.0–1.10.0；KEV；修 **1.10.1+** |
| **CVE-2026-0770** | `validate` + `exec_globals` | 与 9198 **并行测** |
| **WAF `%0a`** | 路径里换行编码 | nginx 按前缀拦 `/api/v1/validate`，未规范化 `%0a` 时 403→业务响应 |
| 历史 | CVE-2024-37393 / `/api/v1/run` 无鉴权 Flow | 旧面，指纹到仍记 |

AI 编排面常挂 LLM Key、向量库、内网回调。未授权进控制面 = 直接 L2，不必先撞弱口。

## 3. WAF 换行绕过（学习样本）

样本前置 nginx 对 `validate/code` 回 403。根因：WAF 按**路径前缀**匹配，未对 URL 解码后的换行做规范化；后端解析与 WAF 解析不一致。

detect 会对无害 `{"code":"def _probe(): return 1"}` 比较：

- `/api/v1/validate/code`
- `/api/v1/%0avalidate/code`
- `/api/v1/validate%0a/code`

普通路径 403、编码路径 200/400/422 且 body 含 `errors`/`valid` = **L2 WAF 差分成立**。  
不把 `%0a` 自动接到 exploit。

## 4. RCE 后横向（学习样本，概念级）

```
容器 root
  → 环境凭据（超管 / DB / API Key）
  → 业务库 + 第三方 BaaS（只记表数/行数，敏感值不进可同步文档）
  → 云元数据令牌（concealment 未开）
  → 存储桶只读枚举
  → 云函数源码里的部署 SA 私钥 → 高权限令牌
  → 实例/快照/磁盘/防火墙全读
```
