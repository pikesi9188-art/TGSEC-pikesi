# PocketBase 规则误配手法

> Skill：`杀招/口袋库`  
> 指纹：`tools/1day-kit/custom-templates/pocketbase-admin-ui-exposed.yaml`  
> 常见伴随：Hostinger Horizons · `/hcgi/platform`  
> 红线：仅授权目标；改超管密码默认先问

---

## 1. 一句话

PocketBase 集合 **API rules 过松**（匿名读/登录写）或 **`/_/` 管理 UI 暴露**（超管未设密）→ 业务数据/后台可拿。  
业务 admin 与 PB `_superusers` **分流测**，勿混成一个登录框。

---

## 2. 指纹

| 信号 | 路径 |
|------|------|
| Admin UI | `/_/` |
| Health / 集合 | `/api/health` · `/api/collections` |
| 超管集合名 | `_superusers` |

```bash
python3 tools/1day-kit/od_kit.py nuclei --url https://授权站 --case <案卷> \
  --template-id pocketbase-admin-ui-exposed
```

---

## 3. 档位

| 档 | 动作 | 成功证据 |
|----|------|----------|
| **L1** | UI/API 指纹 | 确认 PocketBase |
| **L2** | 匿名 list/view 规则 | 未登录可读敏感集合 |
| **L3** | 登录写 / 安装向导 / 超管 | 可写或超管会话；BOLA/Mass Assignment 补测 |

细节与 403 绕过矩阵走 Skill 全文，本卡只定分流。

---

## 4. 复工条件示例
