## 1. 一句话

Crocoblock **JetEngine ≤3.8.14** 被报未认证模板注入 RCE。本库只核对插件版本；没有公开注入点就不打模板表达式。

---

## 2. 指纹

```bash
python3 炼蛊房/jetengine_surface_probe.py --base https://授权站 --case <案卷>
python3 tools/1day-kit/od_kit.py nuclei --url https://授权站 --case <案卷> \
  -t tools/1day-kit/custom-templates/jetengine-rce-cve-2026-66613.yaml
```

路径：`/wp-content/plugins/jet-engine/readme.txt`  
影响：`Stable tag` ≤ `3.8.14`。修：`3.8.14.1+`。

其它 WP 未授权插件（ussync / 6storage / 预约假付）仍走 `wordpress-plugin-unauth-takeover`，不要和本卡混。
