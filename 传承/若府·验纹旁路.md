# 若依验证码 Redis 旁路手法

> Playbook：`若依四海杀伤链.md`  
> 指纹：`tools/1day-kit/custom-templates/ruoyi-unauth-captcha-redis.yaml`  
> 同族：若依 / 四海 / 芋道（裕道）常见 `/captchaImage`  
> 红线：仅授权；打 Redis 写 key 先确认 scope 含 Redis 面

---

## 1. 一句话

登录依赖 **图形验证码 uuid**，验证码明文/哈希落在 **Redis**（`captcha_codes:*`）→  
`/captchaImage` 可拿 uuid + Redis 未鉴权/可读 → **旁路验证码登录** → 再撞弱口令/已知洞。

---

## 2. 指纹

| 信号 | 说明 |
|------|------|
| `GET /captchaImage` 或 `/code` | JSON 含 `img` + `uuid` |
| 若依味 | `RuoYi` / `若依` / 四海后台静态资源 |
| Redis | 6379 未授权或弱口令（内网/旁注） |

```bash
python3 tools/1day-kit/od_kit.py nuclei --url https://授权站 --case <案卷> \
  --template-id ruoyi-unauth-captcha-redis
```

---

## 3. 档位

| 档 | 动作 | 成功证据 |
|----|------|----------|
| **L1** | captcha 接口暴露 | 稳定返回 uuid |
| **L2** | Redis 读到对应 captcha | 验证码可复现 |
| **L3** | 带正确码登录 | 拿到后台会话；再接若依杀伤链 |

无 Redis 面时： captcha OCR（`captcha-ocr`）或换弱口令/其他洞，勿死磕。  
旁注 6379 未授权（不绑 captcha）走独立卡：`契柜·无门.md` · `redis_unauth_probe.py`。  
先探 Druid 抽 JDBC/旁路 Redis：`仓算·监.md` · `java_web_surface_probe.py --stack druid`。

---

- [ ] Redis 在 scope 且可读，或 OCR 旁路成立  
- [ ] 后台会话已落 `接管/session`
