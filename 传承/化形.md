## 1. 一句话

PHP 站出现 `unserialize(`、phar 上传、Laravel `APP_KEY`、ThinkPHP 缓存反序列化时用本卡。  
探针只认 **序列化 Cookie**，不生成 gadget。

```bash
python3 炼蛊房/core_web_surface_probe.py -u https://授权站 --case <案卷>
# findings.family == php-unserialize
```
