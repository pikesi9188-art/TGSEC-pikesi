# 大爱仙尊 SSI / ESI 作业手法

> 杀招：`注门·2`  
> 工具：`python3 炼蛊房/ssi_esi_probe.py --base https://授权站 --case <案>`  
> 模板引擎走 `ssti-exploit`。Java EL 走 `expression-language-injection`。

目标须在 scope。`.shtml` / nginx SSI / Akamai·Varnish ESI 才是这张卡。

---

## 1. 立刻跑

```bash
python3 炼蛊房/ssi_esi_probe.py --base https://授权站 --case <案>
# 回显成立后再加深（exec / 外带 include）
python3 炼蛊房/ssi_esi_probe.py --base https://授权站 --case <案> --deep
```

产物：`案卷/ssi_esi/`。

---

## 2. 四刀

1. **认解析器** — 路径 `.shtml` / 头 `Surrogate-Control` / `Edge-Control`；参数回显仍带 `<!--#` 是没解析  
2. **无害回显** — `<!--#echo var="DATE_LOCAL" -->`、`DOCUMENT_NAME`、`<!--#printenv -->`  
3. **include** — `virtual` / `file` 读已知静态；ESI `<esi:include src="…">`  
4. **加深** — `--deep` 才打 `<!--#exec cmd="id" -->`；外带 include 只用自己的探测 URL

负对照：同一参数放纯文本 `se-ssi-neg`，页面本来就有日期不算阳性。

---

## 3. 档位

| 档 | 成立 |
|----|------|
| L1 | echo/printenv 被吃掉，响应里出现解析后的值 |
| L2 | include 读到站内文件或 ESI 拉了探测路径 |
| L3 | exec 回 `uid=` / `se-ok`，或外带确认 |

单次反射原样注释 = 阴性，换点再打，不要结案。
