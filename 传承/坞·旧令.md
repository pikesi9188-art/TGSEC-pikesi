# WordPress xmlrpc 暴露面手法

> Skill：`杀招/坞·旧令`  
> 工具：`炼蛊房/wp_xmlrpc_probe.py` · nuclei `wordpress-xmlrpc-surface.yaml`  
> 情报：HITCON 多次 xmlrpc.php 暴露 / wp2shell（ZD-2026-00858、00864、00937）  
> 红线：只 `listMethods`。禁止 multicall 爆破、禁止 pingback 打内网。

---

## 1. 一句话

`/xmlrpc.php` 开着就能 `system.listMethods`。若有 `system.multicall` 就是撞密加速面；有 `pingback.ping` 就是 SSRF 面。HITCON 把「暴露」本身当通报。本卡先钉方法列表。

---

## 2. 指纹

| 信号 | 路径 |
|------|------|
| 说明页 | `GET /xmlrpc.php` → `XML-RPC server accepts POST requests only` |
| 方法表 | `POST` `system.listMethods` |
| 常见前缀 | `/` · `/wp/` · `/blog/` · `/wordpress/` |

```bash
python3 炼蛊房/nday_route.py -u https://授权站 --case <案卷>
python3 炼蛊房/wp_xmlrpc_probe.py --base https://授权站 --case <案卷>
python3 tools/1day-kit/od_kit.py nuclei --url https://授权站 --case <案卷> \
  -t tools/1day-kit/custom-templates/wordpress-xmlrpc-surface.yaml
```

## 3. 档位

| 档 | 动作 | 成功证据 |
|----|------|----------|
| **L1** | xmlrpc 存活或 listMethods 成功 | 403/404 |
| **L2** | 方法含 `system.multicall` 或 `pingback.ping` | 没撞密也算面 |
| **L3** | 凭据碰撞 / pingback SSRF / 上传目录遍历 | 默认不做 |
