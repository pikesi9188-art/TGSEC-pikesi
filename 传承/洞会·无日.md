# HITCON ZeroDay 情报落库手法

> 站点：https://zeroday.hitcon.org  
> Skill：`杀招/洞会`  
> 工具：`炼蛊房/hitcon_zd_harvest.py`  
> 快照：`docs/intel/hitcon-zeroday/`

公开通报平台，用来 **学手法、补本库卡**。通报里的学校 / 医院 / 公司 **不是授权目标**。

## 3. 2026 窗口：高频族 → 本库

| 族 | HITCON 信号（例） | 走 |
|----|-------------------|----|
| Ollama 未授权 | ZD-2026-00572 台大電機 Ollama | **`ollama-unauth`** |
| PHP-CGI RCE | ZD-2026-00944 等反复出现 CVE-2024-4577 | **`php-cgi-cve-2024-4577`** |
| WP xmlrpc | xmlrpc.php / pingback / multicall / wp2shell | **`wordpress-xmlrpc-surface`**；已落地马 → 高熵狩猎 |
| 弱口后台 | 後台弱密碼、E-ORDER POS | `auth-brute` |
| SQLi | 後台 / 學號 / WP SQLi | `core-web-vuln-kit` + sqlmap_kit |
| 路径穿越 / 目录遍历 | 網頁目錄遍歷、檔案讀取泄凭据 | `lfi-rfi-exploit` |
| IDOR / BOLA | 只用 user id、只验登录不验权、权限管理失效 | `idor-bola-chain` · `rbac-bypass-authz` · 对象矩阵 |
| 客户端状态窜改 | 驗證狀態可竄改 → 免费骑乘 / 购物逻辑 | **`client-state-skip`** · 对象矩阵 |
| 源站 IP 泄 WAF | Origin IP → Akamai 旁路 → OWA | `cdn-origin-tracing` · `cdn-origin-bypass` |
| 信任头 / IP 伪造 | SQL Injection 与 IP 偽造 | **`trusted-ip-header`**（加款另走 cfip 卡） |
| Session / 重置 token | Session Fixation、广告请求泄 reset token | **`reset-token-surface`** |
| 密钥空间缩减 | 金鑰空間縮減、短 token 永久盗用 | **`reset-token-surface`** |
| 开放重定向 | returnUrl / 控制字元 | **`open-redirect-chain`**（探针 `open_redirect_surface_probe`） |
| 已植入 Webshell | 後門、shell、内网扫 | `host-ir-check` · WP 高熵马（不扩情报域） |
| 监视器未授权 | CCTV | **跳过**（不当网站案主线） |

目录开放 / `.LOG` 走 **`sensitive-dir-dump`**。WP SQLi / 付费电子书仍走已有 WP / IDOR 卡。

授权站一条龙：

```bash
python3 炼蛊房/hitcon_chain_probe.py --base https://授权站 --case <案卷>
```

## 4. 何时新开专卡

同时满足才写新 Skill（对照 `房睇长·耳报.md` 六件套）：

1. 本库没有能填格子的专卡  
2. 组件指纹稳定（路径 / 头 / 标题）  
3. 授权站上能跑到 L1，最好 L2 只读证明  
4. HITCON 或在野 **反复出现**，不是一次性业务逻辑

未修高频已落专卡：Ollama、PHP-CGI 4577、WP xmlrpc、客户端状态、敏感目录、重置 token、信任 IP 头、开放重定向。其余弱口/SQLi/IDOR 走已有卡。

---

## 5. 红线

- 禁止把 `*.edu.tw` / 医院 / HITCON Vendor 自动写入 `scope`
- 禁止把详情页账密、内网 IP、完整证件抄进可同步文档
- nuclei / 探针默认指纹或只读；不把公开 RCE POST 写进模板
- 手法复用可以，目标必须另有授权
