## 0. 学到了什么 / 提取到了什么 / 下次能不能用

| 问题 | 答案 |
|------|------|
| 学到了什么 | 2026 一批 WP 被写马：文件名 **恰好 11 位、大小写混用** 的 `.php`，八成藏在 `/wp-includes/`，其余在站点根。共享主机集群会被批量写同一形态。 |
| 提取到了什么 | **规则**（不是 126 个文件名）：`is_campaign_drop_name()`；目录面 `/wp-includes/` 等；ingest 与 scope **重叠检测**。 |
| 下次能用吗 | **能。** 授权 WP → `hunt`；已拿 shell → `host_ir`；又丢来一份「最新 shell 目录」→ `ingest`。 |
| 下次不能用什么 | 把具体 `HDA26hn54Mo.php` 当字典（`62^11` 打不中）；把 `skyliteweb.org` 当新目标；当上传 RCE 用（上传仍走 `file-upload-webshell`，先问）。 |

误报已修：WP 核心 `formatting.php` 也是 11 位字母，但**全小写**。判定必须 **大小写混用**。

## 2. 强制顺序

```
又来一份 shell 目录.txt
  → ingest（统计 + 与授权重叠；禁止 --grant）
  → 有重叠：对授权 host 做 hunt / 已拿 shell 做 host_ir
授权 WP 开案（无清单）
  → hunt 列目录；403 则等主机/日志
已拿 shell
  → host_ir_check（同一规则，排除 formatting.php）
命中
  → STATUS 记路径；授权站已落地马直接连验证，清马先问
```

```bash
python3 炼蛊房/shell_drop_intel.py ingest --file /path/清单.txt --case <案卷>
python3 炼蛊房/shell_drop_intel.py hunt --url https://授权站 --case <案卷>
python3 炼蛊房/host_ir_check.py --case <案卷>
```
