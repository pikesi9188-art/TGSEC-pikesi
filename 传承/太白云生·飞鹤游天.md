# 太白云生·飞鹤游天

> 工具：`tools/tunnel-kit/` · Skill：`杀招/内地道`  
> 本机被封要换**公网出口**：`传承/狼烟.md`（`config/proxy-nodes.txt`）。  
> 本手册只负责 **已拿 shell 之后的内网隧道**。禁止把用户主机 SSH 当成换 IP。

## 选型速查

| 条件 | 优先 |
|------|------|
| 交互 shell + 出站 SSH | `ssh_reverse` |
| 出站 HTTP(S)、要反向 SOCKS | `chisel` |
| 多端口长期跳板 | `frp` |
| 整网段路由漫游 | `ligolo` |
| 已有 SOCKS | `socks_chain`（curl/proxychains） |

```bash
bash tools/tunnel-kit/install_tunnels.sh
python3 tools/tunnel-kit/tunnel_plan.py recommend --have shell --egress http
python3 tools/tunnel-kit/tunnel_plan.py emit --kind chisel --attacker <攻击机IP> --case <案卷>
```

模板：`tools/tunnel-kit/templates/`  
证据：`案卷/<案卷>/案卷/tunnel/`

## 硬规则

1. 目标在 scope。授权内横向 SOCKS/反代直接做。清日志、改超管、改生产 webhook **先问**。
2. 搭好后用内网目标验证（`curl -x socks5h://127.0.0.1:1080 ...`），不要只看 listen。
3. 隧道工具走 `tunnel-kit`；授权主机 C2 落地验 L3 走 `host-c2-verify`（二进制不进本仓）。

## 与多阶段渗透

拿 shell → 本手册出网/进内网 → 再扫内网服务；Web 面仍走业务 Skill / 1day-kit。
