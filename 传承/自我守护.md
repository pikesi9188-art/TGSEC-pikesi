## 2. 档位

| 档 | 看什么 | 成功证据 |
|----|--------|----------|
| **L1** | 用户列表、监听口、`last`、crontab、authorized_keys | JSON 预览非空 |
| **L2** | uid=0 且非 root；`/etc/ld.so.preload` 非空；`rc.local` 含反弹/下载 | `findings` 对应 signal |
| **处置** | 先取证拷贝，再决定是否禁用账号 | 须用户点头；本卡默认不改 |

Windows：本探针不做。用案卷记录 + PCHunter / 火绒剑 / WES-NG（课程 11.4）。

## 3. 时间线（Web 入侵时并行）

1. 记录 `date -u` / 时区  
2. 中间件日志（nginx/apache access + error）按时间戳搜本机出口 IP  
3. `find /var/www/html -name '*.php' -mtime -3`（路径写死，禁止 `-L` 扫全盘）  
   WP 站并行：`wp-includes` / 站点根下 **11 位** `[A-Za-z0-9].php` → `坞壳落子猎.md`  
4. 本卡 IR JSON + `linux_lpe_checker.py --local-only`  
5. 落 `接管/IR.md`：时间线、落点、是否还要隧道  

挖矿/勒索：先隔离出口（本机被封换 `proxy-nodes`，**禁止 SSH 用户家宽当跳板**），再取证。本卡不提供解密器。
