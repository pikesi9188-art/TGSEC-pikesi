# 1day 在野洞情报手法（KEV / EPSS / 公开利用 → 本库对照）

> 源站：[cvebase.io](https://cvebase.io/)（语义 CVE 搜索引擎；NVD+KEV+ExploitDB+Nuclei+厂商通告聚合）  
> 工具：`python3 tools/1day-kit/od_kit.py cvebase …`  
> Skill：`杀招/一日针匣`  
> 红线：仅 `授权范围`；匿名 API ≈ **10 次/日/IP**，有 Key 走 `CVEBASE_API_KEY`

---

## 0. 情报源怎么用（给作业用的口径）

| 能力 | 作业用途 |
|------|----------|
| 语义搜（组件/昵称/ATT&CK） | 指纹后查「有没有公开利用 + KEV」 |
| `/api/cve/{id}` 富化 | EPSS / KEV / 在野 / 有无 PoC·Nuclei |
| `/api/trending` | 每周补课：刚进 KEV 的洞 → 决定要不要写模板/Playbook |
| MCP `https://cvebase.io/mcp` | Cursor 里直接问 CVE（可选，占配额） |

**不是**替代业务 Skill：Actuator/假支付/GVA 仍走专用链；本手法只负责 **1day 情报面**（底层可接 cvebase.io）。  
业务站开打分流见 **`凤九歌·天地歌.md`**；赌博台见 **`凤九歌·认族.md` §6**（cvebase 筛网站向）；设备类 KEV 默认降权，勿抢网站案主线。

---

## 1. 本库命令（先背这三条）

```bash
# 看本周进 KEV / 高 EPSS（省配额，优先）
python3 tools/1day-kit/od_kit.py cvebase trending

# 查单洞（富化 + 可选 exploit 文档列表）
python3 tools/1day-kit/od_kit.py cvebase lookup --cve CVE-2026-72898 --docs

# 语义搜（组件 / 手法）
python3 tools/1day-kit/od_kit.py cvebase search --q "Metabase SQL Injection" --limit 5
python3 tools/1day-kit/od_kit.py cvebase search --q "spring gateway actuator" --limit 5
```

可选环境变量：

```bash
export CVEBASE_API_KEY="cvb_..."   # Free 起；不设则匿名 10/日
```

产物（有 `--case` 时）：`案卷/<案>/案卷/1day/cvebase_*.json`

---

## 2. 决策树（从 cvebase 到动手）

```text
cvebase 命中 CVE
 ├─ 本库已有专用 Playbook/Skill？ → 直接走专用链（勿只跑 nuclei 结案）
 ├─ KEV 或 exploited_in_wild 或 EPSS≥0.5？
 │    ├─ 有公开 Nuclei/PoC → od_kit nuclei / custom-templates 指纹
 │    └─ 无 PoC → 写指纹模板 + STATUS 复工「等公开利用/厂商细节」
 └─ 仅 research/低 EPSS → 记笔记，不占 ACTIVE A 级
```

成功口径永远是业务验证（RCE/读库/未授权数据），不是 JSON 里 `exploit_available: true`。
