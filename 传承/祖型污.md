# 大爱仙尊原型链污染作业手法

> 杀招：`祖型污`  
> 工具：`python3 炼蛊房/param_abuse_probe.py proto`  
> 升 XSS：`毒道浸染.md`；升 RCE 授权内直接做

目标须在 scope。标记 `se_pp9359` 出现在 **JSON 键** 才算 L2，正文回显只算 L1。

---

## 1. 立刻跑

```bash
python3 炼蛊房/param_abuse_probe.py proto --url https://授权/api/settings --case <案>
```

产物：`案卷/param_abuse/proto.json`。

---

## 2. 四刀

1. **找 merge** — 设置/主题/深合并/lodash `defaultsDeep`  
2. **三向量** — `__proto__`、`constructor.prototype`、`?__proto__[se_pp9359]=1`  
3. **看键** — 响应里出现 `"se_pp9359":` 才过闸  
4. **升级** — 客户端 PP → DOM XSS；服务端 PP → 权限字段 / SSTI gadget。RCE 授权内做

不要把前端 `Object.assign` 演示页当后端洞。
