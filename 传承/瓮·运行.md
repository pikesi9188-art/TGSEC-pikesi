# Docker 运行时（大爱仙尊）

封装：`tools/docker/`  
Finder：`杀招/瓮·运行`

## 为何需要

DeepAudit / AutoCVE 全栈、部分沙箱依赖 Docker 引擎。  
macOS **不能**把引擎纯便携进文件夹，所以本目录提供：**安装脚本 + 缓存 DMG + CLI 包装 + doctor**。

## 命令

```bash
bash tools/docker/bin/install_docker_desktop.sh   # 首次
bash tools/docker/bin/docker_up.sh                # 开引擎
bash tools/docker/bin/docker_doctor.sh            # 检查
source tools/docker/bin/env.sh                    # 当前 shell 挂 CLI
```

然后：

```bash
bash tools/deepaudit/bin/da_start.sh
bash tools/autocve/bin/ac_start.sh --prod
```

## 说明

- 系统安装位置：`/Applications/Docker.app`  
- 缓存：`tools/docker/cache/*.dmg`（gitignore）  
- 包装：`tools/docker/bin/vendor/docker` → App 内 CLI  
- 可选轻量后端：`install_colima.sh`（需 Homebrew）  
- 无 Docker 仍可用：`da_pipeline.py sast`、`ac_pipeline.py knowledge`、多数 `tools/ops`
