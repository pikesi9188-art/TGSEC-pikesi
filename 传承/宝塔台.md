# 宝塔与 phpMyAdmin 拿面板手法

> 指纹：`tools/1day-kit/custom-templates/panel-bt-pma-surface.yaml`  
> 探针：`炼蛊房/panel_surface_probe.py`  
> 同族：若依四海 Phase 8 · 博彩完整杀伤链「登 phpMyAdmin」  
> 红线：仅授权；PMA 短字典默认试。不改面板密、不拖全库。

---

## 1. 一句话

源站或非标端口上的 **宝塔（BT / aaPanel）** 与 **phpMyAdmin / Adminer** 是主机控制面：弱口、默认端口、随机 path 泄露 → 进面板 → 读站点 `.env` / 改 Nginx / 出 MySQL。  
Web 主线阴性后，这是 Linux 发卡/盘口的高频旁路。

---

## 2. 指纹

| 产品 | 端口/路径 |
|------|-----------|
| 宝塔国内 | `:8888` · `/login` · 体含 `宝塔` · Cookie `BT_*` |
| aaPanel | `:8888` · 体含 `aaPanel` |
| phpMyAdmin | `/phpmyadmin/` · `/pma/` · `/mysql/` · `:8080/phpmyadmin` |
| Adminer | `/adminer.php` · `/adminer/` |

```bash
python3 炼蛊房/panel_surface_probe.py -u https://授权站 --case <案卷>
# 已知源站 IP 时扫面板口：
python3 炼蛊房/port_admin_scan.py -d <授权域名> --case <案卷>
```

弱口优先级（授权试）：`admin/admin` · `admin/123456` · 主机名变体；宝塔常见要 **一次性安全入口 path**（`admin_path.pl`，有 shell 再读）。

---

## 3. 档位

| 档 | 动作 | 成功证据 |
|----|------|----------|
| **L1** | 端口/登录页指纹 | 确认宝塔或 PMA |
| **L2** | 弱口 / 空口 / 安全入口猜解 | 进入面板或 PMA 会话 |
| **L2s** | **已有 shell**：读 `default.db` / 本机 MySQL 弱口 | `mysql_root=weak-or-empty` 或 `local-auth-ok`（不 dump） |
| **L3** | 读站点配置（打码） | `.env`/账密线索；不 mysqldump |

有 SSH 时：`bt default`、读 `/www/server/panel/data/admin_path.pl`（见若依四海）。

### 3.1 已有低权 shell（宝塔单机高频）

Web 登面板走上面 L1/L2；**已经在机器上**时不要只扫 `:8888`。

```bash
# 检测器（推荐）
python3 linux_lpe_checker.py --local-only --json --out /tmp/lpe.json
# 关注 LOCAL-BT-MYSQL / LOCAL-ROOT-PROC / LOCAL-PATH

ls -ld /bin /sbin /usr/bin          # lrwxrwxrwx 是链接，不是 777 可写
cat /etc/crontab | head             # root 的 PATH= 才算劫持面
ps -ef | grep -E 'mysqld_safe|qemu-kvm_ga' | grep -v grep
```

| 落点 | 动作 | 红线 |
|------|------|------|
| `/www/server/panel/data/default.db` | 可读则 checker 只输出 `mysql_root=weak-or-empty` 或 `set(len=N)` | **不要**把明文密写进可同步文档 |
| 本机 `mysql -uroot` | 空口 → `root` → `admin` → `123456`，只 `SELECT 1` | 不 mysqldump |
| `mysqld_safe` 以 root 跑 | 看 `/www/server/mysql` 是否对当前用户可写 | 记录可写路径 |
| `/bin/bash /bin/qemu-kvm_ga` 类包装 | 脚本可写才是 L2 | 记录可写脚本 |

`ls /bin` 显示 777 时先 `readlink -f /bin`：宝塔 Debian 几乎都是链到 `/usr/bin`（555），PATH 劫持不成立。

## 4. 交接

| 发现 | 切到 |
|------|------|
| 仅 8888 被墙 | IP 白名单 / 源站直连 |
| PMA 进了库 | 假支付 KEY / 超管哈希 |
| 已在面板 root 等价 | `反客·总诀.md` 可跳过 LPE |
| 已有 www-data、进不了面板 | 本卡 §3.1 + `linux_lpe_checker` LOCAL-BT-MYSQL |
