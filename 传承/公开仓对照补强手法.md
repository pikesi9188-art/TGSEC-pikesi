
## 1. 本库作业面（对照外界话题）

| 公开仓话题 | 本库走 | 备注 |
|------------|--------|------|
| XSS / SQLi / SSTI / SSRF / LFI / XXE / 上传 | 已有专卡 + `core_web_surface_probe` / `tpl_inject_probe` | PAT 百科更深，作业走本库探针 |
| 缓存投毒 | `web-cache-poisoning` · `cache_poison_probe.py` | 未键控头 |
| **缓存欺骗** | 同上卡 · 探针默认带欺骗路径 | 以前只有词，没有探测 |
| HTTP 走私 / 缓存 Host | `http-request-smuggling` / `http-host-header-attacks` | H2 走私另走 `http2-specific-attacks` |
| JWT / GraphQL / CSRF / CORS / IDOR | 已有专卡 | |
| **SSI / ESI** | `ssi-esi-injection` · `ssi_esi_probe.py` | PAT 有章，本库原先并进 SSTI 会假阴性 |
| **OPTIONS / TRACE / PUT / WebDAV** | `http-method-webdav` · `http_method_surface_probe.py` | ownCloud 预签名仍走专卡 |
| **OAuth/OIDC 授权码 / redirect_uri** | `oauth-oidc-flow` · `oauth_oidc_surface_probe.py` | 曾误分到 password-grant |
| SAML / Passkey / WebAuthn | `identity-federation` | |
| .git / Index of / `.env` | `sensitive-dir-dump` | |
| pickle / YAML / Java 反序列化 | `deserialization-testing` | Fastjson/Shiro 走专卡 |
| DOM clobbering / mXSS | `xss-testing` | 不单开卡 |
| EL / SpEL / OGNL | `expression-language-injection` | 不是 SSTI |
| 云元数据 / S3 / Cognito | `cloud-metadata-harvesting` / `cognito-unauth-s3-chain` | |
| Unity / IL2CPP / 反作弊 / 外挂 | `client-crack-cheat` · `client_crack_cheat_probe.py` | 过闸看服务端，不发公网挂 |
| AD / Kerberos / SMB | `ad-windows-router` | HackTricks 网络章走这里 |
| nuclei CVE 模板 | `1day-nuclei-kit` | 先 `nday_route.py`，禁止只扫 CVE 结案 |
| ToB 审计/fuzz/semgrep | 已收编同名卡（`fp-check` / `semgrep` / `variant-analysis`…） | 白盒，不替代打站专卡 |
| Masriyan 01–20 课纲 | 侦察/IR/OT/GRC 走已有百科或 `cybersecurity-catalog` | 不复制 20 张空课纲 |
| Ak-cybe「191 张」 | 当营销目录 | 有探针的才收，禁张数竞赛 |
