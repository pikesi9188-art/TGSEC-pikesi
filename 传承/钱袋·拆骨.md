# 钱袋·拆骨

> Skill：`杀招/钱袋`  
> 前置：`apk-recon` 抽出 `.so` / JNI 符号  
> 工具：`python3 炼蛊房/apk_recon.py` · `python3 炼蛊房/nday_route.py --hint wallet`  
> iOS 钱包应用面：`ios-pentest`；助记词导出扫描：`ios_crypto_loot.py`  
> 红线：只打授权 APK/IPA。真提币 / 转 USDT 先问。

---

## 1. 一句话

Java/Kotlin 层多半是壳。助记词、KDF、XPUB、签名在 **Rust/C++ JNI**。没进 `.so` 不算结案。

---

## 2. 开场

```bash
python3 炼蛊房/apk_recon.py --apk <授权.apk> --case <案>
# 看 lib/arm64-v8a/：libtcx.so / libwallet_core.so / libtoken*.so
```

| 档 | 成立 |
|----|------|
| L1 | 钉到 JNI/FFI 入口 |
| L2 | BIP39 熵源 + passphrase 是否为空 |
| L2b | Keystore KDF 轮次 / XPUB 密钥来源 |
| L3 | Frida hook 出派生/签名参数 |
| L4 | 用授权测试助记词走通加解密（生产钥只记哈希） |

---

## 3. 优先读开源，再拆闭源

| App | 库 | 先读 |
|-----|-----|------|
| imToken | token-core（Rust） | 空 passphrase、静态 XPUB、debug KDF |
| Trust Wallet | wallet-core（C++） | BIP44 路径、KDF |
| MetaMask | JS keyring | 非本卡；走 `js-reverse` |

检查点：

1. 熵：`OsRng` / `getrandom` 才合格；`thread_rng` / 时间种子记漏洞。  
2. BIP39 passphrase 为空 = 12 词即全权。  
3. Keystore：`KDF_ROUNDS`、`is_debug` 降轮。  
4. XPUB 若硬编码或公共 key 包一层，记 L2b。

---

## 4. 证据

`案卷/wallet-core/`：符号表、JNI 映射、KDF 参数、hook 日志。助记词原文进案卷加密区，不进可同步 md。

## 5. 不走本手法

RPC 交易池 → `rpc-txpool-mev`。合约 → 智能合约审计。纯 JS 钱包 → `js-reverse`。
