> 专档入口：`传承/白凝冰·探府/README.md`  
> Skill：`杀招/白凝冰·探府`  
> 内核 / KASLR / AKS：`内核攻击面与原语.md` · `CVE-2026-65343-AppleKeyStore研究.md`  
> 运行时配方：`杀招/白凝冰·探府ing-tricks` + `IOS_RUNTIME_TRICKS.md`

授权范围内对 **iOS 应用 + 测试机** 打到可验证结论。默认不在应用面停：静态 → 解密 → 运行时 Hook → 沙箱翻盘 → 解 TLS → 后端专卡。内核 infoleak 与越狱原语走同目录另外两篇，不降权、不改成摘要。

证据：`案卷/<案>/案卷/ios/`

## 2. 静态 IPA

```bash
unzip App.ipa -d ios_out/
APP=ios_out/Payload/*.app
plutil -p "$APP/Info.plist"
otool -l "$APP/$(basename $APP .app)" | grep -A4 LC_ENCRYPTION_INFO
otool -hv "$APP/$(basename $APP .app)" | grep PIE
otool -I -v "$APP/$(basename $APP .app)" | grep __stack_chk_guard
strings "$APP/$(basename $APP .app)" | rg -i 'password|token|secret|http|api|key'
```

| 看 | 含义 |
|----|------|
| `cryptid 1` | FairPlay 仍加密。越狱机 `frida-ios-dump` / `bagbak`；无设备则复工条件写「解密 IPA」 |
| `cryptid 0` | 立刻 `class-dump -H`，搜 `isJailbroken` / `isAuthenticated` / Keychain / `IOConnect` |
| `CFBundleURLTypes` | Scheme 承担 OAuth/支付回调 → §4 劫持 |
| `NSAllowsArbitraryLoads` / `NSExceptionAllowsInsecureHTTPLoads` | ATS 洞，HTTP 降级 |
| 硬编码密钥 | 立刻交接假支付 / 业务 API，不要在客户端耗着 |

`codesign -d --entitlements - --xml "$APP"`：看 Keychain group、`get-task-allow`、推送、App Group。侧载研究包最小组只要 `keychain-access-groups`。

## 3. 解密与 class-dump

越狱：

```bash
# frida-ios-dump
python dump.py com.target.app
# bagbak
bagbak com.target.app
```

未越狱：从设备拉加密包只能看 plist / 资源；主二进制仍 cryptid 1。要运行时就走 §5 FridaGadget 重签。

解密后：

```bash
class-dump -H decrypted.bin -o headers/
rg -i 'jailbreak|isrooted|isauthenticated|keychain|seckey|ioconnect|tokenid' headers/
```

Swift 名用 `dsdump` / `ipsw class-dump`。Hopper / Ghidra / IDA 走 `ghidra-reverse` / `ida-reverse`。

## 4. URL Scheme 与 Universal Links

```bash
plutil -p "$APP/Info.plist" | rg -A 20 CFBundleURLTypes
curl -s "https://授权域/.well-known/apple-app-site-association"
curl -s "https://授权域/apple-app-site-association"
```

| 配置 | 打法 |
|------|------|
| 自定义 Scheme 做 OAuth/支付回调 | 研究 App 注册同一 Scheme，截 `code=` / `token=` |
| AASA `"paths": ["*"]` | UL 过宽；长按「用 Safari 打开」、JS 跳转、跨域 302 链可把 UL 打回 Scheme |
| 无 AASA | 敏感动作全走 Scheme，按劫持测 |
| AASA `application/json` 以外 | 关联失败，同样退回 Scheme |

成功：自己的回调 URL 被另一包接到，或 AASA 通配导致非预期 path 拉起 App。

## 5. 运行时

| 能力 | 越狱 | 未越狱 |
|------|------|--------|
| Keychain | Objection / keychain-dumper | 备份提取受保护类限制；侧载 Gadget 可 Hook SecItem |
| 沙箱文件 | `/var/mobile/Containers/Data/Application/<UUID>/` | 备份 + Gadget |
| Hook | `frida -U -f com.target.app` | 重签嵌入 `FridaGadget.dylib` |
| 越狱检测 | `ios jailbreak disable` + 自写 path/canOpenURL Hook | 先过检测再谈 |

Objection：

```text
ios keychain dump --json
ios cookies get
ios sslpinning disable
ios jailbreak disable
ios info binary
ios pasteboard monitor
ios hooking watch method "-[AuthManager isAuthenticated]" --dump-args --dump-return
ios hooking set return_value "-[AuthManager isJailbroken]" false
```

Frida 配方（越狱检测 / 类枚举 / pinning）见 `IOS_RUNTIME_TRICKS.md`。Pinning 加深走 `mobile-ssl-pinning-bypass`（SecTrust、SSL Kill Switch、Alamofire/TrustKit）。

未越狱 Gadget：

1. 解 IPA，把 `FridaGadget.dylib` 放进 `Frameworks/`
2. `insert_dylib` / `optool` 给主二进制加 load command
3. 开发者证书重签（entitlements 保留原 keychain group 或研究组）
4. `ios-deploy` 装上，等 Gadget listen 再 `frida -U -n Gadget`

Keychain 保护类：

| 类 | 风险 |
|----|------|
| `AfterFirstUnlock` / `AfterFirstUnlockThisDeviceOnly` | 锁屏后后台仍可读 |
| `WhenUnlocked` | 解锁窗口可读 |
| `WhenUnlockedThisDeviceOnly` | 紧 |
| `Always`（旧） | 直接报严重 |

## 6. 沙箱翻盘

App UUID：

```bash
find /var/mobile/Containers/Data/Application -name 'com.target.app' 2>/dev/null
```

| 路径 | 查 |
|------|-----|
| `Library/Preferences/*.plist` | Token、开关、明文密码 |
| `Library/Application Support/*.sqlite` | 用户/订单缓存 |
| `Library/Cookies/Cookies.binarycookies` | 会话 |
| `Library/Caches/` | API 响应、带 PII 图 |
| `Library/SplashBoard/Snapshots/` | 进后台截屏（余额/证件） |
| `Library/Keyboard/` | 敏感输入联想 |
| `Library/WebKit/WebsiteData/` | LocalStorage / IndexedDB |
| App Group `group.*` | 扩展/兄弟包共享容器 |

`plutil -p` + `sqlite3 .tables`。自己的测试账号默认可读；他人账号 / 真提现 / 改原超管密仍先问。

相册截图助记词、剪贴板私钥、授权机 USDT：走 `相册剪贴板与USDT资产面.md`，先导出再 `ios_crypto_loot.py`。

## 7. 流量与后端

解开 TLS 之后当 Web/API 案继续打，不要停在客户端：

| 看到 | 交接 |
|------|------|
| 支付回调 / 验签 | 假支付 / `pay_matrix` |
| JWT / GraphQL | `jwt_gql_probe` / `rbac-bypass-authz` |
| 硬编码 Token + 信任头 | `hardcoded-token-cfip-fund` |
| 开放平台签名 | 对应业务专卡 |

ATS 全关或域名例外 → HTTP 降级 + 代理截断。证书校验 Hook 失败就换 SSL Kill Switch / `boringssl` 层。
