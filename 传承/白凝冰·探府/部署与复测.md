# CVE-2026-65343 部署与复测

> 口径：**没有真机日志，漏洞就不算成立。**  
> 实验包：`ios-research/tools/aks-oob/`  
> 入口：`python3 ios-research/tools/aks-oob/bin/aks_oob_lab.py doctor`  
> 原理：`CVE-2026-65343-AppleKeyStore研究.md`

公开仓 README 里那条 `clang -o poc poc_aks_oob.m` **不能直接装进 iPhone**。iOS 只跑 `.app` / IPA，还要开发者签名。本目录把上游 `main` 改成 `aks_oob_run()`，包进带按钮的 App，点一下把 stdout 写到 `Documents/aks_oob.log` 并复制到剪贴板。

---

## 0. 本机现状（先跑）

```bash
python3 ios-research/tools/aks-oob/bin/aks_oob_lab.py doctor
```

缺任何一项都不要谈「已验证」：

| 条件 | 为什么 |
|------|--------|
| 完整 **Xcode**（不是只装 Command Line Tools） | 要 `iphoneos` SDK；iOS 26 真机要能认该系统的 Xcode |
| **Apple Development** 证书 | Automatic Signing，免费 Apple ID 也可以 |
| **真机 USB** + 开发者模式 + 信任 | 模拟器没有 SEP / AppleKeyStore，Phase 1 必挂 |
| 设备构建 **23G71**（未修）或 **23G83**（对照） | 见版本表 |

`doctor` 报 blockers 时：漏洞状态 = **NOT_RUN**。

---

## 1. 一次性准备

1. App Store 安装 Xcode，打开一次，装附加组件。iPhone 若是 iOS 26.6，Xcode 必须支持 iOS 26。
2. Xcode → Settings → Accounts 登录 Apple ID。第一次真机 Run 会注册设备、发 Development 证书。
3. iPhone：设置 → 隐私与安全性 → 开发者模式 → 开，重启后再确认。
4. USB 插上，点信任。
5. 看 Team ID：Xcode → Settings → Accounts → Manage Certificates，或 Apple Developer 网页 10 位字母数字。

```bash
# 设备版本（有 libimobiledevice 时）
ideviceinfo -k ProductVersion -k BuildVersion -k UniqueDeviceID
# 或 Xcode Window → Devices and Simulators
```

未修目标：`ProductVersion=26.6` 且 `BuildVersion=23G71`。  
已修对照：`26.6.1` / `23G83`。

授权测试机 UDID 写进案卷；需要进 scope 就 `scope_expand.py --grant`。

## 3. 真机上怎么跑

1. 打开 App **AKSOob**。
2. 点 **Run CVE-2026-65343**（要等几秒：建 SE 密钥 + 签名 + 最多 163 个 selector）。
3. 屏幕出日志；同时进剪贴板。文件在：
   `App 沙箱 Documents/aks_oob.log`
4. 用 Xcode Devices → Download Container，或直接把剪贴板粘进电脑存成 `aks_oob.log`。

越狱机若 Phase 1 失败，同一二进制仍会走零 handle fallback；那只证明路径，**不能**单独当 KASLR 成立。

---

## 4. 判定（只认日志）

```bash
python3 ios-research/tools/aks-oob/bin/aks_oob_lab.py classify \
  --log aks_oob.log --build 23G71 --case <案卷名>
```

| verdict | 算不算漏洞成立 |
|---------|----------------|
| `CONFIRMED_KASLR` | **成立**（打出 `KASLR SLIDE`） |
| `CONFIRMED_INFOLK` | **成立**（`KPTR @+` 或 `OOB CONFIRMED`，slide 可能还要对 `known_off`） |
| `PHASE1_BLOCKED` | **未成立**（没抓到 handle，换机/越狱后再测） |
| `PATCHED` | **本编号不成立**（23G83 且无 kptr） |
| `NOT_RUN` | **未验证** |

证据落 `案卷/<案>/案卷/ios/65343/`（`aks_oob.log` + `verdict.json`）。没有这两样，STATUS 里不准写「65343 已确认」。

## 5. 和「clang 一条命令」的关系

| 步骤 | 单独 clang 二进制 | 本实验 App |
|------|-------------------|------------|
| 能在 Mac 上链出 arm64 | 有 iphoneos SDK 时可以 | 同样需要 SDK |
| 能在 iPhone 上运行 | 否（不是 .app） | 是 |
| SE / AKS 路径 | 必须在设备上 | 必须在设备上 |
| 漏洞成立 | 不能 | 只看 classify 的 CONFIRMED_* |

不要在模拟器上点按钮然后写阴性结案。
