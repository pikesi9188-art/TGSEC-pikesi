# 开棺·蓝鸟

> 蓝鸟猎手（`cn.wanghw.JDumpSpider 1.1-SNAPSHOT` + `HunterLauncher`）堆转储凭据抽取。  
> Skill：`杀招/开棺·蓝鸟`  
> 工具：`python3 炼蛊房/heap_cred_scan.py` · JAR `tools/heap-hunter/lanniao-hunter.jar` · 规则 `tools/heap-hunter/spiders.json`  
> 后续杀伤链：下完堆之后走 `春府·开棺.md`。Shiro 密钥回灌 `记忆蛊.md`。  
> 授权：只拆已授权目标的 heapdump。禁止把 JAR 当全网扫描器。

---

## 1. 它是什么

不是目录猎杀 / Credential Hunter。是 **hprof 对象图抽凭据**：

1. VisualVM / NetBeans heap 解析器打开 `.hprof` / `.phd` / `.heap` / `.bin`
2. 按 class 版本选 `GraalvmHeapHolder` 或 `NetbeansHeapHolder`
3. 17 只 `ISpider.sniff()` 找类实例、抽字段、`HashMapUtils.dumpString`
4. 蓝鸟加的壳：`cn.wanghw.HunterLauncher -batch <目录>` → `_hunter_reports/` + `_summary_report.txt`（**class file 70，要 Java 26**；本库 `batch` 不调它，逐文件走 `Main`）

本库原来的 `heap_cred_scan` **只扫字节**（`LTAI` / `jdbc:` / UTF-16 窗口）。对象图上的 `password.thePassword`、`encryptionCipherKey`、`ProcessEnvironment` 它看不见。融合后：**正则先跑，有 Java 再跑蜘蛛，结果并进 `HEAP_CREDS.json`**。

不要默认 `export-strings`（全堆 `java.lang.String`）。

## 2. 默认命令

```bash
# 下堆仍按 IP+HOSTNAME+total 分桶
python3 tools/spring-gateway-killchain/bin/heapdump_range_fetch.py \
  --url https://授权/actuator/heapdump --out 案卷/.../案卷/heapdump/

# 一刀：正则 + 蓝鸟蜘蛛
python3 炼蛊房/heap_cred_scan.py \
  案卷/.../案卷/heapdump/heapdump_nodeA.hprof \
  --out 案卷/.../接管/heap_creds/

# 只要对象图（本机有 Java）
python3 炼蛊房/heap_cred_scan.py spider --dump <hprof> --out <dir>

# 一目录多份堆
python3 炼蛊房/heap_cred_scan.py batch --dir <目录> --out <dir> --case <案>

# probe 说可达才下（kit / auto_campaign / nday 默认走这条）
python3 炼蛊房/heap_cred_scan.py from-probe \
  --probe exports/<案>/案卷/actuator/probe.json \
  --dump-dir exports/<案>/案卷/heapdump \
  --out exports/<案>/接管/heap_creds \
  --case <案>
```

无 Java：正则仍出报告，`spider_ran=false`。装 Temurin：`tools/spring-gateway-killchain/bin/install_vendor.sh`。

## 3. 十七只蜘蛛（逐帧）

| # | 蜘蛛 | 堆里找谁 | 抽出什么 | 下一刀 |
|---|------|----------|----------|--------|
| 1 | DataSource01 | `DataSourceProperties` | driver / user / pass / url | JDBC 连通 |
| 2 | DataSource02 | WebLogic `DataSourceConnectionPoolConfig` | url / `defaultConnectionInfo` 口令 | 同左 |
| 3 | DataSource03 | `com.mongodb.MongoClient` | cluster host + credentialsList | Mongo URI |
| 4 | DataSource04 | `DruidDataSourceWrapper` | user / pass / jdbcUrl | 芋道/若依库 |
| 5 | DataSource05 | Hikari `DriverDataSource` | jdbcUrl + driverProperties | 同 JDBC |
| 6 | Redis01 | `RedisStandaloneConfiguration` | host / `password.thePassword` | Redis 卡 |
| 7 | Redis02 | `redis.clients.jedis.Client` | hostname / password / db | 同左 |
| 8 | ShiroKey01 | `CookieRememberMeManager` | `encryptionCipherKey` → Base64 | Shiro 弱钥 |
| 9 | PropertySource01 | `OriginTrackedMapPropertySource` | yml/properties Map | Jasypt / Nacos / AK |
| 10 | PropertySource02 | `MutablePropertySources` | 整份 Environment | 同左 |
| 11 | PropertySource03 | `MapPropertySource` | source Map | 同左 |
| 12 | PropertySource04 | `ConsulPropertySource` | Consul KV | 配置中心 |
| 13 | PropertySource05 | `java.util.Properties` | 全堆 Properties | 噪声大，只作补漏 |
| 14 | EnvProperty01 | `java.lang.ProcessEnvironment` | 进程环境变量 | 云 AK / JDBC |
| 15 | OSS01 | 所有 Map，键含 oss/s3/cos/… | id/secret/bucket/endpoint | 阿里云 AK 链 |
| 16 | UserPassSearcher01 | 字段名含 user/pass/token/… | 任意 POJO | 补专类漏网 |
| 17 | CookieThief + AuthThief | String 含 `Cookie:`；Map 键 auth/cookie | 会话 / Bearer | 后台冒充（授权） |

`ExportAllString` 是第 18 刀，可选，默认关。

## 4. 和本库其它卡的交接

| 抽出 | 交接 |
|------|------|
| `LTAI` / oss secret | `云府·临钥.md` |
| JDBC / Druid / Hikari | 直连或芋道 `syscache` |
| Redis 口令 | `契柜·无门.md` / 若依验证码旁路 |
| Shiro Base64 钥 | `记忆蛊.md` |
| `ENC(` / jasypt | Gateway 链 `jasypt_decrypt.sh` |
| Nacos 地址+口令 | 先探版本，3.x 走 `nacos-authscope-unauth` |
| Cookie / Authorization | 授权后台只读证明，不改原超管密 |

正则仍保留本库金标准：`LTAI5t`、UTF-16 `AccessKey`、`ENC(`。蜘蛛负责对象图。

## 5. 成功口径

| 档 | 成立 | 不算 |
|----|------|------|
| L1 | 报告里出现蜘蛛标题或类名指纹 | 空文件 |
| L2 | 抽出可复用口令 / JDBC / Redis / Shiro 钥 / AK 片段 | 只有 `password=` 三个星号 |
| L3 | 凭据在授权目标上验证（Identity / 连库 / rememberMe） | 只落了 txt |

混节点 heapdump 禁止合并。测完仍走 Actuator 链的云/SSH，不要在本卡结案。
