## 1. 指纹

```bash
python3 炼蛊房/nday_route.py -u https://授权站 --case <案卷>
python3 tools/1day-kit/od_kit.py nuclei --url https://授权站 --case <案卷> \
  -t tools/1day-kit/custom-templates/freepbx-unauth-cve-2026-73665.yaml

curl -skI https://授权站/admin/
curl -skI https://授权站/ucp/
# UCP Node 默认口（常未走 443）
curl -skI http://授权主机:8001/
curl -skI https://授权主机:8003/
```

命中信号：标题/页脚 `FreePBX`；`/admin/config.php`；UCP；`:8001`/`:8003` 出现 `socket.io` 或 Engine.IO 握手。

---

## 2. L2 验证（授权内）

**仅当目标明确在 scope，且用户未说暂停。**

### 2.1 73665（优先）

1. 对 `:8001` 或 `:8003` 做 Socket.IO / Engine.IO 握手（默认 namespace 可能要票）。  
2. 再连 **非默认 namespace**（advisory：自定义 ns 未统一 `checkAuth`）。  
3. L2 成功 = **未认证连接被接受**（握手/sid 落证）。  
4. AMI 换行注入 / 命令执行：授权内直接做（先 `id`/`hostname` 回显，再写马/反弹）。改原超管密先问。

### 2.2 73663

需能对监控分机打一通未接来电并控制 `From` 显示名。无 SIP 授权通道则只记「missedcall 模块在、版本未修」，不要对公网乱呼。

---

## 3. 修复对照

- UCP ≥ **17.0.9**；missedcall ≥ **16.0.11 / 17.0.4**  
- 防火墙只放行可信来源访问 8001/8003  
- 入局 SIP 只受信令中继；拨号计划覆盖 Caller ID 显示名
