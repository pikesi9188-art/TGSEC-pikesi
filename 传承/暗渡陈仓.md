# 大爱仙尊开放重定向作业手法

> 杀招：`暗渡陈仓`  
> 工具：`python3 炼蛊房/open_redirect_surface_probe.py`  
> OAuth：`oauth2-password-grant-login-testing`；SSRF：`定仙游.md`

目标须在 scope。不跟随跳转。Location 指到外域探测 URL 才算 L2。

---

## 1. 立刻跑

```bash
python3 炼蛊房/open_redirect_surface_probe.py --base https://授权站 --case <案>
```

产物：`案卷/open_redirect/`（以探针落盘为准）。

---

## 2. 四刀

1. **找参** — `next` `returnUrl` `redirect` `goto` `redirect_uri`  
2. **外域** — `https://example.com/se-open-redirect`；探针不 follow  
3. **绕白名单** — `//evil`、`/\evil`、`https://授权.evil`、`@`  
4. **升级** — OAuth `redirect_uri`、登录回跳偷码、再链 XSS/钓鱼。不要当 SSRF 结案

---

## 3. 档位

| 档 | 成立 |
|----|------|
| L1 | 参数进 Location |
| L2 | Location/Refresh 指向外域 |
| L3 | 接 OAuth / 会话劫持 |
