# 中门无门

> Skill：`杀招/中门无门`  
> 探针：`炼蛊房/middleware_unauth_probe.py`  
> Redis **另卡**：`契柜·无门.md` · `redis_unauth_probe.py`  
> 红线：仅授权；只读握手/列举。不删索引、不 flush、不写 webshell。

---

## 1. 一句话

源站/旁注/SSRF 常见未授权口：

| 服务 | 端口 | 本卡 |
|------|------|------|
| Redis | 6379/6380 | 不在这，走 Redis 卡 |
| MongoDB | 27017 | isMaster |
| Elasticsearch | 9200 | `/` + `_cat/indices` |
| Memcached | 11211 | `stats` |

```bash
python3 炼蛊房/middleware_unauth_probe.py --host <授权IP或域名> --case <案卷>
# SSRF 打到内网时，目标 host 也须在 scope（或先 scope_expand）
```

落盘：`案卷/middleware/probe.json`

---

## 2. 档位

| 档 | Mongo | ES | Memcached |
|----|-------|----|-----------|
| **L1** | isMaster / hello（含 OP_MSG，适配新 Mongo） | 根 JSON `cluster_name` | `STAT` 回显 |
| **不算未授权** | — | `es-auth-required`（401/403） | — |
| **L2** | 只读 `listDatabases`（手跑） | `_cat/indices` 已由探针拉 | 抽样 `get` 键名（手跑） |
| **先问** | `$eval` / 写盘 | `_delete` / 改映射 | `flush_all` / 写 session |

```text
L1 未授权
  → 有业务库/索引 → 抽样只读（证件/密钥打码）
  → session/验证码键 → 旁路登录
  → 无有用数据 → 记版本，转 JDBC/SSH/云
```
