# Redis 未授权手法

> 探针：`炼蛊房/redis_unauth_probe.py`  
> 指纹：`tools/1day-kit/custom-templates/redis-unauth-surface.yaml`（仅 HTTP 反代面）  
> 同族：`若府·验纹旁路.md`（captcha uuid 是本卡的一种用法）  
> 红线：仅授权；默认 PING/INFO + 读 captcha/session 键名。不写 CONFIG SET webshell。

---

## 1. 一句话

6379（或 6380）**无密码 / 弱口** → 读 session、验证码、队列、配置 → 旁路登录。  
不绑若依：任何 Java/PHP 站旁注、SSRF、源站端口都可能出 Redis。

---

## 2. 指纹

| 信号 | 说明 |
|------|------|
| 端口 | 6379 / 6380 对源站或内网开放 |
| SSRF | `ssrf_probe` 的 `localhost_6379` |
| 应用 | 若依 captcha、session、队列、缓存 |

```bash
python3 炼蛊房/redis_unauth_probe.py --host <授权IP> --port 6379 --case <案卷>
# 只读：PING + INFO + 抽样 SCAN（默认限制条数）
# HTTP 反代误暴露 Redis 协议时：
python3 tools/1day-kit/od_kit.py nuclei --url https://授权站 --case <案卷> \
  --template-id redis-unauth-surface
```

弱口试：空口 → `redis` → `123456` → `root`（可 `--passwords`）。

---

## 3. 档位

| 档 | 动作 | 成功证据 |
|----|------|----------|
| **L1** | PING 通、INFO 有 `redis_version` | 未授权或弱口成立 |
| **L2** | 读 `captcha*` / `login_tokens*` / session | 可旁路登录或拿会话 |
| **L3** | 有 captcha 则走若依旁路登录 | 后台会话 |

```text
L1 未授权
  → 有 captcha/login_tokens → 若依验证码旁路卡
  → 有业务 session → 直接顶会话
  → 无有用 key → 记 INFO/DBSIZE，转 JDBC/SSH
```
