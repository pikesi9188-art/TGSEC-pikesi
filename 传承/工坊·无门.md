# Jenkins 未授权与脚本控制台手法

> 指纹：`tools/1day-kit/custom-templates/jenkins-unauth-surface.yaml`  
> 分流：`凤九歌·天地歌.md`  
> 红线：仅授权目标；Script Console / 建 Job 属高破坏，先问再打

---

## 1. 一句话

Jenkins 管理面暴露时看：**匿名可读**、**未鉴权或弱鉴权 Script Console**、**可建 Job/节点** → 直接或间接 RCE；常与 CI 密钥/云 AK 同机。

---

## 2. 指纹

| 信号 | 路径/头 |
|------|---------|
| 产品头 | 响应头 `X-Jenkins` / `X-Hudson` |
| 登录/面板 | `/login` · `/` 体含 `Jenkins` |
| 匿名 API | `/api/json` · `/whoAmI/api/json` |
| 脚本台 | `/script` · `/scriptText`（有会话或匿名） |
| 管理 | `/manage` · `/computer/api/json` |

```bash
python3 tools/1day-kit/od_kit.py nuclei --url https://授权站 --case <案卷> \
  --template-id jenkins-unauth-surface
```

---

## 3. 档位

| 档 | 动作 | 成功证据 |
|----|------|----------|
| **L1** | `X-Jenkins` / 登录页 | 确认 Jenkins + 版本线索 |
| **L2** | 匿名 `/api/json`、whoAmI、可读 Job | 未登录拿到实例/任务元数据 |
| **L3** | Script Console / 建 Job（**先问**） | 命令回显或等价 RCE 证据 |

与 TeamCity 分链：TeamCity 走 `工城·开天.md`。
