# VeloCloud 编排器命令注入手法（CVE-2026-16812）

> 情报：`od_kit.py cvebase lookup --cve CVE-2026-16812`  
> 配套指纹：`tools/1day-kit/custom-templates/velocloud-vco-cve-2026-16812.yaml`  
> 总览：`新伤·在野.md`  
> 红线：仅 `授权范围`；厂商未公开完整利用路径前，**禁止瞎喷命令注入 payload**；破坏性先问

---

## 1. 一句话

Arista **VeloCloud Orchestrator（VCO）on-prem** 把本应仅内部的功能暴露到 Web 管理面 → **未授权 OS 命令注入** → 编排器主机与其管理的 Edge 配置/凭据一并失陷。  
KEV · 在野 · CVSS **10.0** · CWE-78。  
公开 exploit 文档暂稀；Hosted/Dedicated 厂商称已提前打补丁。

---

## 2. 战场价值

VCO = SD-WAN 控制面：设备清单、隧道、证书、运维凭据。  
打穿 on-prem 编排器 ≈ 拿一整片边缘网，不只是「一个 Web 后台」。

**不在本洞范围**：VeloCloud Gateway / Edge 产品本身（厂商口径）；云 Hosted 已补。

---

## 3. 影响版本（on-prem）

| 线路 | 未修 | 修复 |
|------|------|------|
| 5.2.x | &lt; 5.2.3.14 | **5.2.3.14+** |
| 6.1.x | &lt; 6.1.3.4 | **6.1.3.4+** |
| 6.4.x | &lt; 6.4.2.4 | **6.4.2.4+** |
| 7.0.x | 7.0.0 | **7.0.0.1+** |

通告：https://www.arista.com/en/support/advisories-notices/security-advisory/24364-security-advisory-0144

厂商强调：管理面**默认暴露**，无「关一下就好」的产品开关；临时只能网络层收口。
