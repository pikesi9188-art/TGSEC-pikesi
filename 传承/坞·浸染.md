# WordPress 登录 XSS 链手法（CVE-2026-64638 · XSS2Shell）

> 情报：`od_kit.py cvebase lookup --cve CVE-2026-64638`  
> 指纹：`tools/1day-kit/custom-templates/wordpress-xss2shell-cve-2026-64638.yaml`  
> 总览：`新伤·在野.md`  
> 红线：仅 `授权范围`；对真实管理员做钓鱼链 **先问**

---

## 1. 一句话（别把档位说混）

| 段 | 是否要登录目标站 | 含义 |
|----|------------------|------|
| **反射 XSS** | **不要**（未授权） | 特制失败登录 / 恶意页诱导访问 → 在站点源下执行 JS |
| **→ RCE（XSS2Shell）** | 要 **已登录的管理员点一下** | 应用密码 / REST / 插件上传等核心能力链到 PHP |

所以：**XSS 是未授权面；整链 RCE 不是纯未授权一键**，依赖管理员交互。名字用「登录 XSS 链」，避免写成「未授权 RCE」误导。

CVSS 8.9 · 有公开研究/利用材料 · **非 KEV**（截至入库日）。修复：`7.0.3` 及各分支 backport（至 4.7）。

---

## 2. 根因备忘

登录失败路径里 `strip_tags` 与 KSES 对用户名的解析差 → 畸形输入进错误页 DOM → 反射 XSS。  
再叠 DOM/同源能力 → 对已登录管理员走应用密码批准与插件上传，才到 shell。

## 3. 档位与成功口径

| 档 | 动作 | 成功证据 |
|----|------|----------|
| **L1 指纹** | `wp-login.php` / 版号 | WordPress 且 &lt; 对应修复线 |
| **L2 XSS** | 失败登录反射差分（授权自控页） | 错误页出现可控 HTML/脚本上下文 |
| **L3 链** | 仅实验室或明确授权的管理员诱导场景 | 应用密码/插件上传/PHP 执行；生产钓鱼先问 |

```bash
python3 tools/1day-kit/od_kit.py nuclei --url https://授权站 --case <案卷> \
  --template-id wordpress-xss2shell-cve-2026-64638
python3 tools/1day-kit/od_kit.py cvebase lookup --cve CVE-2026-64638 --docs
```

参考：https://pwn.ai/blog/xss2shell · 修：WordPress 7.0.3 公告

## 4. 旁路洞（同生态 · 与 XSS2Shell 不同链）

| CVE | 要点 | 成功口径 |
|-----|------|----------|
| **CVE-2026-60137**（KEV） | `WP_Query` 的 `author__not_in` 未正确消毒 → 插件/主题喂不可信输入时可 **SQLi** | 布尔/报错差分 |
| **CVE-2026-63030**（KEV · EPSS≈0.96） | REST **batch** 路由混淆 + 上条 SQLi → 可推到 **RCE** | 见专用卡 |

未修线摘要：`6.9.x`&lt;`6.9.5`、`7.0.x`&lt;`7.0.2`。  
REST/SQLi/RCE **整链作业** → **`坞·歇门.md`**（勿并进 XSS2Shell 一句话结案）。
