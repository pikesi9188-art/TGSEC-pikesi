# 1day 与 Nuclei 作业手册

> 工具：`tools/1day-kit/od_kit.py` · Skill：`杀招/一日针匣`  
> **先学**：`针匣·手册.md`（官方 v3 + YAML + 本库三层）  
> 官方模板默认：`tools/1day-kit/nuclei-templates/`（gitignore；`NUCLEI_TEMPLATES` 可覆盖）。  
> 本地研究 PoC：`poc-db/exploitarium/`。  
> 情报面：`新伤·在野.md`（Metabase / LoadMaster / Tomcat集群 / VeloCloud 等手法卡）

## 何时用 / 何时不用

- **用**：指纹清晰、要过已知 CVE/misconfig；靶场漏洞利用题；每周跟 KEV/在野洞。
- **不用结案**：已出现 `/actuator`+heapdump、支付 notify、GVA 等 → 切专用 Skill。
- **NGINX `Server` / CVE-2026-42945**：切 `nginx-rift-cve-2026-42945`（`nginx_rift_probe.py` + 自定义模板），勿只扫通用 cve 标签结案。
- **Metabase / CVE-2026-72898**：先看 `库府·吞库.md` + nuclei 指纹，再谈利用。
- **MLflow / CVE-2026-64849**：`mlflow-ssrf-webhook`；L2 是 `GET /api/2.0/mlflow/webhooks`，不是 `/list`。
- **Zimbra / CVE-2026-73570**：`zimbra-snmp-rce`；只指纹+版本，勿把 `cacheVersion` 当 ZCS 版本。
- **TrueConf / CVE-2026-72529**：`话巢·脚本.md`；BaseURL 对准 Web 口（常 :4307）。
- **挖新洞**：`autocve`；白盒：`deepaudit`。

## 流程

```bash
python3 tools/1day-kit/od_kit.py doctor
python3 tools/1day-kit/od_kit.py learn               # 一屏速记
python3 tools/1day-kit/od_kit.py explain --id spring-actuator-unauth
python3 tools/1day-kit/od_kit.py update-templates    # 首次 / 模板为空
python3 tools/1day-kit/od_kit.py index
python3 tools/1day-kit/od_kit.py search --q <组件名>

# 情报（cvebase，匿名约 10 次/日；Key: CVEBASE_API_KEY）
python3 tools/1day-kit/od_kit.py cvebase trending
python3 tools/1day-kit/od_kit.py cvebase lookup --cve CVE-2026-72898 --docs
python3 tools/1day-kit/od_kit.py cvebase search --q "spring gateway" --limit 5

# 先本库指纹，再社区 CVE 标签
python3 tools/1day-kit/od_kit.py nuclei --url https://授权站 --case <案卷> --custom-only
python3 tools/1day-kit/od_kit.py nuclei --url https://授权站 --case <案卷> --tags cve
# 单条本库模板（nday_route / 手法卡同一写法）
python3 tools/1day-kit/od_kit.py nuclei --url https://授权站 --case <案卷> \
  -t tools/1day-kit/custom-templates/metabase-sqli-cve-2026-72898.yaml
python3 tools/1day-kit/od_kit.py nuclei --url https://授权站 --case <案卷> \
  --template-id metabase-sqli-cve-2026-72898
```

证据：`案卷/<案卷>/案卷/1day/`（`nuclei.jsonl` + `nuclei_cmd.json` + `cvebase_*.json`）

## 约定

- **禁止**把完整 nuclei-templates 硬塞进 `tools/vendor`（见 vendor README）。本库缓存目录已 gitignore。
- nuclei 命中只算 L1；要按业务成功口径验证（RCE/读文件/未授权数据）。
- exploitarium 条目偏研究/本地复现，**默认不自动对线上狂打**；`show` 读 README 后人工裁定。
- cvebase 匿名配额紧：优先 `trending` / 精确 `lookup`，少做广搜。
