> 杀招：`信网柜`  
> 工具：`python3 炼蛊房/http_method_surface_probe.py --base https://授权站 --case <案>`

目标须在 scope。默认只写 marker，不删生产文件。

---

## 1. 立刻跑

```bash
python3 炼蛊房/http_method_surface_probe.py --base https://授权站 --case <案>
```

产物：`案卷/http_method/`。

---

## 2. 四刀

1. **OPTIONS** — 记 `Allow` / `DAV` / `Public`  
2. **TRACE / TRACK** — 回显请求头则 XST 成立（L1）  
3. **PROPFIND** — `207` + `DAV:` 多半是 WebDAV  
4. **PUT marker** — 只写 `/se-http-method-marker.txt`，GET 回来才算 L2；禁止一上来 PUT 马

`MOVE` 只在 PUT 已回读后做，目标仍是 marker。`DELETE` 默认不做。

---

## 3. 档位

| 档 | 成立 |
|----|------|
| L1 | TRACE 回显，或 Allow 含 PUT/PROPFIND/MOVE |
| L2 | PUT 的 marker 能 GET 回来 |
| L3 | MOVE/COPY 改到另一可访路径 |

`405` / `501` 是阴性。WAF 拦 OPTIONS 换直连 IP 仍走本库出口池，禁止拿用户主机当跳板。
