# 大爱仙尊 CSRF 作业手法

> 杀招：`借刀杀人`（作业）· `csrf-exploitation`（附录）  
> 工具：`python3 炼蛊房/cors_csrf_probe.py csrf`  
> CORS 链：`借刀杀人·借窗.md`

目标须在 scope。改密 / 改收款 / 加款仍先问。L2 必须打 **状态改变** 接口，首页 200 不算。

---

## 1. 立刻跑

```bash
python3 炼蛊房/cors_csrf_probe.py csrf --url https://授权/ --case <案>
python3 炼蛊房/cors_csrf_probe.py csrf --url https://授权/ \
  --post https://授权/api/profile --cookie 'sid=自己的会话' --case <案>
```

产物：`案卷/cors_csrf/csrf.json`。

---

## 2. 四刀

1. **认会话** — Cookie 有没有 SameSite / HttpOnly；无 SameSite 或 `None` 记 L1  
2. **认 token** — 表单有没有 `_token` / `csrfmiddlewaretoken`；JSON API 常把 token 放 Header  
3. **跨站打** — `--post` 无 Origin、恶 Origin+Referer；2xx 再看 body 是不是真改了  
4. **绕法** — GET 也能改状态、方法覆盖、`text/plain` JSON、CORS 把 token 读出来再链

SameSite=Lax 挡跨站 POST，不挡顶级 GET 导航。状态改变走 GET 仍是洞。

---

## 3. 档位

| 档 | 成立 |
|----|------|
| L1 | 会话 Cookie 无 SameSite，或表单无 token |
| L2 | 无 Origin / 恶 Origin 的状态改变仍 2xx，且对照证明改了 |
| L3 | 登录 CSRF / 改绑 / 改权成立（破坏性先问） |
