## 为什么 APK 逆向对博彩站特别有效

| 从 APK 里找到 | 命中率 | 价值 |
|--------------|--------|------|
| API 签名算法+密钥 | 85% | 直接伪造任意请求，包括充值入账 |
| 后台管理隐藏路径 | 70% | 绕过 Cloudflare 路径白名单 |
| 测试/预发布环境 URL | 60% | 无 WAF 直接打，通常弱口令 |
| MQTT/WS broker | 50% | 实时数据全量监听 |
| 运营商 API Token | 40% | 跨商户越权 |
| 数据库连接串 | 15% | 直连内网 DB |

**案例**：wldzylbot 的 `4523E51C8F78D3ED` (AES key) + `FA72ACE1…` (MD5 salt)，
如果先拿到 APK，5 分钟即可提取，不需要逆向 JS。

## 快速开始（完整流程 < 15 分钟）

### Step 1 — 获取 APK

```bash
# 方式 A：目标站提供下载链接
curl -L https://TARGET/download/app.apk -o /tmp/app.apk

# 方式 B：从 APKPure / APKCombo 下载（搜品牌名）
# 方式 C：Scrapling 抓下载页面
python3 tools/scrapling/scrapling_fetch.py --url https://TARGET/download --case CASE

# 方式 D：社工 TG 群获取 APK 文件
```

### Step 2 — 快速字符串扫描（30 秒）

```bash
python3 炼蛊房/apk_recon.py strings \
  --apk /tmp/app.apk --case 站点_日期
```

重点看：
- `[测试/预发布环境]` ← 马上去打
- `[URLs]` 里有无 `/admin/` `/operator/` 路径
- `[密钥]` 里的 hex 字符串

### Step 3 — 完整反编译（按需，彻底）

```bash
python3 炼蛊房/apk_recon.py extract \
  --apk /tmp/app.apk --case 站点_日期
```

产出：`案卷/.../案卷/apk/apk_intel.json`

### Step 4 — 专项：签名算法提取

```bash
python3 炼蛊房/apk_recon.py sign-algo \
  --apk /tmp/app.apk --case 站点_日期
```

找到算法后：
- 有 MD5 + salt → 在 `pay_matrix.py` 中填入 sign 算法
- 有 AES key → 在 API 调用脚本中解密响应

### Step 5 — 用反编译源码做深度审计

```bash
# jadx 反编译后的 Java 代码送给 DeepAudit
python3 tools/deepaudit/backend/bin/da_pipeline.py \
  --src exports/<案卷>/案卷/apk/decompiled/ \
  --case <案卷>
```

## 常见命中模式

### 1. API 签名还原

```java
// APK 里找到这种代码 → sign 算法清晰
public static String sign(Map<String, Object> params, String appKey) {
    StringBuilder sb = new StringBuilder();
    // 参数按 key 排序 + appKey + MD5
    params.entrySet().stream()
        .sorted(Map.Entry.comparingByKey())
        .forEach(e -> sb.append(e.getKey()).append("=").append(e.getValue()).append("&"));
    sb.append("key=").append(appKey);
    return MD5.encode(sb.toString()).toUpperCase();
}
```

对应 `pay_matrix.py` / `apk_intel.json` 中的 `sign_algorithms: ["md5_sign"]`。
