# 大爱仙尊类型混淆作业手法

> 杀招：`型乱型`  
> 工具：`python3 炼蛊房/param_abuse_probe.py juggl`  
> 登录 SQLi 旁路：`authbypass-authentication-flaws`

目标须在 scope。只打 JSON/PHP 弱比较。`0e` 魔法哈希要对照错误密码。

---

## 1. 立刻跑

```bash
python3 炼蛊房/param_abuse_probe.py juggl --url https://授权/api/login --user admin --case <案>
```

产物：`案卷/param_abuse/juggl.json`。

---

## 2. 四刀

1. **认弱比较** — PHP `==` / `strcmp` 当布尔 / 松散 JSON  
2. **换类型** — `password: true` / `0` / `[]` / `"0e123456"`  
3. **对照** — 字符串错密失败，换类型出票才算  
4. **别处** — 优惠券 `0=="abc"`、文件名、hash 比较。`===` 就停

不要和 NoSQL `$ne` 混报。

---

| 档 | 成立 |
|----|------|

| L2 | 绕过登录或比较 |
| L3 | 拿到会话后走对象矩阵 |
