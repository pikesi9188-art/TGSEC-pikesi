# 提权手法（分流总卡）

> 「提权」在本库分两层，别混：  
> **A. 应用/业务提权**（Web 里普通用户→超管）  
> **B. 主机提权 LPE**（低权限 shell→root）  
> 细链：应用走各栈专卡；主机走 `反客为主.md`；容器走 `瓮中逃.md`；Windows 走 `反客为主-窗府.md`  
> 红线：仅授权；内核 exploit / 写 passwd / 容器逃逸先问

---

## 1. 30 秒分流

```text
你现在手里是什么？
  │
  ├─ Web 会话 / JWT / 普通用户（还没有 OS shell）
  │     → §2 应用提权（GVA / 代理 / PB / API 越权）
  │
  ├─ 低权限 Linux shell（www-data、app 用户…）
  │     → §3 Linux 主机提权（先跑 linux_lpe_checker）
  │
  ├─ 容器内 shell
  │     → `瓮中逃.md`（docker.sock / 组 / cap；内核先问）
  │
  ├─ Windows 低权进程
  │     → `反客为主-窗府.md`（配置优先；内核/Potato 先问）
  │
  └─ 已是 root / 云 AK Root
        → 凭据收割 / 横向 / 隧道（勿再空跑 LPE）
```

## 2. 应用 / 业务提权（无 shell 时优先）

| 指纹 | 手法 | 成功口径 |
|------|------|----------|
| GVA 开放注册 | `锦府·静默.md` | 植入超管 / 伪造 JWT |
| 博彩代理 `level` | Skill `使探针` · 代理社工杀伤链 | 代理→运营商近管 |
| PocketBase 规则松 | `口袋库.md` | 超管/可写集合 |
| 业务 API 垂直越权 | `万我·信门.md` | 普通用户调 admin |
| 芋道隐藏超管 | Actuator 堆转云 · `yudao_hidden_admin_sql` | syscache 登录 |
| JWT 弱密钥/可改 claim | 九阶段 jwt / 各栈专卡 | 伪造高权 token |

这些**不算**主机 LPE，但作业里常被口语叫「提权」。

## 3. Linux 主机提权（有 shell）

真源卡：`反客为主.md`  
工具：`python3 炼蛊房/linux_lpe_checker.py`  
Skill：`杀招/青丘`

优先序（成功率）：

1. `sudo -l` NOPASSWD / 危险 sudo  
2. 高权限组：`docker` / `lxd` / `disk`  
3. SUID/SGID → GTFOBins  
4. Capabilities（`cap_setuid` 等）  
5. Cron/可写脚本、PATH 劫持（先确认 `/bin` 不是 symlink 假象）  
6. 宝塔 `default.db` / 本机 MySQL 弱口（`LOCAL-BT-MYSQL`；拉库先问）  
7. 内核 CVE（DirtyPipe / nf_tables / SCTPhantom…）— **先问再打**  
8. 提权失败 → 收割 `.env`/配置/历史命令 → 横向

```bash
# 在目标机（或上传后）执行
python3 linux_lpe_checker.py --json --out /tmp/lpe.json
# 本机预检脚本路径：
python3 炼蛊房/linux_lpe_checker.py --help
```

## 4. 容器逃逸

真源卡：`瓮中逃.md` · K8s 细卡：`群瓮·特权.md`  
优先：可写 `docker.sock` / `docker` 组挂载宿主机 → lxd → Privileged/cap → K8s SA（独立卡）→ 内核逃逸（先问）。

## 5. Windows（降权主战场）

真源卡：`反客为主-窗府.md`  
检测：`python3 炼蛊房/windows_lpe_checker.py`（须在 Windows 目标上跑）  
长文：`智道藏书/九转/stages/07-本地提权（低权限升级高权限）.md`  
盘口/发卡 Linux 站默认**不进** Windows LPE 主线。
