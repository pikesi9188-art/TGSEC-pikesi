# ACG 共享货上游库存杀伤链（Playbook）

配套 Skill：`杀招/秦百胜·货仓/SKILL.md`（§共享货上游）  
工具：`tools/acg-faka/bin/acg_shared_upstream.py`  
授权：仅 `授权范围`；主站链发现的中转/供货域 → `scope_expand` 静默并入。

> **发卡网默认优先级**：先找上游库存，再打橱窗 RCE / 假支付。  
> 成功口径 = **能稳定读上游库存（或 SQL）**，不是死磕前台 GetShell。

---

## 0. 核心心智模型（gmail168 真经）

前台站往往只是**橱窗**；账密/卡密真源在**上游库存系统**。

```text
gmail168.com（橱窗）
    └─ 接口/资源露出 → api.code92.top（库存真源）
         ├─ /metrics 画 API 地图
         ├─ 弱口令 jobs/1234qwer
         └─ execute.sql → 超管 + 全库 → cookie.store 出货

favip / luankao（橱窗）
    └─ cover / shared_code 露出 → www.guopi.org（库存真源）
         ├─ Shared API（app_id + sign）
         ├─ inventory / items / trade
         └─ 后台 Entrance / 源站 SSH 仍待破
```

口诀：

- **支付上游管钱；共享货上游管货。钱打不通就打货。**
- **资源宿主 + 共享码 + 历史凭据 = 上游候选。**
- ACG「共享货」≈ gmail168 的 `cookie.store`（都是库存库出口）。

## 1. 「发现上游」的固定动作（可背）

| 步骤 | 做什么 | 例子 |
|------|--------|------|
| ① 跟资源 | 封面、OSS、codeUrl、跳转域 | favip cover → `guopi.org` |
| ② 跟业务字段 | `shared_id` / `shared_code` / 供货商名 | `shared_id=4` + `6C5C4D5ADD6D4398` |
| ③ 历史案卷复用 | 同供货商是否打过 | `guopi_20260715`、aaaib shared 表 |

| ⑤ 静默扩权 | 主站链发现的中转/供货域进 scope | `*.guopi.org` 并入 company |

工具一条龙：

```bash

```

## 2. 「打进数据库」的三档定义（避免空转）

| 档 | 含义 | gmail168 | 本轮 guopi |
|----|------|----------|------------|
| **L1 API 读库** | 经业务 API 读库存/出卡 | `cookie.store` 下载 | Shared inventory 已达；trade 卡余额 |
| **L2 管理/SQL** | 后台或 `execute.sql` | jobs→SQL→超管 | Entrance 未破 |
| **L3 主机/面板** | SSH/宝塔/MinIO/真 MySQL | 端口多未开 | 源站 22 开、无凭据 |

复工时先问：**目标是 L1 出卡，还是 L2/L3？** 别三档一起空扫。  
默认先冲 **L1**；L2/L3 写清复工条件再挂。

## 3. Shared 协议（异次元源码对齐）

```text
sign = md5( urldecode( http_build_query( ksort(params) ) ) + "&key=" + app_key )
# 空字符串字段不参与签名；不含 sign 自身
```

| 接口 | 作用 |
|------|------|
| `POST /shared/authentication/connect` | `shopName` + `balance` |
| `POST /shared/commodity/items` | 上游全盘 |
| `POST /shared/commodity/item` | `code=<shared_code>` 详情 |
| `POST /shared/commodity/inventory` | `sharedCode` → count / factory_price |
| `POST /shared/commodity/trade` | **强制余额**出卡（=读库） |

- `app_id` = 上游站上的商户用户 ID  
- `app_key` = 该用户对接密钥（注册时随机 **16 位大写 hex**）  
- 橱窗 `commodityDetail` **会漏** `shared_id`/`shared_code`，**不漏** `domain`/`app_key` → 用 cover / 历史 dump 补全  
- 已通样例：果皮 `app_id=1291`，`balance=0.5`（完整 key 只落案卷/本地字典，勿散写可公开文档）

## 4. 七步执行清单

- [ ] ① 授权橱窗 + Triage；假支付若已硬化 → **切本链**（勿死磕 callback）  
- [ ] ② 枚举 `shared_id` / `shared_code`  
- [ ] ③ 发现上游 domain：cover → 历史 shared 表 → 同族复用  
- [ ] ④ `scope_expand` 并入供货域  
- [ ] ⑤ Shared：`connect` → `items` → `inventory`（对齐 code）  
- [ ] ⑥ L1：余额 ≥ `factory_price` 则 `trade` 出卡；否则写复工「余额/充值」  
- [ ] ⑦ L2/L3：Entrance / 源站；STATUS + `UPSTREAM_*.json`

---

## 5. 发现上游 domain（优先序）

1. **封面/图标绝对 URL**（最高频）：`https://www.guopi.org/assets/cache/...`  
2. **历史案卷 shared 表**（RCE/后台 dump）：`domain + app_id + app_key`  
3. **同族店 cover 复用**（aaaib / zexin / gulu 等）  
4. 错误回显 / 同步失败文案含 URL（少见）  
5. CT/子域（`api.`/`oss.`）— 易遇 CF 泛解析，需 HTTP 指纹确认  

同库线索：橱窗多域名共用 `order.id`（如 favip ↔ luankao）→ 可能是**多域名同库橱窗**，上游仍可能是第三方 Shared，勿当成「已进库」。

## 6. Entrance / 源站（L2/L3）

| 形态 | 命中信号 | 注意 |
|------|----------|------|
| 核心 AdminEntrance | 响应头 `Refresh` → `/admin` + 正文「认证成功」 | 认 **Refresh**，勿只看 Location |
| Entrance 插件 | 「没有使用正确入口」+ `Config.php` 路径 | 记绝对路径；`.bak` 403 常表示存在 |
| 源站 | FOFA/历史 IP + `origin_recon` | 仅 22 开也要落 STATUS |

**禁止**未确认 Entrance 命中时广谱喷登录（`@login.lock`）。

## 7. 踩坑清单（学习向）

| 坑 | 正解 |
|----|------|
| 支付上游 ≠ 库存上游 | zephique/LemPay/TokenPay 是**钱**；guopi/code92 才是**货**。gmail168 也不是去打 USDT，而是打 code92 |
| 假支付已加固 | `sign=true` / JSON bool 在这族站失效 → **不要再当主路径** |
| 死磕前台 RCE | 成功口径改成 L1 读库存；RCE 是加分项不是必选项 |
| 三档一起扫 | 复工先选定 L1 或 L2/L3 |
| 同 order.id | 多橱窗同库 ≠ 已拿上游库存 |

与假支付分工：松散回调走 `payment-callback-forgery`；严签 + `shared_id` **走本 Playbook**。

## 8. 证据与 STATUS 模板

```text
案卷/<案卷>/案卷/acg_shared/
  discover.json          # shared_id/code + cover hosts
  connect_<host>.json
  match.json             # 橱窗 code ↔ 上游 inventory
  UPSTREAM_CHAIN.json    # 一页结论
```

STATUS 最少写清：

```text
橱窗 → 上游 domain
shared_id / 命中 codes
app_id（完整 app_key 勿写进可公开同步文档）
balance / 最低 factory
当前档位 L1/L2/L3 + 复工条件
```

## 9. 复工条件示例（可勾选）

- [ ] Shared 余额 ≥ 最低 `factory_price` 且已 `trade` 出卡（L1 闭环）  
- [ ] 上游 Entrance 路径确认 + 弱口令/会话（L2）  
- [ ] 源站非 CDN IP 上面板/SSH 可验证登录（L3）  
- [ ] 白盒/备份读出 `app_key` 或 DB 连接串
