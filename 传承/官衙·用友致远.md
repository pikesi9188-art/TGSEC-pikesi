# 用友与致远 OA 手法

> 指纹：`tools/1day-kit/custom-templates/yonyou-seeyon-oa-surface.yaml`  
> 分流：`凤九歌·天地歌.md`（国内站旁路，非盘口主线）  
> 红线：仅授权；文件上传/反序列化 RCE **先问**

---

## 1. 一句话

**用友 NC/U8/NC Cloud** 与 **致远 OA（Seeyon）** 是国内政企/内部运营常见管理面：登录页指纹 → 未授权接口/文件 → 已知历史洞。  
赌博台/发卡主线阴性、扫到 OA 子域时再打；不要当盘口第一刀。

---

## 2. 指纹

| 产品 | 路径/信号 |
|------|-----------|
| 用友 NC | `/nccloud` · `/uapws` · 体含 `Yonyou` / `用友` |
| 用友 NC Cloud | `/nccloud/resources/` · `iufo` |
| 致远 | `/seeyon/` · `/seeyon/main.do` · 体含 `Seeyon` / `致远` |
| 伴生 | 登录验证码、协同办公标题 |

```bash
python3 tools/1day-kit/od_kit.py nuclei --url https://授权站 --case <案卷> \
  --template-id yonyou-seeyon-oa-surface
```

---

## 3. 档位

| 档 | 动作 | 成功证据 |
|----|------|----------|
| **L1** | 登录页/静态资源指纹 | 确认用友或致远 |
| **L2** | 未授权信息接口、目录、备份 | 可下载配置或用户目录 |
| **L3** | 历史上传/反序列化（**先问**） | webshell 或命令回显 |

L2 阴性 → 转弱口、VPN 旁路、或回到业务主站；勿对 OA 盲打全量 1day 包轰炸。
