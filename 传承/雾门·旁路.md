# FortiOS 符号链接补丁旁路手法（CVE-2025-68686）

> 情报：`od_kit.py cvebase lookup --cve CVE-2025-68686`  
> 指纹：`tools/1day-kit/custom-templates/fortios-symlink-bypass-cve-2025-68686.yaml`  
> 总览：`新伤·在野.md`  
> 红线：仅 `授权范围`；这是**二阶读文件**，不是一键打穿 FortiGate

---

## 1. 一句话（档位别说错）

| 事实 | 含义 |
|------|------|
| KEV / 在野 | 要修、要查痕迹 |
| **不是**初访问 RCE | 厂商口径：攻击者须**先已在文件系统层**落地（先前洞/持久化） |
| 本洞干什么 | 绕过针对 `/lang/custom` symlink 持久化的补丁 → **继续读敏感文件** |
| 绕过手法 | 路径双斜杠：`/lang//custom/...`（`strstr("/lang/custom")` 失效，服务器仍解析到同目录） |

CVSS 中等（约 5.9）· 前提含 SSL-VPN 相关面；**从未开过 SSL-VPN 的不受影响**（厂商）。

## 3. 档位与成功口径

| 档 | 动作 | 成功证据 |
|----|------|----------|
| **L1 指纹** | FortiGate/FortiOS Web / SSL-VPN 门户 | 确认产品 |
| **L2 补丁旁路差分** | 授权内对比 `/lang/custom` vs `/lang//custom`（403 vs 200） | 双斜杠可过补丁检查 |
| **L3 读敏** | 仅在已有 FS 落点/symlink 场景继续读配置 | 配置/密钥类文件内容；**无先洞勿硬报 RCE** |
