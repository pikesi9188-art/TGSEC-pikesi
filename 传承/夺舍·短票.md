# 重置 Token 泄露与短密钥 ATO 手法

> 杀招：`夺舍·票面`  
> 工具：`炼蛊房/reset_token_surface_probe.py`  
> 情报：HITCON 重置 token 经广告请求外泄、金鑰空間縮減、Session Fixation  
> 红线：默认不提交邮箱；L3 只动自己的号。

```bash
python3 炼蛊房/reset_token_surface_probe.py --base https://授权站 --case <案卷>
```

| 档 | 动作 | 成功 |
|----|------|------|
| L1 | 忘记密码页 | 404 |
| L2 | 查询串 token、长度 <16、重置页挂 GTM/FB 且无 Referrer-Policy | 没发信 |
| L3 | 短 token 进自己的号 | 先问再碰他人 |

盘口 `resetPassword` 的 `code` 可空/任意 → **先** `ato_reset_withdraw_probe.py dummy-reset`（只打自己），不要先爆破验证码。  
深挖走 `account-takeover-chain`。登录后 SID 不换 = Session Fixation，记 STATUS。
