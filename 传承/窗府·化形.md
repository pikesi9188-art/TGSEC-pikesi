## 1. 一句话

on-prem **Microsoft SharePoint** 对不可信数据反序列化（CWE-502）→ **未授权网络 RCE**（CVSS 9.8）。  
KEV · 在野 · 有公开利用；常见后续是**窃取 IIS machine key**，补丁后仍可能凭密钥伪造视图状态/持久访问。

同窗常并提：`CVE-2026-58644`（需 Site Owner 等条件的另一条 RCE）——侦察时一并记 STATUS，勿混成功口径。

### 2026-08-14 新链（P1，55040 在野）

| CVE | 角色 | 补丁 |
|-----|------|------|
| **CVE-2026-55040** | JWT 校验绕过，可伪造超管票（CVSS 9.1） | 2026-07-14 |
| **CVE-2026-63520** | BCS 不安全 .NET 类型实例化 RCE（8.1） | 2026-08-11 |

两洞链在一起 = **未认证 RCE**。只打 7 月补丁即可打断链。SharePoint Online 不受影响。8/14 媒体报 55040 在野伪造凭据；**CISA KEV 正式日 2026-08-18**（不重建卡，复测本卡即可）。  
L1 仍用本卡指纹模板；L3 完整链 **先问**。详见 `CVE日报-2026-08-14.md` §3。

## 2. 战场价值

SharePoint = 文档/域集成/服务账号。打穿后不只 webshell，**machine key** 才是长期门票。  
成功口径：L3 命令执行 **或** 密钥外泄证据；修完必须写「已轮换 machine key / 凭据」。
