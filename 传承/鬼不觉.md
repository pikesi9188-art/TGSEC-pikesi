# 授权主机 C2 落地验证（L3 默认）

> 档位：**顶级默认**——在已入 scope 的自有/授权主机上，用作业机自备的开源 C2（默认 **Sliver**）验证「能否执行、杀软是否拦、能否回连、会话是否可控」。  
> 工具闸：`炼蛊房/host_c2_verify.py` · Skill：`杀招/鬼不觉·回连`  
> 前置：目标主机已在 `授权范围`；C2 服务端跑在**攻击机/实验室**，implant **不进 git**。  
> 不是社工、不是对未授权机器投递。

---

## 1. 一句话

授权主机上的 **落地执行 + 回连会话** 才算 L3 主机面过关。隧道（`internal-tunnel`）是「已有 shell 再转网」；本卡是「这台授权机上顶级 C2 能不能活」。

---

## 2. 硬闸

1. `host_c2_verify.py init` 必须通过 scope（hostname / IP / 标签在 targets 内）。  
2. 监听只绑实验室网卡；**禁止**把 C2 端口裸暴露公网扫段。  
3. implant 二进制、私钥、会话 dump **只落本机攻击机或案卷外加密盘**；案卷只记哈希与成败。  
4. 清日志 / 改原超管：**仍先问**。多机舰队的 C2 校验 + 持久化清单走 `authorized-botnet-lab` · `botnet_lab.py`（授权内直接做计划/`host_ir_check`，不传播）。  
5. 测完：结束会话、删授权机上的测试文件（除非 RoE 要求留证）。

---

## 3. 默认栈（顶级）

| 角色 | 选型 |
|------|------|
| C2 | Sliver（Bishop Fox，作业机自备官方 release） |
| 通信 | 优先 mTLS；受限网络再改 HTTP / WireGuard（仍只连实验室 IP） |
| 目标 OS | 按授权主机：windows / linux / darwin |
| 证据 | `案卷/<案卷>/案卷/host_c2/` |

安装与 `generate` / listener 以 [Sliver 官方文档](https://github.com/BishopFox/sliver) 为准，在攻击机完成；本仓库不存放 server/implant 二进制。

## 4. 最短命令（引擎侧）

```bash
# 开案 + scope 闸 + 空 verdict
python3 炼蛊房/host_c2_verify.py init \
  --case <站_日期> \
  --host <授权主机IP或主机名> \
  --os windows \
  --stack sliver

# 攻击机完成 listener + implant 后，把结果写回（勿贴密钥）
python3 炼蛊房/host_c2_verify.py record \
  --case <站_日期> \
  --host <授权主机IP或主机名> \
  --implant-sha256 <sha256> \
  --av-action <deleted|quarantined|allowed|unknown> \
  --callback <yes|no|partial> \
  --session-id '<会话编号或 none>' \
  --note '一句话'

# 结案核对
python3 炼蛊房/host_c2_verify.py check --case <站_日期> --strict

# 脚本级回连（payload_forge 出的 se_cb.*）用本库监听，案卷落 listen.jsonl
python3 炼蛊房/se_listen.py --lhost 0.0.0.0 --lport 4444 --case <站_日期>
```

## 5. 成功定义（L3）

| 项 | 通过 |
|----|------|
| scope | init 未拒 |
| 执行面 | 授权机上进程曾启动，或杀软明确隔离/删除（也算「测到了」） |
| 回连 | `callback=yes` 且有 `session_id` |
| 可控 | 至少一条只读命令证据写在 note / SUMMARY（whoami / hostname） |
| 清理 | 会话已 kill；测试文件已删或 RoE 注明保留 |

`av-action=deleted` 且无回连 → **L3 未过**，但案卷记「EDR/AV 有效拦截」——这是有效结论，不是空转。

## 7. 与 EDR / 「免杀」怎么接

落地前先清自己的特征，再验回连。implant 不进 git，作业照做。

```text
sig_cleanup_scan.py --path <样本>     # dirty 先清
  → edr-bypass-re 认产品
  → host_c2_verify.py init --edr <产品>
  → 攻击机自备 C2（doctor 只检查 PATH）
  → 仅复制到授权主机执行
  → record --av-action --callback --edr
```

手法：`传承/隐鳞.md`

| 现场 | 记法 | 含义 |
|------|------|------|
| 文件秒删 / 隔离 | `av-action=deleted\|quarantined` `callback=no` | EDR 有效，L3 未过，**这是有效结论** |
| 进程起来但无回连 | `partial` | 网络/监听问题，不是一定被杀 |
| 回连 + 有 session | `allowed` + `callback=yes` | L3 过关；再开隧道/域卡 |

`host_c2_verify.py doctor` 只确认攻击机有没有官方客户端，不生成 implant。
