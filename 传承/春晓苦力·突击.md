> 探针：`炼蛊房/strike_probe.py`

## 1. 一句话

指纹/目录侦察跑完、还没有 TP3 / XXL / 假支付 / Actuator 等专卡命中时，**先打一遍 S1–S8 短字典突击**，再交给已有细探针深挖。  
禁止另起利用脚本；`--deep` 只调用 `dirbrute` / `auth_brute` / `core_web` / `ssrf`，首页命中 Next/ASP.NET/gRPC/VPN 指纹时再拉对应猎面探针。

```bash
python3 炼蛊房/strike_probe.py doctor
python3 炼蛊房/strike_probe.py -u https://授权站 --case <案卷>
# 交接已有探针（本层仍是快面；命中后授权内写马/反弹直接做）
python3 炼蛊房/strike_probe.py -u https://授权站 --case <案卷> --deep
```

落盘：`案卷/strike/surface.json`

## 3. 何时用 / 何时不用

**用**：无专用栈业务站；`auto_campaign` / `kit_run web|php` 侦察后；用户点名「黑盒突击 / strike_probe / S1–S8」。  
**不用**：已命中专卡（TP3 分销 / XXL-JOB / TG 号管 / 假支付 / Gateway）；只扫 health 的 Actuator（走全链）；破坏性 OUTFILE / 改超管密。

---

## 4. 成功口径

L1：露出后台/API/上传表。  
L2：弱 token 须 401/403→200 或 JSON 新出 token；IDOR 须 JSON 里 id 真为 1 vs 2；SQL 须语法报错句（禁止 phpinfo 里的 `mysql_`）；LFI 文件内容；SSTI 算出 9359 且对照请求没有；提权参数新出 `"role":"admin"`。  
**禁止**把 S8 算术阳性写成 RCE 结案。
