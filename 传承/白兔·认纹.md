# 图形验证码 OCR 与旁路

> 工具：`炼蛊房/captcha_auto.py ocr` · Skill：`杀招/白兔·认纹`  
> 仅 `scope` 授权目标。

## 分流（先选型再动手）

| 类型 | 做法 |
|------|------|
| 数字/字母图 | `captcha_auto.py ocr` |
| 滑块 / 点选 / GeeTest | `captcha_auto.py solve/slide`（本机有头真鼠标）；有打码 Key 走 `token` |
| Cloudflare Turnstile / 挑战页 | `scrapling` / `cf_session` |
| 短信 / TG 接码 | `ff_jiema` 等，非本手册 |
| 若依等 Redis 存码 | 读 `captcha_codes` **旁路 OCR**（见若依四海） |
| GVA 领奖墙 | 可 OCR；复杂时人工 `--confirm` |

## 命令

```bash
python3 炼蛊房/captcha_auto.py doctor
python3 炼蛊房/captcha_auto.py ocr doctor
python3 炼蛊房/captcha_auto.py ocr file --path captcha.png --case <案卷>
python3 炼蛊房/captcha_auto.py ocr url  --url https://授权站/.../captcha --case <案卷>
# 识别差可加 --beta

# 极验 / 滑块（不要 OCR）
python3 炼蛊房/captcha_auto.py doctor
python3 炼蛊房/captcha_auto.py solve --url https://授权站/login --case <案卷>
# 字母图整页自动抽图
python3 炼蛊房/captcha_auto.py ocr --url https://授权站/login --case <案卷>
```

打码 Key：`config/captcha_keys.env`（gitignore）。过闸会话：`接管/session/storage_state.json`。

证据：`案卷/<案卷>/案卷/captcha_ocr/`

## 成功口径

- OCR 文本可用于后续登录/业务请求，且响应证明码被接受；或
- 旁路成立（Redis/禁用验证码/人工）并留下证据，不必强行 OCR。
