# 空间眼（Playbook）

参考：CSDN《从 Censys 出发，绕过 CDN 识别真实 IP》（VoltCary）  
截图引擎表：Shodan / **Censys** / FOFA / **ZoomEye** / **Quake**  
工具：`tools/space-search/bin/space_search.py`  
衔接：`炼蛊房/origin_recon.py`（FOFA + cdn_tracer）· 总览见 `云帷·源溯.md`

## 1. 心智

CDN 前的域名往往与源站共用（或高度相关）TLS 证书。空间引擎扫全网 IP 时会收下证书；用「域名证书指纹/SAN/序列号」反查 Hosts，即可得到源站候选 IP。

| 关联场景 | 含义 |
|----------|------|
| 证书完全一致 | 同指纹/公钥出现在 CDN 与某 IP |
| 主题/颁发者相关 | 同组织证书族 |
| 证书链关联 | 同中间 CA 批量签发（弱线索） |
| 协议行为 | Server 头等辅助 |

**注意：** CDN 厂商共享证书易误报；候选必须用 `Host:` 直连验证，勿直接当源站开打。

## 2. 五引擎分工（截图对齐）

| 引擎 | 用途 | 本库状态 |
|------|------|----------|
| FOFA | 国内空间搜索首选 | 已有 `config.yaml` + `origin_recon` |
| Shodan | 全球空间搜索、证书/Favicon | 已有 Key |
| **Censys** | 证书序列号/指纹反查 IP（文章主推） | Platform PAT + `organization_id` |
| **ZoomEye** | 国内备用 | **需补 api_key** |
| **Quake (360)** | 国内空间搜索 | **需补 token** |

## 3. 申请 Key（一次性）

1. Censys（推荐新版）：https://accounts.censys.io/settings/personal-access-tokens  
   - `api_token`：Personal Access Token（`censys_…`）  
   - `organization_id`：同页 **Current Organization** 的 UUID（付费组织必填，否则搜索 API 当免费档拒绝）  
   - 旧版 Legacy：`api_id` / `api_secret` 仍可选用  
2. ZoomEye：https://www.zoomeye.ai/profile → `API-KEY`  
3. Quake：https://quake.360.net → 用户信息 / API Token  

写入 `config.yaml`（模板见 `config.example.yaml`），**勿把完整 Key 写进 STATUS/公开文档**。

```bash
python3 tools/space-search/bin/space_search.py doctor
```

## 4. 自动化

```bash
# CDN/证书旁路（多引擎）
python3 tools/space-search/bin/space_search.py cert-origin \
  --domain 授权根域 --case <案卷>

# 任意语法
python3 tools/space-search/bin/space_search.py search \
  --query 'cert="example.com"' --engines fofa,censys,zoomeye,quake \
  --case <案卷>

# 经典链路仍可用
python3 炼蛊房/origin_recon.py --domain 授权根域 --case <案卷>
```

产物：`案卷/<案卷>/案卷/space_search/cert_origin.json`

## 5. 常用查询备忘

| 引擎 | 证书/域名 |
|------|-----------|
| FOFA | `cert="域名"` `domain="域名"` |
| Shodan | `ssl.cert.subject.CN:域名` `hostname:域名` |
| Censys Hosts | `services.tls.certificates.leaf.names: 域名` |
| Censys Certs | `names: 域名` → 再按 fingerprint 查 hosts |
| ZoomEye | `ssl:"域名"` `hostname:"域名"` |
| Quake | `cert:"域名"` `domain:"域名"` |

## 6. 与防御侧对照（文章）

源站应：禁公网直连、拒 IP 握手（nginx `ssl_reject_handshake`）、默认假站、屏蔽测绘 UA。红队作业时这些会降低命中率——记 STATUS「证书反查无果」。

## 7. 优先级

```text
授权域名
  → origin_recon（FOFA + cdn_tracer + DNS）
  → space_search cert-origin（Censys 优先补证书）
  → Host 头验证非 CDN 候选
  → 新 IP/Host 进 scope 再打
```
