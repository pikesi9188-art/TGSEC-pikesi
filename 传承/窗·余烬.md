# 浏览器 Cookie 与窃密包离线分诊手法

> 杀招：`偷生`（离线段）  
> 探针：`炼蛊房/browser_loot_triage.py`  
> 回灌授权站：`replay`（整包 + 指纹 UA）→ `session_import.py` → `session_pipeline`  
> **报告/屏幕禁止出现 Cookie 值、密码、Token。**

现场常见三种包（本次实证）：

| 形态 | 指纹 | 不要当成 |
|------|------|----------|
| Firefox `cookies.sqlite` | 表 `moz_cookies` | Chrome `Cookies` SQLite |
| Chrome 窃密目录 / `.rar` | `fingerprint.json` + `Default/cookies.json` + `passwords.json` + `tokens.json` | HackBrowserData 现场输出（字段不同） |
| 单份 `cookies.json` | `host/name/value` 或 Playwright | 随便粘的 `Cookie:` 头（走 session_import） |

`Chrome.rar` 与 `Chrome (1).rar` 曾是同一份，先 `md5` 去重。RAR 里的 `9.py` 已收进本库：`replay --url`（整包 Cookie + 指纹 UA 打授权 URL）。多编码修 JSON、去 host 前导点、UA 跟 `browser_version` 一并回收。

## 强制顺序

```text
包丢进案卷根 / 测绘 / 接管
 → auto_campaign plan|run --case <案> 自动 from-case --url <授权站>
   或手跑 from-case / replay
 → 活会话 → session_import --domain 授权域
 → session_pipeline 验活
 → 对象矩阵；密码表只当「该站有存密」线索，不回放他人账密
```

`.rar` 由探针找 `unar`（PATH / `tools/vendor/unar` / `/tmp/unar-bin/unar`）解到同级 `<stem>_unpacked`。没有 unar 会明确报缺，不要装死。

`tokens.json` 的 `service=AccountId-<数字>` 是 Chrome GAIA 绑定票，不是网站 JWT。不要丢进 `jwt_gql_probe`。

## 命令

```bash
python3 炼蛊房/browser_loot_triage.py doctor
# 案卷里有包：战役自动分诊 + 回放授权 URL
python3 炼蛊房/browser_loot_triage.py from-case --case <案卷> --url https://授权域
python3 炼蛊房/auto_campaign.py plan -d <授权域> --case <案卷>
# 整包回放（9.py 同款：全 jar + fingerprint UA）
python3 炼蛊房/browser_loot_triage.py replay --path /path/Chrome.rar --url https://授权域 --case <案卷>
# 把整包域名改写到目标 host 再发（host 对不上时）
python3 炼蛊房/browser_loot_triage.py replay --case <案卷> --url https://授权域 --whole-jar
python3 炼蛊房/browser_loot_triage.py triage --path /path/cookies.sqlite --case <案卷>
python3 炼蛊房/browser_loot_triage.py export-scope \
  --path /path/包 --domain 授权域 --case <案卷>
python3 炼蛊房/session_import.py --domain 授权域 \
  --input 案卷/<案>/案卷/browser_loot/SCOPE_COOKIES.json \
  --out 案卷/<案>/接管/session
```

窃密 JSON 的域在 `host`（不是 `domain`），HttpOnly/Secure 在 `is_httponly` / `is_secure`。`session_import` 已认这两套字段。损坏 JSON 按 utf-8 / gbk / latin-1 等试，末尾多余逗号会修，不要先当二进制扔掉。

`replay` 默认按 Cookie 原 host 装 jar（与 `9.py` 相同，由客户端按域发送）。`--whole-jar` 把全部 Cookie 改写到目标 host。URL 必须在 `in_scope`。

## 不要做

- 把 GAIA `AccountId-*` 当网站 session
- 把完整 `passwords.json` 或 Cookie 值写进可同步文档 / 打到屏幕
- 对未写入授权范围的 URL 回放（先 `scope_expand --grant`）
