# 业务 API 未授权与越权手法

> 打网站时**无专用栈指纹**、或栈专卡阴性后的默认面。  
> 工具：`python3 main.py authz-probe -u <授权站>`  
> 细读：`智道藏书/新手SEC快速升级指南/01-基础知识-逻辑漏洞.md` · 九阶段 `api-security-testing`  
> 红线：仅 `授权范围`；大规模拉库先问

---

## 1. 一句话

先找 **Swagger/OpenAPI / 前端 JS 里的 API**，再按 **未鉴权 → 水平越权 → 垂直越权** 两阶段压；命中专用栈（支付/GVA/PB/Actuator）立刻切专卡，勿在通用面空转。

---

## 2. 指纹与入口

| 信号 | 常见路径 |
|------|----------|
| OpenAPI | `/v3/api-docs` · `/v2/api-docs` · `/swagger-ui/` · `/swagger.json` · `/api-docs` |
| 前端泄路由 | `*.js` 里 `/api/`、`authorityId`、`notify`、`getConfigs` |
| 管理面 | `/admin` · `/api/admin` · 随机 path（发卡） |
| 文档站 | ShowDoc / Knife4j / Druid |

```bash
# 未鉴权 + 越权双阶段（引擎内置）
python3 main.py authz-probe -u https://授权站 --scope 授权范围

# 1day 指纹并行（勿替代专卡）
python3 tools/1day-kit/od_kit.py nuclei --url https://授权站 --case <案卷>
```

---

## 3. 档位

| 档 | 动作 | 成功证据 |
|----|------|----------|
| **L1** | 文档/JS 还原接口清单 | 可复用 path 列表落 `案卷/` |
| **L2** | 无 Cookie/错 Token 调敏感读 | 200 + 业务数据（非登录页 HTML） |
| **L3** | 改 `id`/`userId`/`orderNo` 水平；普通用户调 admin | 他户数据或管理写成功 |
| **L3b** | info 类吐 **bcrypt / 资金密码 hash** | 两枚 userId 哈希不同（全表拖库先问） |
| **L3c** | 给自己加款失败、给他人成功 | **B 自己的票**查到余额差（快照不算） |

`/api/user/info` 默认当 IDOR 测。给自己写失败立刻打他人 uid。进超管后先收配置/COS 钥。细则：`万我.md`。  
资金面换 `wallet_id` / 双路径 / 展示层地址 / 消息神谕：`血神子·账.md`（uid 阴不准写无越权）。

两轮同态失败 → 换：CDN 源站 / IP 白名单头 / WAF SQLi / 支付矩阵 / DeepAudit。

## 4. 与专卡的交接

| 发现 | 立刻切 |
|------|--------|
| `notify` / `callback` / 易支付 | 假支付 / `pay_matrix` |
| `/actuator` · `gateway/routes` | Actuator / Gateway 全链 |
| GVA `register` · `authorityId` | GVA 静默提权 |
| PocketBase `/_/` | PB 规则误配 |
| 若依 `captchaImage` | 验证码 Redis 旁路 |
| 已有低权票 + 管理路由 / `role` / Method-Override / 批量 ids | **`无极·职分.md`** · `rbac_bypass_probe.py` |

分流总卡：`凤九歌·天地歌.md`。水平换 uid 仍走对象矩阵；垂直功能面走 RBAC 卡。

## 5. 复工条件示例

- [ ] OpenAPI 或 JS 已还原 ≥1 条高价值写接口  
- [ ] L2 未鉴权读或 L3 越权写有差分证据  
- [ ] 无会话/全 CF 墙 → 写 `session_import` 复工，勿只刷 authz
