> 本机只读检测：`炼蛊房/ad_surface_check.py`  
> 前置：已有 shell 或 SOCKS → `太白云生·飞鹤游天.md` · `纵横天下.md`  
> 主机面：`反客为主.md` / `反客为主-窗府.md`  
> 细读：九阶段 `active-directory-lateral-movement`（步骤以作业机已有官方工具为准）  
> 红线：仅授权域；本库跑 `ad_surface_check` + 隧道 + `internal_scan` + LPE checker

---

## 1. 一句话

打网站主战场是 **Linux 业务机**。只有目标明确是 **Windows 域** 且已在 scope，才进本卡。  
默认路径：认出域 → 隧道 + `internal_scan` → 本机 LPE checker。

---

## 2. 默认命令（L1，在跳板/目标本机）

```bash
python3 炼蛊房/ad_surface_check.py --case <案卷>
# 或
python3 炼蛊房/ad_surface_check.py --json --out 案卷/ad/surface.json
```

落盘：`案卷/<案卷>/案卷/ad/surface.json`  
L1 成功：`is_domainish=true` 且记下网段/角色；或明确 `false` 并退回内网扫描卡。

```text
是域
  → SOCKS 通：python3 tools/tunnel-kit/internal_scan.py （存活/端口/webfp）
  → 当前 Linux 跳板：python3 炼蛊房/linux_lpe_checker.py --json --out 接管/lpe/lpe.json
  → 当前 Windows 低权：python3 炼蛊房/windows_lpe_checker.py --json --out 接管/lpe/windows_lpe.json
  → Kerberos/BloodHound 细读九阶段全文
不是域
  → 退回 纵横天下.md，继续打业务站
```
