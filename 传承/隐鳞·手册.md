## 1. 基本思路

```
遭遇 WAF 拦截
 └─ 识别 WAF 类型（waf-detector Skill）
     └─ 选对应编码变体（evasion.py encode --waf ...）
         └─ 在授权目标上批量测试（evasion.py matrix）
             └─ 取通过的变体 → 进后续利用链
```

---

## 2. WAF 类型判断

| 响应特征 | WAF |
|---------|-----|
| `cf-ray` 响应头 | Cloudflare |
| `Ali-Swift` / `X-Cache: MISS from` | 阿里云/SafeDog |
| `X-SafeLine-*` 头 | SafeLine |
| `Server: BaiduYunSP` | 百度云 |
| `X-Tengine-Error` | Tengine/阿里 |
| 直接 444 TCP RST | Nginx 限速/腾讯 |

## 3. 编码绕过矩阵

```bash
# 查看 payload 的所有变体
python3 tools/evasion-kit/evasion.py encode \
  --payload "' OR 1=1--" \
  --waf cloudflare

# 在授权目标上批量测试（每 800ms ± 40% 一个请求）
python3 tools/evasion-kit/evasion.py matrix \
  --url https://TARGET/search \
  --payload "' OR 1=1--" \
  --param q \
  --waf cloudflare \
  --case <案卷> \
  --delay-ms 800 \
  --insecure
```

### 常见组合

| 场景 | 推荐变体 |
|------|---------|
| SQLi / Cloudflare | `double-url-encode` + `comment-insert` |
| SQLi / 阿里云 | `aliyun-unicode` + `newline-inject` |
| SQLi / SafeLine | `safeline-multipart`（将参数放进 multipart body）|
| XSS / 通用 | `html-decimal` + `html-hex` 混用 |
| 路径穿越 | `url-encode-upper` + `double-url-encode` |

## 5. 时序控制

- 默认 `--delay-ms 800`（560–1040ms 随机）
- 对频率敏感目标用 `--delay-ms 3000`（2100–3900ms）
- 脚本内调用 `jitter_sleep(base_ms, variance_pct)`

## 6. 蜜罐 / 沙箱检测

```bash
python3 tools/evasion-kit/evasion.py sandbox-detect \
  --url https://TARGET --case <案卷>
```

检测逻辑：
1. 异常响应头（X-Honeypot / X-Canary 等）
2. 响应体关键词（cowrie / dionaea / glastopf）
3. 不存在路径返回 200 且 body 长度与首页一致
4. 异常 Server 头（nginx/0.x / fake）

| verdict | 处理 |
|---------|------|
| `clean` | 正常推进 |
| `suspicious` | 降低侦察烈度，上报 triage 冷冻 |
