## 今日新卡 1：MLflow CVE-2026-64849

**原理**：默认 Tracking Server 无鉴权。`POST /api/2.0/mlflow/webhooks/{id}/test` 只对原始 URL 跑 `_validate_webhook_url()`，delivery 跟随 302 且不钉解析 IP，可打内网/云元数据并把 `response_body` 回给调用方。  
**影响**：`< 3.15.0`。**修**：`3.15.0`。  
**默认只做到 L2（指纹 + 未授权 `GET /api/2.0/mlflow/webhooks`）**。不要写成 `/webhooks/list`。协作域验证可做；打 `169.254.169.254` / 无关网段禁止。

```bash
python3 炼蛊房/nday_route.py -u https://授权站 --case <案卷>
python3 tools/1day-kit/od_kit.py nuclei --url https://授权站 --case <案卷> \
  -t tools/1day-kit/custom-templates/mlflow-ssrf-cve-2026-64849.yaml
```

- Skill：`杀招/流实验`  
- 手法：`传承/流实验·游方.md`

## 今日新卡 2：Zimbra CVE-2026-73570

**原理**：可选包 `zimbra-snmp` + 开启 SNMP 通知 + `swatchdog` 时，未认证 SMTP 输入进命令拼接，以 `zimbra` 用户执行。  
**影响**：`< 10.1.20` 且满足上述三条件。**修**：`10.1.20+`。  
CERT Polska 08-17 报在野；CISA 08-21 进 KEV。无公开 PoC。

**默认只 HTTP 指纹 + 抠版本。** 禁止自造 SMTP 注入包。

```bash
python3 炼蛊房/nday_route.py -u https://授权站 --case <案卷>

  -t tools/1day-kit/custom-templates/zimbra-snmp-cve-2026-73570.yaml
```

- Skill：`杀招/信巢`  
- 手法：`传承/信巢·闻管.md`
