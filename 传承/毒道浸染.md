# 大爱仙尊 XSS 作业手法

> 杀招：`毒道浸染`  
> 面探：`python3 炼蛊房/core_web_surface_probe.py --base https://授权站 --case <案>`  
> 检索：`python3 炼蛊房/payload_lookup.py --type xss`

目标须在 scope。打真实用户 cookie 先问。

---

## 1. 立刻跑

```bash
python3 炼蛊房/core_web_surface_probe.py --base https://授权站 --case <案>
python3 炼蛊房/payload_lookup.py --type xss
```

验收：**脚本在目标源执行**（自己的 payload 回显进 DOM / 事件），不是 alert 弹了就算。  
CSP 在就换事件处理器 / JSONP / 上传 SVG，不要连打 50 条反射。

---

## 2. 四刀

1. **钉点** — 搜索框 / 昵称 / 富文本 / URL 回显 / JSON 进 innerHTML  
2. **认上下文** — HTML 文本、属性、JS 字符串、URL，各用各的闭合  
3. **过滤器** — 编码一次不够就二次；`payload_lookup` 取变体，WAF 走 `evasion-kit`  
4. **要会话** — 反射只证明执行；要票走 cookie 的 HttpOnly 与 CORS，存储型才接账号

DOM XSS：先搜 `location` / `innerHTML` / `document.write`，再谈 payload。  
WP / 盘口富文本有专卡先专卡。
