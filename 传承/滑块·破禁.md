| 特征 | 版本 |
|------|------|

| `captchaId` + `lot_number` + `gen_time` | **v4（当前主流）** |

## 路线 B：JS 逆向本地生成（无需打码费，但复杂）

### B.1 抓包定位关键请求

```
目标：找 gcaptcha4-hrc.geetest.com 的 load 和 verify 请求
工具：Reqable / Burp + 真机或模拟器（tools/vendor/MkTs-UU 已有配置）
```

```
GET https://gcaptcha4-hrc.geetest.com/load?captcha_id=62c528ea...
→ 返回 challenge / lot_number / bg (背景图) / slice (滑块图) / y (滑块位置)

POST https://gcaptcha4-hrc.geetest.com/verify
→ 带 w 参数（核心：鼠标轨迹加密串）
→ 返回 lot_number / pass_token / gen_time / captcha_output
```

### B.2 w 参数构成

v4 的 `w` 参数 = `AES(轨迹数据 JSON) + RSA(AES_KEY)`，其中：
- AES 密钥：每次随机 16 字节
- RSA 公钥：从 Geetest JS 中提取（固定）
- 轨迹：模拟鼠标从起点到终点的 x/y/t 数组

```python
# 本库无 geetest_v4_w.py。实战入口：python3 炼蛊房/captcha_auto.py solve --url … --case …
import json, random, time
from Crypto.Cipher import AES
from Crypto.PublicKey import RSA
from Crypto.Cipher import PKCS1_v1_5
import base64

GEETEST_RSA_PUB = """-----BEGIN PUBLIC KEY-----
MIIBIjANBgkqhkiG9w0BAQEFAAOCAQ8AMIIBCgKCAQEA...（从极验JS提取）
-----END PUBLIC KEY-----"""

def gen_track(distance: int) -> list:
    """生成从 x=50 滑动 distance 像素的模拟轨迹"""
    track = []
    x, y = 50, 300
    t = int(time.time() * 1000)
    # 匀加速→匀减速模拟
    for i in range(distance):
        x += 1
        y += random.randint(-1, 1)
        t += random.randint(8, 20)
        track.append([x, y, t])
    return track

def build_w(lot_number: str, track: list, aes_key: bytes) -> str:
    payload = json.dumps({
        "lang": "zh-cn",
        "userresponse": track,
        "lot_number": lot_number,
        "em": {"ph": 0, "cp": 0, "ek": "11", "wd": 1, "nt": 0, "si": 0, "sc": 0},
        "ep": "123",
        "passtime": track[-1][2] - track[0][2],
    }, ensure_ascii=False, separators=(",", ":"))

    # AES-CBC 加密 payload
    iv = b"0000000000000000"
    cipher = AES.new(aes_key, AES.MODE_CBC, iv)
    pad_len = 16 - len(payload) % 16
    payload_enc = base64.b64encode(
        cipher.encrypt(payload.encode() + bytes([pad_len]) * pad_len)
    ).decode()

    # RSA 加密 AES key
    rsa_key = RSA.import_key(GEETEST_RSA_PUB)
    rsa_cipher = PKCS1_v1_5.new(rsa_key)
    key_enc = base64.b64encode(rsa_cipher.encrypt(aes_key)).decode()

    return payload_enc + key_enc
```

> ⚠️ 极验会更新 JS 混淆，此方法需要定期逆向维护。打码平台更稳定。

## 路线 C：Playwright 有头浏览器

```python
from playwright.sync_api import sync_playwright
import time

with sync_playwright() as p:
    browser = p.chromium.launch(headless=False)   # 有头模式
    ctx = browser.new_context()
    page = ctx.new_page()

    # 打开登录页
    page.goto("https://yzgj777.cc/login")
    page.fill("input[name='username']", "pikesikaifa")
    page.fill("input[name='password']", "71DvydB9")

    # 触发极验
    page.click("button[type='submit']")

    # 等待极验弹出 → 人工滑动 → 继续
    print("请人工完成滑块验证，完成后按 Enter 继续")
    input()

    # 抓登录成功后的 token（从 Cookie 或 localStorage）
    cookies = ctx.cookies()
    token = page.evaluate("localStorage.getItem('token') || ''")
    print("Token:", token)
    print("Cookies:", [c for c in cookies if "token" in c["name"].lower()])
```
