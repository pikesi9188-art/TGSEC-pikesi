# 搜魂蛊

> 杀招：`搜魂蛊`  
> 工具：`炼蛊房/sensitive_dir_dump_probe.py`  
> 大爱仙尊专卡。开放目录 × AI 工具 × heapdump/Actuator/Nacos。破限脚本不进本库。  
> 红线：目标必须在 `授权范围`。L2 报告只记片段；全文只落案卷 `案卷/dir_dump/`。  
> FOFA/Shodan **必须带授权域**，禁止无域全网扫，禁止 `fofoapi.com`。

---

## 0. 本卡闸门

| 外部常见打法 | 大爱仙尊 |
|---------|------|
| 六引擎裸搜 `title="Index of"` + `.claude` | 只搜 `domain="授权域" && …`（`space-queries`） |
| `fofoapi.com` / 无域全网 | **禁止**；只用 `config.yaml` Yanbai VIP |
| 100 线程扫全网存活 | `--base` 单站 / 已授权 URL 列表 |
| SSH `whoami` | **hunt 默认连**：仅 scope 内 host，只读 `whoami` |
| `/models` + 余额 | **先问**；你点头后加 `--verify-balance` |
| heapdump 只 strings / 自造 JDump | `heap_cred_scan.py`（正则 + 蓝鸟对象图） |
| 目标机助手配置破限 / SOUL 注入 | 不跑；高级模型身份走开源版不带的助手注入 |
| Discord/TG 推未脱敏 key | 不做 |
| HTML 报告全文 key | 案卷 JSON 片段；raw 只在 `案卷/dir_dump/raw/` |

主机后渗透 LSASS / 浏览器密仍走 `credential-harvest`，不并进本卡。

## 1. 何时启用

- `Index of /` / `Directory listing` / `Parent Directory`
- href 出现 `.env` `.git/` `.ssh/` `.claude/` `.cursor/` `.kube/`
- 用户点：开放目录、猎杀资产、凭证淘金、`.hermes`/Codex 目录、tfstate

**不要走**：无会话打管理 API（`rbac-bypass-authz`）；Vite `@fs`（`vite-fs-read`）；路径穿越（`lfi-rfi-exploit`）。

### 帧 4–11 — AI / IDE / 本地模型 / 自动化目录

每类只取短名单：`settings.json` `credentials.json` `.env` `config.json` `auth.json` `config.toml`。

目标机 `.hermes`：`auth.json` → `credential_pool[].source=env:VAR` → 回根目录 `.env` 取 `VAR`。  
Codex：`config.toml` 即使用 OAuth 也可能夹第三方 token。  
Ollama / n8n / Dify / Flowise / Langflow：credentials 当配置面，不是只扫 health。

### 帧 14 — SSH 连接（默认开）

发现私钥且 host ∈ scope：

```text
ssh -o BatchMode=yes -o StrictHostKeyChecking=no -o IdentitiesOnly=yes \
    -o ConnectTimeout=8 -i <raw密钥> <user>@<host> whoami
```

用户试：`root` `ubuntu` `admin` `www-data` `debian` `ec2-user`。  
只读 `whoami`。禁止跳到 scope 外 IP。`--no-ssh` 关闭。

### 帧 15 — 第三方余额（先问）

你明确说「验余额」或命令带 `--verify-balance` 才打供应商接口。  
默认只做前缀分类（`sk-ant-`→Anthropic）。  
验证只走 `/models` 或官方余额/额度 GET，**不发 chat 耗量**。

| 前缀 | 探 |

| `sk-ant-` | Anthropic `/v1/models` |
| `sk-` | OpenAI `/v1/models` + billing |
| `deepseek-` | DeepSeek `/user/balance` |
| `gsk-` | Genspark（无公开余额则只 /models） |
| `groq_` / `together_` / `fireworks_` / `cohere_` / `mistral-` / `r8_` / `jina_` / `xai-` / `hf_` | 对应官方 `/models` 或 account GET |

## 4. 最短命令

```bash
python3 炼蛊房/sensitive_dir_dump_probe.py doctor

# 浅扫（旧行为）
python3 炼蛊房/sensitive_dir_dump_probe.py dump --base https://授权站 --case <案卷>

# 全帧猎取（默认 SSH whoami；余额先问）
python3 炼蛊房/sensitive_dir_dump_probe.py hunt --base https://授权站 --case <案卷>

# 你点头后再验余额
python3 炼蛊房/sensitive_dir_dump_probe.py hunt --base https://授权站 --case <案卷> --verify-balance

python3 炼蛊房/sensitive_dir_dump_probe.py space-queries --domain 授权域
python3 炼蛊房/sensitive_dir_dump_probe.py space-hunt --domain 授权域 --case <案卷> --tier extra,ai
# --tier all 跑满；--wayback 拉 CDX；--then-hunt 对命中 URL 再 hunt
```

新开对话：给授权域名 → 读本手法 / Skill `搜魂蛊` → **先 `space-hunt` 再 `hunt`**。路由钉在 `AGENTS.md` 与 `.cursor/rules/大爱仙尊-项目定位.mdc`（每会话必读）。禁止去掉 `domain=` 做全网猎杀。
