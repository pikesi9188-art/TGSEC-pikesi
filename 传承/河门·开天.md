> 情报：`od_kit.py cvebase lookup --cve CVE-2026-8037`

## 1. 一句话

Progress Kemp **LoadMaster** 管理 API **`/accessv2`** 未鉴权；`escape_quotes()` 未正确 `\0` 终止 → 堆 OOB 读把攻击者喷入的命令拼进 `system()` → **预认证 root RCE**。  
KEV · 在野 · EPSS≈0.99 · CVSS 9.8。

同批还可连看厂商公告里的 **CVE-2026-33691**（高危，非本卡主路径）。

---

## 2. 为什么值钱

边缘 ADC / 负载均衡：打穿后常见收获是证书、后端实 IP、管理会话、内网跳板。  
勿只当「WAF 指纹里的 Kemp」记一笔就过——有 `/accessv2` 就要按本手法推档。
