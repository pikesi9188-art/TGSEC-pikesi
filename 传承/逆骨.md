# 大爱仙尊逆向作业手法

> 这是本库自己的作业层，不是工具百科。  
> 别人列 GhidrAssist / GEPETTO / ChipWhisperer。我们写：**认族、dump、复现、过闸**。  
> 杀招：`逆骨` · 分诊：`python3 炼蛊房/re_sample_triage.py`  
> 路由：`python3 炼蛊房/reverse_skill_route.py --hint "<任务>"`  
> 专题表：`逆骨·分科.md` · 缺口表：`逆骨·认族.md`

目标须在 `授权范围`。本地自有样本写进案卷 `案卷/`。  
专链（假支付 / 芋道 / Gateway / 盘口加密）优先于通用逆向。

## 1. 开场

```text
用户丢样本 / 说「逆向」
  → re_sample_triage.py --path <文件>     # 认族，不联网
  → reverse_skill_route.py --hint "<原话>" # 专卡
  → 有 --target 先过 scope（未授权 exit 2）
  → 打开 PRIMARY，跑卡上默认命令
  → 验收：服务端接受，或本地对同一输入复现签名
```

```bash
python3 炼蛊房/re_sample_triage.py --path ./app.apk --case <案>
python3 炼蛊房/re_sample_triage.py --self-test
python3 炼蛊房/reverse_skill_route.py --hint "JSVMP wasm worker"
```

浏览器偶发成功、只贴 hex、只 `strings` 到一行盐，**都不算交付**。

## 2. 四刀（本库口径）

| 刀 | 做什么 | 不做 |
|----|--------|------|
| **认族** | 魔数 + 包内文件名 + 短字符串 → 一张主卡 | 同时开 IDA + Ghidra + r2 |
| **dump-first** | 壳 / 加密 so / 动态 DEX 先落地明文 | 对磁盘壳 so 下结论；一上来 Frida spawn |
| **观察-采样-复现** | 页面/运行时证据 → 本地最小脚本 | 空想补 `window/document/crypto` |
| **过闸** | 服务端接受，或 `pure-*` 对同一输入出相同签名 | 控制台偶发、截图当结案 |

专卡阴性必须回对象矩阵换格子，禁止「逆向没看懂 → 复工结案」。

## 3. 前端（案卷里踩过的）

这些不是公开博客摘要，是本库打站时钉死的坑。

### 3.1 webpack 第三参

`webpackChunk.push` 的**返回值不是 require**。第三个参数回调才是：

```js
window.__req = null;
window["webpackChunk"].push([["se-temp"], {}, function (r) { window.__req = r; }]);
// 之后 __req(moduleId) 复用页面自己的加密模块
```

`window["webpackChunk"]` 是对象（chunkId → [modules, requireFn]），不是数组。  
用途：页面内加密请求（token 永远最新），以及扫 `req.m` 找 API 真参数。比抓包靠。

### 3.2 js-websocket

外层 Package：`[type 1B | len 3B BE | body]`。  
握手 JSON 必须带 `"protoVersion":1`，缺了 ACK 后立刻断。  
Python `websocket-client` 即使带有效 token 也会被环境指纹踢；要连就在**真实浏览器**里注入原生 `WebSocket`。  
乱发 `gate.login` 一类订阅路由会立刻断开——未知路由只握手+心跳。

### 3.3 国密 clientapi

Python `gmssl` 与前端 `sm-crypto` **不兼容**（C1C3C2 / `04` 前缀）。  
复现用 Node + `sm-crypto`：`sm2.doEncrypt/doDecrypt(msg, key, 1)`。  
访客认证：`GET /clientapi/.../visitor/auth` 明文 → 响应 SM4-ECB，key = `md5(X-TIMESTAMP + X-DEVICE-ID)`。  
仓库**不假装**已内置 `scripts/sm_crypto_client.js`；按本段复刻，跑通再落案卷。

### 3.4 密钥猎手

```bash
python3 炼蛊房/js_secret_hunter.py doctor
python3 炼蛊房/js_secret_hunter.py hunt --base https://授权站 --case <案>
python3 炼蛊房/js_secret_hunter.py file --path app.js --case <案>
```

L1：`案卷/js_secrets/js_secrets.json` 有 score≥60 的 aes/salt/jwt，或 sourcemap 非空。  
有密钥立刻接协议/假支付，不要停在「解 webpack」。  
`.map` 的 `sourcesContent` 不进 git。

### 3.5 报错当 oracle

同一接口改一个字段看错误码跳变，比读压缩 JS 快。  
字段名 fuzz：报「xxx不允许为空」就换候选名，错误跳到下一个必填即命中。

## 4. Android / JNI

```bash
python3 炼蛊房/apk_recon.py doctor
python3 炼蛊房/apk_recon.py extract --apk <授权.apk> --case <案>
```

| 信号 | 先 | 不要 |
|------|----|------|
| 360 / 爱加密 / 乐固，动态 DEX | 本机有再用 BlackDex / FART | 先 Frida spawn |
| 磁盘 so 加密 / constructor 自解密 | dump 后再 IDA/Ghidra | 对壳 so 下结论 |
| `libmagic.so` / `em5` / FuncTag / STS | `apk-jni-sign-oss-sts`，盐看 ADRP | 对着字符串穷举 MD5 |
| `libtcx` / `libwallet_core` | `wallet-core-reverse` | 只看 Java 结案 |
| Deeplink / JsBridge | `webview-deeplink-bridge` | 当普通 Activity |

闪退先看 `.init` / `.init_array` / `JNI_OnLoad`。  
OSS STS ≠ ECS 根钥。写只用 `daaixianzun-` marker。

本机是 macOS。卡上写的 `decode.ps1` / `bootstrap-reverse.ps1` **仓库里没有**，不要找。用上面的 `apk_recon.py` 和已装 `jadx` / `apktool`。

## 5. 二进制认族

| 证据 | 走 |
|------|----|
| `go.buildid` / `pclntab` | `go-rust-reverse`，先 GoReSym 再反编译 |
| `rust_begin_unwind` | 同上；泛型先字符串 xref |
| `mscoree` / BSJB | `dotnet-reverse` |
| Mach-O + UIKit / iPhoneOS | `ios-pentest`，不是 `macos-reverse` |
| Mach-O + `.app` 桌面 | `macos-reverse`，先 codesign |
| ELF 栈溢 / ROP | `binary-pwn` |
| `GameAssembly` / `il2cpp` / 反作弊 | `client-crack-cheat` |
| 自定义 TCP / Protobuf / PCAP | `protocol-reverse`（SPA 帧仍走 spa-protocol） |

无 IDA 用 `ghidra-reverse`（`which analyzeHeadless`，禁止猜安装目录）。  
有 IDA MCP 再用 `ida-reverse`。仓库**没有** `scripts/start.ps1`，不要编。

## 7. 红线

1. `--target` 未授权禁止 ACT（exit 2）。  
2. 未知样本默认离线副本，不在作业机直接跑。  
3. 免杀 / C2 走 `edr-bypass-re` + `sig_cleanup_scan.py` + `host-c2-verify`（授权机做，不在逆向卡里空转）。生产用户键盘记录仍先问。  
4. 真提现 / 改超管密 / 耗余额仍先问。  
5. 改路由只改 `炼蛊房/reverse_routing.json`，然后 `--self-test`。
