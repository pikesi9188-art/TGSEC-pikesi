# PHP-CGI CVE-2024-4577 手法

> Skill：`杀招/幻页·门廊`  
> 工具：`炼蛊房/php_cgi_4577_probe.py` · nuclei `php-cgi-cve-2024-4577.yaml`  
> 情报：HITCON 2026 多次（ZD-2026-00944 等）  
> 红线：仅 scope。本库模板 **只指纹**，不发软连字符 RCE。

---

## 1. 一句话

Windows 上 PHP 以 CGI 跑时，`0xAD`（软连字符）会被当成参数分隔，攻击者可注入 `-d` 改 PHP 配置并衔接到代码执行。HITCON 上仍在修。本卡先确认 **Windows + PHP CGI 面**。

---

## 2. 指纹

| 信号 | 看什么 |
|------|--------|
| PHP | `X-Powered-By: PHP` / `Server` 含 PHP |
| Windows | `Server: Microsoft-IIS` · `Win64` · `ASP.NET` |
| 脚本 | `/index.php` `/info.php` 等 200/500 且像 PHP |

```bash
python3 炼蛊房/nday_route.py -u https://授权站 --case <案卷>
python3 炼蛊房/php_cgi_4577_probe.py --base https://授权站 --case <案卷>
python3 tools/1day-kit/od_kit.py nuclei --url https://授权站 --case <案卷> \
  -t tools/1day-kit/custom-templates/php-cgi-cve-2024-4577.yaml
```

影响面常见：Windows + PHP 8.1/8.2/8.3 未打 2024-06 补丁，IIS/XAMPP/php-cgi.exe。Linux mod_php / php-fpm **不是**本 CVE。

---

## 3. 档位

| 档 | 动作 | 成功证据 |
|----|------|----------|
| **L1** | Windows/IIS + PHP 头或 php-cgi | 仅 Linux PHP |
| **L2** | 探针比较基线 vs `?%ADd+-n`（只关 php.ini） | 体/状态无差 |
| **L3** | `allow_url_include` + `php://input` 执行 | 授权内直接做（whoami / 写马 / 反弹） |

公开链（只作知情，**不进本库 yaml**）：查询串软连字符 + `-d allow_url_include=1 -d auto_prepend_file=php://input`。
