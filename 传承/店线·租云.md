# Shopline 电商 SaaS 手法

> Skill：`杀招/商燕飞·店线`（全文步骤）  
> 探针：`python3 炼蛊房/shopline_probe.py --base https://店铺 --case <案>`  
> 红线：只打**已授权店铺域**。禁止打 `shoplineapp.com` / `admin.shoplineapp.com` / CDN 基础设施。

---

## 1. 一句话

AngularJS + Rails 多租户店。结账 `config_data` 常漏店主 PII；密码重置可枚举；GraphQL 与 REST 都要打。平台域不扩权。

---

## 2. 开场

```bash
python3 炼蛊房/shopline_probe.py --base https://授权店 --case <案>
```

L1：`window.mainConfig` 出 merchantId / handle / plan。  
L1b：重置接口对已注册 / 未注册响应不同。  
L2：结账回包 `config_data` 含姓名/手机/地址/合约号。  
L3：结账建号 → 重置 → 登录 → 订单 IDOR。

---

## 3. 强制顺序

1. 探针抽 mainConfig，确认不是平台域。  
2. 进结账页抓 Angular `getFormData()` / 配送 `config_data`。  
3. 密码重置差异 + 登录限速（至少 10 次）。  
4. GraphQL Storefront 内省；不能只打 REST。  
5. 下过单再测订单 IDOR（平台隔离常有效，必须验证）。  
6. 支付回调另走 `payment-callback-forgery`。

PII 进 `案卷/shopline/`，报告只写字段名和存在性，不写完整手机号。

## 4. 交接

GraphQL 深挖 → `graphql-pentest`。ATO 链 → `account-takeover-chain`。APP 店 → 先 `apk-recon`。
