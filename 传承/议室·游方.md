# MRBS SSRF 手法（CVE-2026-46382）

> Skill：`杀招/议室`  
> 组件：Meeting Room Booking System（MRBS）  
> 情报：`od_kit.py cvebase lookup --cve CVE-2026-46382 --docs`  
> 指纹：`tools/1day-kit/custom-templates/mrbs-ssrf-cve-2026-46382.yaml`  
> 总览：`CVE日报-2026-08-13.md`  
> 红线：仅授权目标；SSRF 验证优先打协作监听器/内网元数据（授权内），勿扫无关第三方

---

## 0. 画像

PHP 会议室预订系统。CVE-2026-46382 为 **SSRF（high）**：可控 URL/拉取面可打到内网服务、云元数据或协作域名。

成功口径：协作回调命中 **或** 读到内网特征响应（如云 metadata JSON）并落证据。

---

## 1. 指纹

```bash
python3 tools/1day-kit/od_kit.py nuclei --url https://授权站 --case <案卷> \
  -t tools/1day-kit/custom-templates/mrbs-ssrf-cve-2026-46382.yaml

curl -sk https://授权站/ | rg -i 'mrbs|meeting room|房间预订'
```

常见路径：`/mrbs/`、`/web/`、登录页 title 含 MRBS。

---

## 2. L2 验证思路（授权内）

1. `cvebase lookup --cve CVE-2026-46382 --docs` 钉具体参数/路由。  
2. 找「拉远程图 / URL / 代理预览 / 邮件抓取」类参数。  
3. 先打 **你控制的** 协作 URL（案卷监听），确认出网；再测 `169.254.169.254` / 内网仅限 scope。  
4. 证据：请求、协作 hit、响应片段 → `案卷/1day/mrbs_ssrf.*`

云元数据链可并行概念：`docs/playbooks` 内 SSRF/云元数据相关卡（若有）与内网扫描。
