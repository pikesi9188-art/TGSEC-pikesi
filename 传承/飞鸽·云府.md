| 族 | 指纹 | 主刀 |

## 1. 强制顺序

```text
scope 确认
 → 认族（Fernet / 系统选择 / JWT 默认钥）
 → Fernet 族：tg_cloud_panel_probe（指纹+弱口）
 → 有 openapi → 枚举 accounts/session/export/relay
 → session 为 gAAAAA → fernet-session-decrypt（并行 Vite@fs / .env / heap）
 → JWT 族：jwt_gql_probe（先试 your_secret_key）→ GET /proxy/list /admin/users → Session ZIP
 → 明文 session → 外连验活 →（可选）踢旧设备 / 改 2FA
 → 主机面：Portainer / WolfStack / etcd / Redis
 → 证据落 案卷/<案>/接管/ + 桌面 sessions_live/
```

## 3. 弱口与导出注意

- 同时试 **JSON** 与 **form-urlencoded**（TG Panel 已踩坑）。
- 登录判定已收紧：要 `access_token` / `success:true` / 鉴权 cookie；`success:false` 与纯登录 HTML **不算**命中。
- API 有账号无 `session_string` → 不要结案；切读盘/RCE/@fs。
- Fernet 密文 LIVE ≠ 可登录；无 KEY 不算接管完成。
