# 大爱仙尊 CRLF 作业手法

> 杀招：`折行`  
> 工具：`python3 炼蛊房/param_abuse_probe.py crlf`  
> 缓存链：`浸窖.md`；Java 收窄：`ghost-bits-cast-attack`

目标须在 scope。必须看到**新响应头**，不要把正文里的 `%0d%0a` 当洞。

---

## 1. 立刻跑

```bash
python3 炼蛊房/param_abuse_probe.py crlf --url 'https://授权/?next=x' --param next --case <案>
```

产物：`案卷/param_abuse/crlf.json`。

---

## 2. 四刀

1. **找进头的参数** — `next` / `url` / `file` / `callback` 进 Location / 日志  
2. **拆行** — `%0d%0aX-SE-CRLF:1`、单 `%0a`、UTF-8 `%E5%98%8A%E5%98%8D`  
3. **认头** — 响应出现 `X-SE-CRLF: 1` 或 `Set-Cookie: se_crlf=1`  
4. **升级** — 双 CRLF 进正文 → XSS；未键控头 → 缓存投毒。Java 拦 `%0d` 走 Ghost Bits

---

## 3. 档位

| 档 | 成立 |
|----|------|
| L1 | 参数进 Location/头，但未拆行 |
| L2 | 注入出自家头或 Cookie |
| L3 | 拆出 XSS / 固定会话 / 毒缓存 |
