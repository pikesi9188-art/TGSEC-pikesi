## 3. 通用网站面（无专用栈时）

按顺序，**两轮同态失败就换路**，勿空扫：

1. **资产**：子域 / 历史 IP / CDN 源站（`cdn-origin-tracing`）  
2. **入口**：登录、注册、上传、回调、Swagger、`/api`、备份  
3. **鉴权**：`万我·信门.md`（`authz-probe`）；已有低权票打管理功能走 `无极·职分.md`  
4. **黑盒突击**：`春晓苦力·突击.md`（S1–S8 短字典；`--deep` 交接已有探针）  
5. **核心 Web 面**：`薄青·岁岁索命.md`（XXE/SSTI/LFI/CORS/上传，勿只扫目录）  
6. **挡路**：IP 白名单头 → WAF SQLi → session_import  
7. **1day**：先读 `针匣·手册.md`；`od_kit.py nuclei --custom-only` + `custom-templates/`  
8. **有源码/备份**：DeepAudit → 密钥回灌支付  
9. **已有身份**：对象矩阵（info IDOR / 给他人加款 / 配置泄云钥）→ `万我.md`；垂直管理面 → `无极·职分.md`
