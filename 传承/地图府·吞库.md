## 2. L2 验证（授权内）

**仅当目标明确在 scope，且用户未说暂停。**

1. 从 GetCapabilities / 图层列表取一个 **PostGIS/Oracle** 图层（有 JSON/字符串字段更佳）。  
2. 经 **WFS GetFeature** 或 WMS CQL/`FILTER` 带 `jsonArrayContains(...)`，做 **布尔真假 / 报错差分 / 短延时**（无害证明即可）。  
3. 成功：两次响应长度/状态/报错 SQL 片段可复现差分，落 `案卷/1day/geoserver_sqli.*`。  
4. **默认停止**。RCE（`COPY TO PROGRAM` 等）先问；未授权公网层不要喷。

公开细节随 advisory 变，作业前可再搜「GeoServer jsonArrayContains Hadrian」。勿在 nuclei 模板里塞注入 payload。

---

## 3. 修复 / 缓解对照

官方补丁未出前：

- 公网关掉 WFS/WMS 或加鉴权  
- 禁用 `jsonArrayContains`（业务不依赖 JSON 数组查询时）  
- PostGIS：关 encode functions、开 prepared statements（对旧族有效，对本洞部分缓解）  
- 库账号去掉超管 / `pg_execute_server_program`

补丁发布后：升到 OSGeo 公告版本，并查 WFS 日志里的异常 `jsonArrayContains`。
