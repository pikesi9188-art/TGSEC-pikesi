# 微域·静审

> **`run` 三刀**（scan/analyze/report）。不搬 unveilr.exe、不搬越狱头。  
> Skill：`杀招/微域`  
> 工具：`python3 炼蛊房/wxmini_static_probe.py`  
> 正则真源：`tools/wxmini/secret_scanner.py` · `tools/wxmini/endpoint_extractor.py`  
> 授权：目标须在 `授权范围`。抽出的业务域未授权先 `--grant`，禁止拿小程序里的第三方域去打。

**不是** TG Mini App / 芋道 TMA（那些走 `yudao_appapi_probe`）。  
**不是** 网页 JS 签名（走 `js-reverse`）。

---

## 1. 何时启用

| 指纹 / 用户说法 | 走 |
|-----------------|----|
| `wxapkg` / `unveilr` / `__APPID__` / `wx[a-f0-9]{16}` / `wx.request` | **本卡** |
| 「分析这个微信小程序目录」 | 本卡 `scan --dir` |
| 小程序里又吐出授权站 API | 扩权后按业务专卡（假支付 / 越权）继续 |
| 只有 H5，没有 wxapkg | `js-reverse` / `js_secret_hunter.py` |

---

## 2. 强制顺序

```
拿包（wxapkg 或已反编译目录）
  → python3 炼蛊房/wxmini_static_probe.py run --dir <目录> --case <案卷> [--focus "支付"]
  → 案卷必须有 security_report.md（没有=没做完）
  → 授权域才 --probe-urls（GET）
  → 支付钥 → 假支付；云 AK → 阿里云 AK 卡；接口越权 → 对象矩阵
```

禁止：把 `raw_*.json` 写回小程序源码目录；默认对微信 CDN / `servicewechat.com` 发请求；用抽出的 AppSecret 去打未授权公众号。

---

## 3. 默认命令

```bash
python3 炼蛊房/wxmini_static_probe.py doctor
python3 炼蛊房/wxmini_static_probe.py run \
  --dir /path/to/decompiled-miniprogram \
  --case <案卷>
# 用户说了重点：
#   ... run --dir ... --case <案卷> --focus "支付 amount"
# 只对 in_scope host 做 GET（先问）：
#   ... run --dir ... --case <案卷> --probe-urls
```

落盘：`案卷/<案卷>/案卷/wxmini/`  
必有：`security_report.md` · `secrets_full.md` · `api_endpoints_full.md` · `findings.json`。

档位：

| 档 | 口径 |
|----|------|
| L1 | 正则命中接口或非占位符密钥 |
| L2 | Critical 钥，或抽出 host 已在 scope；`--probe-urls` 拿到 200 |
| L3 | 授权域上验证越权/假付（另切专卡，本探针不做 POST） |

## 4. `run` 已覆盖的分析面

`scan` 一次写出：`file_inventory.json` · `raw_secrets.json` · `raw_endpoints.json` · `summary.json`（含 `crypto`/`vulns`/`hidden_pages`）· `domains.txt` · `endpoints_fuzz.txt`。

| 面 | 机器口径 | 主会话接着做什么 |
|----|----------|------------------|
| 密钥 | `raw_secrets`；Critical 且非占位符 → L2 | 支付钥假支付；云 AK 走阿里云卡 |
| 接口 | `raw_endpoints` + `endpoints_fuzz.txt` | 授权域才 `--probe-urls` / 对象矩阵 |
| 加解密 | `summary.crypto`：CryptoJS/SM/JSEncrypt/ECB/硬编码 PEM·IV | 还原走 `js-reverse`，不在小程序里盲 decrypt |
| 配置 | `app.json` 含 admin/debug/backdoor 页；`urlCheck:false`；vConsole | 记隐藏页，授权内再打开 |
| 认证/数据 | `setStorageSync(token)`；前端 `role==='admin'` | 对象矩阵；Storage 明文不当后端洞 |
| 业务 | `requestPayment`/`totalFee`；`/api/user/${` | **需后端验证**，禁止只凭前端断言可改金额 |
| WebView | `<web-view src="{{` | 可控 URL = Critical；加深走 `webview-deeplink-bridge` |
| 云开发 | `wx.cloud.callFunction` | 查云函数权限，不默认打云环境 |

目录里只有 `.wxapkg`、没有 JS：探针会找 PATH 上的 `unveilr` 解到 `--out/unpacked`；没有 unveilr 就停并提示，不把 exe 推进 git。

## 6. 本卡边界

| 不这么做 | 本库 |
|----------|------|
| 无域 FOFA 猎小程序后台 | 禁止；有授权域走 `sensitive-dir-dump space-hunt` |
| 7 个 Claude Agent 窗口 | `run` = scan + analyze + report；不启子对话 |
| 全程禁止网络 | 默认静态；授权 host 可 `--probe-urls` |
| Windows + unveilr.exe | macOS/Linux 同样走目录扫描；exe 不进 git |
