## 3. PDF::WebKit CVE-2026-16770（P1）

Perl `PDF::WebKit`：恶意 HTML `meta` 可注入 **wkhtmltopdf** 参数（critical）。

作业口径（授权站）：

1. 找「HTML/URL → PDF」导出（发票、报表、合同预览）。
2. 控制 HTML 正文时插入可疑 `meta`/参数面（细节跟 advisory；勿对未授权目标喷）。
3. 验证：能否打到内网 URL、本地文件或异常进程参数（L2 可读证明即可）。

无专用 Skill 时：记 STATUS「PDF 渲染链 + CVE-2026-16770」，并行 `od_kit search --q wkhtmltopdf`。
