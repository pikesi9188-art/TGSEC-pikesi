## 今日新卡 1：ICEcoder CVE-2026-63722

**原理**：`lib/terminal-xhr.php` 见任意 `password` 当已登录、非空 `csrf` 过 CSRF，`command` 进 `proc_open()`。  
**影响**：`≤ 8.1`。官方补丁未钉死时：断公网或拆掉 terminal 端点。  
**默认只做到 L1**（标题，或 GET 终端回 `no command received`）。**禁止** POST `command=`。

```bash
python3 炼蛊房/icecoder_surface_probe.py --base https://授权站 --case <案卷>
```

- Skill：`杀招/白凝冰·冰码`  
- 手法：`传承/冰码·开天.md`
