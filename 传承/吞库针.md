## 心智

```text
认 WAF（waf_detect）
  → 签名墙优先 Unicode/%0a（waf_sqli_bypass），勿直接裸 sqlmap
  → sqlmap_kit recommend / cmdline 选 tamper 组合
  → guide 查 --level/--risk/--hpp/--cookie 等专题
  → 授权内执行 sqlmap ladder：--dbs → --tables → --columns → --dump
  → 百万级拖号先问
```

## 命令

```bash
# tamper 著译
python3 炼蛊房/sqlmap_kit.py tamper list
python3 炼蛊房/sqlmap_kit.py tamper search unicode
python3 炼蛊房/sqlmap_kit.py tamper show space2comment

# 按 WAF 推荐
python3 炼蛊房/sqlmap_kit.py recommend --waf cloudflare --case <案卷>
python3 炼蛊房/sqlmap_kit.py presets

# 查图形解说
python3 炼蛊房/sqlmap_kit.py guide --q hpp
python3 炼蛊房/sqlmap_kit.py guide --q cookie

# 拼命令（有 URL 过 scope）
python3 炼蛊房/sqlmap_kit.py cmdline \
  --url 'https://授权/page?id=1' -p id \
  --preset unicode_newline --case <案卷>

# 取数阶梯（过 scope）
python3 炼蛊房/sqlmap_kit.py ladder \
  --url 'https://授权/page?id=1' -p id --case <案卷>
```

## 预设（presets.json）

| preset | 场景 |
|--------|------|
| `generic_waf` | 未知 WAF |
| `cloudflare` | CF 类（并提示 Unicode 探针） |
| `modsecurity` | ModSecurity 版本化注释 |
| `asp_iis` | percentage 等 |
| `mysql` / `mssql` | 已知后端 |
| `unicode_newline` | 与 `waf_sqli_bypass` 联用 |

## 与邻近手法

| 场景 | 工具 |
|------|------|
| 只认 WAF | `waf_detect.py` |
| `%u0027` / `%0a` | `隐鳞·折行.md` |
| 通用 SQLi Skill | 九阶段 `sqli-sql-injection` / `sql-injection-testing` |

## 硬规则

- 未进 scope 的 URL：`cmdline` 拒绝。  
- 本工具生成命令与知识查询，不代跑 sqlmap 进程。  
- 授权内 dump 按 `ladder` 直接做。百万级拖号、耗余额、删站、改原超管密仍先问。
