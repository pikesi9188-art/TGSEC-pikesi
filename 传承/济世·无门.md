# JeecgBoot 未授权手法

> 指纹：`tools/1day-kit/custom-templates/jeecgboot-unauth-surface.yaml`  
> 探针：`炼蛊房/java_web_surface_probe.py`（`--stack jeecg`）  
> 分流：`凤九歌·天地歌.md` · 常与 Shiro / Druid 同机  
> 红线：仅授权；改密、JMReport SSTI、任意文件上传先问

---

## 1. 一句话

Jeecg-Boot 低代码后台常见 **接口鉴权漏挂**（字典/用户/报表）+ **Shiro 路径绕过** + **积木报表 JMReport** 表达式面 → 未登录读数据或直接 RCE。  
国内中小企业 / 内部运营站极常见，打网站 Java 味时与若依/芋道并列优先。

---

## 2. 指纹与路径族

| 信号 | 常见路径 |
|------|----------|
| 产品 | 标题 `Jeecg` · `/jeecg-boot/` · `window._CONFIG` |
| 验证码 | `GET /jeecg-boot/sys/randomImage/{key}` · `/sys/randomImage/{key}` |
| 登录 | `POST /jeecg-boot/sys/login` |
| 字典未授权族 | `/sys/dict/getDictItems/*` · `/sys/api/getDictItems/*` |
| 用户/重置 | `/sys/user/querySysUser` · `/sys/user/passwordChange`（视版本） |
| 积木报表 | `/jmreport/` · `/jeecg-boot/jmreport/` |
| 伴生 | `rememberMe`（Shiro）· `/druid/` · Knife4j |

```bash
python3 炼蛊房/java_web_surface_probe.py -u https://授权站 --case <案卷> --stack jeecg
python3 tools/1day-kit/od_kit.py nuclei --url https://授权站 --case <案卷> \
  --template-id jeecgboot-unauth-surface
```

## 3. 档位（深挖顺序）

| 档 | 动作 | 成功证据 |
|----|------|----------|
| **L1** | UI/`randomImage`/JS `_CONFIG` | 确认 Jeecg-Boot + API 前缀 |
| **L2a** | 无 Token 打字典/用户查询类 | 200 + 业务 JSON（非登录页） |
| **L2b** | Shiro 路径变体（`;`/`%2e`/`/..;/` 等，见 Shiro 卡） | 原 401/302 变 200 |
| **L2c** | 默认口 `admin/123456`、`jeecg/123456`（仅授权试） | 拿到 `token`/`X-Access-Token` |
| **L3** | JMReport 表达式 / 文件接口（**先问**） | RCE 或读配置/KEY |

```text
L1 确认 Jeecg
  → L2a 未授权 API 清单（字典/用户/文件）
  → 并行 L2b Shiro 绕过 + L2c 弱口令
  → 有 token → 垂直越权 / 系统配置 / 数据源
  → JMReport 暴露 → L3（先问）
  → 同机 Druid/Actuator/Nacos → 切对应专卡
```
