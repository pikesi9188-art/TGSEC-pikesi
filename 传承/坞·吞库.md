# WordPress Premium Packages 未授权 SQLi 手法（CVE-2026-12800）

> 情报：[cvebase.io/cve/CVE-2026-12800](https://cvebase.io/cve/CVE-2026-12800)  
> 指纹：`tools/1day-kit/custom-templates/wpdm-premium-packages-sqli-cve-2026-12800.yaml`  
> 分流：`秦百胜·拍卖.md`  
> 红线：仅授权；拖库/写库先问

---

## 1. 一句话

WP 插件 **Premium Packages – Sell Digital Products Securely**（`wpdm-premium-packages`，WPDM 卖数字货/卡密类）  
`POST /wp-json/wpdmpp/v1/cart/coupon` 的 **`code`** 拼进 SQL → **未授权 SQLi**（≤6.2.0）。

同族降权：CVE-2026-15906（Admin+ `orderby` SQLi，≤7.0.4）——有后台会话再测。

---

## 2. 指纹

| 信号 | 路径 |
|------|------|
| 插件目录 | `/wp-content/plugins/wpdm-premium-packages/` |
| REST | `/wp-json/wpdmpp/v1/` · `cart/coupon` |
| 业务 | 数字下载、优惠券、卡密发货味 |

```bash
python3 tools/1day-kit/od_kit.py nuclei --url https://授权站 --case <案卷> \
  --template-id wpdm-premium-packages-sqli-cve-2026-12800
```

## 3. 档位

| 档 | 动作 | 成功证据 |
|----|------|----------|
| **L1** | 插件/REST 指纹 | 确认 WPDM Premium Packages |
| **L2** | 未授权打 `cart/coupon`（错误差分/时间盲注探针） | SQL 差分成立（勿直接 dump） |
| **L3** | 授权内抽敏感表（订单/卡密）（**先问**） | 卡密或用户表证据打码落盘 |

假支付/ACG 主线阴性且站是 WP 数字货时，本卡升优先。
