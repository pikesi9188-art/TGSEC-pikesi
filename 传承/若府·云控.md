# 若府·云控

> 芋道 `ruoyi-vue-pro` 管理端（`/admin-api`、`mock-enable`、`infra/file-config`）切 **`芋府·假面开天.md`**，不要只跑本卡 Druid/Redis。  
> 工具入口：
> - **融合流水线**：`python main.py recover`（默认含 `ruoyi` 阶段，非若依自动跳过）
> - **独立若依链**：`python main.py ruoyi-recover` 或 `python scripts/ruoyi_recover.py`

---

## 0. 与 recover 流水线融合

`config/recovery.yaml` 默认阶段已包含 `ruoyi`（在 `fingerprint` 之后、`portscan` 之前）：

| 行为 | 说明 |
|------|------|
| 非若依站点 | 约 3 次 HTTP 探针后 **快速跳过**，不影响 weakpass/pentest |
| 若依站点 | 自动跑 **若依全链**（Druid→Redis→Login→面板→MySQL→JWT→SSH） |
| 若依 + portscan | 额外扫 `8080,8088,6379,3306,8888`（需 scope `allow_service_weakpass`） |
| auto 阶段 | JWT 伪造写入 `report.tokens`，凭据合并进 `credentials.json` |

```powershell
# 全流水线（推荐，多数站非若依也会自动跳过 ruoyi）
python main.py --stealth --proxy recover --scope 授权范围 -u https://目标

# 仅测若依检测 + 杀伤链
python main.py --stealth --proxy recover --scope 授权范围 `
  -u https://目标 --phase fingerprint,ruoyi,auto
```

## 6. 常用命令


## 9. 与自有资产关系

当前 scope 内站点（maika / tokenpay / yifan7788 等）**多数非 RuoYi 栈** — 这正是融合设计：**同一套 `recover` 命令**，若依手法作为独立阶段嵌入，命中才跑全链。

本 playbook 用于：

1. **日常 recover** 自动尝试若依链（非若依零成本跳过）
2. FOFA 发现 **同款 TG+若依** 关联 IP（`preset run ruoyi-8080`）
3. 确认某源站为 RuoYi 后 **`ruoyi-recover` 深度链**（可指定 `--redis-host`）
4. 从 `server_info` / JDBC **复用口令** 打 SSH
