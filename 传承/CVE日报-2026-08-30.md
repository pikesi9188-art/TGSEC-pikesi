## P0：CVE-2023-49105 — ownCloud WebDAV 预签名绕过

**影响**：ownCloud core 10.6.0 起，修复 **10.13.1**。  
**原理**：用户未配置 signing-key 时，预签名 URL 仍被接受；知道用户名即可未授权读写删文件。

### 指纹（只读）

```bash
python3 炼蛊房/nday_route.py -u https://授权站 --case <案卷>
python3 tools/1day-kit/od_kit.py nuclei --url https://授权站 --case <案卷> \
  -t tools/1day-kit/custom-templates/owncloud-webdav-cve-2023-49105.yaml
curl -sk https://授权站/status.php
```

### 成功口径

- `productname=ownCloud` 且 `versionstring` ∈ [10.6.0, 10.13.1) → **P0 确认，上报**
- 禁止伪造 `OC-Signature` 读/改/删文件

Skill：`杀招/私云`  
手法：`私云·预签.md`
