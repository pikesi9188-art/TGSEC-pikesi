## 3. 档位

| 档 | 动作 | 成功证据 |
|----|------|----------|
| **L1** | checker + `id/sudo/groups/SUID` | `lpe.json` 有候选向量 |
| **L2** | 配置面利用（sudo/SUID/docker/cron/cap） | `id` 变 uid=0 或等价 root |
| **L3** | 内核 CVE / 容器逃逸（**先问**） | root + 逃逸出容器到宿主机 |

checker 覆盖摘要：SUID/GTFOBins、sudo、cron（含 run-parts 目录）、PATH（用户 + crontab，分辨 `/bin` symlink 777 假象）、root 包装脚本/`mysqld_safe`、宝塔 `default.db`/本机 MySQL 弱口、capabilities、docker.sock、K8s SA、NFS、敏感文件；CVE 含 DirtyPipe、nf_tables、OverlayFS、sudo heap、regreSSHion、SCTPhantom 等。

---

## 3.1 宝塔机 / PATH 假象（作业里常看走眼）

`ls -ld /bin` 见 `lrwxrwxrwx`（777）**不等于可写**。Debian/宝塔常见 `/bin` → `/usr/bin`，目标是 `555`。以 `os.access` / checker `LOCAL-PATH` 为准，不要按链接自身权限下结论。

root cron 的 `PATH=` 在 `/etc/crontab`，不是你的 `$PATH`。相对命令（如 `run-parts`）才吃这条 PATH。

已有 www-data 且是宝塔单机：

```text
L1  checker → LOCAL-BT-MYSQL / LOCAL-ROOT-PROC
  → default.db 可读：只记 mysql_root=weak-or-empty 或 set(len=N)
  → 本机 mysql SELECT 1（空口 / root / admin / 123456）
  → mysqld_safe 以 root 跑且目录可写 → 配置面 L2
L3  百万拖号先问；改 passwd / 覆盖包装脚本先问；读库证明直接做
```

细步骤见 `宝塔台.md` §3.1（已有 shell）。

## 4. 向量优先序（作业习惯）

```text
NOPASSWD sudo → docker/lxd 组 → 危险 SUID → capabilities
  → cron/可写 / crontab PATH 劫持 → 宝塔 default.db / 本机 MySQL 弱口
  → passwd/shadow 可写 → 内核 CVE
  → 全阴：收割 env/.env/application*.yml/历史命令 → 横向
```

博彩/发卡场景 root 后优先：`支付 KEY`、`application*.yml`、本机 MySQL/Redis、`actuator/heapdump`。

## 6. CVE 版本闸（先 checker，再选 PoC）

`linux_lpe_checker.py --cve-only` 只做**版本/配置匹配**，命中 ≠ 已提权。内核 PoC 先评估稳定性。

| CVE | 俗称 | 匹配条件（摘要） | 注意 |
|-----|------|------------------|------|
| CVE-2021-3156 | Baron Samedit / sudo heap | sudo 受影响版本 + `sudoedit -s` | 点名走 `hypothesis_route.py --signal baron` |
| CVE-2021-4034 | PwnKit | pkexec SUID 在 | 点名走 hypothesis_route；新发行版多已修 |
| CVE-2022-0847 | DirtyPipe | 内核 5.8–5.16.x（未回移补丁） | 写 overlay 管道覆盖 |
| CVE-2023-0386 | OverlayFS SUID | 容器内 + 可挂 overlay | 容器逃逸常见 |
| CVE-2023-6246 | Looney Tunables | glibc 2.34–2.38 左右 `GLIBC_TUNABLES` | 任意写目标已不是 `__free_hook` |
| CVE-2023-2640 / 32629 | GameOver(lay) | Ubuntu overlayfs | 单行即可，先确认发行版 |
| CVE-2024-1086 | nf_tables UAF | 内核 < 6.4.1 一类 | 公开 PoC 猛，可能锁机 |
| CVE-2024-6387 | regreSSHion | 受影响 sshd + 32 位/特定 glibc | 远程 root，本机 checker 只报版本 |
| CVE-2026-64564 | SCTPhantom | SCTP UAF（checker 已探） | LPE + 容器逃逸线索 |

glibc ≥ 2.34：`__free_hook` / `__malloc_hook` 已移除。任意写改走 GOT / `system` / ROP，不要套旧堆笔记。

配置面永远优先于内核：NOPASSWD sudo → docker/lxd 组 → 危险 SUID → cap → cron/PATH → 宝塔 default.db → 内核。
