# 大爱仙尊缓存投毒作业手法

> 杀招：`网面窖`  
> 工具：`python3 炼蛊房/cache_poison_probe.py`  
> CRLF 链：`折行.md`

目标须在 scope。未键控头反射 + 缓存命中才是洞，单次反射不算。

---

## 1. 立刻跑

```bash
python3 炼蛊房/cache_poison_probe.py --url https://授权站/ --case <案>
# 只要欺骗面（路径混淆）
python3 炼蛊房/cache_poison_probe.py --url https://授权站/ --case <案> --deception-only
```

产物：`案卷/cache_poison/`。

投毒：未键控头进缓存，别人吃到你的响应。  
欺骗：给受害者看 `/account/x.css`，CDN 当静态缓存，你再拉同一 URL 读到别人的页。

---

## 2. 四刀

1. **认缓存** — `X-Cache` `Age` `CF-Cache-Status`  
2. **未键控头** — `X-Forwarded-Host` `X-Forwarded-Scheme` `X-Original-URL`  
3. **二次请求** — 不带头再打同一 URL，看毒是否留下  
4. **欺骗路径** — `/me/x.css` `/account/x.js` `/profile/x.svg`；响应是 HTML/JSON 且可缓存才算

`core_web_surface_probe` **不会**打缓存投毒/欺骗。

---

## 3. 档位

| 档 | 成立 |
|----|------|
| L1 | 头被反射，或 `.css/.js` 路径回了 HTML/JSON（未证明缓存） |
| L2 | `X-Cache: HIT`（或等价）且反射/私有页还在 |
| L3 | 其他用户吃到毒，或无会话拉到他人账号页 |
