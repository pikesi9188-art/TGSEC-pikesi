# 巨阳·八十万雄兵

> 散装探针的**顺序 + 交接**。不要一张卡打完就停。  
> 执行器：`炼蛊房/kit_run.py`  
> 菜单（并列工具、不交接）：`auto_campaign.py plan`  
> 资金/发卡：`pay_matrix.py` · 日志抽钥 `sensitive_dir_dump_probe.py` · Next `dujiao-next-1yuan-pay` · 异次元 `acg_probe.py`

---

## 1. 一句话

能力不在「又多一张手法卡」，而在 **上一步的 JSON 能驱动下一步命令**。  
本卡四套覆盖已打穿路径；资金、发卡、GVA 静默提权继续走原专卡，不重复造。

```bash
python3 炼蛊房/kit_run.py list
python3 炼蛊房/kit_run.py run --kit web -u https://授权站 --case <案卷>
```

子进程**实时刷进度**（每 10s 心跳）。单步超时会杀进程组再走下一步，不会整段无输出像卡死。  
落盘：`案卷/<案卷>/案卷/kit/<套装>/kit_report.json`

---

## 2. 四套（本库可跑）

| 套装 | 串什么 | 成功口径 |
|------|--------|----------|
| **web** | JS hunt → dispatcher → 短字典路径 → nday → JWT/GQL → **核心Web面 + 弱口登录** | 密钥可重放 / L2 文件读或弱口 / 专卡已跑 |
| **java** | java_web（含 Shiro L2）→ actuator → heapdump 则下堆；否则 Redis + **Mongo/ES** | 弱口/弱钥或堆转云下一跳 |
| **php** | ThinkPHP → FastAdmin → 路径短字典 → PMA → Redis → **核心Web + 弱口 + 中间件** | .env / PMA / captcha / 代付拖树 / LFI·SSTI |
| **gambling** | web 套装 + 非标口；交接假支付 / APK / IP 白名单 | API 重放或管理面 |

资金成套（已有，不进 kit_run）：

```bash
python3 炼蛊房/pay_matrix.py --base https://授权站 --case <案卷>
```

发卡成套（先认族，勿一律 acg_probe）：

```bash
python3 炼蛊房/sensitive_dir_dump_probe.py --base https://授权站 --case <案卷>
python3 炼蛊房/pay_matrix.py --base https://授权站 --case <案卷>
# /dj.svg + use_balance → Skill dujiao-next-1yuan-pay
# acg.js / shared_id → python3 tools/acg-faka/bin/acg_probe.py --base … --case …
```

GVA / Actuator 下堆后的云面：命中后仍走原 Skill，kit 只负责接到那一跳。
