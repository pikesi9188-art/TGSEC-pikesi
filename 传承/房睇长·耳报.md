# CVE 情报日报手法

> 把「今天有什么新 CVE」落成可复用的本库资产，而不是聊天里口头汇总。  
> 目录真源：`docs/intel/cve-daily/`  
> **主 Skill**：`杀招/房睇长·日更`（入库）· 扫站复现 `1day-nuclei-kit`  
> 总表：`新伤·在野.md`

---

## 1. 何时写日报

- 用户问「今天/本周有什么新 CVE」
- `cvebase trending` 或 Tenable/厂商通告出现 **网站向 P0/P1**
- Patch Tuesday 次日（通常周二后）补一节
- 用户说「转成能用的技能 / 完善进大爱仙尊」→ **必须落 Skill**，禁止只改 md

**不写**：纯设备/本地提权堆砌（可在日报末「降权记一笔」）。

---

## 2. 落盘清单（完整 = 这六样齐）

| # | 产物 | 路径 |
|---|------|------|
| 1 | 结构化 JSON | `docs/intel/cve-daily/YYYY-MM-DD.json` |
| 2 | 人类日报 | `传承/CVE日报-YYYY-MM-DD.md` |
| 3 | 网站向专卡（P0/P1） | `传承/<组件>手法.md` |
| 4 | nuclei 指纹（只探测、不炸） | `tools/1day-kit/custom-templates/*.yaml` |
| 5 | **可调用 Skill（P0 必做）** | `杀招/<name>/SKILL.md` |
| 6 | 索引挂钩 | `1day在野洞` · `nday_route.py` · `build_clear_entry.sh` · 词表 |

对照模板：`nginx-rift-cve-2026-42945` · `upsnap-unauth-rce` · `mrbs-ssrf`。

---

## 3. 优先级口径（本库）

| 级 | 条件 | 动作 |
|----|------|------|
| **P0** | 未授权 RCE/接管 · 自托管面板常见 · 有公开细节 | 专卡 + 模板 + **Skill** + nday_route |
| **P1** | SSRF/未授权读/高 EPSS·KEV · 本库栈相关 | 专卡 + 指纹；常用则升 Skill |
| **P2** | 云编排/依赖库/需源码命中 · 设备向 | 日报记一笔；有指纹再升 |

业务专链（Actuator/假支付/GVA）永远优先于「新 CVE 编号」。

---

## 4. 命令骨架

```bash
# 1) 情报
python3 tools/1day-kit/od_kit.py cvebase trending
python3 tools/1day-kit/od_kit.py cvebase lookup --cve CVE-… --docs

# 2) 写 JSON + 日报 +（P0）手法卡/yaml

# 3) 重建杀招
bash scripts/build_clear_entry.sh

# 4) 授权站验证（必须在 scope）
python3 炼蛊房/nday_route.py -u https://授权站 --case <案卷>
python3 tools/1day-kit/od_kit.py nuclei --url https://授权站 --case <案卷> --custom-only
```

证据：`案卷/<案卷>/案卷/1day/`

---

## 5. 禁止

- 把报告里的第三方 UAT/无关域扩进 scope
- 只扫 CVE 编号就结案（命中指纹后要切专卡验业务影响）
- 在模板里放破坏性 exploit payload（指纹/暴露面即可）
- 匿名 cvebase 配额空转广搜
