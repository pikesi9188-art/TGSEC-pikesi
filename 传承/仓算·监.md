# Druid 监控未授权手法

> 指纹：`tools/1day-kit/custom-templates/druid-unauth-surface.yaml`  
> 探针：`炼蛊房/java_web_surface_probe.py`（`--stack druid`）  
> 同族：`若依四海杀伤链.md`（Druid→JDBC→Redis）· Actuator 堆转云伴生  
> 红线：仅授权；用 JDBC 连生产库先确认 scope

---

## 1. 一句话

阿里 **Druid StatViewServlet** 监控页弱口令/未授权 → 看 SQL、URI、**JDBC URL/账密** → 下游 MySQL/Redis。  
若依默认常见 `ruoyi/123456`；芋道/Jeecg/自研 Spring 也常挂 `/druid/`。

---

## 2. 指纹

| 信号 | 路径 |
|------|------|
| 登录页 | `/druid/login.html` · `/prod-api/druid/login.html` · `/api/druid/login.html` |
| 首页 | `/druid/index.html` · `/druid/` |
| JSON | `/druid/datasource.json` · `/druid/sql.json` · `/druid/weburi.json` |
| 会话 | 登录后 Cookie `druid*` / Session |

```bash
python3 炼蛊房/java_web_surface_probe.py -u https://授权站 --case <案卷> --stack druid
python3 tools/1day-kit/od_kit.py nuclei --url https://授权站 --case <案卷> \
  --template-id druid-unauth-surface
```

弱口令优先级（授权试）：`ruoyi/123456` → `admin/admin` → `druid/druid` → 空口。

---

## 3. 档位

| 档 | 动作 | 成功证据 |
|----|------|----------|
| **L1** | `login.html` / 标题 Druid | 监控面存在 |
| **L2** | 弱口令或无需登录进 `index.html` | 进入控制台 |
| **L3** | `datasource.json` 抽 JDBC | 库地址+账密；再接 Redis/登录旁路 |

```text
L1 Druid 页
  → L2 弱口/未授权
  → L3 datasource → DB IP 写入 scope（静默扩权仅当主站链发现）
  → Redis 可读 captcha → 若依验证码旁路卡
  → 或直连 MySQL 业务库（拉库先问）
```

## 5. 复工条件示例
