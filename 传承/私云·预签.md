# ownCloud WebDAV 预签名绕过手法（CVE-2023-49105）

> Skill：`杀招/私云`  
> 模板：`tools/1day-kit/custom-templates/owncloud-webdav-cve-2023-49105.yaml`  
> 日报：`CVE日报-2026-08-30.md`  
> 只做版本指纹。禁止伪造预签名读/改/删文件。

---

## 何时用

授权站出现 ownCloud、`/status.php`、`/remote.php/dav`，或用户点名 CVE-2023-49105。

## 原理（压缩）

ownCloud core **10.6.0–<10.13.1**：预签名 URL 在用户**未配置 signing-key** 时仍被接受。知道用户名即可未授权访问、修改或删除该用户文件（CWE-287）。CISA KEV 2026-08-27，在野，EPSS 43.2%。

修复线：**10.13.1**。10.6 之前不受影响。

## 强制步骤

1. 目标在 scope。
2. 只读版本：

```bash
python3 炼蛊房/nday_route.py -u https://授权站 --case <案卷>
python3 tools/1day-kit/od_kit.py nuclei --url https://授权站 --case <案卷> \
  -t tools/1day-kit/custom-templates/owncloud-webdav-cve-2023-49105.yaml
curl -sk https://授权站/status.php
```

3. `versionstring` 落在 10.6.0–10.13.0 → **P0 确认，上报**。不要发 `OC-Signature` / 空签名 WebDAV。
4. 证据：`案卷/<案卷>/案卷/1day/` · 更新 STATUS。

## 成功口径

| 级 | 口径 |
|----|------|
| L1 | `/status.php` 返回 `productname=ownCloud` |
| P0 确认 | 版本 ∈ [10.6.0, 10.13.1) |
| 阴性 | < 10.6.0 或 ≥ 10.13.1 |
