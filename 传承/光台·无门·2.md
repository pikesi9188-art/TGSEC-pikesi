# Grafana 未授权与默认口令手法

> 指纹：`tools/1day-kit/custom-templates/grafana-unauth-surface.yaml`  
> 分流：`凤九歌·天地歌.md`  
> 红线：仅授权目标；改密/删看板/写数据源先问

---

## 1. 一句话

Grafana 常见面：**匿名组织可读**、**默认 `admin/admin`**、历史 **path traversal 读文件**（如 CVE-2021-43798 未修实例）→ 看板/数据源密钥 → 下游库或云。

---

## 2. 指纹

| 信号 | 路径 |
|------|------|
| 登录/产品 | `/login` · `/` 体含 `Grafana` |
| API | `/api/health` · `/api/org` · `/api/dashboards/home` |
| 匿名 | 无 Cookie 调 `/api/org` 得 200 JSON |
| 插件目录（老洞） | `/public/plugins/<plugin>/../../../../../../etc/passwd`（仅授权验证存在性） |

```bash
python3 tools/1day-kit/od_kit.py nuclei --url https://授权站 --case <案卷> \
  --template-id grafana-unauth-surface
```

---

## 3. 档位

| 档 | 动作 | 成功证据 |
|----|------|----------|
| **L1** | health/login 指纹 | 确认 Grafana |
| **L2** | 匿名 `/api/org`、默认口令登录 | 组织信息或 admin 会话 |
| **L3** | 数据源密钥 / 老版路径穿越读敏感文件 | 凭据或文件内容落盘（打码） |

L2 默认口令阴性 → 转业务 API 越权 / CDN 源站；勿空扫全插件列表轰炸。

---

## 4. 复工条件示例

- [ ] Grafana 子域/路径可达且版本或匿名面已记录  
- [ ] L2/L3 任一成立，或写明需会话/弱口令字典复工
