# MkTs — UU 模拟器 + Reqable / Charles 抓包手册

授权：`授权范围/scope.mkts.json`（`app.mkts.vip` / `api.mkts.vip`）  
产物目录：`案卷/mkts_20260724/capture/`

> 本机是 macOS；**UU 模拟器多在 Windows**。推荐：Windows 开 UU+TG+Reqable；或 Mac 装 Reqable/Charles 当代理主机，模拟器指过来。

---

## 方案 A（你选的主路径）：UU + Reqable

### 1. 准备
1. 安装 **UU 模拟器**（或雷电/MuMu，需能装 TG）
2. 模拟器内安装 **Telegram 正式版**
3. 电脑安装 **Reqable**（https://reqable.com/ ）并打开 **HTTP 抓包**
4. 记下 Reqable 代理端口（默认常见 `9000` / `8080`，以软件显示为准）

### 2. 模拟器走代理
在 UU：设置 → 网络 / 代理 → **手动**

| 项 | 值 |
|----|-----|
| 主机 | 电脑局域网 IP（UU 与电脑互通；桥接网卡时用 `ipconfig` 看） |
| 端口 | Reqable 监听端口 |
| 类型 | HTTP / HTTPS（Reqable 一般两者都代理） |

UU 与电脑若在同一虚拟网：常用网关形如 `192.168.x.1` 或 UU 提示的共享 IP。不通就先 `ping` 电脑 IP。

### 3. 安装 CA 证书（关键，否则只看到 CONNECT）
1. 模拟器浏览器打开 Reqable 提示的证书地址（常见 `http://reqable.com/ssl` 或软件内「安装证书」二维码/链接）
2. 下载 `.crt` / `.pem`
3. Android：设置 → 安全 → **加密与凭据** → **安装证书** → **CA 证书**
4. 若 Android 7+ 用户证书对 App 无效：
   - **Root 模拟器**：把 CA 推进系统证书存储（见下方 Charles/Root 节）
   - 或 Reqable 开启 **抓包所有应用 / 不校验**（若版本支持）
   - TG 若仍证书固定失败：换 **可改系统证书的 Root 镜像**，或改用 WebView「在浏览器打开」小程序

### 4. 过滤（必开，不然刷屏）
Reqable 主机过滤只留：

```
api.mkts.vip
app.mkts.vip
```

可再加：`nft.fragment.com`（礼物媒体，次要）

### 5. 操作顺序（对着 MkTs）
1. Reqable 清空会话，开始录制  
2. TG 打开 `@mkts8_bot` → 进小程序 `mkts`  
3. 点首页 / 市场 / 钱包 / 任意礼物详情  
4. 停止录制，导出 **HAR** 或 **Reqable 会话**  
5. 文件丢进：`案卷/mkts_20260724/capture/inbox/`

### 6. 优先找这些请求
| 请求 | 要什么 |
|------|--------|
| `POST https://api.mkts.vip/api/v1/noauth/app/login` | JSON 里的 **`init_data`** |
| 任意 `Authorization: Bearer ...` | **access_token** |
| `POST .../noauth/auth/refresh` | **refresh_token** |
| `POST .../telegram-deposit/internal-bind` | 头 **`X-Telegram-Gift-Api-Key`**（少见，listener 才有） |
| `POST .../api/admin/v1/noauth/login` | 管理端账密（若你打开过后台） |

解析：

```bash
python3 scripts/by_site/mkts/parse_capture.py 案卷/mkts_20260724/capture/inbox/
```

## 方案 B：Root 模拟器 + Charles

适合 TG 证书钉死、用户证书无效时。

1. 安装 Charles，代理端口默认 `8888`，勾选 **SSL Proxying**  
2. SSL Proxying Settings 增加：
   - `api.mkts.vip:443`
   - `app.mkts.vip:443`
3. Help → SSL Proxying → **Install Charles Root Certificate on Mobile Device**  
4. Root 后把 Charles CA 装到 **系统证书**（Android 需哈希文件名进 `/system/etc/security/cacerts/`；Magisk 可用 Move Certificates 模块）  
5. 模拟器 Wi‑Fi 代理 → 电脑 IP:`8888`  
6. 同样打开小程序，导出 Charles Session / HAR → `capture/inbox/`
