# ASP.NET ViewState 猎面手法

> 杀招：`残网·猎面`  
> 探针：`炼蛊房/aspnet_surface_probe.py`  
> 大爱仙尊专卡。`_layouts` / SharePoint **先**走 `sharepoint-unauth-rce`。  
> 默认不发反序列化 gadget，不抽 machineKey。

---

## 1. 一句话

IIS + WebForms 授权站：认 ViewState 是否只签不加密、trace/ELMAH/Telerik 是否匿名、双解析器误差。  
完整 ysoserial / Telerik 密钥链 **L3 先问**。

```bash
python3 炼蛊房/aspnet_surface_probe.py --base https://授权站 --case <案卷>
# 双解析器对照（只比错误文案，不发 gadget）
python3 炼蛊房/aspnet_surface_probe.py --base https://授权站 --case <案卷> --parser-diff
```

落盘：`案卷/aspnet/surface.json`

---

## 2. 分流

| 信号 | 走 |
|------|----|
| `MicrosoftSharePointTeamServices` / `_layouts` / `_vti_bin` | `sharepoint-unauth-rce` |
| `__VIEWSTATE` / `X-AspNet-Version` / `.aspx` / `elmah.axd` / Telerik | 本卡 |
| 只有 `Server: IIS` 无 ViewState | 回核心 Web / 弱口 |

---

## 3. 档位

| 面 | L1 | L2 | L3 先问 |
|----|----|----|---------|
| 指纹 | `X-AspNet-Version`、`.ASPXAUTH`、`__VIEWSTATE`（name/value 属性顺序不限） | 空 `__VIEWSTATEENCRYPTED` = 只签不加密 | 伪造 ViewState |
| 错误页 | — | 陈旧 VS POST 出框架版号 / `customErrors=Off` | — |
| 双解析器 | — | `--parser-diff`：垃圾 vs XML 形 VS 标题不同 | 用差分打 MAC 前解析 |
| `trace.axd` / `elmah.axd` | 匿名 200 | 记为敏感日志面 | 拖全量 trace |
| Telerik `WebResource.axd?type=rau` | 正文 `RadAsyncUpload` / `Telerik.Web.UI`（禁止 404 回显 `rau`） | 只记指纹 | 历史 RCE / 密钥碰撞 |
| `.svc?wsdl` | WSDL 200 | 列操作名 | 调写方法 |

---

## 4. 成功口径

| 级别 | 口径 |
|------|------|
| L1 | WebForms / ASP.NET 头或 `__VIEWSTATE` |
| L2 | 只签不加密 **或** 匿名 ELMAH/trace **或** 双解析器文案分流 **或** Telerik RAU 活 |
| L3 | gadget / machineKey（先问） |

---

## 5. 不要做

- 默认发 ViewState gadget / Telerik 上传链
- 把 SharePoint 农场当本卡结案
- 过长 VS POST 打垮站点
