# 使证闸

> 杀招：`宝黄天·器匣` · `osint-recon` · `cve-triage` · `agent-evidence-gate`  
> 探针：`crypto_decode.py` · `http_probe_batch.py` · `source_extract.py` · `osint_recon.py` · `cve_triage.py` · `evidence_gate.py`  
> 同族：JWT 利用 → `jwt-bypass-pentest`；源站/FOFA → `origin_recon` / `space-search`；CVE 入库 → `cve-daily-intel`  
> 红线：目标须在 `授权范围`。本卡**填格子、对照、闸结案**，不替代假支付 / Actuator / 盘口专链。  
> 溯源一行：对照 Netw0rkNoob/VulnClaw（MIT）的编解码与证据闸思路，已按本库 L 级 / 对象矩阵改写。

## 1. 一句话

编码串先解码，变体一次对照，着色页先还原，banner 只当假设，**口头结论必须对得上案卷原文**。  
高信号没打完不准写结案。有身份先填 `案卷/object_matrix.md`。

```bash
python3 炼蛊房/crypto_decode.py auto --input '<串>' --case <案卷>
python3 炼蛊房/http_probe_batch.py --base https://授权站 --case <案卷> \
  --variant '{"label":"clean","path":"/api","params":{"q":"ok"}}' \
  --variant '{"label":"probe","path":"/api","params":{"q":"1 OR 1=1"}}'
python3 炼蛊房/source_extract.py --url https://授权站 --case <案卷>
python3 炼蛊房/osint_recon.py --url https://授权站 --case <案卷>
python3 炼蛊房/cve_triage.py --query '<产品 版本>' --case <案卷>
python3 炼蛊房/evidence_gate.py --case <案卷> --from-status
```

落盘：`案卷/crypto_decode/` · `案卷/http_batch/` · `案卷/source_extract/` · `案卷/osint/` · `案卷/cve_triage/`

## 2. 30 秒分流（本库口径）

```text
拿到编码串 / 着色页 / banner / 准备结案
  → 业务指纹（支付/Actuator/盘口/发卡）仍走专链
  → 编码串     → crypto_decode → 明文像 JWT/支付 sign 再交接
  → 多发对照   → http_probe_batch（DIFF=L1；要 L2 必须接到注入/越权专卡）
  → highlight  → source_extract → sink 交接 lfi / 反序列化 / 命令注入
  → 四维侦察   → osint_recon → 必须接 origin_recon / FOFA / js_secret
  → Server 版  → cve_triage（假设）→ nday_route / 专卡，禁止当 L2
  → 写 STATUS  → evidence_gate + case_review；矩阵「未测」禁止结案
```

---

## 3. 档位

| 档 | 谁 | 成功证据 | 不是洞 |
|----|----|----------|--------|
| **L1** | 解码出可读明文 / 对照有 DIFF / 抽出 sink 或表单 / 四维首页维完成 / NVD 有命中 | 对应 JSON 非空 | same-body、banner 列表 |
| **L2** | 对照 DIFF 被专卡复现（注入/越权/未授权读）或 sink 打出文件读/算术差分 | 专卡 findings + 本卡 JSON | 只解码、只分诊 |
| **L3** | 仍走原专卡（加款/写配置/RCE） | 对象矩阵对应格 | 本卡工具本身不打 L3 |
| **停** | 证据闸 misses / 近成功 leftover / 矩阵未测 | 撤回口头结论或继续打 | 改 STATUS 措辞蒙混 |

先问只剩：耗余额下单、删站、改原超管密。对照和还原默认直接做。

## 4. 强制交接

| 产物 | 立刻切 |
|------|--------|
| JWT claims / 弱 secret | `jwt-bypass-pentest` · `jwt_gql_probe.py` |
| 支付 sign / notify | `payment-callback-forgery` · `pay_matrix.py` |
| `gAAAAA` Fernet | `fernet-session-decrypt` |
| `unserialize` / `eval` / `php://filter` | `java-deserialization` / `command-injection` / `lfi-rfi-exploit` |
| `/actuator` · `gateway/routes` | Spring Gateway 全链，禁止只扫 health |
| 有身份 | `object_matrix.py init` → 专卡只填格子 |
| 版本 CVE 假设 | `nday_route.py`；今天新洞入库走 `cve-daily-intel` |

人员维（`--people`）仅用户明确要作者/社工画像时开。禁止把无关社交域扩进 scope。

## 5. 证据闸（结案前）

```bash
python3 炼蛊房/case_review.py --case 案卷/<案卷>
python3 炼蛊房/object_matrix.py check --case <案卷> --strict
python3 炼蛊房/evidence_gate.py --case <案卷> --from-status
```

1. 声称的 L 级 / CVE 编号必须在 `案卷/` `接管/` `支付/` `证据/` 里**逐字符**出现。STATUS 自证不算。  
2. 证据里还有 sink / 表单 / DIFF / actuator，STATUS 却写「无路 / 结案」→ 近成功闸拦住。  
3. 有身份线索但矩阵缺或仍「未测」→ 不能交差。  
4. 专卡阴性必须回表换格子，禁止本卡阴性当复工结案。

---

## 6. 失败处理

| 现象 | 不要 | 要 |
|------|------|----|
| NVD 超时 | 写成已验证 CVE | 记假设，改 `nday_route` / 日报 |
| 对照全 SAME | 当注入阴性结案 | 换参数/头，或走 `core_web_surface_probe` |
| auto 认不出 | 猜明文 | `--list` 指定操作 |
| 首页 403/CF | 四维结案 | `session_pipeline` / `egress-proxy-pool` |
| 闸门 FAIL | 改措辞 | 补命令输出或撤回结论 |
