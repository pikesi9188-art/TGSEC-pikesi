## P0-1：CVE-2026-60004 — Gitea diffpatch RCE

**影响版本**：Gitea < 1.27.1  
**原理**：认证用户通过 `/api/v1/repos/{owner}/{repo}/diffpatch` API 写入恶意 diff，触发 Git hook 执行任意命令。EPSS 82.4%（99.6 百分位），已入 CISA KEV，在野利用确认。

### 指纹探测步骤

```bash
# 1. 版本指纹（只读）
curl -sk https://TARGET/api/swagger | grep '"version"'
curl -sk https://TARGET/-/admin/self-check  # 登录后看 gitea 版本

# 2. nuclei 扫描
nuclei -t tools/1day-kit/custom-templates/gitea-diffpatch-cve-2026-60004.yaml \
       -u https://TARGET -silent

# 3. API 探测（需低权账号）
curl -sk -H "Authorization: token YOUR_TOKEN" \
     https://TARGET/api/v1/repos/search?limit=1 | python3 -m json.tool
```

### 成功口径

- `gitea_version < 1.27.1` 且 `/api/v1` 可达 → **P0 确认，上报**
- 禁止实际 POST diffpatch payload 或安装 hook

### 后续

Skill：`杀招/文仓`  
Template：`tools/1day-kit/custom-templates/gitea-diffpatch-cve-2026-60004.yaml`

## P0-2：CVE-2026-21962 — Oracle WebLogic Proxy Plug-in 未授权 RCE

**影响版本**：Oracle HTTP Server + WLS Proxy Plug-in 12.2.1.4.0 / 14.1.1.0.0 / 14.1.2.0.0  
**原理**：Proxy 插件访问控制缺失（CWE-284），未授权 HTTP 请求可接管 Oracle HTTP Server 及 WebLogic。CVSS 10.0，EPSS 42%，已入 KEV。

### 指纹探测步骤

```bash
# 1. Server header 探测
curl -skI https://TARGET/ | grep -i 'server\|x-oracle\|x-powered-by'

# 2. wls-wlst 路径探测
curl -sk https://TARGET/wls-wlst/ -o /dev/null -w "%{http_code}"
curl -sk https://TARGET/weblogic/ -o /dev/null -w "%{http_code}"

# 3. 版本页
curl -sk https://TARGET/console/login/LoginForm.jsp | grep -i 'weblogic\|version'

# nuclei 模板（指纹）
nuclei -t tools/1day-kit/custom-templates/weblogic-proxy-cve-2026-21962.yaml \
       -u https://TARGET -silent
```

### 注意

暂无完整公开 PoC，禁止盲打；指纹阳性即上报等待更多情报。
