# 大爱仙尊客户端破解与外挂作业手法

> 杀招：`客器破禁`（**最高权限作业面**，授权内 L2/L3 默认直接做）  
> 工具：`python3 炼蛊房/client_crack_cheat_probe.py`  
> 认族：`re_sample_triage.py`  
> H5 旗标并行：`client-state-skip`  
> 盘口协议：`星宿·秘语.md`（先还原再改字段）

目标须在 scope，或案卷里的授权本地包。  
本卡交付的是**可跑 hook + 结算口对照**，不是认到 Unity 就停。

---

## 1. 立刻跑

```bash
python3 炼蛊房/re_sample_triage.py --path <样本> --case <案>
python3 炼蛊房/client_crack_cheat_probe.py drive --path <样本或解包目录或.apk> --case <案>
python3 炼蛊房/client_crack_cheat_probe.py replay --base https://授权站 --case <案>
```

`drive` 会写：

| 文件 | 干什么 |
|------|--------|
| `案卷/crack_cheat/surface.json` | 引擎 / 反作弊 / hook 目标 |
| `hooks/il2cpp.js` | dump.cs 有 RVA 则直接 `Interceptor.attach`；按类名 hook 才要 `frida-il2cpp-bridge`。License/VIP 强制 true |
| `hooks/net.js` | `send/recv` hexdump |
| `hooks/java.js` | Android Java 结算方法 |
| `hooks/ce_hint.lua` | CE 值猎步骤（地址≠L2） |

```bash
frida -U -f <包名> -l 案卷/<案>/案卷/crack_cheat/hooks/il2cpp.js --no-pause
```

Il2CppDumper 本机有再用它出完整 `dump.cs`，然后：

```bash
python3 炼蛊房/client_crack_cheat_probe.py hooks --path ./dump.cs --case <案>
python3 炼蛊房/client_crack_cheat_probe.py meta --path global-metadata.dat --case <案>
```

## 2. 六步

1. **认引擎** — `GameAssembly` / `global-metadata.dat` / `Assembly-CSharp` / UE / H5。APK 先 `apk-recon`；`drive --path *.apk` 会直接从 zip 抽 `global-metadata.dat` / `dump.cs`，不必先全盘解压。
2. **抽结算名** — `meta` 读 IL2CPP 字符串；`dump.cs` 抽 `Gold/Score/Settle/License/Send`。
3. **出 hook** — `hooks` 写 Frida。改返回值、拦发包。不要手抄空模板。
4. **打结算口** — `replay` 同一 POST：空/原值 vs `gold=99999&win=true`。负对照必须成对。
5. **内存只辅助** — `memscan --int` 找地址；冻结本地值不算过闸。
6. **过闸** — 服务端业务字段变了才 L2。填对象矩阵「自己×写」。

---

## 3. 档位

| 档 | 成立 |
|----|------|
| L1 | 引擎/反作弊/结算函数名/CE 地址 |
| L2 | dump.cs 落到类名/RVA hook，**或** replay：401/403→200、JSON 结算字段变了；指定 `--url` 才允许体长差 |
| L3 | 授权自控局稳定复现。他人局 / 清榜 / 耗余额 **先问** |

反作弊进程在 ≠ 已绕过。EAC / BE / ACE / TP 记面，L2 仍看业务接口或 hook 返回值。

---

## 4. 栈怎么打穿

| 栈 | 命令 | 下一刀 |
|----|------|--------|
| Unity IL2CPP | `drive` + `meta` + `hooks` + frida | `replay` 打房间/结算 HTTP；TCP 走 `net.js` |
| Unity Mono | `Assembly-CSharp.dll` → `dotnet-reverse`，方法名回 `hooks` | 同上 |
| UE | 字符串名进 `hooks/net.js`；深挖 `ida-reverse` | 复制品先问清榜 |
| H5 | `replay --base` + `client-state-skip` | 加密 body 先还原再 flip |
| 盘口 APK | 先加密 API 专卡 | 客户端局才回本卡改字段 |

`global-metadata.dat` 魔数 `0xFAB11BAF`。本库解析字符串字面量；完整类型树仍可用本机 Il2CppDumper，**禁止只交 dump 结案**。

## 5. replay 口径

```bash
python3 炼蛊房/client_crack_cheat_probe.py replay --base https://授权站 \
  --url /api/game/settle --body base.json --header "Authorization: Bearer <票>" \
  --flip gold=99999 --flip player.gold=99999 --flip win=true --case <案>
```

成立：`401/403→200`（非 HTML），或 JSON 里 `gold/score/win/success` 相对基线变了。  
指定 `--url` 时，同为 200 且体长差 ≥ 40 也可。短表扫路径**禁止**只靠体长报 L2。  
两端都是 HTML / 404/405 不算。无 `--case`/`--out` 不落盘。

---

## 6. 不要做

- 验证码破解、哈希离线破解（走 captcha / hashcat）
- scope 外对公网游戏发挂、卖挂
- 只认 Unity / 只交 dump.cs
- 把盘口 `sk_encrypt` 当没加密的 JSON 乱 flip
