# 秦百胜·魂压（Playbook）

又名：Client-side price gate / `claim-free-*` 业务逻辑缺陷  
工具：`炼蛊房/free_claim_bypass.py`  
参考报告：（开源包不收个案摘记）（Crown Coins Casino）  
授权：仅 `授权范围`。未授权站只学手法，不开打。

## 1. 心智（不限赌博）

产品意图：**只有 `price == 0`（或 isFree）的礼包** 能走「免费领取」API。  
实现缺陷：

1. **前端**拦截：`if (price !== 0) return;` —— 不发请求  
2. **服务端** `claim-free-package`（或同类）**不校验**标价 / 支付状态 / 订单  
3. 攻击者带登录 Token **直接调 API**，提交 `price > 0` 的 `packageId`（常附带完整 `activeEvent`）  
4. 钱包/权益到账，**无对应付款**

```text
UI 只让领免费包
    ↓ 绕过 UI
POST …/claim-free-package { packageId: 付费档 }
    ↓ 服务端未验 price/支付
钱包 SC/GC/积分/会员天数 ↑
```

同类场景（应尝试同一手法）：

| 场景 | 常见接口名关键词 |
|------|------------------|
| iGaming / Sweepstakes | `claim-free-package`、`rolling-offers`、`starter-pack` |
| 电商/会员 | `claimFree`、`freeGift`、`receive-free`、`redeem` |
| SaaS / 额度包 | `trial/claim`、`free-tier`、`activate-offer` |
| 发卡/积分商城 | `free_claim`、`bonus/claim`、`package/claim` |

与假支付分工：假支付打 **回调验签**；本链打 **「免费领取」入口误挂付费 SKU**。可并行。  
GIN-VUE-ADMIN 领奖中心（`sendCReward` / 配置裸奔 / 验证码墙）见 **`锦府·赏.md`**，可先 `ginvue_admin_probe.py recon` 再衔接到本链。

## 2. 成功口径

| 级别 | 证据 |
|------|------|
| L0 指纹 | 存在 `claim-free*` / `event-trigger` + packages 且含 `price > 0` |
| L1 逻辑确认 | free-claim 对付费 `packageId` 返回成功（非 4xx「必须购买」） |
| L2 到账确认 | claim 前后钱包/权益差分（且无新支付订单） |

**注意：** 欢迎礼 / 设计内 `price=0` 包 **不是漏洞**。只有 **标价 > 0 未付款到账** 才算。

## 3. Crown 参考链（范式）

| 步 | 接口 |
|----|------|
| 登录 | Bearer Token |
| 拉活动 | `POST /v2/event-trigger/events` → `activeEvent` + `packages` |
| 未付款领取 | `POST /v2/offers/rolling-offers/claim-free-package` |
| 验钱包 | `GET /v2/user/get-wallet` |

前端逻辑摘要：`price !== 0` 则不请求；服务端未对齐该规则。

## 4. 自动化

```bash
# 发现：活动/礼包里标价>0 的包 + 猜测 claim 路径
python3 炼蛊房/free_claim_bypass.py discover \
  --api https://api.授权站 --token "$TOKEN" --case <案卷>

# 干跑：组 claim body，发请求但不要求你确认「就是洞」
python3 炼蛊房/free_claim_bypass.py probe \
  --api https://api.授权站 --token "$TOKEN" --case <案卷> \
  --package-id 585206

# 领取（高成本：改余额）——必须 --confirm
python3 炼蛊房/free_claim_bypass.py claim \
  --api https://api.授权站 --token "$TOKEN" --case <案卷> \
  --package-id 585206 --confirm

# 只看钱包
python3 炼蛊房/free_claim_bypass.py wallet \
  --api https://api.授权站 --token "$TOKEN" --case <案卷>
```

预设路径可用 `--preset crown`（Crown 系路径）；其它站用 `--events-path` / `--claim-path` / `--wallet-path` 覆盖。

产物：`案卷/<案卷>/案卷/free_claim/`

## 5. 通用检查清单

- [ ] JS/APP 搜：`claim-free`、`price !== 0`、`Cannot claim package`  
- [ ] 枚举 offers/events/packages，列出 **price > 0**  
- [ ] 对每个付费 packageId 调 free-claim（先 probe）  
- [ ] 对比 wallet / entitlement；查有无 payment/order  
- [ ] 试篡改 body 内 `activeEvent.packages[].price`→0（服务端若信客户端价格，也是洞）  
- [ ] 多账号是否每号可领 1 次（批量面）  

## 6. 修复（写报告用）

1. 服务端：free-claim **仅**允许 `price==0` / `isFree`  
2. **以服务端目录为准** 校验 packageId，勿信客户端 `activeEvent`  
3. test/animation 活动勿挂生产付费包  
4. 监控：free-claim 成功且标价 > 0 → 告警
