# ICEcoder 未授权 RCE 手法

> CVE-2026-63722 · Skill：`杀招/白凝冰·冰码`  
> 工具：`炼蛊房/icecoder_surface_probe.py` · nuclei `icecoder-unauth-cve-2026-63722.yaml`  
> 红线：仅 `授权范围`。默认 **只 GET**。`--deep` 才 POST `command=id`。

---

## 1. 一句话

浏览器 IDE **ICEcoder ≤8.1** 的 `lib/terminal-xhr.php` 认证/CSRF 可被参数旁路，命令进 `proc_open`。本卡先确认暴露面，不复现命令执行。

---

## 2. 指纹

| 信号 | 路径 |
|------|------|
| 标题 / 登录 | `ICEcoder` |
| 终端端点 | `/lib/terminal-xhr.php` · `/icecoder/lib/terminal-xhr.php` |
| 静态 | `/lib/` · `coder.css` · `ice-coder` |

```bash
python3 炼蛊房/nday_route.py -u https://授权站 --case <案卷>
python3 炼蛊房/icecoder_surface_probe.py --base https://授权站 --case <案卷>
python3 炼蛊房/icecoder_surface_probe.py --base https://授权站 --case <案卷> --deep
python3 tools/1day-kit/od_kit.py nuclei --url https://授权站 --case <案卷> \
  -t tools/1day-kit/custom-templates/icecoder-unauth-cve-2026-63722.yaml
```

GET `terminal-xhr.php` **不带 body** 时，正版脚本回 JSON：`Sorry, no command received`。这是 L1 铁证，不必 POST。

---

## 3. 档位

| 档 | 动作 | 成功证据 |
|----|------|----------|
| **L1** | 标题 ICEcoder，或 GET 终端回 `no command received` | 空 200 / 泛 JSON 404 |
| **L2** | `--deep`：任意 `password` + 非空 `csrf` + `command=id` 回 `uid=` | 不把 GET 200 当成已 RCE |
| **L3** | 写马 / 反弹 | 授权内直接做 |

nuclei 模板仍只做 GET 指纹，不带 POST。
