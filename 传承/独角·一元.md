# 独角 Next 混合支付 1 元购手法

> 产品：Dujiao-Next（Go API + Vue SPA），不是 PHP 独角、不是异次元。  
> Skill：`杀招/独角`  
> 长文根因：`智道藏书/旁支传承/skills/redteam/dujiao-next-1yuan-pay/SKILL.md`  
> 红线：仅 scope；**首单验证默认做**；批量出卡 / 循环耗余额先问。

---

## 1. 30 秒

```text
/dj.svg + use_balance + ≥2 渠道 + 无 app_version（旧构建）
  → 注册/登录，钱包 = 自动发货价 − 1
  → payments(order_id, 渠道A, use_balance=true) 得小额 L1
  → 换渠道 B 退余额
  → 复用或直开 L1，网关仍约 1 元 → 实付出卡
游客面并行：GET .../auth-defaults 泄查密（同 order_no 打旁域认同库）
```

收工：自动发货明文卡密。管理后台 / RCE / 无钥 callback **不是**本卡主线。

## 3. 作业坑（2026-08 审计补）

1. 会员创建支付用 **`order_id`（数字）**。旧笔记里的 `order_no` 会空转。
2. 余额必须 **≈ 价 − 1**。余额 ≥ 价 = 全额钱包扣款，不是 F18。
3. 网关页 `total_amount` 常见 `1.03`（1+3%），以页面为准。
4. 履约后订单可能显示 `online_paid_amount=全额`——对账假象，以网关实付为准。
5. 人工发货 SKU：F18 能把订单标已付，**不出卡不算打穿**。
6. 无钥 `POST /api/v1/payments/callback` 恒 `fail`。
7. `auth-defaults` 跨多域命中 = 同租户同库，任一域等于整租户订单面。

## 4. 复测（已修构建）

- 换渠后 L1 全额或 410/作废。
- 付约 1 元不得 `completed` + payload。
- `auth-defaults` 401/404。
