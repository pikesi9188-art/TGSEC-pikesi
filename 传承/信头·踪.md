# 信任 IP 头旁路手法

> 杀招：`信头·踪` · 工具：`炼蛊房/trusted_ip_header_probe.py`  
> HITCON：后台信 XFF。加款专用仍走 `和稀泥·加款.md`。

```bash
python3 炼蛊房/trusted_ip_header_probe.py --base https://授权站 --case <案卷>
```

| 档 | 成功 |
|----|------|
| L1 | admin/login/backend 基线 401/403 |
| L2 | 信任头 = 环回后变 200，或 302 进后台，且不是同一块 WAF 页 |

## 头与值

探针已打：`X-Forwarded-For` `X-Real-IP` `True-Client-IP` `Client-IP` `X-Client-IP` `X-Originating-IP` `Forwarded`。  
手工补：`X-Forwarded-For: 8.8.8.8, 127.0.0.1`（信最后一个）、`::1`、`127.0.0.1%00`。

经 CDN 的 200 可能是边缘，对照直连源站。禁止把 CF 边缘 IP 当源站。命中后填对象矩阵。
