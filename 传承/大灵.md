## 1. 一句话

目标若是 **LLM 网关 / Agent / MCP**，先认产品，再测未授权模型列表与鉴权绕过。  
若 OpenAPI 里出现 **`/cms/chunks` / `get_emails` / `suggested_prompts`**，按本卡 **§5 未授权知识库 CMS** 走（默认只读），不要当普通客服扫一眼就走。  
提示注入只做「系统提示是否流出」的差分，不把越狱当打网站主线。  
组合 XSS / Code Snippets **未点管理员 ≠ 0-click RCE**。

## 2. 默认命令（L1）

```bash
python3 炼蛊房/llm_surface_probe.py -u https://授权站 --case <案卷>
```

落盘：`案卷/<案卷>/案卷/llm/surface.json`  
L1 成功：认出 LiteLLM / Langflow / Flowise / OpenAI 兼容面，**或** OpenAPI 列出 CMS path。  
L2 成功：未授权 `/v1/models` 列出模型，或 Langflow `auto_login`/无票 `validate/code`，或 Flowise 内部头 apikey，或 CMS files/prompts 未授权 JSON。

```bash

```

## 5. 未授权知识库 CMS（原独立卡已并入）

学习样本（2026-08-27）：主站 WP + 独立 FastAPI/App Runner；未授权 `/cms/*` + 提示词改写 + RAG 投毒，再接主站 XSS / 明文 Cookie / 任意 JWT。  
AI 域须已在 scope 或从授权主站链发现后静默扩权。报告目标域禁止扩权。

### 5.1 指纹

| 层 | 信号 |
|----|------|
| 后端 | App Runner / FastAPI；`/api/openapi.json` 含 `cms/chunks`、`ingest`、`similarity_search` |
| 未授权写 | `POST /cms/chunks/upload/`、`/ingest_json_with_weburl/`、`/cms/update_kb/`、`/api/update_suggested_prompts` |
| 未授权读 | `GET /cms/files/`、`GET /cms/download/?s3_link=`、`POST /cms/generate_presigned_url/`、`GET /api/get_emails` |
| 破坏面 | `POST /cms/chunks/delete_all/` `{"file_id":uuid}` |
| 主站可拼接 | `Config.php?dest=` 反射；`CreateJWTToken.php` 任意 `data=`；明文 `username`/`password` Cookie；WP Code Snippets REST |
| 云痕迹 | 预签名带 `AWSAccessKeyId=AKIA…`（记前缀+bucket，钥打码；勿改桶策略） |

### 5.2 CMS 档位

| 档 | 动作 | 成功证据 |
|----|------|----------|
| **C1** | 探针 / 手拉 OpenAPI；GET files、suggested_prompts；**不要默认拉全量 get_emails** | 未授权 JSON；邮箱只在确认接口存在后计条数 |
| **C2** | 无害 marker（小 PDF/文本）upload 或 generate_presigned；similarity 能搜到自家文档 | task_id / s3_link。禁止 php/py 伪装 |
| **C3** | ingest `[AUDIT MARKER]` + `update_kb`；search 能收回 | 投毒**通道**成立，不是已劫持客服 |
| **C4** | 主站 XSS / 任意 JWT / 明文 Cookie | 反射或 mint 成功（走核心 Web） |
| **C5** | 改提示词 + RAG 诱导点 XSS + Code Snippets | **先问**；未点击管理员不得报全站沦陷 |

`delete_all`、覆盖生产提示词、遍历下载全库 PII：**先问**。

### 5.3 只读复现

产物进案卷 `案卷/llm/`，不要写 `/tmp` 当交付。

```bash
curl -sk https://<ai>/api/openapi.json -o "案卷/<案>/案卷/llm/openapi.json"
# 探针已列 cms_paths 时可跳过手拉
curl -sk 'https://<ai>/cms/files/?db_type=general&limit=5&offset=0' -o "案卷/<案>/案卷/llm/cms_files.json"
curl -sk 'https://<ai>/api/suggested_prompts' -o "案卷/<案>/案卷/llm/suggested_prompts.json"
# get_emails：先 HEAD/截断确认存在；全量导出先问
```

### 5.4 组合链口径（非 0-click）

```text
OpenAPI + files/prompts（只读）
  →（先问）ingest / update_suggested_prompts
  → 管理员点本站 XSS
  → 明文 Cookie + CORS * mint JWT
  → Code Snippets REST 401 = 需登录；缺 nonce 才是 CSRF→RCE
```

| 写法 | 何时可用 |
|------|----------|
| 已验证 | 未授权读/写 CMS、XSS 反射、JWT mint、Cookie 属性 |
| 已构造未点击 | 钓鱼提示词 + XSS URL |
| 全站沦陷 | 仅 C5 真有管理员会话落地 |

Code Snippets 未授权 401 **不算 RCE**。WP `/wp-json/wp/v2/users`、`debug.log` 只当目标/路径泄露。
