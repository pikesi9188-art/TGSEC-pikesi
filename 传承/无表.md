# 大爱仙尊 NoSQL 作业手法

> 杀招：`无表`  
> 工具：`python3 炼蛊房/param_abuse_probe.py nosql`  
> 关系型 SQL：`sqlmap_kit.py ladder`

目标须在 scope。对照错误密码基线，接口本来就 200 不要报 `$ne`。

---

## 1. 立刻跑

```bash
python3 炼蛊房/param_abuse_probe.py nosql --url https://授权/api/login --case <案>
python3 炼蛊房/param_abuse_probe.py nosql --url https://授权/api/login \
  --user-field email --pass-field pass --case <案>
```

产物：`案卷/param_abuse/nosql.json`。

---

## 2. 四刀

1. **认 JSON** — 登录/搜索 body 是对象，不是 form  
2. **操作符** — `$ne` `$gt` `$regex` `$nin`；再打 `user[$ne]=` 查询串  
3. **对照** — 假用户失败，操作符变 token/`code:0` 才是 L2  
4. **枚举** — `$regex` 一次一个字符；`$where` 授权内再做

Cast to ObjectId / MongoError 是指纹，不是洞。

---

## 3. 档位

| 档 | 成立 |
|----|------|
| L1 | 操作符被吃（报 BSON/Cast） |
| L2 | 绕过登录或读到他人文档 |
| L3 | 写出管理员 / 拖库（破坏性先问） |
