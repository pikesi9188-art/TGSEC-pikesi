## 二、社会工程学攻击框架

### 2.1 社工七步法

```
1. 信息收集 → 社交媒体、公司官网、招聘网站、泄露数据库
2. 目标画像 → 职位、部门、兴趣、人际关系、工作习惯
3. 关系建立 → 制造信任、共同话题、权威伪装
4. 信息利用 → 利用收集的信息制造可信场景
5. 攻击执行 → 钓鱼邮件、电话诈骗、物理尾随
6. 权限维持 → 建立持久联络/后门
7. 痕迹清除 → 删除通信、清理证据
```

## 五、物理社工（Tailgating）

```
技术 1: 尾随进入
"我是新来的，还没领门禁卡，帮我开一下门好吗？"
→ 双手抱箱子制造不便，提高成功率

技术 2: 伪造身份
穿着快递公司制服，手拿包裹
"顺丰快递，有个急件需要XYZ先生签收。"

技术 3: USB Drop
在停车场/茶水间丢弃带公司Logo的U盘
包含恶意文件如"薪资调整方案.xlsm"（含宏病毒）

防备:
- 无例外门禁制度
- 所有访客必须登记并陪同
- 不插不知来源的USB设备
```

## 九、2026 新兴社会工程威胁与技术

### 9.1 AI 深度伪造语音钓鱼（Deepfake Vishing）

2026年AI语音克隆诈骗呈爆发式增长。2025年全球报案量同比增长超300%，2026年Q1较2025年同期再增180%。

**技术门槛已降至临界点：**

| 指标 | 2024年 | 2026年 | 趋势 |
|---|---|---|---|
| 所需语音样本 | 30秒+ | 3-10秒 | ↓ 70% |
| 实时推理延迟 | 500ms+ | <200ms | ↓ 60% |
| 克隆成本 | 数千元 | 数十元 | ↓ 95% |
| 普通听众辨识率 | ~60% | <30% | ↓ 50% |
| 单笔最大涉案金额 | ~百万 | 数百万 | ↑ 3x |

**典型攻击场景：**

1. **职务指令类**：克隆企业负责人声音指令财务转账（2026年高频）
2. **紧急求助类**：克隆亲属声音谎称车祸/绑架
3. **虚假服务类**：冒充银行/电商客服套取验证码
4. **政务冒充类**：冒充公检法实施恐吓诈骗

**检测特征（可量化差异）：**

| 声学特征 | 克隆语音 | 真人语音 |
|---|---|---|
| 基频轨迹 | 过于平滑 | 存在自然微扰动 |
| 共振峰动态 | 过渡僵硬 | 自然过渡 |
| 相位相干性 | 短时FFT下一致性过高 | 自然变化 |
| 高频细节 | 缺失 | 丰富 |

**红队演练方法：**

```bash
# 1. OSINT收集目标语音样本（社交媒体视频/公开演讲/播客）
# 2. 使用开源TTS克隆工具生成测试语音
#    工具：Coqui TTS, Tortoise TTS, XTTS v2
# 3. 实时语音转换测试（验证延迟和自然度）
# 4. 模拟vishing攻击（仅授权环境）
# 5. 记录被攻击者辨识率，评估组织脆弱性

# 检测工具：
# - Pindrop: 语音反欺诈平台
# - Agnitio: 深度伪造音频检测
# - AI Voice Detector: 浏览器插件
```

### 9.3 MFA 疲劳攻击（Push Bombing）

MFA疲劳攻击是2026年勒索软件运营的**主要初始访问向量**，身份攻击已超越漏洞利用成为首要威胁。

**攻击流程：**

```
1. 攻击者获取目标凭据（泄露/撞库/社工）
2. 向目标认证App发送数十至数百个推送通知
3. 目标因疲劳/困惑/误触而批准
4. 攻击者获得会话访问权限
5. 利用会话进行横向移动/勒索部署
```

**2026年三大MFA绕过技术对比：**

| 技术 | 原理 | 防御 | 绕过防御方法 |
|---|---|---|---|
| MFA疲劳攻击 | 大量推送通知直到批准 | 号码匹配 + 上下文通知 | 无法绕过号码匹配 |
| AiTM代理钓鱼 | 实时中继凭据+捕获会话Cookie | FIDO2/WebAuthn硬件密钥 | 无有效绕过 |
| SIM交换 | 劫持手机号码接收SMS | 摒弃SMS MFA | 社工运营商 |

**号码匹配防御与局限：**
- 号码匹配要求用户在登录屏幕看到随机数字并在App中选择相同数字
- 配合上下文感知通知（应用名称、地理位置、设备类型、IP地址）
- **局限**：无法防御AiTM代理攻击（攻击者可实时中继号码）

**MFA安全等级对照：**

| MFA方法 | 安全等级 | 易受攻击 | 2026推荐 |
|---|---|---|---|
| SMS验证码 | 基础 | SIM交换、钓鱼、拦截 | ❌ 不推荐 |
| 认证器App推送 | 强 | 疲劳攻击、AiTM代理 | ⚠️ 需号码匹配 |
| 认证器AppTOTP | 强 | AiTM代理钓鱼、设备恶意软件 | ⚠️ 可接受 |
| 硬件安全密钥(FIDO2) | 最高 | 物理盗窃（有PIN保护） | ✅ 强烈推荐 |
| 生物识别+设备 | 很强 | 高级设备入侵 | ✅ 推荐 |

### 9.4 Quishing（二维码钓鱼）2026

**Microsoft 2026 Q1邮件威胁报告：**

| 指标 | 2026年1月 | 2026年3月 | 增长率 |
|---|---|---|---|
| QR码钓鱼月实例 | 760万 | 1,870万 | **146%** |
| 审查的钓鱼威胁总量 | — | 83亿+/季度 | — |
| 波及范围 | 26国/13,000组织/35,000+用户 | — | — |

**2026年新攻击向量：**

1. **邮件/PDF附件内嵌QR码**：
   - 攻击者将QR码作为图片嵌入PDF/Word附件（伪装为发票、工资单、MFA重新注册）
   - 传统邮件过滤器扫描文本和URL，**不扫描附件内图片像素** → QR码图片直接通过

2. **移动设备跳跃（Device Hop）**：
   - 邮件到达受管理办公笔记本，用户必须用**个人手机**扫描QR码
   - 恶意链接在无企业代理、无托管DNS过滤、小屏幕隐藏完整URL的设备上打开
   - 企业安全防线**完全失效**

3. **物理世界Quishing**：
   - 伪造QR码覆盖真实停车支付机器（英国Action Fraud 2024年1,386起，损失350万英镑）
   - FBI IC3标记"刷单"诈骗（未订购包裹中的QR码）

4. **Smishing交叉融合**：QR码钓鱼与短信钓鱼融合为移动优先单一漏斗

**防御演进：**

| 防御层 | 技术 | 效果 |
|---|---|---|
| 邮件网关 | OCR读取图片/附件内QR码 | 中（攻击者以扭曲/分割QR码应对） |
| 移动浏览器 | URL信誉检查（加载前） | 中 |
| 设备端 | QR码目标预检查 | 高 |
| 用户培训 | 不扫描来源不明QR码 | 中低 |
