# 最小探测 Payload 样例库

> 只用于已授权、低影响、非破坏性验证。
> 这里是“最小探测样例”，不是利用库。

## 1. SQL 注入轻量探测

优先级从低到高：
- `'`
- `"`
- `)'
- `and 1=1`
- `and 1=2`
- `or 1=1`
- `or 1=2`

使用原则：
- 每次只测一个参数
- 只看报错、状态码、长度、业务差异
- 不使用 `sleep()` / `benchmark()` / 大型 union

## 2. 未授权 / 越权探测

最小变体：
- 去掉 `Authorization`
- 去掉 `Cookie`
- 空 token
- 替换单个资源 ID
- 同接口切换一个低权限身份

使用原则：
- 不做批量 ID 枚举
- 不做真实删除、支付、写入

## 3. 命令执行轻量探测

仅用于观察过滤与转义：
- `;`
- `|`
- `&&`
- `` ` ``
- `$()`

使用原则：
- 默认不发送会导致真实执行的危险命令
- 仅观察报错、过滤、转义和拒绝策略

## 4. SSRF 轻量探测

关注点：
- URL 参数是否被接受
- 协议是否受限
- 是否出现解析错误 / 访问失败差异

最小测试思路：
- 合法公网 URL 样例
- 明显非法 URL 样例
- 协议切换对比（http/https/file/gopher 仅观察是否被拦截，不深入）

## 5. 任意文件读取轻量探测

关注点：
- 路径穿越是否被拦截
- 路径规范化是否存在差异
- 仅做存在性或错误差异验证

最小测试思路：
- `../`
- `..%2f`
- 不同层级相对路径

## 6. 逻辑缺陷验证

关注点：
- 步骤是否可跳过
- 前端状态是否可篡改
- 重放是否存在窗口
- 价格/角色/状态是否只在前端校验
