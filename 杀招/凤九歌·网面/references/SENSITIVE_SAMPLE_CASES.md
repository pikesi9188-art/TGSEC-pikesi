# 敏感信息样例判定参考

## 1. 更像真实敏感信息的情况
- 出现在真实用户资料接口返回里
- 同时伴随姓名、地址、用户ID等上下文
- 多次出现在不同接口或页面中
- 明文展示且未脱敏

## 2. 更像测试样例的情况
- 出现在 mock 文件、demo 页面、注释中
- 字段值明显是示例域名、示例号码
- 与业务上下文无关
- 单次出现且无真实用户关联字段

## 3. 脱敏数据
- 手机号中间位被掩码
- 身份证中间位被掩码
- 邮箱用户名部分被掩码

## 4. 报告建议
- 真实疑似泄露：写入正式风险
- 测试样例：单列“非风险样例”
- 脱敏数据：单列“低风险展示问题”或“信息最小化建议”
