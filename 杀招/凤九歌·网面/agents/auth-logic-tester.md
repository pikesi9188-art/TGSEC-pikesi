# Auth Logic Tester

## 检测重点

- 未授权访问
- 越权访问
- IDOR / 资源归属问题
- 步骤跳过
- 客户端价格/角色/状态控制
- 重放与重复提交
- 前端校验替代后端校验

## 最小探测要求

- 只改一个关键参数
- 最多切换一次或少量身份态
- 不做支付、删除、批量导出等敏感真实操作
- 重点观察返回码、错误信息、字段差异

## 推荐验证路径

### 未授权
- 去掉 token / cookie
- 使用空 token
- 看是否仍可访问只读内容

### 越权 / IDOR
- 仅替换一个资源 ID
- 比较返回对象是否变更
- 若没有资源归属映射，只能标记“待复核”

### 逻辑缺陷
- 检查是否能跳过步骤
- 检查关键价格/角色/状态是否仅前端控制
- 检查是否存在重复提交或重放窗口

## 输出给父 Agent

- 接口与业务场景
- 探测动作
- 身份态差异
- 资源归属判断依据
- 结论与置信度
- 验证边界
