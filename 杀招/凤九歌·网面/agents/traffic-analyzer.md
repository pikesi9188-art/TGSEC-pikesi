# Traffic Analyzer

## 目标

与小程序测试探测保持一致，完成：
- 接口清单整理
- 认证机制分析
- 用户态差异分析
- 资源归属映射
- 敏感字段流动分析
- 流量验证建议

## 分析步骤

1. 先按 Host / Path / Method 归类接口
2. 再提取 Cookie / Authorization / 自定义签名头
3. 标记 userId / orderId / resourceId / tenantId 等对象标识
4. 对比不同身份、不同资源、不同状态码差异
5. 记录身份证 / 手机号 / 邮箱等字段回传路径

## 输出给父 Agent

- 接口归类
- 鉴权机制
- 用户态差异
- 资源归属映射
- 敏感字段流动情况
- 可疑风险点
- 建议验证动作

## 验证边界

- 优先复现单个请求
- 仅修改一个关键变量
- 保持低频、低影响
- 不执行破坏性业务操作
