# Web 渗透测试 Skill

## 概述

本 skill 用于**已授权**的 Web / H5 / SPA 站点安全测试，参考 `wechat-miniapp-pentest` 的组织方式，采用：
- **前端静态审计**：分析页面源码、JS、静态资源、前端加密逻辑
- **JS 文件清单筛选**：先用 Python 工具提取页面 JS 文件名，再交给大模型筛出更像开发者自写业务功能的 JS
- **业务 JS 自动归档**：把筛出的业务功能类 JS 自动下载到本地，便于后续 grep、接口提取和静态审计
- **接口最小探测**：只做低影响、非破坏性验证
- **流量分析与验证**：与小程序测试探测保持一致
- **敏感信息专项检测**：针对身份证、手机号、邮箱，以及泄漏的 API 与 Key/Secret 进行识别、归类和单独报告输出

**架构特点**：
- 多 Agent 协作
- 审计和验证阶段可拆分给子 Agent
- 父 Agent（Coordinator）统一复核、排重、降误报、出最终结论
- 严格执行“最小探测、低频、低影响、非破坏性”原则

## 强制起手确认

在开始任何测试前，**必须先找用户确认**：
1. 是否已获得明确授权
2. 这次是：
   - **只进行代码静态分析**
   - **只进行流量分析**
   - **静态分析 + 流量分析都进行**

如果用户没有明确回答：
- 默认**不做主动探测**
- 最多只做非侵入性的前端资源梳理建议

建议固定话术：

> 先确认下，这次目标是否已授权？另外你要我只做代码静态分析、只做流量分析，还是两者都做？如果没明确授权，我只停留在非侵入性分析。

## 角色与职责

### 父 Agent
- `agents/coordinator.md`
  - 授权检查
  - 模式确认
  - 调度子 Agent
  - 复核与误报排除
  - 汇总输出

### 分析阶段子 Agent
- `agents/frontend-static-auditor.md`
  - 通过 curl 抓取页面 / JS / 静态资源
  - 输出 `网站目录结构.md` 与 `接口说明.md`
- `agents/sensitive-data-detector.md`
  - 识别身份证、手机号、邮箱、API 泄漏、Key/Secret 泄漏
  - 输出敏感信息线索供父 Agent 复核

### 验证阶段子 Agent
- `agents/sqli-tester.md`
  - SQL 注入最小探测
- `agents/auth-logic-tester.md`
  - 未授权、越权、逻辑缺陷最小探测
- `agents/injection-tester.md`
  - 命令执行、SSRF、任意文件读取最小探测
- `agents/sensitive-data-validator.md`
  - 对敏感信息泄露结论做复核与降误报

### 流量阶段子 Agent
- `agents/traffic-analyzer.md`
  - 流量分析、身份态差异、资源归属映射、流量验证建议

## 最小探测原则

所有子 Agent 都必须遵守：
- 单点、低频、低影响
- 不爆破、不批量 fuzz、不压测
- 不做高危命令执行
- 不做破坏性写入
- 不对支付、删除、批量导出等接口做真实利用
- SQL 注入优先布尔差异和轻量报错探测
- SSRF 仅做低风险 URL 接受性验证
- 文件读取仅做最小存在性和轻量路径差异验证
- 逻辑缺陷以流程梳理和单步验证为主

## 输出物要求

### 1. 网站目录结构.md
必须包含：
- 入口页面
- JS/CSS/静态资源路径
- API 前缀
- 前端路由
- 管理后台路径
- 调试文件、测试文件、配置文件线索

### 2. 接口说明.md
必须包含：
- 接口路径
- 请求方法
- 主要参数
- 鉴权方式
- 来源页面/JS 文件
- 关联业务
- 风险备注
- 是否建议进入最小探测

### 3. 渗透测试-静态分析验证文档.md
必须包含：
- 测试范围
- 测试时间
- 最小探测原则说明
- SQL 注入探测结果
- 未授权/越权探测结果
- 命令执行探测结果
- SSRF 探测结果
- 任意文件读取探测结果
- 逻辑缺陷探测结果
- 前端加密方法与验证结果
- 请求样例 / 响应差异 / 结论 / 风险等级 / 修复建议

### 4. 渗透测试-流量分析报告.md
必须包含：
- 流量来源说明
- 接口清单
- 认证信息
- 会话/身份标识
- 参数特征
- 资源归属映射
- 敏感字段流动情况
- 可验证风险点
- 后续验证建议

### 5. 敏感信息检测报告.md
必须包含：
- 识别范围
- 身份证命中结果
- 手机号命中结果
- 邮箱命中结果
- API 泄漏命中结果
- Key / Secret 泄漏命中结果
- 所在页面 / JS / 接口 / 响应位置
- 是否明文展示
- 是否前端缓存 / 本地存储 / 接口返回
- 泄露风险等级
- 修复建议
