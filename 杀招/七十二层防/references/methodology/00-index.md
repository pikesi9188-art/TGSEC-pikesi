## 与 SRC 平台的对齐

不同平台对"算分要素"的偏好：

| 平台 | 偏好的漏洞类型 | 必须有 |
|------|---------------|--------|
| **HackerOne** | RCE、Auth Bypass、IDOR、SQLi、SSRF | CVSS 3.1 或 4.0 + 可执行 PoC + 影响范围 |
| **Bugcrowd** | VRT 分级（P1–P5），偏好可链接的攻击链 | 步骤可复现 + 截图/视频 |
| **补天 / CNVD** | 通用型 RCE、SQLi、未授权、敏感信息泄露 | 漏洞证明（截图、复现包） |
| **众测/HVV** | 内网入口、控制权、横向 | 影响资产清单 + 后利用证据 |

**统一规则**：
1. 只测授权资产，不外溢
2. SRC/众测：不删、不改他人数据、不批量拖库，证明即止
3. 数据脱敏（用户名、手机号打码）
4. SRC/众测默认不留马；授权自检按本库闸，命中后写马/反弹直接做

## 价值排序（精简版）

| 等级 | 漏洞类型 | 平均赏金区间（参考 H1 / Bugcrowd） |
|------|---------|---------------------------------|
| 顶级 | 未授权 RCE / SSRF→RCE / 反序列化 | $5k – $50k |
| 高 | 鉴权绕过 / 公开 IDOR 大面积数据 / 任意文件读 | $1k – $10k |
| 中 | SQLi / 越权 / 文件上传（受限） | $300 – $3k |
| 低 | XSS / 信息泄露（无敏感数据） | $50 – $500 |

> 这个顺序就是 `01-attack-priority.md` 里"攻击路径最短原则"的现金体现。
