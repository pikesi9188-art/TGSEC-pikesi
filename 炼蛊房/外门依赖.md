# 外门依赖

炼蛊房本体是 Python 脚本，**不**把 nuclei / sqlmap / jadx / JDK 打进 git（体积和许可都不合适）。
先跑 `python3 炼蛊房/check_deps.py`。

## 必须

| 东西 | 干什么 | 怎么做 |
|------|--------|--------|
| Python 3.10+ | 跑脚本 | 系统自带或 python.org |
| `requests` | HTTP 探针 | `pip install -r 炼蛊房/requirements.txt` |
| `态度蛊.json` | 授权闸 | `cp 态度蛊.example.json 态度蛊.json`，写入你的域 |

本地认族 / 解 metadata / 生成 Frida **不需要** 态度蛊。对授权站发请求的脚本要。

## 按需装（太大不进仓）

| 东西 | 干什么 | 怎么做 |
|------|--------|--------|
| nuclei | 一日针匣扫 CVE 模板 | [Releases](https://github.com/projectdiscovery/nuclei/releases) 或 `brew install nuclei`，再 `nuclei -update-templates` |
| sqlmap | 无底洞阶梯 | `git clone https://github.com/sqlmapproject/sqlmap.git`，把目录放到 PATH 或改 `sqlmap_kit.py` 里的路径 |
| ffuf | 目录 / 爆破 | [Releases](https://github.com/ffuf/ffuf/releases) |
| jadx | APK 反编译 | [skylot/jadx](https://github.com/skylot/jadx/releases) |
| frida + frida-tools | 客器破禁动态 hook | `pip install frida-tools` |
| frida-il2cpp-bridge | 按类名 hook | `npm i frida-il2cpp-bridge`；dump.cs 有 RVA 可不装 |
| Il2CppDumper | 出 dump.cs | [Perfare/Il2CppDumper](https://github.com/Perfare/Il2CppDumper/releases)，需 .NET |
| Temurin 17 | Java 堆 / 网关 / jadx | [adoptium.net](https://adoptium.net) |
| unar | 解 rar | `brew install unar` |

## 客器破禁最小可跑

1. `pip install requests`（只要 `replay`）
2. 本地包：`python3 炼蛊房/client_crack_cheat_probe.py drive --path 包.apk --case demo`
3. 要挂进程：`pip install frida-tools`，有 RVA 就能 attach；按类名再 `npm i frida-il2cpp-bridge`
4. 要完整 dump.cs：本机跑 Il2CppDumper，再 `hooks --path dump.cs`
