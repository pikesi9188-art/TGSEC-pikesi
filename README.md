## 杀招

招是**用法**。仙道杀招和凡道杀招不是一个量级。

### 仙道

| 杀招 | 配哪门 | 为什么这么配 |
|------|--------|----------------|
| **万我大手印** | 对象矩阵 + 水平越权 + 批量身份 | 方源的招牌：一掌拍出无数个「我」。自己 vs 他人、换号、换票，格子要填满。 |
| **万我** | 多会话 / 分身 | 大手印的底子：同时存在很多个自己。 |
| **自我守护** | 已拿据点后的自保 | 先护住己身，再谈扩张。 |
| **逆流护身** | 停手 / 收势 | 进攻面立刻停。 |
| **天地伟力** | 成套 kit | 借天地的力，不靠单招硬磕。 |
| **纵横天下** | 内网横向 / 域 | 一尊出手，旁路都要走。 |

| 杀招 | 配哪门 | 为什么这么配 |
